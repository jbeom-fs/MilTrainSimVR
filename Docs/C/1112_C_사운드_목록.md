# C 시가지 전투 — 필요한 사운드 목록

작성: C · 2026-11-12

C 시가지 전투(`C_UrbanBlock`)에 넣을 소리를 C 코드에 실제로 있는 사건(사격 · 탄창 · 장전 · 피격 · 경기 진행 · 적 행동) 기준으로 뽑았다. 총 37개다.

- **1차** = 없으면 전투가 어색한 것 (15개)
- **2차** = 몰입감 (13개)
- **3차** = 나중 (9개)

"칸 있음"은 코드에 소리 칸이 이미 있어서 파일만 넣으면 나는 것이다. 나머지는 재생 코드를 새로 붙여야 한다.

## 0-1. 11/16 진행 — 1단계(플러그인 없이 C 안에서) 연결함

사용자가 가져온 녹음 9개를 잘라 `Assets/C/Audio`에 임시로 넣었다 (학원 개발 중 개인 시연용, 나중에 만들거나 산 효과음을 같은 파일 이름으로 덮어써서 바꾼다).

| 들어간 것 | 클립 | 코드 |
|---|---|---|
| 사격음 (내 총 · 적 공용, 3D) | `Weapons/C_Shot` | `CombatAudio` (리그) — 거리 감쇠 · 고음 깎기 · 소리 속도 지연 · 벽 가림 · 쏜 자리 실내 울림 |
| 탄피 · 장전으로 빠진 탄 | `Weapons/C_Casing` | `CombatAudio` |
| 탄창 바닥 충돌 | `Weapons/C_MagDrop` | `RifleMagazine` → `CombatAudio` |
| 조정간 · 탄창 끼움(2) · 뺌 · 장전 손잡이 당김 · 복귀 | `Weapons/C_Selector` 외 | `TempRifle` (총에 붙은 3D 소리) |
| 플레이어 · 적 발소리, 착지 | `Footsteps/C_Step_1~8` | `FootstepAudio` (리그) |

아직 없는 것: 빈 방아쇠 딸깍, 적 쓰러짐, 탄착(재질별), 피격, 경기 경보 · 결과음, 환경음. 방향의 앞뒤 · 위아래 구분은 HRTF 플러그인(Steam Audio)이 있어야 한다 — 발표(11/20) 뒤에 본다.

## 0. 11/12 상태 (당시)

- C 시가지 전투에서는 아무 소리도 나지 않는다.
- 내 총(`TempRifle`)에는 사격 · 빈 방아쇠 · 탄창 · 장전 손잡이 복귀 · 조정간 소리 칸이 있다. 하지만 `C_K2C1` 프리팹에서 다섯 칸이 모두 비어 있다.
- 적 사격(`EnemyShooter`)도 소리 칸은 있지만 `C_EnemyDummy`에서 비어 있다.
- A의 상호작용 총(`K2C1_Rifle`)은 코드로 만든 임시 소리(`TempSound`)를 쓴다. C 총은 A의 모델 프리팹(`K2C1.prefab`)의 Variant라 그 소리가 따라오지 않는다.
- C 씬 네 개 모두 AudioSource와 리버브 존이 0개다.
- `Assets/C`에는 오디오 파일이 없다. 프로젝트 안의 소리 파일은 B의 교육 효과음(`Assets/B/Audio/TrainingSfx`)과 XRI 샘플 버튼음뿐이다.

## 4. 참고

- **실내 사격음:** 실내에서 쏘면 울림이 커야 한다. 사격음을 실내용 · 실외용 둘로 받거나 리버브 존으로 처리한다.
- **2D / 3D:** 내 총 · 내 몸 소리는 2D, 적 · 탄착 소리는 거리감 있게 3D로 재생한다.
- **임시 소리:** A의 `TempSound`처럼 코드로 만든 임시 소리로 1차의 사격 · 딸깍 · 철컥류는 파일 없이 바로 채울 수 있다. 환경음 · 발소리 · 숨소리는 실제 파일이 있어야 한다.
