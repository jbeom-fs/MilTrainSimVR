## 2. C 씬의 출구

경기가 끝나야 나갈 수 있습니다. 경기 중에는 출구가 없습니다.

- **성공(적 섬멸 · 점령지 점령):** 허브 포탈이 열립니다. 이긴 순간 플레이어가 서 있던 자리 근처에 하나, 출발 자리 근처에 하나입니다. 둘 다 그 자리에서 10 m 안(보통 5 m)의 빈 곳에 서고, 걸어 들어가거나 광선으로 고르면 넘어갑니다. 이긴 자리의 포탈이 출발 자리에서 10 m 안이면 하나만 엽니다.
- **실패(전사 · 적이 점령 · 무승부):** 포탈은 없고, 결과판에 "다시하기" · "연병장으로" 버튼이 나옵니다.

A 것을 이렇게 씁니다.

| 쓰는 것 | 방식 |
| --- | --- |
| 포탈 | `Assets/C/Prefabs/C_HubPortal.prefab` — `HubPortal_ToHub.prefab` 의 Variant 이고 바꾼 값은 `m_CourseId = C_Urban` 하나입니다. 성공하면 실행 중에 세웁니다 (씬에 미리 놓지 않음) |
| 버튼 | C 코드(`Assets/C/Scripts/MatchExit.cs`)가 `CourseRoute.CanLoad` 로 확인한 뒤 `CourseRoute.Enter("C_Urban", CourseRoute.HubScenePath)` 를 부릅니다 — 포탈이 넘어갈 때와 같은 길입니다 |
| 화면 가림 | C 리그에 A 의 `ScreenFader` 를 붙였습니다. 재질 `Assets/A/Materials/Common/ScreenFade.mat` 은 참조만 하고, 머리는 비움 · 반지름 0.25 · 검정(허브 · B 씬과 같은 값)입니다 |

C 스크립트는 Assembly-CSharp 라서 `MilTrainSimVR.A.Common` 을 그대로 참조합니다.

**에디터 Play 확인 (C, 11/12 — 헤드셋 없이 스크립트로):** 섬멸 · 2층 점령 · 전사 세 경우 모두 화면이 까매진 뒤 `A_Hub` 가 열렸고, `CourseRoute.Last = C_Urban`, 플레이어는 시가지 전투 포탈 2.5 m 앞에 포탈을 등지고 섰습니다. 헤드셋으로는 아직 확인하지 않았습니다.

**부탁:** 아래를 바꿀 때는 먼저 알려 주세요. C 가 이 이름 · 경로에 묶여 있습니다 (B 가 부탁한 것과 같은 범위입니다).

- `Assets/A/Prefabs/HubPortal_ToHub.prefab` 경로, `HubPortal` 의 `m_CourseId` 필드 이름
- `CourseRoute.Enter` · `CourseRoute.CanLoad` · `CourseRoute.HubScenePath`
- `ScreenFader.FadeTo` 와 `m_Material` 필드 이름, `ScreenFade.mat` 경로

## 3. 이동 설정 — 공통 값을 맞추자는 제안 (B도)

씬마다 리그가 따로라서 값이 조금씩 다릅니다. 11/12 에 프리팹과 씬 파일에서 읽은 값입니다.

| 항목 | XRI 기본 리그 (B 씬 = 그대로) | A 씬 (`A_Hub` · `A_Sandbox`) | C 리그 |
| --- | --- | --- | --- |
| 이동 | 왼 스틱 · 2.5 m/s · 머리 방향 기준 | 같음 | 같음 |
| 회전 | 오른 스틱 끊어 돌기 45° (0.5초 간격, 스틱을 뒤로 당기면 뒤돌기) | **부드러운 회전 60°/초** (양손 `m_SmoothTurnEnabled`, 10/27) | 끊어 돌기 45° (기본과 같음) |
| 멀미 비네트 (움직일 때 시야 가장자리가 어두워짐) | 없음 | 없음 | 있음 — 조리개 0.82 · 번짐 0.25 |
| 오른손 텔레포트 | 오른 스틱 앞으로 | 같음 | 없음 |
| 점프 | 오른손 A (1.25 m) | 같음 | 총 손잡이를 쥐지 않은 손의 A/X · 오른 스틱 누르기 |
| 스틱으로 쥔 물건 당기기 · 돌리기 | 켜짐 | 켜짐 | 꺼짐 |
| 광선으로 잡은 물건 | 멀리 둔 채 잡음 | 같음 | 손으로 끌려옴 |

C 는 걸어 다니며 싸우는 과정이라 이동과 회전을 가장 많이 쓰고 멀미도 나기 쉽습니다. 그래서 **씬을 오가도 똑같아야 하는 값은 C 쪽에 맞추기**를 제안합니다.

1. **이동 속도 2.5 m/s** — 이미 셋이 같습니다. 그대로 둡니다.
2. **회전은 끊어 돌기 45°** — A 가 10/27 헤드셋 확인에서 "45° 씩 끊긴다"고 해서 부드러운 회전으로 바꾼 것을 알고 있습니다 ([A 헤드셋 확인 목록](../A/1027_헤드셋_확인목록.md)). 다만 C 씬에서는 걸으면서 도는 일이 많아서 부드러운 회전이 멀미가 가장 나기 쉬운 조합이고, 지금대로면 허브(부드러운 회전)와 C(끊어 돌기)를 오갈 때 오른 스틱 동작이 바뀝니다. A 과정은 회전을 거의 쓰지 않으니 끊어 돌기로 맞추는 쪽이 부담이 적다고 봅니다. 끊기는 느낌이 문제라면 각도를 30° 로 줄이는 방법도 있습니다 (그러면 C 도 같이 바꿉니다). 나중에 허브에 환경 설정이 생기면 사용자가 고르게 하면 됩니다. **A 의견을 알려 주세요.**
3. **멀미 비네트를 A · B 리그에도** — 허브는 넓어서 걸어 다니게 됩니다. C 값은 11/12 에 0.75 · 0.2 에서 0.82 · 0.25 로 줄였는데 **아직 헤드셋으로 확인하기 전**입니다. 확인해서 정해지면 다시 알리겠습니다. 넣는 방법은 기본 리그의 `Camera Offset/Main Camera` 밑에 Starter Assets 의 `TunnelingVignette/TunnelingVignette.prefab` 을 두고, `TunnelingVignetteController` 의 Locomotion Vignette Providers 에 Turn(Snap · Continuous) · Move 를 넣는 것입니다. 원하시면 공통 값만 담은 리그 Variant 를 C 가 만들어 둘 수 있습니다 (각 씬에서 기본 리그 대신 쓰는 것).

아래는 C 만 다른 것이고, 맞출 필요는 없습니다.

- **점프 버튼:** 오른손으로 총을 들면 A 버튼이 탄창멈치라 점프와 겹쳤습니다. 그래서 총 손잡이를 쥐지 않은 손의 A/X 와 오른 스틱 누르기로 옮겼습니다.
- **오른손 텔레포트 없음:** 전투 중에 순간이동을 쓰지 않습니다.
- **스틱 조작 끔 · 광선으로 잡으면 손으로 (A 사격장 참고):** 기본 리그는 물건을 광선으로(멀리서) 잡으면 XRI 가 '멀리 잡은 상태'로 두고, 그동안 그 손의 스틱 이동 · 회전 입력을 끕니다(`ControllerInputActionManager`). C 에서는 "총을 쥐면 회전이 안 된다"로 나타났습니다(11/11). 리그 양손의 `InteractionAttachController.m_UseManipulationInput` 을 끄고 `NearFarInteractor.m_FarAttachMode` 를 Near 로 바꿔 고쳤습니다. 사로에서 총을 광선으로 집으면 같은 일이 생길 수 있으니 한번 확인해 보세요.

## 4. 빌드 목록 (통지 5절)

- 지금 목록 (11/12): `SampleScene` · `B_CBRN` · `B_FirstAid` · `A_Hub`(B 가 11/11 에 끝에 추가). `C_UrbanBlock` 은 없습니다. 그래서 에디터에서는 허브에서 C 씬으로 들어오지만, 빌드에서는 시가지 전투 포탈이 "준비 중"으로 뜹니다.

- **아직 바꾸지 않았습니다.** A · B 가 이의 없다고 알려 주면 바꾸고, 바꾼 날짜를 여기에 적겠습니다. B 의 배포용 Build Profile 은 B 가 맞춰 주세요.
