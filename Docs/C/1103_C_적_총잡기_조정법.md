# C 적 병사 — 총 잡는 모양 직접 맞추는 법

작성: C · 2026-11-03

적 병사가 K2C1 을 드는 모양(두 손 자리, 손가락 굽힘, 조준 자세, 낮춘 자세)은 설정 에셋 하나에 모여 있다. Play 중에 값을 바꾸면 바로 보이고, Play 를 멈춰도 바꾼 값이 남는다. 프리팹을 다시 만들 필요도 없다.

## 1. 순서

1. `Assets/C/Scenes/C_EnemyShowcase` 를 열고 **Play** 를 누른다. 병사 8명이 대기, 걷기, 뛰기, 조준(앞, 위, 아래), 돌아가며, 쓰러짐을 되풀이한다.
2. **Scene 창**에서 보고 싶은 병사를 클릭하고 **F** 를 눌러 맞춘다. 마우스 오른쪽 드래그로 돌려 가며 가까이 본다.
3. Project 창에서 `Assets/C/Models/Enemy/C_EnemyHold` 를 선택한다. Inspector 에 값이 나온다.
4. 값을 바꾸면 Scene 창의 병사가 바로 바뀐다. 슬라이더는 끌면서 보면 된다.
5. 마음에 들면 그냥 Play 를 멈춘다. **에셋이라 Play 중에 바꾼 값이 그대로 남는다** (보통 컴포넌트는 되돌아가는데 이것은 아니다).

- 시가지 씬(`C_UrbanBlock`)의 적 10명도 같은 에셋을 쓴다. 여기서 맞추면 실제 적도 같이 바뀐다.
- 값을 처음 상태로 되돌리려면 **에셋을 지우고 메뉴 MilTrainSimVR → C → 적 병사 만들기**를 누른다. 코드에 적힌 기본값(11/03 에 맞춘 값)으로 다시 만든다. 또는 git 에서 `C_EnemyHold.asset` 을 되돌린다.

## 2. 좌표와 단위

- 길이는 **cm**, 각도는 **°**.
- **총 기준**: X = 총의 오른쪽, Y = 위, Z = 총구 쪽. 원점은 권총손잡이.
- **몸 기준**: X = 병사의 오른쪽, Y = 위, Z = 병사의 앞. 원점은 두 발 사이 바닥.

## 3. 증상별로 고칠 값

| 보이는 문제 | 고칠 값 | 방향 |
|---|---|---|
| 오른손이 손잡이보다 위나 아래를 쥔다 | 오른손 `rightShift` Y | + 위, − 아래 |
| 오른손이 손잡이 앞이나 뒤로 어긋난다 | `rightShift` Z | + 앞(방아쇠 쪽), − 뒤 |
| 오른손이 손잡이에 파묻히거나 떠 있다 | `rightShift` X | + 오른쪽(떨어짐), − 왼쪽(파묻힘) |
| 손바닥이 손잡이 옆면에 붙지 않고 비스듬하다 | `rightPalmTurn` | + 손바닥이 뒤로, 손가락 뿌리가 앞으로 |
| 손 전체가 앞뒤로 기울어 보인다 | `rightTilt` | |
| 가운뎃손가락이 손잡이를 뚫거나 떠 있다 | `rightCurl` 의 middleBase, middleMid, middleTip | + 더 굽힘 |
| 집게손가락이 방아쇠울에 안 걸린다 | `rightCurl` 의 indexBase, indexMid | + 더 굽힘 |
| 엄지가 총몸을 뚫거나 벌어져 있다 | `rightCurl` 의 thumbIn, thumbMid, thumbTip | thumbIn + = 손바닥 앞으로 모음 |
| 왼손이 총열덮개에서 앞뒤, 위아래로 어긋난다 | 왼손 `leftShift` (Z 앞뒤, Y 위아래, X 좌우) | |
| 왼손 손가락이 뻗는 쪽이 어색하다 | `leftFingerAngle` | 0 = 바로 오른쪽, + = 총구 쪽 |
| 왼손 손바닥이 밑면에 안 붙고 옆으로 기운다 | `leftTilt` | + 손바닥이 오른쪽으로 |
| 왼손 손가락이 총열덮개를 뚫거나 떠 있다 | `leftCurl` | + 더 굽힘 |
| 조준할 때 총이 얼굴에 박히거나 멀다 | `eyeRelief` (가늠자와 눈 사이), `aimShift` | aimShift X + = 오른쪽(뺨에서 떨어짐) |
| 조준할 때 총이 기울어 있다 | `aimTilt` | X 총구 숙임, Y 좌우, Z 기울임 |
| 대기, 걷기, 뛰기에서 총이 몸에 박힌다 | `lowGrip` Z (앞으로), X (오른쪽으로) | 몸 기준 cm |
| 대기 자세의 총 높이 | `lowGrip` Y | 바닥에서 cm (104 = 배꼽 위) |
| 대기 자세의 총구 방향 | `lowYaw` (− 왼쪽), `lowPitch` (+ 위), `lowRoll` | |
| 뛸 때 상체가 숙으면 총이 배에 박힌다 | `lowFollowChest` | 1 = 가슴을 따라 같이 숙임 |
| 팔꿈치가 옆으로 뜨거나 몸에 붙는다 | `rightElbowBias`, `leftElbowBias` | X 바깥, Y 아래 (cm) |
| 손목이 꼬여 늘어나 보인다 | `twistToForearm` | 크게 할수록 아래팔이 더 비튼다 |
| 왼팔이 짧아 왼손이 총열덮개에 안 닿는다 | `leftSlide` | 닿지 않을 때 뒤쪽을 쥐는 최대 거리 |

- 손 자리를 옮기면 팔은 IK 로 따라온다. 팔 길이(어깨~손목 48cm)보다 멀면 손이 끝까지 닿지 않는다.
- 손가락 값은 T 자세(편 손)에서 굽히는 각도다. 0 이면 편 손가락이다.

## 4. 고급 — 치수 (모델을 바꿀 때만)

`gripCenter`, `gripUp`, `handguardCenter`, `rearSight` 는 K2C1 메시에서 잰 손잡이, 총열덮개, 가늠자 자리다. `rightFistCenter`, `leftCupCenter` 는 손 뼈 기준으로 쥔 것의 가운데다. 총이나 병사 모델을 바꾸지 않으면 건드리지 않는다.

`rightEyeFromHead`(오른눈 자리)만은 바꾼 뒤 **메뉴 → 적 병사 만들기**를 다시 눌러야 반영된다. 나머지는 모두 바로 반영된다.

## 5. 11/03 에 맞춘 상태 (참고)

- 오른손: 손바닥이 손잡이 오른쪽 면에 닿고, 가운뎃손가락이 손잡이 앞을 감아 끝이 왼쪽 면에 닿는다. 집게는 방아쇠울, 엄지는 손잡이 왼쪽 위.
- 왼손: 손바닥이 총열덮개 밑면, 손가락이 오른쪽 면을 감아 오르고, 엄지는 왼쪽 면을 따라간다.
- 총과 몸 겹침: 대기, 걷기, 뛰기의 대부분 프레임에서 0cm. 걸음 중 몇 프레임에서 개머리판이 오른쪽 엉덩이를 1.2cm 이하로 스친다. 조준 때 개머리판이 뺨에 1cm 붙는다 (뺨 견착).

## 6. 11/16 엄폐 · 재장전 애니메이션

Mixamo 에서 받은 6개를 넣었다 (`Assets/C/Models/Enemy/Animations/C_Enemy@*.fbx`): 엄폐 대기(웅크려 섬) · 무릎 쏴 · 옆걸음 왼쪽 · 오른쪽 · 재장전 서서 · 앉아서.

- 숨어 있을 때와 옆걸음 때도 총은 위 1~5절의 낮춘 자세 · 조준 자세 그대로다. 손은 계속 IK 로 총에 붙는다.
- **재장전 때만** 총이 애니메이션의 오른손을 따라간다. 따라가는 기준은 조준 애니메이션 첫 자세에서 잰 오른손 ↔ 총 관계다. 왼손은 IK 를 풀어 애니메이션대로 움직이고, 탄창(`Part_Magazine`)은 왼손이 잡는 때부터 새 탄창을 끼우는 때까지 왼손을 따라간다.
- 손볼 값은 적 프리팹(`C_EnemyDummy`)의 **EnemySoldier → 재장전 (11/16)** 에 있다.

| 값 | 뜻 |
|---|---|
| `m_MagazineInHandStand` / `m_MagazineInHandCrouch` | 탄창이 왼손을 따라가는 구간 (재장전 0~1). 탄창이 손에서 떨어져 보이면 시작을 늦추거나 당긴다 |
| `m_ReloadBlendSeconds` | 재장전 동작으로 들어가고 나오는 시간(초) |
| `m_ReloadClipSeconds` | 잘라 쓴 재장전 길이 — 빌더가 넣는 값이라 손대지 않는다 |

애니메이션 파일을 바꾸거나 자르는 구간을 바꾸면 **메뉴 → MilTrainSimVR → C → 적 애니메이션만 다시 넣기** 를 누른다. 프리팹의 몸 · 총 · 판정 상자는 그대로 두고 애니메이터와 잰 값만 바꾼다.
