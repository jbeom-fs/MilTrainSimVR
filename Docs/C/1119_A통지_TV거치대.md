# A에게 — UI를 올릴 대형 TV 거치대

작성: C · 2026-11-19
커밋: 이 문서와 같은 커밋 (main)

요청하신 대형 TV를 만들었습니다. 바퀴 달린 칠판 틀 모양이고, 칠판 자리에 TV가 걸려 있습니다. **씬에는 놓지 않았습니다.** 놓을 자리와 색은 A가 정해 주세요.

**A가 할 것 (요약)**

1. `Assets/C/Prefabs/Prop/C_TvStand.prefab`을 원하는 씬에 놓습니다. 뿌리의 +Z(파란 화살표)가 화면이 보는 쪽입니다.
2. UI 캔버스를 프리팹 안의 `ScreenAnchor` 자식으로 두고 위치 · 회전을 0으로 합니다 (2절).
3. 색이 마음에 안 들면 3절대로 바꿉니다. 다리 길이를 바꿔야 하면 C에 알려 주세요 (4절).

## 1. 크기

| 항목 | 값 |
| --- | --- |
| 전체 | 가로 2.14 m · 높이 2.32 m · 깊이 0.68 m |
| 화면 (`Screen`) | 1.75 × 1.07 m (81인치급, 비율 1.63) |
| 화면 높이 | 바닥에서 1.15 ~ 2.23 m (가운데 1.69 m) |
| TV 아래 테두리 | 바닥에서 1.10 m |
| 기둥 사이 폭 | 약 1.94 m |

다리는 `A_Sandbox`의 `Room_Assembly/Desk`(높이 0.95 m, 가로 2.10 m) 뒤에 세웠을 때 화면이 책상 위로 다 보이도록 맞췄습니다. 그 방 천장(2.64 m) 아래에 들어갑니다. 기둥 사이가 책상보다 좁아서 책상 위로 걸쳐 세울 수는 없습니다.

## 2. UI 붙이기

- `ScreenAnchor`: 화면 가운데에 있는 빈 오브젝트입니다. +Z가 화면 안쪽을 보게 해 두어서, World Space 캔버스를 자식으로 두고 위치 · 회전을 0으로 하면 앞에서 바로 읽힙니다. 시험 캔버스(1748 × 1073, 배율 0.001)를 붙여 글자가 뒤집히지 않는 것을 확인했습니다.
- `Screen`: 평평한 검은 판입니다 (재질 `Assets/C/Models/Tripo/TvStand/TvStand_Screen.mat`). 캔버스가 화면보다 작으면 남는 둘레가 이 판 색으로 보입니다.
- 테두리가 화면보다 26 mm 앞으로 나와 있으니, 캔버스는 화면 크기 안에 두는 것이 좋습니다.
- 뿌리에 몸을 막는 상자 판정이 두 개 있습니다 (위쪽 틀, 아래 발). 필요 없으면 빼도 됩니다.

## 3. 색 바꾸기

텍스처는 부위별 단색입니다. Tripo가 준 텍스처는 얼룩이 심해서 버렸습니다.

| 부위 | 색 (sRGB) | 매끈함 |
| --- | --- | --- |
| 틀 (기둥 · 버팀대 · 발) | 58, 61, 66 | 0.35 |
| TV 테두리 · 뒤판 | 18, 18, 20 | 0.46 |
| 선반 | 150, 153, 157 | 0.48 |
| 바퀴 | 24, 24, 25 | 0.27 |

- 부위별로 바꾸려면 `TvStand_basecolor.png`를 그림 편집기에서 열어 그 색 영역을 다른 색으로 채우면 됩니다. 매끈함은 `TvStand_metallicSmoothness.png`의 알파입니다.
- 전체 색조만 바꾸려면 `TvStand.mat`의 Base Map 색을 바꾸면 됩니다 (전체에 곱해집니다).
- 금속 값은 0입니다. 방에 반사 프로브가 없어도 같은 모습으로 보이게 하려는 것입니다.

## 4. 다리 길이 · 배율

- 프리팹의 `Model/TvStand`는 FBX의 메시 대신 `TvStand_Tall.asset`을 씁니다. Tripo 메시에서 기둥 구간만 0.42 m 늘리고 울퉁불퉁한 면을 편 사본입니다.
- 높이를 바꾸려고 세로로만 늘리면 TV와 바퀴까지 같이 늘어납니다. 다리만 더 길게 또는 짧게 해야 하면 C에 알려 주세요. 늘릴 때 쓴 스크립트는 저장소에 없습니다.
- 전체 크기는 뿌리를 같은 비율로 키우거나 줄이면 됩니다.

## 5. 확인한 것과 못 한 것

- 에디터에서 책상 크기 상자와 시험 캔버스를 세워 놓고 렌더로 확인했습니다.
- 헤드셋에서는 보지 못했습니다.
- 받침쇠와 테두리 모서리에 밝은 작은 삼각형이 몇 개 남아 있습니다. 가까이서 봐야 보이는 정도입니다.
- 사격장에 넣으신 `A_Monitor_760x560`과는 별개의 자산입니다.
