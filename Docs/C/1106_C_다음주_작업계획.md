# C 시가지 전투 — 다음 주 작업 계획 (11/9 ~ 11/13)

작성: C · 2026-11-06

11/6 까지 바깥벽 1~4단계(마감 · 반복 줄이기 · 입체 디테일 · 설비)와 가구 모델 경량화를 끝냈다. 처음 일정(1~3단계 11/9 주 초, 4단계 11/10~11)보다 사흘쯤 앞서 있다. 완료 발표는 **11/20(금)**. 날짜와 걸리는 시간은 어림이다.

큰 단계는 늘 같은 순서로 한다: 세부 계획 → 목업(메모리에서만, 같은 자리 전/후 사진) → 확인 → 빌더에 적용 → 같은 자리 사진으로 다시 확인.

## 1. VR 성능 실측 — 월, 1시간 이내

- Play 에서 시작 자리 통계(프레임 · 그리기 호출 · 삼각형)를 잰다.
- 가구를 가볍게 해서 맵 꼭짓점은 약 860만 → 226만으로 줄었지만, 입체 디테일 · 설비로 렌더러가 400개쯤 늘었다. 지금까지는 계산만 했고 실제로 재지는 않았다.
- 5단계에 성능을 얼마나 쓸 수 있는지 이 숫자로 정하니 맨 앞에 둔다.

## 2. 5단계 막힌 층 창 — 월 ~ 수 (가장 큰 일)

- 세부 계획을 먼저 정리해 확인받고, 두 안을 목업으로 비교한 뒤 고른 안을 적용한다.
  - **① 진짜 창 구멍 + 유리 + 어두운 방 상자** — 단순하다. 메시가 늘어 씬 파일(지금 34.6 MB)이 더 커진다.
  - **② 창 너머로 방이 보이는 셰이더(인테리어 매핑)** — 가볍다. 셰이더를 새로 만들어야 한다.
- 4단계에서 미뤄 둔 막힌 층의 창턱 · 창틀도 이때 같이 붙인다.
- 벽걸이 실외기는 막힌 층 창 띠 아래에 붙어 있다 — 창 자리가 바뀌면 실외기 자리도 같이 맞춘다.

## 3. 조명 · 색감 비교 — 수 또는 목, 반나절

- 4단계 계획 때 약속한 것: 앰비언트를 하늘 · 지평 · 땅 그라디언트로, C 씬 전용 볼륨(톤매핑 · 약한 색보정)을 넣어 '지금'과 나란히 비교한다.
- 공용 설정은 건드리지 않는다. SSAO(공용 PC 렌더러, 지금 반경 0.3 m)까지 바꾸려면 팀 공지를 먼저 한다.
