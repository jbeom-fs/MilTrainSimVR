# A에게 — 총기 완성본(C 총): 숨 참기 · 숨으로 반동 줄이기 · 사로용 이벤트

작성: C · 2026-11-17
관련: [A 문서 — 허브 사격 방식 고르기](../A/1117_허브_사격방식_선택.md) 3절 · 4절 (`CRangeRifle`), [A 문서 — 손 모델 통일](../A/1117_손모델_통일.md), [A 문서 — 총기 통합 1단계](../A/1117_총기통합_1_두손파지.md)

A · C가 이야기해서 정한 대로, A 기믹 중 **숨 참기**를 C 총(`C_K2C1`)에 합쳤습니다. 사로가 C 총을 다루기 쉽게 `TempRifle`에 이벤트 · 함수도 몇 개 열었습니다. A 파일은 고치지 않았습니다. 이 문서와 같은 커밋으로 올립니다.

**A가 할 것 (요약)**

1. **총은 C 총 하나로 갑니다 (0절).** A 사격장도 총기 조작은 C 총을 쓰고, 연병장 선택에 따라 **조준 방식만** 바꾸도록 맞춰 주세요. 지금 A 사격장의 "A 방식 = A 리그 + A 총(`K2C1Rifle`)"(`RifleStyleSwitch`), 안내판 글, A 총에 C 기능을 옮기는 총기 통합 1~5단계는 이 합의와 방향이 반대입니다.
2. 다리(`CRangeRifle`)는 C 총을 사로 절차에 잇는 데 그대로 씁니다. 사로에서 공격발 "탁" 소리가 필요하면 다리 쪽에서 내 주세요 (4절).
3. 숨 막대를 보이고 싶으면 `RifleBreath.BreathLeft`를 읽어 그려 주세요 (3-4절).

## 0. 정한 것 (A · C 이야기, 사용자 11/17)

- **총은 C 총(C 기믹) 하나입니다.** 사로를 포함해 어디서든 총기 조작 기믹(두 손 파지 · 방아쇠 · 조정간 · 탄창 · 장전 손잡이 · 반동 · 숨 참기 등)은 C 것을 따릅니다. A 기믹 중 필요한 것(숨 참기)은 C 총에 합쳤습니다 (이 문서).
- **연병장(허브)에서 고르는 것은 조준 방식뿐입니다** — C 조준(지금 C 가늠자 그대로) / A 조준(A 확대 조준, `SightAim`). 그 밖의 총기 조작은 어느 쪽을 골라도 C 것입니다 → [사격 방식 · 확대 조준](1117_A통지_C시가지_사격방식_확대조준.md).
- **사로 사격에서는 트리거 컨트롤러가 아니라 손 컨트롤러를 씁니다.** 손 컨트롤러 = C 리그의 손 모델(`C_ControllerHand_L/R`, 컨트롤러를 쥔 손)입니다. → A가 이미 했습니다 (`4c238ff`, [손 모델 통일](../A/1117_손모델_통일.md)).
- **반동은 C 것(`RifleRecoil`)을 그대로 씁니다.** 숨을 참는 동안은 반동이 줄어듭니다 (3-3절, 사용자 11/17 "숨참기로 반동을 더 잡을 수 있게").
- **C 총엔 공이치기 · 빈 격발 소리를 넣지 않습니다** (사용자 11/17). 지금처럼 0발(약실이 빔)에서 방아쇠를 당기면 소리 없이 손에 약한 진동만 옵니다. 사로의 공격발 "탁"은 A 다리가 지금처럼 맡습니다 (4절).
- [총기 통합 1단계](../A/1117_총기통합_1_두손파지.md) 1절의 "A 총에 C 기능을 가져오고, 끝에 C도 A 총으로 옮긴다"는 위 합의와 반대입니다 — 총은 C 총으로 합칩니다.

## 1. 바뀐 것 한눈에

| 기능 | 어디에 | A 총과 같은 점 / 다른 점 |
| --- | --- | --- |
| 숨 참기 | 새 컴포넌트 `RifleBreath` (`C_K2C1`의 잡기 변환기) | 입력(앞손 트리거) · 상태 · 시간 · 흔들림 값은 `SightAim`과 같습니다. 확대 창이 없어서 **총 자체**를 움직이고, 숨 막대 대신 진동으로 알립니다 |
| 반동 | `RifleRecoil` (C) | 숨 상태에 따라 반동 크기와 돌아오는 빠르기가 바뀝니다 |

## 2. 사로가 C 총을 다루기 쉽게 연 것

총 동작은 바꾸지 않았습니다. 0발(약실이 빔)에서 방아쇠를 당기면 지금처럼 소리 없이 손에 약한 진동만 오고, 공이치기는 없습니다.

**`TempRifle`에 새로 연 것** (이름 · 뜻은 `RangeRifle`과 같습니다):

| 종류 | 이름 |
| --- | --- |
| 이벤트 | `Fired`(실탄 — 명중 처리가 끝난 뒤) · `DryFired`(약실이 빈 채 당김 — 소리 없음, 당길 때마다) · `TriggerBlocked`(안전에서 당김) · `FireModeChanged(FireMode)` · `ChargingHandlePulled` · `ChargingHandleReturned` (`HammerDown` · `HammerCocked`는 없습니다) |
| 함수 | `SetFireMode(FireMode)` — 바로 그 위치로 돌리고 소리는 한 번만 냅니다 |
| 함수 | `ResetState()` — 손에서 놓게 하고, 탄창은 떨어뜨리지 않고 없애고, 약실을 비우고, 안전으로 둡니다. 소리는 없습니다 |
| 함수 | `TestCycleChargingHandle()` — 장전 손잡이를 끝까지 당겼다 놓은 것과 같습니다 |
| 함수 | `MagazineWell.Clear()` — 꽂힌 탄창을 소리 · `Removed` 없이 없앱니다 |

## 3. 숨 참기 (`RifleBreath`)

### 3-1. 입력 · 상태 (`SightAim`과 같음)

- **두 손으로 받친 채(앞손이 총열덮개에 붙은 채) 앞손 트리거를 누르고 있으면** 숨을 참습니다. 0.6 이상 누르면 시작하고, 0.4 아래로 풀면 내쉽니다. 한 손으로 들었을 때는 숨을 참을 수 없습니다.
- 상태는 `보통 → 숨 참기 → 6초 넘으면 숨 한계` 순서입니다. 숨 한계에서는 트리거를 놓고 2.5초 쉬어야 다시 참을 수 있습니다. 보통 상태에서는 참은 시간이 같은 비율로 줄어듭니다.
- 앞손 트리거는 C 총에서 다른 데 쓰지 않습니다. 격발은 손잡이를 잡은 손의 트리거만 듣습니다.

### 3-2. 효과 — 확대 창 대신 총 자체가 움직입니다

| 상태 | 흔들림 (mrad, A와 같은 값) | 손 떨림 거르기 (총이 손을 따라가는 시간 상수) |
| --- | --- | --- |
| 보통 | 2 (25 m에서 ±5 cm) | 0초 — 손 그대로. 시가지 전투 감각을 바꾸지 않으려고 이렇게 했습니다 (A 확대 창은 0.06) |
| 숨 참기 | 0.15 | **0.3초** — 거의 멈춘 듯 겨눌 수 있습니다 (A 확대 창은 0.4. C는 손 모델이 붙은 총 자체가 늦게 따라오므로 조금 짧게) |
| 숨 한계 | 4 | 0초 |

- 총은 손잡이 잡기 점(`Attach_Grip`)을 중심으로 돕니다. 손잡이는 손 자리에 남고 총구 쪽이 움직입니다. 가늠자 · 가늠쇠 · 총구가 같이 움직이므로 보이는 곳이 맞는 곳입니다.
- 상태가 바뀔 때는 0.25 ~ 0.3초에 걸쳐 부드럽게 넘어갑니다.
- 진동: 숨 참기 시작 시 앞손에 약하게, 남은 숨이 30 % 아래로 떨어지면 0.5초마다 앞손에 톡, 숨 한계에 닿으면 두 손에 크게 한 번 옵니다. C에는 숨 막대가 없습니다. A가 막대를 그리려면 `BreathLeft`를 읽으면 됩니다.
- `SightAim`의 방아쇠 흔들림(0.6 mrad)은 넣지 않았습니다. C 총은 실제 손 떨림이 그대로 들어가기 때문입니다.

### 3-3. 반동 (C `RifleRecoil`)

| 상태 | 한 발 반동 (뒤로 · 위로 · 옆으로) | 제자리로 돌아오는 빠르기 |
| --- | --- | --- |
| 보통 | 1배 (두 손: 위로 1.5°) | 1배 |
| 숨 참기 | **0.6배** (위로 0.9°) | **1.5배** |
| 숨 한계 | 1.3배 (위로 1.95°) | 0.8배 |

- 잡기 변환기 순서는 `XRGeneralGrabTransformer → RifleHands → RifleBreath → RifleRecoil`입니다. 반동이 숨 거르기 뒤에 더해지므로, 참는 동안에도 반동은 걸러지지 않고 날카롭게 튀며 크기만 줄어듭니다.
- 값은 모두 `RifleBreath` 인스펙터에서 바꿀 수 있습니다 (사로 인스턴스에서만 바꿔도 됩니다).

### 3-4. 읽을 수 있는 것

- `Breath`(`RifleBreath.State` — `Normal` · `Holding` · `Exhausted`. A `BreathState`와 같은 순서)
- `BreathLeft`(1 = 가득, 0 = 한계)
- `BreathChanged(State)`
- `RecoilScale` · `RecoveryScale`
- 시험용 `TestBreath` — 손 없이 앞손 트리거를 누른 것으로 칩니다

## 4. A 다리(`CRangeRifle`) — 그대로 두셔도 됩니다, 줄일 수 있는 곳만 제안

- **공이치기 흉내는 그대로 두셔야 합니다.** C 총엔 공이치기가 없어서, 사로의 공격발 "탁" · "공이치기가 떨어져 있습니다" 판정은 다리가 계속 맡습니다. C 총은 0발에서 소리를 내지 않으므로, 사로에서 "탁" 소리가 필요하면 다리가 `DryFired`를 알릴 때 A 쪽에서 소리를 내 주세요 (A 총의 `Temp_DryFire`처럼).
- 아래는 리플렉션 · 매 프레임 확인을 줄이고 싶을 때 바꿀 수 있는 곳입니다. 꼭 바꾸지 않아도 됩니다.

| 다리에서 하던 것 | 바꿀 수 있는 것 |
| --- | --- |
| `LateUpdate`에서 `ShotsFired`가 늘었는지 보기 · 조정간 바뀜 보기 | `TempRifle.Fired` (명중 처리 뒤에 불림 — 조 닫기 순서 그대로) · `FireModeChanged` |
| `ChargingHandlePulled` · `Returned` (`RifleChargingHandle` 구독) | `TempRifle`의 같은 이름 이벤트 |
| `SetFireMode` — `CycleFireMode` 여러 번 | `m_Rifle.SetFireMode((TempRifle.FireMode)(int)mode)` — 소리 한 번 |
| `ResetState` — 리플렉션 (`m_Chambered`, `SetSeated`) | `m_Rifle.ResetState()` (다리 자기 공이치기는 다리에서 내리기) |
| `TestCycleChargingHandle` — 리플렉션 | `m_Rifle.TestCycleChargingHandle()` |

- `TestInsertMagazine`의 `SetSeated` 리플렉션은 그대로 필요합니다 (공개 끼우기 함수는 아직 없습니다). 이름은 바꾸지 않았습니다.

## 5. A 문서 4절의 이름 — 하나도 바꾸지 않았습니다

`Mode` · `FireMode`(순서) · `Chambered` · `ShotsFired` · `FireAt` · `PullTrigger()` · `ReleaseTrigger()` · `CycleFireMode()`, 비공개 `m_Chambered` · `m_FireMode` · `OnHandlePulledBack()` · `OnHandleReturned()`, `MagazineWell.SetSeated(bool, int)` · `m_StartRounds` 모두 그대로입니다. 2절 · 3절은 새로 연 것만 더했습니다.
