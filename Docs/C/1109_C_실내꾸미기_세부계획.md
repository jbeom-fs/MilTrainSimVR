# C 시가지 전투 — 실내 꾸미기 세부 계획 (5단계 대신)

작성: C · 2026-11-09 · **확인 전 초안** (11/09 사용자가 정한 것: 간판 가게부터 · 가게별 핵심 모델 4종 · 1층 가게 구조 맞춤 — 2 · 3-3 · 3-5 · 8절)

11/09 사용자: 5단계 '막힌 층 창'(① 창 구멍 + 유리 + 어두운 방 상자 / ② 인테리어 매핑 셰이더) 대신, 잡 모델을 더 만들어 들어갈 수 있는 실내를 꾸민다. 막힌 층에는 이미 창 띠 텍스처(`Textures/Map/Window1` — 유리 · 창틀 · 블라인드 · 커튼이 칸마다 다름)가 있어서 길에서 보면 창으로 읽힌다. 아무도 못 들어가는 층에 메시와 시간을 쓰는 것보다, 플레이어가 싸우는 실내를 낫게 하는 쪽이 VR 에서 더 크다. 창 자리가 그대로라 벽걸이 실외기는 옮기지 않는다.

순서는 늘 같다: 세부 계획(이 문서) → 목업(메모리에서만, 같은 자리 전/후 사진) → 확인 → 빌더에 적용 → 같은 자리 사진으로 다시 확인.

## 3. 하는 일

### 3-1. 방 용도 나누기 — 판정 상자는 그대로, 씌우는 모델만

- 건물 · 층마다 용도를 정하고(배치의 건물 상자에 칸 하나 — 예: `roomUse`), 지금 가구 자리에 용도에 맞는 모델을 씌운다.
- 판정 상자의 자리 · 크기가 그대로라 **부딪힘 · 엄폐 · 적 길찾기는 안 바뀐다.**

| 용도 | 선반 자리 (1.8 m) | 낮은 장 자리 (0.85 m) | 책상 자리 (0.75 m) | 칸막이 자리 |
|---|---|---|---|---|
| 사무실 | 철제 서류장 · 책장 | 낮은 서류장 | 사무 책상 (지금 모델) + 의자 | 사무 칸막이 |
| 창고 | 산업용 선반 (지금 모델) | 종이 상자 더미 | 작업대 | 팔레트에 쌓은 상자 |
| 학원 | 책장 · 사물함 | 낮은 책장 | 학생 책상 둘 | 바퀴 달린 화이트보드 |
| 가정집 | 장롱 · 냉장고 | TV 장 | 식탁 · 소파 | 옷걸이 |
| 가게 · 식당 | 가게마다 (3-3) | | | |

건물별 배정 초안은 7절 끝에 있다.

### 3-2. 작은 물건 — 보이기만 (판정 없음)

- **천장**: 형광등(사무실 · 학원 · 창고) · 매입등(가게) · 환풍구 · 화재감지기. 빛나는 재질만 쓰고 진짜 조명은 두지 않는다 (방이 많아서).
- **벽**: 시계 · 달력 · 포스터 · 게시판 · 벽걸이 에어컨 실내기 · 소화기. 문 · 창 자리는 피한다.
- **가구 위**: 사무 책상에 모니터 · 키보드 · 서류 더미 · 컵 · 전화기. 산업용 선반 칸에는 이미 물건이 있다.
- **바닥 구석**: 종이 상자 · 쓰레기통 · 화분 · 정수기 · 의자. 문 앞 비울 자리(1.4 m)와 가구 둘레(0.6 m)는 `Furnish` 의 비울 자리 계산을 같이 써서 피한다.
- 자리 · 종류는 건물 이름 씨앗이라 다시 지어도 같다 (설비와 같은 방식). 그림자는 끈다.
- 그리기 호출을 줄이려고 작은 물건은 **방마다 재질별로 합친다** (건물 통째로 합치면 Occlusion Culling 으로 방 단위를 못 거른다 — 5절).

### 3-5. 1층 가게 구조 맞춤 (11/09 사용자)

1층 간판 가게는 방 구조도 가게 목적에 맞게 살짝 바꾼다.

- 바꾸는 곳은 1층 간판 가게 칸만이다. 계단 · 앞뒤 문 · 통과 길(N11)은 그대로 둔다.
- 식당(도야지천국 N23 · 황룡각 N09 · 튄닭! N32): 앞줄 방을 합쳐 홀 하나 + 뒤쪽 주방.
- 매장(문구야모여 N11 · 폰대장 N31 · 뫄뫄굿즈 N24): 매장 칸을 넓히고 진열대 줄로 길을 낸다.
- 10/23 원칙('방 전체가 뚫려 있으면 안 되고 복도형')은 지킨다. 홀을 넓혀도 탁자 · 진열대 · 기둥으로 시야를 끊어 한눈에 다 보이지 않게 한다.
- 1층 간판 가게에는 적이 서는 자리가 없다(적 6 은 N27 1층). 적 길찾기 지도는 다시 굽고, 순찰 경로가 바뀌지 않는지 본다.
- 건물마다 위에서 본 평면을 전/후로 목업한다.
- 2층 가게는 지금 구조가 맞는 편이다 — 노래방은 복도 + 작은 방 그대로. 당구장은 N09 2층 전체를 한 홀로 바꿔 적용했다 (11/09, 3-3).

## 5. 성능 · 씬 크기

- 지금 맵 꼭짓점은 약 226만이고, 그중 Tripo 모델이 188만이다(산업용 선반 1,120토막이 약 154만). 방 용도를 나누면 선반 토막 일부가 다른 모델로 바뀌니, 더 가벼운 모델이면 오히려 준다.
- 작은 물건 예산(꼭짓점 · 그리기 호출)은 **오늘 VR 실측 숫자로 정한다.**
- **Occlusion Culling 이 C 씬에 안 구워져 있다** (`m_OcclusionCullingData` 비어 있음). 지금은 벽 뒤 실내 물건도 화면 쪽에 있으면 그린다. 물건이 늘면 Unity 기본 굽기(Window → Rendering → Occlusion Culling)를 시험한다. 데이터는 C 씬 옆 폴더에만 생긴다 — 공용 설정이 아니다.
- **씬 크기**: 지금 34.6 MB. 코드로 만들어 합친 메시는 씬 파일에 들어가서 씬이 커진다. 실내 물건 메시는 씬 밖 에셋 파일로 빼는 방법을 같이 넣는다 (이번 주 계획 '정할 것'의 씬 크기 항목과 같은 일, GitHub 파일 한도 100 MB).
