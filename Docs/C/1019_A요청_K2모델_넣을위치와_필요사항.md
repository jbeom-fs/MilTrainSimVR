# K2 모델 요청 — C(격발·파지)에 필요한 것

작성: C · 2026-10-19

C 는 A 의 K2 모델을 기준으로 격발과 양손 파지를 만든다.
모델링은 A 방식대로 하고, 아래는 C 가 코드를 붙이는 데 필요한 최소한이다.

## 1. 꼭 필요한 것

| # | 항목 | 내용 |
|---|---|---|
| 1 | 넣을 위치와 파일 이름 | 어느 폴더에 어떤 이름으로 넣을지 알려 주면 된다 (FBX 든 프리팹이든) |
| 2 | 크기와 방향 | Unity 로 가져왔을 때 실제 크기(미터 단위), 총구가 앞(+Z), 위쪽이 +Y |
| 3 | 위치 표시용 빈 오브젝트 | 손잡이 · 앞손 · 총구 · 가늠자/가늠쇠 (또는 광학장비 자리) · 탄창 꽂는 곳. 이름은 A 가 정해서 알려 주면 C 가 맞춘다 |
| 4 | 따로 움직이는 부품 | 방아쇠 · 조정간 · 탄창을 각각 분리된 메시로, 회전 중심(피벗)을 움직이는 축에 맞춰서 |
| 5 | 일정 | 모양만 맞는 러프 버전을 언제 받을 수 있는지, 최종본은 언제인지 |

- A 의 사로 사격에도 격발이 필요하다. 누가 만들지, 같이 쓸지?
