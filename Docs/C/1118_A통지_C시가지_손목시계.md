# A에게 — C 시가지: 떠 있던 손목 표시 → 왼 손목 안쪽 손목시계

작성: C · 2026-11-18
커밋: `c27c5b4` (main)
관련: [A 문서 — 손 모델 통일](../A/1117_손모델_통일.md), [A 문서 — 허브 사격 방식 고르기](../A/1117_허브_사격방식_선택.md) (`MatchDisplay` 탄약 표시를 언급한 곳)

C 시가지 전투(`C_UrbanBlock`)에서 경기 정보를 보여 주는 방식을 바꿨습니다. 왼손 위에 떠 있던 작은 글자판(손목 표시)을 지우고, **왼 손목 안쪽(손바닥 쪽)에 찬 손목시계**로 옮겼습니다 (사용자 11/18). A 파일은 고치지 않았고, A 씬(연병장 · 사격장)에는 시계가 나오지 않습니다.

**A가 할 것 (요약)**

1. **할 일은 없습니다.** 공용 손 모델 프리팹(`C_ControllerHand_L/R`)은 그대로입니다. 시계는 C 씬이 실행될 때만 손목에 붙습니다 (3절).
2. [허브 사격 방식 고르기](../A/1117_허브_사격방식_선택.md)에 적힌 "탄약 표시(`MatchDisplay`)"는 이제 없습니다. 예비 탄창 수는 화면에 나오지 않습니다 (1절). 다리(A 총 → C)를 만들 때 이 항목은 빼도 됩니다.
3. 시계를 A 씬에서도 쓰고 싶으면 4절 함수만 부르면 됩니다. 화면 구성을 바꿔야 하면 C에 알려 주세요.

## 1. 바뀐 것 한눈에

| 전 | 후 |
| --- | --- |
| 왼손 위에 떠 있는 글자판 — 단계 · 남은 시간 · 남은 적 · 예비 탄창 · (오버타임) 점령지까지 거리 · 점령 시간. 총을 받치면 숨었다 | **지웠습니다.** 정보는 손목시계로 옮겼습니다. 예비 탄창 수 · 점령지까지 거리 · 오버타임 남은 시간은 빠졌습니다 |
| 오버타임이 열리면 눈앞 앞판에 알림 4초 | **시계 화면**에 알림 4초 + 삐비비빅 × 4 (디지털 시계 알람). 앞판은 뜨지 않습니다 |
| 자유 전투 시작 알림 · 결과판 | 그대로 (앞판) |
| 점령 규칙 | 그대로 — 혼자 있는 진영의 점령 시간이 쌓이고 먼저 30초면 승리, 같이 있으면 둘 다 멈춤 |

입력은 하나도 늘지 않았습니다. 버튼 할당도 없습니다. 왼손 메뉴 버튼은 B 일시정지 메뉴가 쓰며, C 결과판의 메뉴 버튼 → 다시하기 할당은 11/17에 뺐습니다.

## 2. 시계 화면

둥근 화면(지름 2.7 cm)에 두 줄을 보여 줍니다.

```
   [적 아이콘]  12/20            ← 남은 적 / 전체
  ───────────────
   [타이머]     3:27             ← 시작 전 · 자유 전투: 남은 시간 (분:초)
   [깃발]       나 12초 / 적 0초  ← 오버타임: 각 진영의 점령 시간
   [깃발]       교착             ← 오버타임: 플레이어와 적이 같이 점령지에 있을 때
```

| 단계 | 위 줄 | 아래 줄 |
| --- | --- | --- |
| 시작 전 | `20/20` (흐린 색) | 자유 전투 길이 `5:00` (흐린 색) |
| 자유 전투 | 남은/전체 | 남은 시간 (흰색) |
| 오버타임 | 남은/전체 | `나 N초 / 적 M초` (주황) · `교착` (빨강) |
| 끝 | 남은/전체 (흐린 색) | `--:--` |

- 오버타임이 열리면 4초 동안 화면 전체가 `오버타임` + 점령지 이름(`백화점 3층`)으로 바뀌고, 삐비비빅이 4번 울립니다. 짧은 삑 4번이 한 묶음이고, 0.9초 간격으로 4묶음, 모두 3.1초입니다. 소리는 손목에서 납니다 (3D).
- 글자는 C 글꼴(`Assets/C/Fonts/NotoSansKR-Regular SDF.asset`, 고정 아틀라스)입니다. 아이콘(적 · 타이머 · 깃발)과 소리는 빌더가 코드로 그려 만듭니다.

## 3. 어떻게 붙나

- 모델: Tripo로 만든 러기드 스마트워치(검정 케이스 · 금속 베젤)를 12,000 삼각형으로 줄였습니다. 실제 크기로 케이스 4.3 cm입니다.
- **손 모델의 손목 뼈 `L_Wrist`**(XR Hands 샘플 손, `C_ControllerHand_L` 안)에 손바닥 쪽으로 붙입니다. 화면 위쪽(12시)은 엄지 쪽이라, 손바닥을 위로 돌려 보면 글자가 똑바로 섭니다.
  - 컨트롤러가 아니라 보이는 손을 따라갑니다. 총을 쥐면 손 모델이 총으로 옮겨 붙는데(`RifleHands`), 그때도 시계가 손에 붙어 있습니다.
  - 손목이 납작해서(단면 5.2 × 3.7 cm) 줄의 손등 쪽만 눌러 맞춘 메시(`Watch_Fitted.asset`)를 씁니다.
- 실행할 때 `MatchDisplay.Start`가 프리팹을 만들어 `L_Wrist`에 채웁니다. 프리팹이나 손 모델 프리팹을 씬에 미리 넣지 않았습니다. 그래서 같은 손 모델을 쓰는 A 씬에는 시계가 없습니다.

## 4. A 씬에서 쓰려면 (선택)

```csharp
using MilTrainSimVR.UrbanCombat;

// 프리팹: Assets/C/Prefabs/C_WristWatch.prefab (WristWatch 컴포넌트)
WristWatch watch = Instantiate(watchPrefab);
watch.Wear(leftWristBone);   // C_ControllerHand_L 안의 "L_Wrist" Transform

watch.ShowTime(WristWatch.State.Running, secondsLeft, alive, total);    // 아래 줄 = 타이머 + 분:초 (seconds < 0 → "--:--")
watch.ShowCapture(alive, total, mineSeconds, theirSeconds, contested);  // 아래 줄 = 깃발 + 점령 시간 / 교착
watch.Notify("오버타임", "백화점 3층", 4f);                               // 화면 전체 알림 + 삐비비빅
```

- `State`는 `Idle`(흐림) · `Running`(흰색) · `Overtime`(주황) · `Ended`(흐림)입니다.
- 매 프레임 불러도 됩니다. 보이는 값이 바뀔 때만 글자를 새로 만듭니다.
- 위 줄은 지금 적 아이콘 고정입니다. 사로용으로 다른 내용(예: 남은 탄 · 표적 수)이 필요하면 아이콘 · 줄을 늘려 드릴 수 있으니 알려 주세요.

## 6. 아직 확인하지 않은 것

- 헤드셋으로 보고 소리를 듣는 확인 (Play 모드에서 오버타임 알림 · 알람 · 교착 표시는 확인했습니다)
- 총을 받친 자세에서는 엄지가 옆을 향해서 글자가 90° 누워 보입니다. 바꿀지는 사용자가 정할 예정입니다.
