팀 기획서 초안(`Docs/B/1020_팀전체_프로젝트_기획서_초안.md`)의 개발 순서 1단계 "담당별 상세 범위·단계 정리"에서 C 가 정할 것(맵, 전투 방식, NPC 구성, 종료·평가 조건)이다. 사용자가 10/26 에 정한 것만 적었다.

## 1. 한 줄로

플레이어 **혼자** 시가지에서 **적 11명**과 싸운다. 처음에는 **자유 전투**를 하고, 길어지면 **점령지가 열리는 오버타임**으로 넘어간다. 피격은 **하드코어**다. 중요 부위가 아닌 곳에 한 번 맞으면 부상이고, 두 번째 총상에서 죽는다.
