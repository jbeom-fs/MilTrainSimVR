# A에게 — 연병장 사격 방식 = 조준 방식만: A 조준이면 확대 조준, 총기 조작은 늘 C 총

작성: C · 2026-11-17
관련: [A 문서 — 허브 사격 방식 고르기](../A/1117_허브_사격방식_선택.md) 5절 (C 시가지에 적용하기), [C 문서 — 총기 완성본(C 총)](1117_A통지_C총_숨참기.md)

A 문서 5절에서 "C 시가지 전투 적용은 C가 한다"고 정한 것을 했습니다. A 파일은 고치지 않았습니다.

## 1. 정한 것 (사용자 11/17)

- **총은 C 총(C 기믹) 하나입니다.** 어디서든 총기 조작 기믹은 C 것을 따르고, A 기믹 중 필요한 것(숨 참기)은 C 총에 합쳤습니다 ([총기 완성본](1117_A통지_C총_숨참기.md)).
- **연병장(허브)에서 고르는 사격 방식은 조준 방식만 바꿉니다.** C가 원래 만들던 조준과 A가 만들던 조준 중 하나를 고르는 것이고, 그 밖의 총기 조작은 어느 쪽이든 C 것입니다. 사용자: "머리에 가져다 대면 조준점 확대되는 방식을 이야기 한 거지 조작 키까지 다 바꾸겠다는 소리가 아님".

| 연병장에서 고른 방식 | 조준 | 총기 조작 · 리그 |
| --- | --- | --- |
| **A** | **A 확대 조준**(`SightAim` — 총을 든 채 눈을 가늠자 뒤로 가져가면 4배 창) | C 총 · C 리그 · C 조작 |
| **C** | C 조준 (C 가늠자 그대로, 확대 없음) | C 총 · C 리그 · C 조작 |

- **A 문서 1절 · A 사격장과 다른 점:** 지금 A 문서와 A 사격장(`RifleStyleSwitch`)은 "A 방식 = A 리그 + A 총(`K2C1Rifle`)"으로 되어 있어 위 합의와 다릅니다. A 사격장도 총은 C 총으로 두고, A 방식이면 그 C 총에 확대 조준만 켜도록 맞춰 주세요. C 총 프리팹에 이미 꺼진 `SightAim`과 켜는 스크립트가 들어 있어서, 사격장에 C 총을 두면 같은 규칙으로 켜집니다 (2절). 안내판 글(특징 세 줄)도 "조준 방식"으로 고쳐 주세요.
- 이 문서는 **C 시가지(`C_UrbanBlock`)에 적용한 것**입니다. 허브 안내판 아래 "시가지 전투 반영은 C 작업 뒤" 줄은 이제 빼셔도 됩니다.
- 허브에서 한 번도 고르지 않으면 `RifleStyle` 기본값이 A입니다 → 확대 조준이 켜집니다.

## 2. 어떻게 했나

- `C_K2C1`(C 총 프리팹)에 A의 `SightAim`을 **꺼진 채**(enabled = false) 붙이고, 새 C 컴포넌트 `RifleSightZoom`이 씬 시작 때 `RifleStyle.Current`를 한 번 읽어 A면 켭니다.
- 이 규칙은 C 총 프리팹에 들어 있어 **C 총을 두는 어느 씬에서든 같습니다.** 지금 A 사격장(`A_Sandbox`)의 C 총(`K2C1_Range_C`)은 `RifleStyleSwitch`가 C 방식일 때만 켜므로 그때는 확대 조준이 꺼진 채입니다. A 사격장이 1절대로 바뀌면(A 방식에도 C 총) 확대 조준이 켜집니다.
  - 꺼져 있어도 `SightAim.Awake`는 돌아서 렌더 텍스처(1024²) 하나와 꺼진 카메라를 만들고, URP 경고 한 줄(`Camera.stereoTargetEye`)을 남깁니다. 동작에는 지장이 없습니다.
- 총 동작 · 사로용 이벤트는 바뀌지 않았습니다. 확대 중에도 C 총 탄은 C 탄도(가늠자 · 25 m 영점)로 나갑니다. `IShotLine`은 쓰지 않습니다.

### 2-1. C 총에 맞춘 `SightAim` 값 (프리팹 값만, A 파일 그대로)

| 값 | A 사격장 | C 총 | 이유 |
| --- | --- | --- | --- |
| 흔들림(보통 · 숨 · 한계) | 2 / 0.15 / 4 mrad | **0** | C 총은 `RifleBreath`가 총 자체를 흔들고 숨 참기도 맡습니다. 창까지 흔들면 창과 탄이 어긋납니다 (창이 따로 흔들리면 최대 2 mrad) |
| 따라가기(보통 · 숨) | 0.06 / 0.4초 | **0** | 창 = 실제 총의 조준선 (재 보니 차이 0.000 mrad) |
| 가까운 면 | 1 m | **0.75 m + 벽 앞에서 당기기** | 아래 |
| 숨 막대 | 보임 | **숨김** | `SightAim`은 C의 앞손(`RifleHands`)을 몰라 숨 상태가 늘 '보통' → 막대가 늘 가득으로 보였습니다 |

**가까운 면 (11/17 검증에서 찾음):**
- 1 m면 벽에서 1 m 안에서 조준할 때 창에 그 벽이 안 찍히고 **벽 너머가 보였습니다** (시가지엔 벽이 많습니다).
- 그냥 줄이면 총구(가늠자에서 0.71 m, 조준선 조금 아래)가 창 아래에 찍힙니다.
- 그래서 평소엔 0.75 m로 두고, 확대 중 가늠자 앞 0.77 m 안에 벽 · 사람이 있으면 `RifleSightZoom`이 가까운 면을 그 바로 앞까지 당깁니다 → 창에 벽이 찍히고 벽 너머는 안 보입니다. 확대 카메라(`AimCamera`)의 가까운 면만 바꾸고, `SightAim`은 이 값을 매 프레임 덮어쓰지 않아서 그대로 둡니다.

## 3. A에게 — 묶인 것 · 부탁 (선택)

**C가 읽는 A 이름 (바꾸면 알려 주세요):**
- `RifleStyle.Current` · `RifleStyle.Style`
- `SightAim`의 `IsAiming`, 직렬화 필드 이름 `m_RearSight` · `m_FrontSight` · `m_OverlayMaterial` · `m_CameraNear` · `m_SwayNormal` · `m_SwayHolding` · `m_SwayExhausted` · `m_FollowNormal` · `m_FollowHolding` (프리팹 값 · `CombatAssetsBuilder`)
- `SightAim`이 만드는 자식 이름 `AimCamera` · `AimBreathBar`
- 재질 `Assets/A/Materials/Aim/AimSightPicture.mat`

**부탁 (급하지 않음):**
1. `SightAim`이 바깥 숨 상태(예: C `RifleBreath.Breath` · `BreathLeft`)를 받을 수 있게 해 주시면 C 총에서도 숨 막대를 다시 켤 수 있습니다.
2. URP에선 `Camera.stereoTargetEye` 줄이 경고만 남깁니다 — 빼도 될 것 같습니다.
3. A 사격장엔 앞에 벽이 없어서 1 m 문제가 안 보이지만, A 총을 벽 많은 곳에서 쓰게 되면 같은 처리가 필요합니다 (`Assets/C/Scripts/RifleSightZoom.cs`의 `NearPlane`).
