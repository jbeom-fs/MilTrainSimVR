# B Editor 메뉴 정리 구현본 정적 검토 — 2026-11-06

## 결론

구현보고서와 실제 Editor diff·메뉴 등록·현재 사용 문서를 대조했다. 추가 필수 코드 오류는 발견하지 못했다. 보고서의 개발 도구 ‘7개 그룹’은 ‘6개 그룹’으로 정정해야 한다. Unity 컴파일·메뉴 실행은 하지 않았다.

## 실제 코드 확인

- Editor 변경은 16개 파일, 81줄 추가/81줄 삭제다. 변경 diff를 읽고 문자열·주석을 제외한 소스 내용도 비교했으며 함수·조건·호출 구조의 변경은 발견하지 못했다. 문자열·주석 밖 내용 비교는 정적 분석이며 컴파일 검사가 아니다.
- 실행 메뉴 38개: B/교육장 4개, B/개발 도구 34개다. 실행 경로 중복 0, 활성 조건 13개는 모두 같은 경로의 실행 등록과 일치한다. 기존 활성 조건 함수와 priority 인자는 변경되지 않았다.
- B/교육장에는 구급법 구성·갱신, 화생방 구성·갱신, 구급법 검사, 화생방 검사 4개가 있다.
- 개발 도구는 K1 방독면 8개, KD-1 6개, 교육 보드 12개, 보호의 4개, 지혈대 2개, 직접 압박·압박붕대 2개다.
- 이전 메뉴 접두사는 현재 Assets/B/Editor C#에서 검색되지 않는다. ApplyInScene과 문구 후보 등 내부 연계 함수는 유지됐다. 교육 보드 전체 대상은 기존 5개 과정이다.
- Git diff 기준 A/C, B 런타임·씬·프리팹·모델·재질, ProjectSettings, Packages 변경이 없다. 기존 설계 문서 등 작업 트리 문서는 보존한다.
- git diff --check에서 해당 Editor 및 AGENTS 변경의 공백 오류는 없었다. LF/CRLF 경고는 메뉴 기능 실패 근거로 분류하지 않는다.

## 정정·잔여 사항

### 1. 보고서 사용자 확인 3번의 그룹 수

실제 그룹은 **6개**다. ‘직접 압박·압박붕대’는 하나의 메뉴 경로이며 직접 압박과 압박붕대를 각각 별도 그룹으로 세면 안 된다. 기존 AGENTS의 새 메뉴 안내에는 이미 이 결합 경로가 맞게 기재돼 있다. 코드 수정 없이 보고서/확인 목록만 바로잡으면 된다.

### 2. 알려진 이전 경로 안내 1곳

TourniquetMeshDeform.cs:45의 읽기 불가 메시 오류 안내는 아직 `B/Tourniquet/1. Build Prefab and Placement Scene`을 가리킨다. 메뉴 재배치 이후 실제 위치는 `B/개발 도구/지혈대/1. 프리팹·실습 씬 생성·갱신`이다.

런타임 변경 금지 범위에 따라 보존한 것으로 보고서와 일치한다. 메뉴 등록/교육 진행 결함은 아니며, 해당 오류가 발생한 개발자에게 오래된 메뉴 위치를 안내하는 잔여 문구다. 이번 작업의 필수 런타임 수정으로 확대하지 않는다. 현재 대응표로 새 위치를 찾을 수 있다.

## 사용자 확인 범위

이번 변경은 메뉴 표시/등록 문자열 변경이다. Unity 컴파일, 실제 메뉴 표시·그룹 수, Play 중 기존 비활성 조건, 읽기 전용 검사 실행 시 저장 파일 변화 여부는 사용자 확인 영역이다. 이전 교육 기능의 사용자 검증 완료 상태는 유지한다.

에이전트는 메뉴·코드·씬·에셋을 수정하거나 실행하지 않았다. Docs/B 검토 기록만 추가·갱신했으며 스테이징·커밋하지 않았다.
