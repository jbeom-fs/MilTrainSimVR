# MilTrainSimVR B 구급법·화생방 발표 참고 기술문서

2026-11-20 초안 · Unity 6000.3.13f1 · Windows PC VR / Meta Quest 2 + Link

B는 구급법과 화생방 교육장에 여섯 개 실습 과정을 구현했다. 실습은 교육 순서와 단계마다 해야 할 핵심 행동을 중심으로 구성했다. VR에서 정밀하게 맞추기 어려운 동작은 조작 조건이나 판정 위치를 조정했다.

## 1. 담당 범위와 체험 흐름

| 교육장 | 과정 | 주요 기능 |
|---|---|---|
| 구급법 | AED | 가상 패드 부착 판정과 교육 보드의 단계별 안내 |
| 구급법 | 지혈대 | 장비 배치 판정과 배치 완료 후 허용 영역 표식 숨김 |
| 구급법 | 직접 압박·압박붕대 | 조작 조건에 따른 감기 진행률과 다음 조작 대상 표시 |
| 화생방 | K1 방독면 | 얼굴 스냅, 머리끈 안착, 거울로 착용 상태 확인 |
| 화생방 | 보호의 | 신체 위치에 따라 움직이는 착용 표식과 장갑·덧신의 착용 상태 변화 |
| 화생방 | KD-1 휴대장비 제독 | 모의 장비 표면의 영역별 접촉 판정과 진행 표시 |

```text
연병장 허브 → 입장 포털 → 구급법 또는 화생방 교육장
                            ↓
                실습대 교육 보드에서 시작
                            ↓
                  단계별 조작과 안내 갱신
                            ↓
                    과정 완료와 수행 요약
                            ↓
                다시하기·교육 종료 → 실습대 시작 화면
```

두 교육장은 빌드에 등록된 별도 씬이며 각 씬에 실습대 세 곳이 있다. B는 교육장과 실습 과정, 전용 XR 리그, 교육 UI와 공통 메뉴 연동을 담당한다.

## 2. 교육 진행 방식

- 실습대의 교육 보드에서 원하는 과정을 시작한다. 한 번에 한 과정만 진행할 수 있으며, 시작 화면으로 돌아오면 다른 과정을 선택할 수 있다.
- 각 과정은 정해진 순서대로 안내한다. 현재 단계에서 필요한 행동을 수행하고 장비 상태가 조건에 맞으면 다음 단계로 넘어간다. 다섯 과정은 이 진행 기능을 공유하며, AED는 장치와 패드 상태를 자체적으로 확인한다.
- 중단, 다시하기, 교육 종료를 선택하면 장비가 초기화되고 시작 화면으로 돌아간다. 중단 확인창에서 계속하기를 누르면 하던 실습을 이어간다. 완료 화면에는 수행 결과가 표시된다.

## 3. 대표 조작 판정

### 압박붕대 감기 진행률

직접 압박과 감기 전 확인을 거쳐 붕대를 감고, 붕대 끝을 배치해 고정하는 순서로 진행한다. 감기 조작은 롤로 여러 지점을 통과하는 방식에서 표시된 영역에 롤을 유지하는 방식으로 바꿨다. 영역을 벗어나거나 롤을 놓으면 진행률이 멈추고, 조건을 다시 충족하면 이어진다. 감기가 끝나면 드레싱이 자동으로 고정되고 다음에 조작할 붕대 끝이 표시된다.

### K1 방독면 착용 조작

실제 착용에서는 손의 감각으로 머리끈과 방독면의 위치를 확인할 수 있다. VR 실습에서는 그 감각을 얻기 어려워 거울에 자신의 아바타를 띄우고 방독면과 머리끈의 위치를 눈으로 확인할 수 있게 했다.

방독면을 얼굴 가까이 가져가면 스냅으로 위치와 방향이 자동으로 맞춰진다. 손을 떼도 방독면이 얼굴에 고정되므로, 한 손으로 머리끈을 잡아 머리 뒤로 가져갈 수 있다. 끈을 잡은 손이 머리 뒤쪽 영역에 들어가면 끈이 자동으로 안착하고 착용이 완료된다. 얼굴에 대고 머리끈을 뒤로 넘기는 순서를 유지하면서, 방독면을 손으로 받친 채 위치를 맞추는 부담을 줄였다.

### 보호의 착용 위치와 표시

보호의 착용 순서를 유지하면서 덧신을 가져가기 쉽도록 판정 영역을 발목 근처에서 무릎 아래로 옮기고 넓혔다. 헤드셋과 컨트롤러의 추적 정보로 가상 신체의 자세를 계산한다. 덧신이 판정 영역에 들어오면 교육 단계와 추적 상태를 확인하고, 착용 조건이 맞으면 발에 신은 모습으로 표시한다.

장갑을 착용하면 해당 손이 장갑을 낀 모습으로 바뀐다. 거울에서는 기본 손 모델을 숨기고, 과정을 초기화하면 헤드셋 화면에 기본 손 모델이 다시 표시된다.

## 4. 공통 VR 조작과 교육 UI

B 전용 XR 리그는 근거리·원거리 선택과 이동 입력을 처리한다. 떨어진 장비를 잡으면 손으로 가져오고, 제자리에서 조작하는 부품은 손을 움직인 만큼 반응한다. 부착과 착용 판정은 장비가 손에 도착한 뒤부터 적용한다.

### 교육 보드의 단계 표시

교육 보드 상단의 번호 칸은 완료한 단계가 초록색, 현재 단계가 파란색, 아직 수행하지 않은 단계가 짙은 회색이다. 2단계를 마치면 2번 칸은 초록색으로, 3번 칸은 파란색으로 바뀐다. 번호 아래에는 현재 단계 이름과 해야 할 행동을 표시한다.

공간 표식은 조작할 위치를 가리키고, 선택·완료·장비 조작 때는 효과음이 난다. 공통 메뉴로 실습을 일시정지해도 헤드셋 추적과 메뉴 조작은 유지된다.

## 6. 요약

구급법과 화생방의 여섯 실습은 각 과정의 교육 순서를 따르는 데 중점을 두었다. 단계마다 필요한 행동을 마쳐야 다음 단계로 넘어간다. VR 컨트롤러로 장비 위치를 세밀하게 맞추는 일이 실습 진행을 가로막지 않도록, 교육 순서는 유지하면서 일부 조작을 간소화했다. 압박붕대는 롤을 지정 영역 안에서 잡고 있으면 감기가 진행되고, 보호덧신은 무릎 아래의 판정 영역에 가져가면 착용된다. 방독면은 얼굴 가까이 가져가면 제 위치에 자동으로 맞춰진다. VR에서는 머리끈을 잡거나 장비가 몸에 닿는 감각을 느끼기 어려워, 거울로 자신의 모습을 보며 방독면과 머리끈의 위치, 보호의 착용 상태를 확인할 수 있게 했다. 교육 보드는 색과 문구로 현재 단계와 해야 할 행동을 안내한다. 실습을 마치면 결과를 확인하고 같은 과정을 다시 시작할 수 있다.
