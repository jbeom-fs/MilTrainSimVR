## 2. 교안과 모델 제한

- 새 순서: 하의 → 상의 → 왼 덧신 → 오른 덧신 → 왼 장갑 → 오른 장갑. 기존 단계·상태 ID는 유지했다.
- 보호의 → 덧신 → 방독면 → 장갑은 공식 군 공개 보도 근거가 있다. 하의 → 상의는 승인 교안 원문 미확보, 좌우는 개발 선택이다. 승인 교안 확정으로 표시하지 않는다.
- h5는 부분 개선 상태다. 가벼운 굽힘 최대 관통 7.95mm, 팔꿈치 최대 늘어남 2.395배, 손 가슴 2.476배, 옆구리 실루엣 축소가 남는다. 추가 Blender 보완 필요성은 별도 판단이다.
- 몸통·다리·발은 추정, 거울은 단안이다. 전체 MOPP, 밀착·여밈·보호성능, 실제 발 추적의 검증으로 확대하지 않는다.

## 3. 이미 반영된 항목 — 다시 미구현으로 배정하지 않음

- 1103 마감의 코드 2건(전시물의 사용자 본 축척 보존, 장갑·컨트롤러 표시 준비 조건)은 후속 보완됐다.
- h5 채택, WornNodeFix 원시 노드·Attach 보완, Unity 메시 공간 기준 스킨 검사, 65본 계약·부위 가중치·본 대응·컨트롤러 연결 보완은 `255d254`에 포함됐다.
- 시작·6단계·자동 완료·요약·완료 후 다시하기의 보호의 과정은 구현됐고 사용자가 이전 묶음의 검증 완료를 보고했다. 장치별·항목별 통과로 확대하지 않는다.
- Unity 루트 대비 −90°만으로 Blender 재내보내기를 요구하지 않는다. 말단 13본이 제거된다는 이전 추정도 현재 기준으로 사용하지 않는다.

## 4. 이후 기능 순서

1. 보호의 발 판정·교육 순서 변경과 남은 제한 정리.
2. 휴대장비 제독의 교육 범위·조작 설계와 구현.
3. 기능 완성 뒤 구급법(AED·지혈대·압박붕대) / 화생방(K1·보호의·휴대장비 제독)의 운영 씬 2개와 선택·복귀 통합.

K1·AED·지혈대·압박붕대의 과거 개별 미확인·보류 항목은 [1103 목록 §3·§4](1103_남은작업_전체목록.md)를 이력으로 보존한다. 오늘 이 장비들의 추가 수정이나 신규 검증을 수행하지 않았다. 음성·CPR·피부 제독·탈의·평가/점수·영구 저장은 별도 범위다.

## 5. 작업 규칙

- 코드 직접 작성·수정 금지. 명시 요청 시 한국어 자연어 구현 프롬프트만 제공한다.
- Unity·메뉴·Play·Simulator·테스트·빌드는 사용자 실행. 검증용 복제 프로젝트를 만들거나 재사용하지 않는다.
- 모델링은 Blender. 사용자·팀의 현재 변경을 보존하고 스테이징·커밋·Push를 자동 수행하지 않는다.
- 다음 재개 시 Git 상태와 사용자 추가 보고를 먼저 확인한다. 이 마감은 구현 승인이 아니다.
- 문서 작업 중 교육 씬과 글꼴 자산에 추가 변경이 관찰됐다. 작성자는 수정하지 않았고 그대로 보존했다. 세부는 마감 §6을 따르며 파일 변경만으로 실행 검증을 추정하지 않는다.
