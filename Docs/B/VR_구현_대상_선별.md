# VR 구현 대상 선별

작성일: 2026-10-19
기준: Quest 2 단독 실행, 기본 컨트롤러 2개, 사용자 1명, 추가 센서 없음.
상태: 기존 구급법·화생방 후보에서 추린 개발 범위 제안. 실기기 구현 검증 및 최종 범위 확정 전.

판단·도구 선택·지정 위치 조작·절차 평가로 완결되는 콘텐츠를 선정한다. 실제 술기와 동일한 물리적 감각이나 측정이 필요한 부분은 평가 대상에서 제외한다. 아래 순서는 실제 처치·제독 순서가 아닌 개발 우선순위다.

## 구급법

| 우선순위 | 선정 콘텐츠 | 구현할 상호작용 | 구현 범위 |
| --- | --- | --- | --- |
| 1 | 현장·환자 상태 확인 및 도움 요청 | 위험 요소 선택, NPC 반응·호흡 관찰, 도움 요청 선택 | 관찰·판단·요청 절차 |
| 1 | AED 사용 | 기기 잡기, 버튼 누르기, 패드 지정 위치 부착, 접촉 여부 확인 | 조작·위치·순서 |
| 1 | 전투용 지혈대 절차 | 부상 위치 확인, 지혈대 배치, 조임막대 회전, 고정·기록 | 적용 판단과 가상 장비 조작; 실제 압력 평가 제외 |
| 1 | 직접 압박·압박붕대 절차 | 도구 선택, 상처 위 접촉 유지, 붕대 지정 경로 배치·고정 | 위치·유지시간·순서; 실제 압박력·천 감기 재현 제외 |
| 2 | CPR 절차·리듬 연습 | 상태 판단, 가상 손 위치 지정, 컨트롤러 반복 동작 | 절차·가상 손 위치·동작 리듬; 실제 압박 깊이·힘·이완·인공호흡 평가 제외 |

구급법 1차 시연은 AED 또는 지혈대 중 하나를 완결된 시나리오로 먼저 구현한다. 실제 처치 조건과 평가 규칙은 적용 부대 교안을 따른다.

## 화생방

| 우선순위 | 선정 콘텐츠 | 구현할 상호작용 | 구현 범위 |
| --- | --- | --- | --- |
| 1 | 방독면 가상 착용·점검 | 장비 확인, 얼굴 앞 지정 위치 배치, 가상 끈 조작, 점검 단계 수행 | 지정 위치 도달 후 착용 상태 전환; 실제 밀착·호흡 측정 제외 |
| 1 | 보호의·장갑·전투화 덮개 착용 절차 | 장비 선택, 아바타 착용 지점에 배치, 여밈·연결부 선택 | 아바타를 이용한 단계별 착용; 실제 전신 착의 재현 제외 |
| 1 | 개인제독 절차 | 도구 선택, 접근 가능한 가상 대상 부위 처리, 도구 회수 | 대상·도구·순서·누락 평가; 실제 제독 효과 평가 제외 |
| 1 | 개인 휴대장비 표면 제독 | 작업대 위 장비 잡기·회전, 지정 표면 처리 | 제한된 크기와 개수의 장비, 처리 범위·재접촉 평가 |
| 2 | 오염 확산 방지·보호장비 탈의 절차 | 가상 오염 물체 접촉, 탈의 단계 선택, 회수함에 넣기 | 아바타·가상 접촉 규칙 중심, 복잡한 실제 탈의 동작 제외 |
| 2 | MOPP에 따른 장비 선택 | 지시 확인, 필요한 장비 선택, 착용 상태 확인 | 별도 대형 모듈 대신 착용 콘텐츠의 조건으로 통합 |

화생방 경보는 도입 이벤트로 포함한다. 개인제독의 신체 대상은 가상 팔·손 또는 앞에 배치된 교육용 인체 모델을 사용한다. 사용자 몸 전체의 실제 접촉 위치를 측정하는 방식은 채택하지 않는다.

## 이번 구현 대상에서 보류

- 실제 압박 깊이·힘을 측정하는 CPR과 인공호흡 실습.
- 실제 밀착도를 검증하는 방독면 착용 및 실제 전신 보호의 착의 평가.
- 기도폐쇄 구조 동작, 실제 부상자 들기·운반, 자유로운 부목·붕대 감기.
- 전문 제독차 조작, 대규모 지역·시설 제독, 제독소 전체 운영.
- 온열질환·골절·탐지·보고·표지 해석의 독립 시나리오: VR 구현 자체는 가능하지만 1차 핵심 범위를 좁히기 위해 보류.

보류는 기술적으로 모두 불가능하다는 의미가 아니다. 추가 장비, 표현 방식 변경 또는 개발 범위 확대가 필요한 항목을 이번 선정에서 뺀 것이다.

## 공통 구현 방식

- 잡기, 배치, 버튼 조작, 회전, 접촉 유지로 상호작용을 제한한다.
- 방독면의 머리 뒤 조임과 보호의의 전신 착용은 아바타 또는 앞쪽 조작 UI로 대체한다.
- 교육용 오염 표시는 실제 오염의 육안 식별이나 물리·화학적 제독 효과를 재현한 것으로 표시하지 않는다.
- 안내 실습·무안내 평가에서 같은 행동 기록 체계를 사용한다.
- 합격 기준·순서·시간 조건은 승인된 교안으로 확정한다.
- 실제 구현 가능성은 대표 조작 프로토타입과 Quest 2 실기기 테스트로 확인한다.
