- **잠금 없음**: 실습 중·중단 확인 중에 포털에 들어가면 B 교육 정리 없이 씬이 바뀐다. 씬이 통째로 다시 로드되므로 다음 진입은 처음 상태다(사용자 확정 사항).
- **순간 이동 겹침**: Walk_Entry 순간 이동 영역이 진입 상자와 일부 겹친다. 그 자리로 순간 이동하면 곧바로 허브로 넘어간다. 사용자 위치 조정 후 겹침 범위와 시작 자리 뒤 거리는 §10.2를 따른다(정적 계산, 실행 미관찰).
- **포털 뒤 공간**: 렌즈 뒤 0.95m로 사람이 지나갈 수 있다. 뒤쪽에서 상자로 들어가도 넘어간다(허브 포털과 같은 동작).
- **비트리거 렌즈 충돌체**: 몸(CharacterController)이 렌즈에 닿기 전에 머리가 상자(렌즈 앞 0.315m)에 먼저 들어가 넘어간다. 반대로 걷기 이동으로 렌즈를 통과할 수는 없다.
- **빌드 목록**: 공용 빌드 목록에 A_Hub가 없으면 빌드에서는 포털이 넘어가지 않는다. 이름판을 꺼서 "준비 중" 표시도 보이지 않는다. A_Hub 추가는 사용자가 한다.
- **CourseRoute.Current**: B 포털은 `CourseRoute.Enter(과정 ID, A_Hub)`로 허브를 불러와 `Current`가 비워지지 않는다(이번 범위 밖, 사용자 확정 6).
- **반짝이 고리 서쪽 끝**(X≈0.69)은 문 쪽으로 퍼지지만 렌즈 평면(Z −1.05) 위의 장식이라 문과 겹치지 않는다.

## 9. A 회신

A 담당 앞(Docs/A는 고치지 않고 여기에 적는다):

- B 두 씬(`B_FirstAid`, `B_CBRN`)의 출구를 `Assets/A/Prefabs/HubPortal_ToHub.prefab` 씬 인스턴스 하나씩으로 바꿨다. B 쪽 직접 분야 이동은 없앴다. 이제 B 출구는 이 포털뿐이다.
- **위치·모양**:
  - 북벽 문 바로 앞에 남쪽(방 안)을 보고 선다(ExitAnchor 아래). 구급법 월드 (−0.019, 0, −0.407), 화생방 (0.027, 0, −0.322). 사용자가 Unity에서 최종 조정한 값이다(§10.2).
  - 루트 배율 0.70으로 줄였다(실내 천장 2.644m). 렌즈 0.35~2.03m, 폭 1.33m.
  - 머리 위 이름판(`Label`)은 인스턴스에서 껐다. 대신 B 목재 명판 "연병장"을 포털 오른쪽 벽에 따로 붙였다.
  - Sparkles `scalingMode`는 루트 배율을 따르도록 인스턴스에서 Hierarchy로 바꿨다.
- **과정 ID**: 각 씬 인스턴스 `m_CourseId`를 `B_FirstAid` / `B_CBRN`으로 넣었다. `m_Label` "연병장", `m_ScenePath`는 프리팹 값 그대로, ReturnPoint·Fader·Head는 비워 두었다.
- **화면 가림**: 각 B 씬 `SceneSystems/ScreenFader`에 A `ScreenFader`를 붙이고 `Materials/Common/ScreenFade.mat`을 참조만 한다. CourseStart는 넣지 않았다.
- **A 자산 무변경**: Assets/A 아래 파일(.meta 포함)을 쓰거나 옮기지 않았다. Variant·사본·Apply·Unpack도 없다. Unity 저장 중 렌즈 재질 1줄이 바뀐 적이 있으나 HEAD로 되돌렸고, 현재 `git status -- Assets/A` 변경 0이다(§10.3).
- **부탁**: 포털 프리팹 구조(자식 이름, 위 fileID), `HubPortal`·`ScreenFader` 필드 이름, ScreenFade 재질 위치를 바꾸면 B·C에 알려 달라. B 씬 override가 그 값에 묶여 있다.
- 실행 확인(에디터 Play·헤드셋·빌드)은 B 사용자가 확인 완료를 보고했다(항목별 결과 미수령, §7).
