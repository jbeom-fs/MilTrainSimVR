# 2026-10-28 K1 거울·사용자 아바타 검토

최신 상태(2026-10-28): 아바타·전신 거울·후면 보기 구현 후 사용자가 메뉴 재실행으로 거울 정상 작동을 확인했다. `3c7837e`에 커밋됐다. 다시하기도 `692f916`에 구현·커밋되고 사용자가 검증 완료를 보고했다. [오늘 마감 기록](1028_작업마감_진행상황.md)을 우선한다.

아래는 정적 조사·설계 당시 기록이다. ‘미구현·메뉴 실행 전·다시하기 후속’ 표현은 현재 완료 상태를 뜻하지 않는다. 구현 상세는 [1028_K1_거울_아바타_구현기록.md](1028_K1_거울_아바타_구현기록.md)를 따른다. 에이전트는 코드·자산 수정이나 Unity 실행을 수행하지 않았으며, 사용자 정상 작동 확인을 HMD 양안·성능 검증으로 확대하지 않는다.

최신 사용자 지시: **`Worn` 이후 끈 풀림은 일단 수정하지 않는다.** 이번 구현 요청은 마네킹 아바타·전신 거울·후면 보기로 한정한다. 아래 끈 문제의 조사 기록은 보존하되 수정 착수 지시로 해석하지 않는다.

## 1. 사용자 요청과 우선순위

- 다음 기능인 다시하기 진행 방향을 확인했다.
- 추가 요청: 전신을 비추는 거울, 이전 마네킹을 이용한 사용자 신체 연동 가능성 검토.
- 사용자가 명확히 한 문제: **`Worn` 이후 손만 놓아도 끈이 풀린다.** T로 벗긴 후 끈이 복귀하는 경우를 말한 것이 아니다.
- 앞선 기능 전체 확인 완료 보고 이후 새로 나온 사용자 관찰이다. 후속 사용자 지시로 끈 유지 문제 수정은 보류하고, 이번에는 거울·아바타를 대상으로 한다. 다시하기는 별도 후속 작업으로 유지한다.

## 2. 끈 유지 문제 — 현재 근거

- 정상 요구: `Worn` 이후 손을 모두 놓아도 착용한 끈 자세와 머리 추종을 유지한다. 명시적 해제·다시하기에서만 착용 상태를 해제한다.
- 현재 `K1MaskWear`는 `Worn` 상태에서 `DriveUnfold`나 `StrapsReturning`을 실행하지 않는다.
- `OnStrapReleased`는 제어 손·기준을 정리하며 끈 진행값을 0으로 돌리지 않는다.
- 현재 읽은 Editor 로그에는 교육 완료와 `Worn` 기록이 있으나, 그 뒤 `Released from the face`·`StrapsReturning` 전환은 보이지 않았다. 로그 부재만으로 실제 본 자세 유지나 화면 표시 정상까지 증명하지 않는다.
- 따라서 사용자 관찰은 수정·확인 대상으로 보존하되, 해제 입력이 원인이라고 단정하지 않는다. 실제 상태·진행값, 본 자세, 렌더링 결과를 나누어 확인할 필요가 있다.
- 거울은 착용 결과를 보는 기능이다. 끈 유지 결함의 원인 확인·수정을 대신하지 않는다.

## 3. 재사용 가능한 인체 자산

| 자산 | 정적 확인 | 활용 판단 |
|---|---|---|
| `Assets/B/Models/Mannequin/Mannequin.fbx` | 원본 FBX에 Mixamo 머리·골반·팔·손·다리 본 이름과 LimbNode·Skin·Cluster 정보 존재 | 사용자 아바타 재사용 후보 |
| `Assets/B/Models/Pad_Mannequin/Mannequin_AED_Attached.fbx` | 본·스킨 변형 정보가 없는 정적 메시. 기존 문서에도 누운 정적 환자 모델로 기록 | 현재 상태 그대로는 팔·다리가 움직이는 아바타에 적합하지 않음 |
| `Assets/B/Prefabs/Mannequin_Patient.prefab` | AED 앵커·패드 표시·좌우 반전 보정·환자 Collider를 가진 환자용 구성 | 사용자 아바타로 직접 변경하지 않고 보존 |

- 원본의 현재 Unity 임포트는 Generic(`animationType: 2`)이며 Humanoid 본 매핑은 비어 있다.
- 본 이름과 스킨 구조 확인은 리깅 재사용 가능성을 뒷받침한다. 실제 Avatar 유효성·변형 품질·기준 자세·눈 위치·키·팔 길이는 실행 검증 전이다.
- K1 전용 복사본/구성을 분리해 원본과 AED의 임포트 설정·참조를 보존한다. Humanoid 설정이 필요하면 K1용 자산에서 검토한다.

## 4. 현재 환경에서 가능한 신체 연동

현재 프로젝트는 Windows PC VR·Quest 2 + Link·OpenXR·XRI를 사용한다. Meta Movement SDK와 Animation Rigging 패키지는 현재 manifest에 없다.

권장 초기 범위는 **머리·양손 추적 + 나머지 몸의 자세 추정**이다.

| 부위 | 초기 연결 방식 |
|---|---|
| 머리·목 | HMD 위치·회전을 기준으로 눈 위치와 머리 자세를 정렬 |
| 손 | 좌우 컨트롤러 위치·회전에 손목 목표를 맞춤 |
| 팔·팔꿈치 | 손목 목표와 몸체를 기준으로 IK 계산 |
| 몸통·골반 | 머리 높이·수평 방향과 기준 자세로 추정 |
| 다리·발 | 1차는 기본 서 있는 자세와 바닥 기준 배치. 실제 발 위치 추적이라고 표시하지 않음 |

- 머리와 두 손만으로 사용자의 모든 관절 자세가 직접 측정되는 것은 아니다.
- Unity 기본 Humanoid IK를 쓰려면 유효한 Humanoid Avatar 구성이 필요하다. 새 패키지 도입 전 기존 기능으로 가능한 범위를 검토한다.
- 패키지·XR 설정을 이번 조사에서 변경하지 않는다. 추가 SDK 도입이 필요하면 팀의 기존 패키지 관리 규칙에 따른다.
- 추적이 끊긴 동안 팔다리가 튀지 않도록 추후 구현에서 중단·복귀 방식을 정한다.

## 5. 거울 구성안

- 전신 거울: 머리·몸·손과 실제 방독면의 현재 자세를 확인한다.
- 뒤통수 확대 보기: 얼굴을 정면 거울로 보는 것만으로는 잘 보이지 않는 후두부 머리끈을 보여 준다. 전신 거울과 별도의 후면 관찰 화면으로 구분한다.
- 1차 아바타는 거울/관찰 화면에 표시하는 구성을 우선해, 기존 1인칭 시야와 장비 조작을 유지한다.
- 방독면은 실제 착용 중인 오브젝트의 자세를 보여 준다. 거울 전용 복제 방독면의 독립적인 착용 판정이나 본 구동을 만들지 않는다.
- 마네킹의 눈·머리 위치와 카메라 아래 얼굴 기준을 맞춰, 거울에서 방독면이 얼굴과 어긋나지 않게 한다.
- 거울의 양안 표시·반사 방향·후면 화면 방향·클리핑·성능은 실제 VR 확인 대상이다. 일반 단안 카메라 화면을 완성된 VR 거울로 간주하지 않는다.
- 거울·확대 화면은 조작 공간을 가리지 않는 위치에 배치한다. UI 완료 화면과 다시하기 버튼을 가리지 않는다.

## 6. 권장 진행 순서

1. 원본 마네킹으로 K1 전용 사용자 아바타를 준비하고 눈높이·손목·몸체 기준을 맞춘다.
2. 전신 거울과 후면 확대 보기로 실제 착용 자세를 확인한다. 거울만을 위해 끈 자세를 강제로 고정하거나 착용 동작을 바꾸지 않는다.
3. 다시하기에서 방독면·주머니·교육·UI를 초기화하고 사용자 아바타·거울은 유지하는 흐름은 별도 후속 작업으로 다룬다.
4. `Worn` 후 손 놓기 때의 끈 유지 문제는 사용자 재요청 전까지 보류한다.

이 순서는 제안이며 아직 구현에 착수한 것이 아니다. 전체 기능 구현 후 Quest 2 + Link 실기 확인이라는 기존 방침을 유지한다.

## 7. 공식 기술 자료

- [Unity 6 Inverse Kinematics](https://docs.unity3d.com/6000.0/Documentation/Manual/InverseKinematics.html): Humanoid Avatar 기반 IK와 손 목표 연결 요건.
- [Unity Animation Rigging Two Bone IK](https://docs.unity3d.com/Packages/com.unity.animation.rigging@1.3/manual/constraints/TwoBoneIKConstraint.html): 목표·팔꿈치 힌트로 두 본 사슬을 구동하는 방식. 현재 설치됐다는 뜻은 아니다.
- [Meta Body Tracking for Movement SDK](https://developers.meta.com/vr/documentation/unity/move-body-tracking/): Quest 기종별 기능과 Link 조건을 별도로 확인해야 한다. Quest 3의 IOBT가 Quest 2에서도 제공된다고 가정하지 않는다. 이 SDK를 현재 프로젝트에 설치하거나 적용하지 않았다.
