## 3. 병행 확정·보류

- **교육 기준 확정:** 지혈대 실제 제품·세대·IFU·적용 교안은 아직 미확정. 기술 시제품 진행과 별개로 정식 교육 문구·완료 기준 확정 전에 해결할 의존성이다.
- **정적 제한:** NearFar 이외 입력의 완료 제한, OnBeforeRender 추적 미반영은 기록된 제약이다. 실행으로 재현된 신규 결함으로 단정하지 않는다.
- **보류 유지:** Quest 2 + Link 실기, K1 Worn 후 끈 풀림 수정, 음성. 실기를 현재 최우선에 다시 배정하지 않는다.
- **이번 순서에 추가하지 않음:** 제독·보호의·CPR·무안내 평가·점수·결과 영구 저장.
- **기존 정적 참고:** K1 안내판 회전 시 버튼 겹침 오판·추출 기준 문제, AED 다시하기 후 XRI 경고 가능성. 미재현/미확인 참고로 유지하며 필수 수정으로 승격하지 않는다.
