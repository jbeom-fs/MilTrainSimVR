
## 4. 초기화·판정 참조 보존 근거

- **장비 복구 기준**: 아래 장비는 깨어날 때 자기 부모 기준의 시작 위치를 저장한다. 저장 씬에서 그룹 단위로 옮기면 복구 지점도 같이 옮겨진다.
  - 지혈대: TourniquetDevice의 initialParent
  - 압박붕대: PressureBandageApplication이 부모·로컬 위치를 기록
  - AED 패드: AedPad의 initialParent·initialLocalPosition
  - 보호의 장비: ProtectiveClothingEquipment가 부모·로컬 위치를 기록
  - 장비 위치를 정하는 월드 좌표형 직렬화 값은 없다(대상 과정 컴포넌트의 Vector3 필드 전수 확인).
- **함께 움직인 그룹**:
  - TQ·PB 키트는 보조대 상판 중심에 그대로 있다(상대 위치 동일).
  - AED 기기(패드·케이블·버튼)는 책상 위 같은 자리에 있다.
  - PC 6개 장비는 PC_Pickups 자식으로 남아 상판 위에 있다.
  - 환자의 판정 영역·부착 지점·상처·의자는 환자 루트의 자식이라 함께 움직인다.
- **실행 중 위치를 정하는 표식**: 가이드 표식·고스트·상처 안내·PC 장비 표식은 대상 위치를 따라 실행 중에 배치되는 코드라 별도 수정이 필요 없다.
- **검사 메뉴 조건**: AED 검사 메뉴 조건(패드·PadAnchors가 프리팹 자세 그대로)은 환자 인스턴스 루트 위치만 바꿨으므로 유지된다.
- **보존 확인**: K1·PC 거울 루트·Surface·farClip 20, 6개 벽걸이 화면 외형·720×440·스크롤 본문, 교육·버튼·차단 참조가 그대로다.

## 5. 보류 항목과 남은 사항

- **구급법 `Walk_Rear`(사용자 보류)**: 수정하지 않았다. 재배치 후에도 AED 책상(Z −9.415~−8.815)과 Z 방향으로 0.135m 겹친다. 자연 해소되지 않았다.
- **AED 환자 팔 범위**: 기존처럼 `Walk_Rear`, `Walk_WestReturn` 가장자리(x −2.25~−2.05)와 겹친다. 변경 전에도 같은 겹침이 있었고 이동 목적지는 바꾸지 않았다.
- **접근 거리 증가**: TQ 키트 0.84m, PB 키트 0.80m, PC 덧신 R 1.55m는 이전보다 멀다. 몸을 기울이거나 반 걸음 이동이 필요할 수 있어 사용자 확인 항목이다.
- **AED 환자 가슴 방향**: 앵커 정면 기준 60° 전후에서 옆(90°)으로 바뀌었다.
- **TQ·PB 의자 간격 9cm**: 의자 형상 기준이다. 실제 앉은 자세 메시(머리·팔)가 벽에 닿는지는 Unity에서 확인해야 한다.
- **문 열림 범위**: 문 모델은 정적이다. 문짝 폭 반경을 양쪽 경첩 기준으로 가정해 계산했다.

## 6. 정적 확인 결과 (실패 0건)

- **YAML 구조**: 두 씬 LF·끝 줄바꿈, 중복 fileID 0, 대상 없는 로컬 참조 0. 부모·자식과 프리팹 인스턴스 연결이 일치한다. 새 GUID는 프로젝트·패키지에서 한 번만 나온다.
- **스탠드 프리팹**: GameObject·Transform·MeshFilter·MeshRenderer만 있고, 기본 Cube·Cylinder와 금속 재질을 쓴다. 받침판 접지, 기둥–판–거치대 연결, 거치대–브래킷 접촉, 판이 기둥·화면 밑을 받치는지 확인했다.
- **씬 결합**: EntryAnchor 위치·회전·배율 불변, 스탠드 부모 배율 1·바닥·수직, 화면 Canvas 월드 배율 0.001·중심 높이 1.50m.
- **기존 화면**: 6개 벽걸이 화면 벽 접촉, 720×440, 차단 UI 정렬 유지. AED 기기 버튼 차단 불변.
- **책상**: 6개 책상 뒤쪽 외곽 0.025m, 상판 높이·바닥 접점 불변. 의자·환자·보조대 겹침 없음. 장비 묶음이 책상 위에 그대로 있음.
- **PC**: 책상과 거울 0.08m 간격, 시선 가림 없음, 자기 반사가 보임.
- **범위·목적지**: 이동한 스테이션 5곳의 LocalArea는 방 안에 있고, 켜진 이동 목적지와 0.25m 여유가 있다. AED는 보류 항목이라 보고만 했다.
- **유지 확인**: 거울 farClip 20, 거울 루트·Surface 불변, 스크롤 본문·이동 목적지 Collider 불변.

## 7. 미확인 사항

- Unity 임포트·스탠드 외형·재질, 받침판 실제 접지와 시각적 안정감, 화면 가독성.
- 실제 손 닿는 범위(TQ·PB 키트, PC 먼 쪽 장비, AED 가슴), 앉은 환자와 벽 사이, 누운 환자 머리 쪽 동선.
- 문 열림 표현, 진입·출구 동선, 순간이동 후 몸 위치, 거울 반사와 몸·손·장비 간섭, 교육 흐름과 초기화 결과.

## 8. 사용자 확인 순서

0. Unity에 저장하지 않은 작업이 있으면 File > Save As로 별도 사본을 먼저 만든다. 그다음 디스크 변경을 반영해 비교한다. 변경 직전 씬은 §1 백업에 있다.
1. 두 씬을 다시 불러와 외형·재질과 스탠드 접지(받침판이 바닥에 붙고 기둥·거치대가 화면 뒤에 연결됨)를 확인한다.
2. 문을 통과해 입구 오른쪽 화면의 위치·가독성·스크롤을 확인한다.
3. 문 열림 범위와 진입·출구 동선이 막히지 않는지 확인한다.
4. AED·TQ·PB·PC 구역에서 장비를 집고 처치 부위·착용 위치에 손이 닿는지 확인한다. 특히 TQ·PB 키트, PC 덧신, AED 가슴.
5. 시작·실습·중단·완료·다시하기·재진입 후 장비가 새 위치로 돌아오는지 확인한다.
6. AED 기기 버튼과 교육 화면의 입력 차단을 확인한다.
7. PC·K1 거울 반사와 몸·손·장비 간섭, PC 책상이 반사를 가리지 않는지 확인한다.

장비가 손에 닿지 않거나, 환자·의자가 벽에 묻히거나, 초기화 위치가 어긋나면 미완료로 판단하고 위치를 기록한다.
