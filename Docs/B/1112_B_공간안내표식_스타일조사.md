# 구급법·화생방 공간 안내 표식 스타일 조사 — 2026-11-12

범위: 운영 씬 `B_FirstAid`·`B_CBRN`의 물체 주변 고리, 방향 화살표, 부착 윤곽, 접촉 영역, 배치 프리뷰. 교육 디스플레이 레이아웃·실제 장비 외형은 별도다.

**저장 파일 정적 조사와 검토용 도식이다. Unity 실행 캡처·실기 검증·통일 구현 결과가 아니다.** 기본 색은 저장 재질 값에 근거하며 도식의 실제 화면 색·선 폭·비례는 설명용이다. 여러 단계의 대표 표식을 한 카드에 함께 배치했다. 새로 작성한 파일은 이 문서와 PNG 2개뿐이다. 기존 코드·씬·재질·프리팹·폰트·설정은 수정하지 않았다.

## 2. 확인한 차이와 원인

1. 같은 행동 대상이 AED/PB는 노랑, TQ/K1/PC는 하늘색, KD-1은 민트로 표현된다.
2. 선 굵기가 3~9mm이며 불투명도도 다르다. 크기·역할 차이도 있으므로 전부 같은 수치로 강제하는 것은 적절하지 않다.
3. PB는 현재 일반 깊이 검사 재질과 Overlay가 혼재한다. 노란 고리 가림의 우선 수정 대상이다.
4. AED는 Mesh/LineRenderer 계열과 다른 uGUI 경로다. 단순히 공통 셰이더를 Image에 넣는 방식으로 통일하면 안 된다. 현 StatusMarkerOverlay에는 스프라이트 `_MainTex` 샘플링과 uGUI 마스킹·Stencil 대응이 없다. 실제 버튼·라벨·입력 차단판과 표시 전용 강조의 관계를 보존하며 Image용 재질 경로를 따로 검토한다.
5. 공통 Overlay 검사 `TrainingFieldSetup.MarkerMaterials`는 TQ·K1·PC 3종을 대상으로 하고 KD-1은 별도 확인한다. PB GuideNext/GuidePath와 AED Image의 가림·색 통일을 이 검사 PASS로 보증할 수 없다.

## 3. 통일 제안 — 아직 미적용

- 행동 대상은 기존 TQ/K1 계열 하늘색을 기준으로 맞춘다. 완료·부착 준비는 초록이되 체크·짧은 문구로 서로의 상태를 구분한다. 주의·보완 문구가 있는 경우만 노랑을 사용한다. AED 충격 강조의 주황빨강 점멸 의미·타이밍은 보존한다.
- **형태는 기능별로 유지한다.** 조작점은 원형 고리, 이동은 화살표/꺾쇠, 부착은 대상 윤곽, 접촉은 윤곽+낮은 알파 면이다. 모든 표식을 원으로 바꾸지 않는다.
- 조작 고리 약 4mm를 검토 출발점으로 삼되 작은 부품·몸 착용·접촉 영역별 크기와 두께는 실제 거리에서 사용자가 조정한다. 판정 반경·스냅 허용치·부위 위치를 스타일 작업으로 바꾸지 않는다.
- 표시 전용 선·윤곽은 현 `B/Common/StatusMarkerOverlay`를 재사용한다. 손·책상 앞에서도 보이는 효과가 생기므로 현재 필요한 대상만 표시하는 기존 단계·중단·완료 정책을 보존한다. Overlay가 카메라 컬링·클리핑이나 모든 후속 패스까지 무시하는 것은 아니다.
- 이미지의 검은 외곽선은 선택적인 가독성 제안이다. 현재 셰이더를 연결하는 것만으로 자동 생성되지 않는다. 검토를 거쳐 보조 선/별도 패스가 필요한지 정하며, 1차 가림 수정의 필수 범위로 확대하지 않는다.
- 흰 배치 프리뷰, 실제 장비 표시등, 상처 외형, 허용/금지 판정 영역은 역할이 달라 별도 유지한다. 완료 체크를 모든 과정에 상시 추가하거나 단계·교육 조건을 바꾸는 요구가 아니다.

권장 작업 순서는 PB 일반 재질 표식의 전용 Overlay 연결 → 기존 표식 색·선 기준 정리 → AED Image 표현 경로 검토 → 검사 범위 보완이다. 실제 구현 프롬프트·구현은 후속 요청 범위다.

## 4. 사용자 실행 확인 기준

구현 후 사용자가 직접 확인한다. 이번 조사에서는 Unity·Play·Simulator·batchmode·테스트·빌드를 실행하지 않았다.

1. 책상 위/옆/아래 시점과 손·장비로 일부 가린 상태에서 현재 행동 표식이 읽힌다.
2. 좌우 눈에서 고리 위치·선 두께·깊이감이 어긋나지 않는다(Quest 2 + Link).
3. 표시용 고리·화살표가 레이·잡기·실제 버튼 입력을 가로채지 않는다.
4. 교육 중단·계속·다시하기·완료 시 표식 표시 정책과 판정이 기존대로다.
5. KD-1 면·윤곽과 실제 접촉 판정 영역, PC 착용 고리와 몸 판정 반경이 일치한다.
6. AED 패드 부착 준비와 충격 점멸이 다른 상태로 오인되지 않고 입력 차단도 보존된다.
