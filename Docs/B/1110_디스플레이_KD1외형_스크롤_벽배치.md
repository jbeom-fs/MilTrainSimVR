- **K1 본문 위치**: K1 코드는 패널 안에 시작·다시하기 외의 조작 요소나 레이 대상 그래픽을 허용하지 않는다. 그래서 K1 본문 3개는 패널 밖(보드 직속)에 두고, CanvasGroup으로 해당 패널이 열린 동안에만 보이고 입력되게 했다. 저장 상태도 시작 화면만 보이게 맞췄다.
- **AED 완료 화면**: 완료 화면이 안내 화면 위에 겹쳐 나온다. 완료 화면 배경을 레이 차단으로 바꿔, 가려진 안내 본문의 스크롤바가 눌리지 않게 했다. 다시하기 버튼은 그보다 위에 있다.

## 5. 스크롤 동작과 조작법

- **기본 조작**: 오른쪽 스크롤바(파란 손잡이)를 컨트롤러 레이로 가리키고 트리거를 누른 채 위아래로 끈다. 본문 빈 곳을 누르고 끄는 것과 에디터 마우스 휠(눈금당 약 48 단위)은 보조 입력이다.
- **짧은 본문**: 스크롤이 잠기고 스크롤바가 숨겨진다(ScrollRect Clamped + AutoHide).
- **긴 본문**: 스크롤바와 손잡이 길이로 남은 양과 스크롤 가능 여부가 보인다.
- **입력 범위**: RectMask2D가 바깥 부분을 숨기고 레이도 막는다. XRI `TrackedDeviceGraphicRaycaster`가 `Graphic.Raycast`를 통해 마스크 필터를 거치는 것을 패키지 소스로 확인했다.
- **버튼과의 분리**: 시작·확인·다시하기 버튼은 PB 확인 버튼을 빼면 모두 본문 밖 고정 영역에 있다. 그래서 스크롤 끌기가 버튼 클릭으로 이어지지 않는다.
- **입력 설정은 그대로**: 새 EventSystem·Raycaster를 만들지 않았다. 기존 XRUIInputModule과 Canvas별 TrackedDeviceGraphicRaycaster를 그대로 쓴다. 조이스틱 스크롤 입력은 추가하지 않았다.

시작 위치 규칙(`TrainingScrollBody`, 실행 순서 1000으로 과정 코드보다 늦게 동작):
- **맨 위로**: 본문이 보일 때마다(시작·실습·최종 확인·완료 화면 전환, 다시하기, 중단 후 복귀, 교육장 재진입).
- **맨 위로**: 지정한 단계 문구가 바뀔 때(AED·PB·PC·KD-1 단계 줄, TQ 조작·최종 확인 제목, K1 단계 제목).
- **위치 유지**: 같은 단계에서 진행률·상태 문구만 매 프레임 바뀔 때는 위치를 되돌리지 않는다. 내용 높이가 바뀌면 ScrollRect가 유효 범위로 보정한다.
- **카드 보이기**: PB 확인 카드가 나타나면 카드 전체가 보이도록 스크롤한다.

## 6. 차단 UI

- **교육 보드 차단**: `Blocker_1_*` 6개(AED·TQ·PB·K1·PC·KD-1)를 새 화면 위치에 맞췄다. 화면 앞 4mm, 같은 회전·sortingOrder, 720×440, Shade 720×440, Message 619.2×378.4이며 저장 상태는 비활성이다. 검사 메뉴의 정렬 조건(위치 2mm·각도 0.5° 이내)을 같은 식으로 계산해 통과했다.
- **차단 범위**: 차단 UI가 스크롤바를 포함한 화면 전체를 덮는다. 그래서 다른 과정 사용 중, 중단 확인 중, 진입 준비 중에는 스크롤바와 시작 버튼 모두 차단 밖에서 누를 곳이 없다.
- **시작 게이트**: 과정의 시작 게이트·소유권 코드는 그대로다.
- **AED 기기 버튼 차단**: `Blocker_2_PowerButtonCanvas`, `Blocker_3_ShockButtonCanvas`는 옮기지 않았다.

- **입구 화면은 벽에 걸지 않았다.** 진입 위치에서 정면으로 보이는 벽이 8.6m 앞의 안쪽 벽뿐이고, 좌우 벽은 4m 옆, 입구 벽은 등 뒤다. 그래서 진입 위치에서 찾을 수 있고 출입을 막지 않는 기존 위치·방향을 유지하고, 외형·크기·스크롤만 바꿨다.
- **현장 패널(FieldPanel)**: 같은 높이로 화면 옆 벽에서 2cm 앞에 붙였다. 화면 테두리와 4cm 간격이다. 위치는 AED·PB·K1·PC·KD-1은 오른쪽, TQ는 환자 뒤를 피해 왼쪽이다.
- **과정 표지**: KD-1 표지는 스테이션 이동 후 벽 밖으로 나가므로 벽 14cm 앞(Z −9.30)으로 당겼다. 나머지 표지는 화면·거울 위쪽이라 간섭이 없다.

책상·거울·스테이션:

| 대상 | 조치 | 벽 간격 |
|---|---|---|
| K1 작업대 | 스테이션 전체 X −1.7→−2.675 | **2.5cm** |
| KD-1 작업대 | 스테이션 전체 Z −7.0→−8.565 | **2.5cm** |
| PC 거울 | 스테이션 전체 X 1.8→2.34 | 후면 지지대 끝 **1.0cm**, 바닥 접점 Y 0 |
| PC 작업대 | 위와 같이 이동 | 0.41m (거울이 먼저 벽에 닿음) |
| K1 거울 | 실습 위치를 향하는 방향(−140.4°)과 높이를 유지하고, 사용자 쪽으로 8.5cm 당겨 벽 모서리 쪽에 둠 | 후면 지지대 모서리 **1.0cm**, 작업대와 21cm |
| K1 후면 보기 화면 | 서쪽 벽 5mm 앞, 작업대 왼쪽 위 (−3.995, 1.55, −4.0) | 휴대용기와 가로로 떨어짐 |
| AED 책상 | 이동 없음 | 0.81m |
| TQ·PB 보조대 | 이동 없음 | 0.68m / 0.70m |

이동하지 않은 대상의 이유:
- **AED**: 누운 환자의 발끝이 이미 안쪽 벽 17cm 앞이다. 스테이션을 벽 쪽으로 옮기면 환자가 벽에 묻힌다. 책상과 AED 기기만 옮기면 실습 위치에서 손이 닿지 않는다.
- **TQ·PB**: 보조대가 앉은 환자 옆에 있다. 벽 쪽 한계는 의자 등받이(벽까지 0.3/0.5m)다. 보조대만 벽으로 보내면 0.65m 이상 멀어져 실습 위치에서 손이 닿지 않는다.
- 세 경우 모두 장비만 따로 옮기면 초기화 기준이 흩어지므로 그대로 두었다.

스테이션 이동은 StationRoot 하나만 바꿨다. 그 아래 환자·장비·실습 앵커·FloorAnchor·차단 UI·현장 패널의 상대 관계가 유지되고, 초기화 기준도 함께 움직인다.

이동에 따라 바꾼 것:
- **LocalArea(검사 정보용)**: 이동한 세 스테이션은 벽 밖으로 나가지 않도록 깊이만 줄였다.
  - K1 z 0.675/2.387 → 0.403/1.843
  - PC 0.653/2.295 → 0.583/2.155
  - KD-1 0.502/1.605 → 0.288/1.175
- **순간이동**: 화생방 `Walk_Rear`(안쪽 가로 통로)는 KD-1 작업대·실습 위치와 겹치게 되어 BoxCollider를 껐다. 좌우 복귀 통로는 Cross로 이어진다.
- **이동 후 간섭 확인**: 세 스테이션의 LocalArea는 방 안에 있고, 켜진 이동 목적지와 0.25m 여유를 두고 겹치지 않는다. 켜진 목적지는 작업대·거울과도 0.25m 안에 들지 않는다.

기존 상태에서 남은 사항(이번 변경 아님): 구급법 `Walk_Rear`(Z −8.95~−8.30)가 AED 책상(Z −8.63~−8.03)과 겹친다. AED·TQ의 LocalArea는 벽 밖으로 조금 나가 있다. 구급법 스테이션은 이동하지 않았으므로 그대로 두었다.

거울 반사 설정(screen·viewCamera·head 참조, farClip 20, Surface 크기, 루트 회전)은 보존했다. 거울 루트의 위치는 이번 사용자 요청에 따라 바뀌었으며, [거울 YAML 배치 기록](1110_거울외형_YAML배치_정적확인.md)의 "루트 위치 유지"는 그 시점 기록이다.

## 9. 미확인 사항

- Unity에서 새 스크립트가 컴파일되는지, 저장 YAML을 다시 불러오는지, 프리팹 연결과 재질 색이 맞는지(실제 색·광택 포함).
- 실제 TMP 줄바꿈 높이와 스크롤 필요 여부, 스크롤바 드래그 감도, 레이 흔들림이 있을 때의 조작감. 휠 감도 값 8은 XRI 소스(눈금당 6 단위) 기준의 계산값이다.
- 정면·사선 가독성. 특히 AED 2.04m와 PC 1.83m, 사선 30° 전후.
- 화면 테두리 깊이 7cm 때문에 사선에서 옆 현장 패널의 안쪽 가장자리가 일부 가려질 수 있음.
- K1 휴대용기 덮개를 열었을 때의 실제 궤적과 K1 화면·후면 보기 화면 사이 간섭.
- 몸·손·장비·순간이동 동선의 실제 간섭, 거울 반사 영상, 차단 UI 실제 입력.

## 10. 사용자 확인 순서

0. **Unity에 저장하지 않은 작업이 있으면** 먼저 File > Save As로 별도 경로에 사본을 저장한다. 그다음 디스크 변경을 반영해 비교한다. 이번 변경 전 씬은 §1 백업 폴더에 있다. 미저장 작업을 버리지 말고 사본과 비교한다.
1. 컴파일 오류가 없는지 확인하고 `B_FirstAid`·`B_CBRN`을 다시 연다. Missing Script·분홍 재질·누락 메시가 없는지 본다.
2. 8곳 외형과 재질(검은 케이스·금속 브래킷), 벽 접촉, 창·문·거울·다른 화면과의 간격을 확인한다. 입구 화면이 기존 위치에 있는지도 본다.
3. 각 실습 위치에서 정면·사선 가독성을 확인한다. 제목·단계가 고정되어 있는지, 본문이 잘리지 않는지 본다.
4. 좌우 컨트롤러로 스크롤바를 잡고 끈다. 짧은 본문에서 스크롤바가 숨는지, 끄는 중에 버튼이 눌리지 않는지 확인한다.
5. 과정마다 시작 → 실습(단계 변경 시 맨 위 복귀, 같은 단계 문구 갱신 중에는 위치 유지) → TQ 최종 확인 / PB 확인 카드 → 완료 → 다시하기 화면과 버튼을 확인한다.
6. 다른 과정 사용 중, 중단 확인 중, 진입 준비 중에 차단 UI가 화면 전체와 스크롤바를 막는지 확인한다. AED 기기 버튼 차단도 기존대로인지 본다.
7. 교육장을 나갔다 다시 들어와 본문이 맨 위에서 시작하는지 확인한다.
8. 손·장비·몸·순간이동 동선을 확인한다. 특히 K1 휴대용기 덮개와 K1 화면·후면 보기 사이, 화생방 안쪽 통로가 꺼진 뒤의 이동 경로.
9. K1·보호의 거울 반사(몸·장비, 다른 과정 아바타 제외)와 K1 후면 보기를 확인한다.

새 외형이 화면이나 거울을 가리거나, 차단이 새거나, 기존 교육 흐름이 바뀌면 미완료로 판단하고 해당 위치를 기록한다. 되돌릴 때는 백업 씬을 복원하고 신규 프리팹·재질·스크립트를 지우면 된다.
