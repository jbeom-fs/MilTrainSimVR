# 구급법·화생방 분리 운영 흐름 설계

작성일: 2026-11-06 · 담당: B

사용자 요구: 실제 예비군 교육장에서 교육받는 느낌을 제공하며, 하나의 공간에서 교육받을 수 있도록 설계한다. 구급법과 화생방은 명확히 구분한다.
상태: 사용자 공간 요구를 반영한 운영 흐름 수정안. 구현·실행 검증 완료를 뜻하지 않는다.

## 후속 사용자 지시 — 아래 초기 공간안을 대체하는 현재 기준

- 구급법과 화생방은 씬을 나누어도 된다. 하나의 공간 유지 기준은 **각 분야 내부**다. 구급법 씬에 AED·지혈대·압박붕대, 화생방 씬에 K1·보호의·KD-1을 배치한다. 두 분야 사이 씬 전환은 허용하며 같은 분야의 과정은 현장 이동으로 연결한다.
- 나중에 씬 전체의 교육장 모델이 들어올 수 있다. 환경 모델과 실습 기능을 분리하고 과정별 `StationRoot` 아래 장비·판정·안내·실습 범위·시작/복원 앵커를 구성한다. 편집 모드에서 루트 위치·수평 회전만 조정하면 새로운 위치에서 동작해야 한다. 루트 배율은 1을 기준으로 두며 실행 중 이동이나 임의 배율 변경은 이번 요구가 아니다.
- 잡기·착용으로 루트 밖 부모를 사용하는 오브젝트도 초기 소속 실습대와 복원 앵커를 유지해야 한다. 월드 좌표 캐시·전역 검색·공유 XR 참조·초기화 시점은 기존 코드에서 실제로 확인해 최소 보완한다. 단순 부모 변경만으로 재배치 지원 완료라 하지 않는다.
- 아래 본문의 ‘하나의 B 교육장 안 두 구역’은 정정 전 공간안이다. 현재 구현 프롬프트와 후속 설계는 이 절의 분야별 씬·이동 가능한 실습 루트 요구를 우선한다. 분야별 현장 교육·완료/중단·다시하기 원칙은 유지한다.

## 1. 하나의 교육장 안에서 분야 구분

B 교육장은 하나의 연속된 공간으로 설계한다. 내부에 구급법 구역과 화생방 구역을 배치하고, 각 구역의 실습 위치에서 교육을 받는다. 분야 구분은 표지·장비 배치·실습 동선·안내판으로 표현한다.

| 구분 | 구급법 구역 | 화생방 구역 |
|---|---|---|
| 구역 표지 | 구급법 교육 | 화생방 교육 |
| 실습 위치 1 | AED 사용 | K1 방독면 착용 |
| 실습 위치 2 | 지혈대 사용 | 보호의 착용 |
| 실습 위치 3 | 직접 압박·압박붕대 | KD-1 휴대장비 제독 |
| 현장 구성 초안 | 환자·사지 모형, 처치 장비, 과정별 안내판 | 방독면·보호장비·제독 장비, 착용·제독 실습 위치, 과정별 안내판 |
| 완료·중단 이후 | 같은 교육장 안에서 다음 실습 위치로 이동 | 같은 교육장 안에서 다음 실습 위치로 이동 |

- 교육장 입구에서 두 구역의 위치를 알아볼 수 있어야 한다. 입구 안내판은 배치와 동선을 안내하며, 여섯 과정을 실행하는 전체 화면 메뉴를 주 동선으로 삼지 않는다.
- 실습대·장비·안내판을 통해 현재 어떤 교육을 받는지 식별할 수 있게 한다. 실습을 마쳐도 주변 교육장과 다른 실습 위치의 공간적 관계가 유지돼야 한다.
- 분야 변경은 교육장 안에서 다른 구역으로 이동하는 행동이다. 상위 메뉴로 돌아갔다가 다른 분야를 선택하도록 강제하지 않는다.
- 과정별로 독립된 방·메뉴·배경으로 교체하는 사용자 경험은 이 공간 요구에 맞지 않는다.
- 실제 교육장 분위기는 배치·표지·장비·현장 안내로 구성한다. 교관 NPC·음성·강제 순차 이수를 이번 요구만으로 추가하지 않는다.
- 물리적 이동, 컨트롤러 이동, 지정 지점 텔레포트 중 이동 수단과 상세 크기·실내외 형태는 후속 공간 배치 설계에서 결정한다. VR 사용자가 실제로 넓은 면적을 걸어야 한다고 가정하지 않는다.

## 2. 공간 배치 개념과 동선

```text
                 하나의 B 교육장
┌──────────────────────────────────────┐
│ 구급법 구역          화생방 구역       │
│ · AED               · K1 방독면      │
│ · 지혈대            · 보호의         │
│ · 압박붕대          · KD-1           │
│                                      │
│       공통 이동 동선·입구 안내        │
└──────────────────────────────────────┘
```

좌우 배치는 개념도이며 확정 치수·실제 위치가 아니다.

교육장 입장 → 현장 표지로 구역 확인 → 실습 위치로 이동 → 해당 안내판 확인 → 교육 시작 → 실습 → 완료·요약 → 같은 위치에서 다시하기 또는 교육 종료 후 다음 실습 위치로 이동.

- 실습 위치에 접근하는 것만으로 교육을 자동 시작하지 않는다. 해당 위치의 시작 안내를 확인한 뒤 명시적으로 시작한다.
- 한 번에 진행하는 과정은 하나다. 다른 실습 위치로 이동해도 기존 과정이 진행 중이면 새 과정을 동시에 시작하지 않는다.
- 과정 시작 순서는 자유 선택을 기본안으로 둔다. 실습 위치의 나열 순서를 필수 이수 순서로 해석하지 않는다. 실제 운영에서 순차 교육이 필요하면 별도로 정한다.

## 3. 실습 위치의 안내와 시작

- 각 실습 위치에 과정명·목표·기본 조작·교육 시작을 표시한다. 교육 화면은 기존 KD-1 기준의 챕터/단계 제목·설명·현재 행동·진행 표시를 재사용한다.
- 기존 과정별 단계 수·판정·장비 조작은 유지한다. 공통 교육장을 이유로 모든 과정을 같은 단계 수로 바꾸지 않는다.
- 시작 대기 중에는 진행을 위한 조작을 잠근다. 둘러보다가 다른 위치로 이동한 것만으로 중단 회차를 만들지 않는다.
- 실습 시작 시 해당 과정만 조작·안내를 활성화한다. 다른 실습대의 장비 입력이나 안내가 현재 실습과 충돌하지 않게 한다.
- 보호의 과정에 방독면 착용을 중복 포함하거나 KD-1을 피부 제독 과정으로 바꾸지 않는다. 실제 효능·술기 합격 판정을 새로 추가하지 않는다.

## 4. 완료·다시하기·교육 종료

| 입력·상황 | 동작 | 이후 상태 |
|---|---|---|
| 마지막 조건 충족 | 해당 위치에서 기존 완료·수행 요약 표시 | 완료 상태로 요약 확인 |
| 완료 후 다시하기 | 해당 과정의 기존 초기화 경로 사용 | 같은 실습 위치에서 시작 대기 |
| 완료 후 교육 종료 | 완료 결과 보존, 장비·안내 정리 | 같은 교육장 안에서 다음 실습 위치로 이동 가능 |
| 같은 위치에서 새 회차 시작 | 초기 상태 확인 후 새 교육 시작 입력 | 이전 회차 진행과 분리 |

완료 직후 사용자를 입구나 메뉴로 자동 이동시키지 않는다. 다른 과정으로 이동할 때도 배경을 교체하거나 메뉴를 거치지 않는다. 장비·진행 초기화와 사용자 이동을 분리하며, 다시하기만으로 사용자의 위치·시점을 강제 변경하지 않는다.

과정 간 장비·착용 상태의 승계는 기본안에 두지 않는다. 기존 과정의 초기화 경로로 정리해 새 실습이 이전 장비·접촉·완료 기록을 이어받지 않게 한다. 장비를 착용한 채 다음 과정으로 이어지는 연속 교육이 필요하면 별도 설계한다.

## 5. 진행 중 중단·다른 위치 이동

- 실습 중에는 현장 안내에서 `교육 중단`을 사용할 수 있게 한다. 장비를 내려놓아야만 사용할 수 있는 위치에 두지 않는다.
- 중단 요청 시 `교육을 중단할까요?`와 `계속하기` / `중단하기`를 표시한다. 확인 중 장비 조작·판정 시간·자동 단계 진행을 멈춘다. 실제 일시정지 연결은 통합 구현에서 확인해야 하는 신규 요구다.
- 계속하기는 확정 진행과 장비 상태를 보존한다. 직접 압박처럼 연속 유지가 필요한 동작은 중단 전후 시간을 합산하지 않는다.
- 중단 확정 시 현재 회차를 중단으로 정리하고 잡기·진행·안내·착용 장비를 해제·복원한다. 사용자는 같은 교육장에 남으며 다음 실습 위치로 이동할 수 있다.
- 실습 범위를 벗어나면 현재 과정을 일시 정지하고 계속하기·중단하기를 안내하는 방안을 기본안으로 둔다. 실습 범위와 복귀 조건은 공간 배치·과정별 조작 범위를 확인해 결정한다. 이탈만으로 완료·중단을 자동 확정하지 않는다.
- 다른 실습대에 접근해도 진행 중인 과정을 자동 중단하거나 새 과정을 자동 시작하지 않는다. 기존 과정을 정리한 뒤 다음 과정을 시작한다.

## 6. 사용자 확인 기준

아래는 구현 이후 사용자가 직접 확인할 기준이며 현재 통과 결과가 아니다.

| 항목 | 기대 결과 |
|---|---|
| 교육장 입장 | 하나의 연속된 공간 안에서 구급법·화생방 구역을 식별 가능 |
| 구역 구분 | 표지·장비·실습대·동선으로 두 분야의 범위가 명확함 |
| 실습 위치 이동 | 메뉴 복귀·독립 배경 교체 없이 교육장 안에서 이동 |
| 각 과정 시작 | 해당 위치에서 안내 확인 후 명시적으로 시작. 접근만으로 자동 시작 없음 |
| 다른 실습대 접근 | 현재 과정과 동시 진행·다른 장비 오조작 없음 |
| 중단 취소·확정 | 취소는 같은 과정 재개, 확정은 정리 후 교육장 안에 잔류 |
| 완료·다시하기 | 요약 확인과 초기화가 같은 위치에서 이뤄짐. 강제 입구 이동 없음 |
| 다음 과정·분야 이동 | 이전 장비·진행이 남지 않으며 교육장 공간의 연속성 유지 |

## 7. 다음 설계로 넘길 사항

1. 교육장의 형태·크기, 구역 경계·실습대 배치·이동 수단·안내판 위치를 구체화한다.
2. 하나의 연속된 공간을 유지할 실제 씬 구성과 XR Origin·카메라·입력·EventSystem 소유권을 설계한다. 과정마다 Single 씬을 교체하는 이전 안은 현재 기본안으로 사용하지 않는다.
3. 과정별 활성화·일시정지/재개·중단·초기화 연결과 실습 범위를 확인한다. 기존 개별 씬은 기능 참고·보존 대상으로 두며 교육생이 과정마다 개별 씬을 이동해야 한다고 가정하지 않는다.
4. A/C와 교육장 출입 지점·결과 전달·빌드 진입점을 협의한다. 교육장 밖 앱 연결과 교육장 내부 구역 이동을 구분한다.

이 문서의 최초안에 있던 분야별 선택 화면·상위 메뉴를 통한 분야 변경은 사용자 공간 요구 반영 전 초안이다. 현재 기준은 하나의 교육장 안에 구급법·화생방 구역과 여섯 실습 위치를 배치하는 흐름이다.
