# A 공간 모델의 B 반입을 위한 정적 조사 — 2026-11-06

## 조사 범위와 결론

`Assets/A/Scenes/A_Sandbox.unity`의 저장된 계층·Transform·BoxCollider·메시/재질 참조와 A의 공간 생성 코드, B 두 운영 씬의 저장된 실습범위를 읽었다. A 파일·씬을 변경하거나 Unity를 실행하지 않았다. 아래 수치는 저장 데이터의 치수이며 실제 VR 가독성·접근성·성능을 확인한 결과가 아니다.

**1차 후보는 내무반·조립실의 빈 외형을 B 전용 교육실로 사용하는 방식**이다. 벽·바닥·천장·창문·문 외형을 가져오고 기존 침대·관물대·A 교육 기능은 제외한다. B의 세 실습대는 기존 일렬에서 2+1 또는 ㄷ자 배치로 검토해야 한다.

**현재 B 일렬 배치를 유지하는 것이 우선이면 사격장 후방 대기 영역도 후보**다. 폭은 충분하지만 독립 교육실로 만들려면 B 작업본에서 전방 마감/가림을 추가해야 한다. 사격장 전체는 세 실습대에 비해 크다.

같은 외형을 B_FirstAid/B_CBRN의 각 환경으로 사용하되 표지와 장비·배치로 분야를 구분할 수 있다. 아직 반입 공간이나 새 배치를 확정하거나 구현한 것은 아니다.

조사도: [저장 씬 평면 비교](1106_A공간_정적조사도.png). Unity 화면 캡처나 최종 배치 도면이 아니다.

## 1. 공간별 치수

| 후보 | 저장 데이터 기준 | 기존 구성 | 반입 판단 |
|---|---|---|---|
| 내무반·조립실 `Room_Assembly` | 바닥 8.00×9.44m, 천장 아래 약 2.644m, 바닥 윗면 Y=0 | 침대 8개·관물대 8개, 중앙 작업대, TV/수납장, 창문·기타 집기 | 빈 외형을 교육실로 활용하기 좋음. 기존 집기를 전부 가져오면 실습 공간이 줄어듦 |
| 사격장 전체 `Room_Range` | 바닥 폭 15.50m, Z=-3.4~32로 길이35.40m, 천장 아래4.67m, 바닥 윗면Y=0 | 사대7개, 표적·레일·방호둑, 사격 안내 | 넓은 강당형 공간 후보. 불필요 사격 시설과 빈 공간이 많음 |
| 사격장 후방 대기 영역 | 폭15.50×깊이6.00m, Z=-3.4~2.6 | 양옆 출입문과 후방 대기 공간. Floor_Firing이 이 구간 바닥 | B 일렬 배치에 유리. 기존 사격장에서는 독립된 방이 아니므로 B 작업본에서 전방 마감 필요 |

바닥 면적은 내무반 약75.5㎡, 사격장 전체 약548.7㎡, 후방 대기 영역 약93㎡다. 집기나 벽 안쪽 경계를 뺀 순수 실습 가능 면적을 뜻하지 않는다.

### 치수 해석 주의

- 내무반 Floor 위치(0,-0.05,-4.72), scale(8,0.1,9.44)다. 바닥 Z 범위는 -9.44~0이다. 북쪽 벽 안쪽면은 약Z=-0.1이라 실내 유효 길이는 바닥 길이보다 약0.1m 짧다.
- 내무반 양옆 벽 안쪽은 X=±4이다. 북쪽 좌우 벽 일부의 메시 외곽은 X=±5.2까지 뻗어 있으므로, 벽 전체 Renderer 경계의 폭을 실내 사용 폭으로 잡으면 안 된다.
- Room_Assembly 루트는 (0,0,0), Room_Range 루트는 (30,0,0)이고 배율은1이다. 서로 같은 씬에 있지만 실제 연결 복도 없이 문 이동 기능으로 오가는 구성이다. 이 조사에서는 각 방의 로컬 공간을 비교했다.
- 내무반 문은 외형 폭 약1.016m·높이2.644m, 사격장 문은 외형 폭1.968m·높이2.284m다. 문틀 안쪽 통과 폭을 측정한 수치는 아니다.

## 3. 반입 후보와 제외 대상

### 내무반 외형 우선 후보

- `Room_Assembly/Shell`: 벽, 바닥, 천장, Ceiling_Joints, 창문 외형.
- `Room_Assembly/Door_Range`: 문 모델 외형만. 손잡이의 DoorTransition 및 A 도착점 참조는 제외한다.
- `Room_Assembly/Barracks`에 들어 있는 천장 형광등 모델: 방 천장 외형과 위치를 확인하여 필요한 것만 선택한다. Barracks 전체를 복사하지 않는다.
- 소화기·포스터 등은 교육실 분위기에 필요할 때만 선택한다. 중앙 Desk와 총기/패널은 A 교육 구성과 분리한다.
- 기존 침대8/관물대8, 총기·조작 안내·훈련 패널·Controller, A XR/카메라/EventSystem, Points와 방 이동 기능은 기본 반입에서 제외한다.
- 창문이 있으므로 B에서 보일 창밖 배경은 후속 결정 대상이다. A의 2km Outdoor 전체를 기본 의존성으로 가져올 필요는 없다.

### 사격장 외형 후보

- `Room_Range/Shell`의 필요한 벽/바닥/천장과 문 외형, 형광등 모델.
- 사격 전용 Backstop_Berm, Targets_25m, Lane4, Booths, 사로 번호·안전수칙·레일은 기본 제외 후보다.
- 후방만 쓰는 경우에는 Floor_Firing/Ceiling_Firing이 별도 오브젝트라 구간을 구분하기 쉽다. 다만 옆 벽/천장 마감과 전방 벽을 포함한 별도 B 공간 구성이 필요하다.
- 저장된 Light 컴포넌트는 내무반9개(9개 활성), 사격장25개(19개 활성)다. 이는 인라인 저장 오브젝트의 활성/부모 상태를 읽은 집계다. 조명 전체를 무조건 복사하는 대신 B에서 필요한 조명만 정하고 기존 B 조명과 중복 여부를 확인한다. 성능 수치는 측정하지 않았다.

## 4. 단일 건물 FBX가 아님

A 공간은 씬의 기본 도형·저장 Mesh 자산·FBX 집기를 조합한 구조다. Models 폴더의 FBX만 복사하면 같은 공간이 완성되지 않는다. 씬 계층의 배치와 아래 의존성을 함께 보존해야 한다.

| 요소 | 실제 참조 예 |
|---|---|
| 벽 메시/UV | Assets/A/Models/Wall/Meshes/WallBox_*.asset |
| 벽 재질 | Assets/A/Models/Wall/Materials/Wall.mat 및 연결 텍스처 |
| 내무반 바닥 | Assets/A/Models/Floor/Materials/Floor.mat 및 연결 텍스처 |
| 천장 | Assets/A/Models/Ceiling/Materials 및 Meshes/CeilingGrid.asset |
| 사격장 바닥 | Assets/A/Models/Floor_2/Materials/Range_Floor.mat |
| 사격장 후방 바닥/천장 | Assets/A/Materials/Range/Range_FloorFiring.mat, Range_CeilingTile.mat |
| 형광등/문/창문 | Assets/A/Models/CeilingPanel, Door 또는 DoubleDoor, Window 내 FBX·재질·텍스처 |

벽의 WallBox 메시 자체는 단위 상자이고 오브젝트 scale이 실제 크기다. UV는 그 크기에 맞춰 생성돼 있다. CeilingGrid는 실제 위치가 정점에 들어간 별도 메시다. 오브젝트 Transform을 모두0/1로 초기화하거나 스케일만 합치는 반입은 형태/무늬/위치를 깨뜨릴 수 있다.

B 전용 독립 작업본을 만들 때는 필요한 메시·재질·텍스처에 새 GUID를 부여하고 B 사본끼리 참조를 다시 연결해야 한다. 원본 meta의 GUID를 그대로 복제하거나, A 재질/메시에 변경을 Apply하는 방식은 사용하지 않는다. 공용 URP 셰이더/패키지는 읽기 참조를 유지하며 수정하지 않는다. A의 공간 생성 Editor 코드는 A 경로에 메시를 저장하므로 B 반입 작업에서 원본 빌더를 실행하지 않는다.

## 5. 권장 다음 작업

1. 내무반 빈 외형과 사격장 후방 중 사용할 후보를 결정한다. 원본 A 변경 금지는 어느 안에서도 유지한다.
2. 선택된 공간의 계층·메시·재질·텍스처 반입 목록을 확정한다. 필요한 경우 형상 수정은 B 작업본에서 Blender로 수행한다.
3. B의 EnvironmentRoot 아래 전용 환경을 구성하고 기존 SceneSystems/XR/교육 코드를 유지한다.
4. StationRoot 위치·수평 회전만으로 각 세 실습대와 EntryAnchor/ExitAnchor, 바닥 이동 영역을 배치한다. 실습대 배율은1을 유지한다.
5. 반입 후 사용자에게 변경된 공간·충돌·동선·안내판 확인만 요청한다. 기존 교육 기능 검증 완료를 철회하지 않는다.
