## 4. 새 UI Overlay 셰이더

`Assets/B/Shaders/Common/UIStatusMarkerOverlay.shader` — `B/Common/UIStatusMarkerOverlay`, 재질 `MAT_Field_AED_GuideImage_Overlay`(흰 tint).

- 기본 UI 셰이더와 같은 입력·처리: 스프라이트 `_MainTex`·알파, `_Color`, `_TextureSampleAdd`, Stencil, RectMask2D(`_ClipRect`·softness), 알파 클립, ColorMask, 캔버스 감마 정점 색 옵션, premultiplied 블렌드, 인스턴싱·스테레오 매크로.
- 차이: `ZTest Always`(깊이로 가려지지 않음). **Queue는 Transparent 유지** — 같은 큐의 캔버스 순서가 남아, 버튼 Canvas 앞 4 mm의 차단판 Shade(α .88)가 중단 중에도 계속 전원·충격 강조를 덮는다. 차단판 재질은 바꾸지 않았다.
- 참고: 설치된 Unity에는 UI-Default 셰이더 원본이 없다(`Resources/CGIncludes/UnityUI.cginc`만 있음). 그 include, XRI 샘플 `UI/NoZTest`, Unity 기본 UI 셰이더 구조를 기준으로 작성했다. 공통 `StatusMarkerOverlay`는 수정하지 않았다.

## 5. 별도 크기 등급·미적용 사항

- PB 장비 안내 메시(런타임 생성, 코드값): 끝 부착 목표 고리 선 5 mm(반지름 = 부착 거리 0.08 m, 중심 고리 12 mm), 테이프 틀 3 mm(100×25 mm, 코드 상수), 감기 영역 상자 모서리 4 mm. 놓을 자리·영역 윤곽이라 조작 고리 기준을 강제하지 않았고 코드 변경을 피했다.
- PB 상처 윤곽 4 mm 유지(상처 위치 윤곽).
- PB 감기 영역은 3D 상자 모서리 윤곽만 유지했다. 낮은 알파 면은 생성 코드 변경이 필요하고 팔 주변을 덮을 수 있어 추가하지 않았다.
- AED 부착 준비 라벨(배경 Image + TMP)은 기존 재질 유지. 배경만 Overlay로 바꾸면 깊이 검사 글자를 덮기 때문이다. 라벨은 윤곽 아래 −112 위치라 준비 윤곽과 겹치지 않는다.
- KD-1 생성 도구(개별 씬용)는 기존 재질 색을 보존하고 최초 생성 때만 민트를 쓴다. 운영 씬은 새 전용 재질을 쓰므로 덮어쓰기 경로가 아니다. 운영 씬을 다루는 생성·갱신 도구는 없다.

## 7. 실행 확인이 필요한 위험

1. **PB 메시 표식의 정점 색**: Guide_Ring·TapeFrame·WrapZone 메시는 정점 색이 없는데, Overlay 셰이더는 정점 색 × `_BaseColor`를 쓴다. Unity가 빠진 COLOR를 흰색으로 채우는 것을 전제했다. 검게 보이거나 보이지 않으면 표시용 메시에 흰 정점 색을 쓰는 최소 코드 보완이 필요하다.
2. UI 강조는 Transparent 큐라 그 뒤에 그려지는 다른 반투명 물체에는 덮일 수 있다. 불투명 손·장비·패드에는 가려지지 않는다.
3. 전원 강조는 기존대로 중단 중에도 켜져 있다. 차단판 Shade가 덮는지 확인한다.
4. 장비명 TMP Overlay: 동적 폰트 아틀라스·대체 글꼴 재질 생성과 양안 표시를 확인한다.
5. 손·책상 위로 항상 보이는 표식의 혼잡도와 가독성. 최종 크기·굵기는 실기로 정한다.

## 8. 사용자 확인 순서

1. Unity 재로드·재컴파일 → `B/교육장/3. 구급법 검사`, `4. 화생방 검사` → 새 FAIL·Missing·셰이더 오류 없음(새 표식 스타일 Check 포함).
2. 압박붕대 드레싱을 책상 위에서 여러 각도로 보기 → 안내 고리 전체가 보이고 드레싱 조작·판정은 기존대로. 끝 부착·테이프·감기 영역 메시도 보이는지(위험 1).
3. 6개 과정의 집기·조작·이동·착용·접촉 안내 → 하늘색과 역할별 형태가 일관되고, 불필요한 표식이 동시에 나타나지 않음.
4. AED 패드 부착 준비·충격 단계 → 초록 준비 표시와 충격 점멸이 구분되고 실제 버튼 입력 정상.
5. 중단 확인 중 뒤쪽 장비·버튼 차단(전원 강조가 Shade 아래로 어두워지는지) → 계속하기·다시하기·종료 후 표시와 상태 정상.
6. KD-1 미수행 번호(하늘색) → 완료 체크(초록) 전환 정상. 보호의 착용 고리와 몸 판정 위치 일치.
7. Quest 2 + Link에서 좌우 눈의 표식 위치·가독성, 손·책상에 겹쳤을 때의 표현, 성능.
