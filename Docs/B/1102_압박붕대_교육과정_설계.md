# 직접 압박·압박붕대 교육 과정 설계 — 기본형

작성: B · 2026-11-02 (Asia/Seoul). 상태: **설계 초안. 구현·모델링·실행 검증 없음.**

## 1. 이번 결정과 범위

- 사용자 선택: **제품 미정, 드레싱과 롤붕대를 사용하는 기본형**으로 설계한다.
- 사용자 지시: **모델링은 추후 Blender에서 진행한다. 이번에는 모델·메시·재질·Prefab을 제작하지 않는다.** 부품과 조작점 요구사항만 기록한다.
- 지혈대는 사용자 검증 완료 및 추가 작업 불필요 보고를 기준으로 현재 범위를 마감한다. 확인한 최신 커밋은 `6b81667`이다. 다른 과정·헤드셋의 개별 항목 통과로 확대하지 않는다.
- 개발 목표는 장비 하나가 아니라 **시작 → 직접 압박 연습 → 붕대 감기·고정 → 처치 후 확인 → 완료 → 다시하기**까지 한 과정이다.
- 이번 초안은 완료 후 다시하기만 제공한다. 교육 중 다시하기·확인창은 넣지 않는 안이다. 10/29 원안의 중간 다시하기와 달라지는 설계 선택이며, 압박붕대에 대한 사용자 확정 지시로 기록하지 않는다.
- 교육 선택 허브·과정 복귀·팀 메뉴 연결은 후속 통합 범위다. 기존 AED·K1·지혈대 기능은 변경하지 않는다.

## 2. 무엇을 배우는 과정인가

팔에 외부 상처가 난 부상자를 대상으로, 출혈 부위를 찾아 드레싱을 대고 직접 압박하는 동작, 드레싱을 유지하며 붕대를 감아 고정하는 동작, 처치 후 상태를 확인하는 순서를 익힌다.

학습 목표:

1. 드레싱은 상처를 덮는 부분이고 붕대는 이를 고정하는 부분임을 구분한다.
2. 직접 압박은 상처 위에 지속해서 압력을 가하는 처치임을 이해한다.
3. 감기와 고정으로 넘어갈 때 드레싱 위치와 압박 유지가 중요함을 이해한다.
4. 고정 후에도 재출혈과 손 쪽 혈액순환 이상을 확인해야 함을 안다.

일반 출혈 처치에서 직접 압박, 출혈 조절 뒤 압박 드레싱 적용, 재평가가 다뤄진다. [AHA·미국 적십자 응급처치 지침][S1]을 교육 원리의 근거로 사용한다. 생명을 위협하는 출혈을 붕대 감기 연습 때문에 지연하는 상황은 이번 시나리오에 넣지 않는다.

VR이 확인하는 것은 **도구 위치·방향, 손의 접촉·추적, 감기 경로, 가상 고정 상태와 확인 행동**이다. 실제 압박력·혈류·지혈 성공·의료적 숙련도는 측정하지 않는다. 짧은 게임 내 유지 시간이 실제 권장 압박 시간으로 보이지 않도록 한다.

## 3. 훈련 상황과 공간

| 항목 | 설계안 |
|---|---|
| 상황 | 안전이 확보된 훈련 공간. 도움 요청과 기본 보호 조치는 수행된 상황으로 설명 |
| 대상 | 성인 교육용 인체 한 명, 팔의 접근 가능한 부위에 상처 한 곳 |
| 팔 자세 | 팔을 안정적으로 지지하되 사용자가 붕대를 아래쪽까지 돌릴 공간 확보 |
| 상처 | 드레싱으로 덮는 외부 상처. 관통 이물·절단·깊은 상처 패킹·골절은 제외 |
| 도구 | 준비된 드레싱, 롤붕대, 마감용 고정 테이프 작업본 |
| 초기 배치 | 도구는 열린 트레이에 준비. 포장 뜯기·가위·실제 무균술 평가는 이번 범위에서 제외 |
| 입력 | 두 컨트롤러. 양손 역할 교환 가능. 장비 조작은 근거리 손 조작, UI는 레이 선택 |
| 시점 | 몸이나 실제 책상에 컨트롤러를 세게 누르지 않아도 모든 조작 가능 |

팔 선택은 장면 구성안이다. 실제 적용 교안에서 허용하는 부위와 맞춰 확정한다. 특정 부대의 실제 처치 상황 전체를 재현한다고 표시하지 않는다.

## 4. 교육 흐름

시작화면 → 아래 실습 단계 → 최종 확인 → 완료화면 → 완료 후 다시하기 → 시작 대기.

| 순서 | 단계 | 교육생 행동 | VR에서 확인할 조건 |
|---|---|---|---|
| 1 | 상황·도구 확인 | 상처 위치와 드레싱·붕대의 역할을 안내받고 해당 도구를 확인 | 이번 회차의 대상·도구 확인 기록 |
| 2 | 드레싱 배치 | 드레싱을 잡아 상처 위에 올바른 면과 방향으로 가져감 | 상처를 덮는 위치·방향이 현재 유효 |
| 3 | 직접 압박 동작 연습 | 드레싱 위에서 손을 유지. 두 손을 겹쳐 누르는 동작을 안내하고 두 컨트롤러 위치로 접촉 연습 | 드레싱 위치와 필요한 손의 접촉·추적이 연속 유효 |
| 4 | 감기 전 확인 | 한 손으로 드레싱을 유지하면서 손 쪽 상태에 관한 훈련 정보를 확인 | 직접 압박 동작 연습 기록 + 유효한 유지 + 감기 전 확인 기록 |
| 5 | 붕대 감기 | 유지하는 손을 남기고 다른 손으로 붕대 롤을 안내 경로에 따라 팔 주위로 이동 | 드레싱 유지, 순차 경로 통과, 손 추적, 관통 없는 감김 상태 |
| 6 | 끝부분 고정 | 감기가 끝난 붕대 끝을 지정 위치에 두고 준비된 테이프로 고정 | 감김 상태·끝 위치·테이프 배치가 현재 유효 |
| 7 | 처치 후 확인 | 상처 주변과 손 쪽 상태를 확인하고 재출혈·순환 확인 항목에 응답 | 고정 상태 유지 + 감기 후 확인 기록 |
| 8 | 최종 확인 | 완료 가능한 상태와 수행 항목을 확인하고 확인 버튼 선택 | 필수 현재 상태와 이번 회차 기록을 입력 순간 재검사 |

위 단계 수는 화면 하나씩 따로 개발하라는 의미가 아니다. 한 과정의 설계 단위이며 내부 구현 순서는 의존성에 맞춰 나눈다.

### 직접 압박에서 감기로 넘어가는 의미

- 접촉 연습을 마치면 `직접 압박 동작 연습 완료`로 표시한다. `충분한 압력`, `지혈 성공`, `실제로 출혈이 멎음`으로 판정하지 않는다.
- 이후 감기는 **출혈이 조절된 상태를 가정하는 훈련 구간**임을 안내한다. 손의 접촉 시간을 채웠다는 이유만으로 혈액 표현을 자동으로 멈춰 의료 효과를 암시하지 않는다.
- 출혈 조절의 실제 임상 판단은 시스템이 수행하지 않는다. 출혈이 계속되거나 다시 시작될 때 재평가가 필요하다는 내용은 완료 후 교육 안내에 포함한다. 구체적인 처치 전환 분기는 적용 교안과 함께 별도 확정한다.
- 감기 전 확인과 붕대 준비 중에는 한 손의 드레싱 유지가 계속 필요하다. 그 상태에서 다른 손으로 UI·붕대를 조작할 수 있게 한다.
- 두 손 직접 압박에서 한 손 유지로 바뀌는 부분은 VR 조작의 축약이다. 실제 압박력 유지가 검증된 동작으로 평가하지 않는다. 배포용 교육 전에는 이 전환을 교육 담당자가 검토해야 한다.

### 처치 전후 상태 확인의 표현

미국 적십자는 붕대 적용 전후 손상 부위 아래쪽의 혈액순환 확인과 재출혈 관찰을 다룬다. 손·발의 색·온도·감각 등이 확인 내용이다.[S2]

- 감기 전과 후의 확인 기록을 따로 둔다. 한 번의 클릭으로 둘 다 완료하지 않는다.
- 손 쪽 위치를 표식으로 안내하고, 가상 부상자의 응답·상태 카드로 확인할 내용을 제시한다.
- `재출혈 여부`, `손 쪽 색·온도·감각 변화`를 구분해 확인하게 한다. 컨트롤러 접촉만으로 실제 맥박·피부 온도·감각을 측정했다고 표시하지 않는다.
- 정상 고정 뒤 상태를 확인하는 한 가지 안내형 시나리오를 기본으로 한다. 이상 상태의 진단·풀기·재처치까지 포함하는 분기는 이번 초안에 추가하지 않는다.
- 실제 관찰·질문 대신 정보를 확인하는 VR 축약이므로 결과는 `상태 확인 항목 수행`으로 기록한다. `정상 혈류 입증`으로 기록하지 않는다.

## 5. 양손 조작과 복구

### 드레싱과 손

- 드레싱은 본체 잡기점을 가지며 실제 상처 접촉 영역과 선택용 Collider를 구분한다.
- 유효 위치에 가까워지면 배치 미리보기를 제공한다. 가까이 왔다는 이유만으로 손에서 분리해 완전 고정하지 않는다.
- 직접 압박 연습에서는 잡기 입력 세기나 피부 관통 깊이를 압박력으로 쓰지 않는다. 정해진 접촉 영역과 손 추적 유효성만 사용한다.
- 연속 유지 설정은 개발용 `접촉 동작 확인 시간`이다. 숫자를 의료적 압박 시간으로 가르치지 않는다. 프로토타입 조정값과 교육 내용 값을 분리한다.
- 접촉 이탈·놓기·관련 손 추적 소실 시 연속 유지량은 0이다. 끊긴 접촉을 합산하지 않는다.
- 양손 역할은 바꿀 수 있다. 인계 중 최소 한 손의 유효한 유지가 있어야 연속 유지로 인정하며, 단순 양손 동시 입력으로 두 개의 장비 소유자가 생기지 않게 한다.

### 붕대 감기

- **손으로 잡는 것은 이동하는 붕대 롤**, 상처 위에 남는 것은 드레싱이다. 이미 감긴 띠 전체를 잡아 팔에서 끌어내리는 조작은 제공하지 않는다.
- 한 손은 드레싱을 유지하고 다른 손은 롤을 팔 주위로 움직인다. 현재 다음 경로만 화살표·원형 표식으로 강조한다.
- 경로는 팔 표면 밖에 있는 연속된 유도 구간으로 구성한다. 최종 위치에 바로 가져가거나 팔을 가로질러 통과해도 완료되지 않는다.
- 빠른 정상 이동은 구간 사이의 실제 유효 이동으로 판정하되, 추적 소실 뒤의 위치 점프는 경로 통과로 사용하지 않는다.
- 감긴 부분은 완료된 유효 경로에 따라 보이고, 미완료 구간은 롤을 따라 움직인다. 자유 천 물리는 사용하지 않는 설계다.
- 감기 방향·회전 수·겹침·장력의 교육 기준은 미확정이다. 경로 개수와 허용오차를 의료 기준으로 만들지 않는다. 기본형의 구체적인 감기 방법은 적용 교안 검토 후 고정한다.

### 고정과 압박 유지의 전환

- 끝부분 배치와 테이프 고정은 별도 사용자 동작이다. 마지막 경로 통과만으로 자동 고정하지 않는다.
- 드레싱을 유지하는 손은 고정이 끝날 때까지 유지한다. 고정 뒤에는 손을 놓아도 가상 감김 상태가 보존된다.
- 기본형은 별도의 압박봉·전용 후크를 추가하지 않는다. 마감 테이프는 설계용 임시 선택이며 실제 사용 재료·방식은 교안과 함께 확정한다.
- 지나치게 당기기나 특정 컨트롤러 간 거리만으로 `적정 압력`을 판정하지 않는다.

### 문제 발생 시 복구

| 상황 | 동작과 안내 |
|---|---|
| 잘못된 위치·뒤집힌 드레싱 | 진행 보류, 올바른 면·위치 미리보기 |
| 직접 압박 중 손 이탈 | 유지량 초기화, 드레싱 위 접촉점 강조 |
| 감기 전후 준비 중 유지 손 놓기 | 감기 진행 보류, 유효 유지부터 복구 |
| 붕대 롤 놓기 | 미완료 부분을 안정된 위치에 유지하고 진행 정지. 재선택 뒤 현재 위치를 새 이동 기준으로 사용 |
| 추적 소실·앱 포커스 상실 | 연속 동작과 경로 계산 정지. 복귀 후 새 위치 표본으로 시작, 소실 중 이동 무효 |
| 경로 건너뛰기·팔 관통 | 성공 처리 없음, 다음 유효 구간과 방향 재안내 |
| 손 접촉만 끊겼고 드레싱·완료 경로는 그대로 | 유효 유지 복구 후 미완료 경로부터 재개. 중단 전 압박 유지 연습의 단순 이력과 현재 상태를 구분 |
| 드레싱이 실제로 벗어나 기존 감김을 신뢰할 수 없음 | 해당 감김·고정·후속 확인을 무효화하고 붕대 적용 구간을 다시 연습. 잘못된 띠 모양을 남긴 채 복구했다고 하지 않음 |
| 고정 후 재조작으로 적용 상태 변경 | 감기 후 확인·최종 확인 수락을 철회. 현 상태 복구와 새 확인 필요 |

복구는 전체 교육을 처음부터 시작하는 기능과 다르다. 교육 단계 번호를 자동으로 되감는 Runner API가 있다고 가정하지 않고, 현재 단계에서도 필요한 선행 동작을 복구할 수 있게 한다.

## 6. 화면과 표식

- 안내판 하나에서 시작 / 실습 / 최종 확인 / 완료 화면을 전환한다.
- 시작 화면: 과정명, 학습 목표, 가상 조작 범위, 교육 시작 버튼. 시작 전 장비 조작 잠금.
- 실습 화면: 단계 제목, 다음 행동 하나, 필요한 오류·복구 안내. 이미 유효한 동작을 반복 요구하지 않는다.
- 현재 조작점에 원형 표식, 감기에는 다음 방향 화살표를 함께 표시한다. 색만으로 방향·성공 여부를 구분하지 않는다.
- 표식은 입력을 받지 않는다. 시작 대기·완료·초기화 중에는 숨긴다. 최종 확인에서는 장비 조작 표식 대신 확인 항목을 안내한다.
- 지혈대 표식 가시성 문제의 수정 방식은 참고하되 해당 코드·머티리얼을 변경하지 않는다. 새 과정에서 실제 재사용 가능한 표시 책임만 검토한다.
- 모든 자막 원문은 과정의 `TrainingSubtitles` static class 상수로 관리한다. 교육 데이터에는 안정적인 ID를 사용한다.
- 사용자 화면에 키보드 조작 안내·디버그 수치·내부 클래스명은 넣지 않는다.

## 7. 상태와 교육 진행의 책임

기존 `TrainingDefinition`·`TrainingRunner`의 State/HoldState를 읽기 전용으로 확인했다. 공통 Runner는 임의 단계 되감기·장비 초기화·임상 판정을 제공하지 않는다.

| 책임 | 담당할 내용 |
|---|---|
| 장비 조작 | 드레싱 배치, 손 접촉, 붕대 경로·표현, 끝·테이프 고정, 장비 초기화 |
| 과정 연결부 | 현재 장비 상태와 회차 기록 분리, 복구 조건, 확인 입력과 회차·단계 귀속 |
| Runner | 단계 조건 충족에 따른 교육 진행 |
| 안내 표시 | 현재 단계와 복구할 조건을 읽고 문구·표식 표시 |
| 다시하기 조정 | 입력 차단, Runner 정지, 선택 종료, 장비·기록·화면 초기화 |

- 장비 UI 버튼이 장비 내부 상태를 강제로 완료시키지 않는다.
- 이력: 대상·도구 확인, 직접 압박 동작 연습 수행. 현재 상태: 드레싱 위치, 감김 유효성, 끝 고정, 관련 상태 확인의 유효성.
- 연습 이력만으로 이후의 잘못된 감김·고정 상태를 통과시키지 않는다. 적용 상태 변경 시 그 상태에 의존하는 확인 기록도 무효화한다.
- 유지 진행량의 소유자는 하나만 둔다. Runner의 HoldState와 장비 타이머가 서로 다른 유지량으로 단계 통과를 중복 판정하지 않게 구현 설계 때 정한다.
- 최종 확인은 버튼 선택 순간 현재 상태를 재검사한다. 무효 상태에서 누른 확인은 보관하지 않고 새 입력을 요구한다.
- 이전 회차의 지연 이벤트·버튼 입력은 새 회차에 전달되지 않아야 한다.

## 8. 완료와 다시하기

완료 제목: **직접 압박·압박붕대 가상 조작 체험 완료**.

요약은 대상·도구 확인, 드레싱 배치, 접촉 유지 동작 연습, 감기 전 확인, 감기, 고정, 감기 후 확인, 최종 확인의 수행 여부를 보여준다. 실제 압박력·출혈량·혈류·합격 점수는 표시하지 않는다.

고정 상태와 요약은 완료 후 유지한다. 완료 화면에는 다시하기 버튼을 제공한다. 허브가 없는 단계에서는 동작하지 않는 과정 복귀 버튼을 먼저 만들지 않는다.

다시하기 순서:

1. 새 입력 차단과 표식 숨김.
2. Runner 정지, 이전 회차 입력·작업 무효화.
3. 드레싱·롤·테이프의 XRI 선택 종료.
4. 도구 트레이 위치, 드레싱·붕대·고정 상태와 시각 표현 복원.
5. 접촉 유지량, 경로, 확인 기록, 오류, 수행 요약 초기화.
6. 시작 화면과 장비 잠금 복원. 사용자 위치·시야·안내판 배치는 유지.

자동 시작·씬 재로드는 다시하기 방식으로 쓰지 않는다. 연속 클릭·양손 입력은 한 번만 수락한다. 실패 시 잠금을 유지하고 안내한다.

## 9. 추후 Blender 제작을 위한 요구사항 — 이번에는 제작하지 않음

| 대상 | 추후 필요한 구성 |
|---|---|
| 드레싱 | 상처 접촉 면, 윗면 접촉 지점, 잡기점, 배치 기준점 |
| 붕대 | 이동하는 롤, 드레싱 쪽 시작점, 미완료 띠, 감김 표현용 띠, 끝 고정 기준점 |
| 마감 재료 | 준비된 테이프 작업본과 붙이는 면·조작점. 제품 확정 전 전용 후크 생성 금지 |
| 인체 작업본 | 상처 기준점, 접근 가능한 팔, 손 쪽 확인 지점, 감기 경로 기준 축 |
| 분리 원칙 | 시각 메시와 잡기 Collider·접촉 판정·감기 경로를 분리. 원본 모델을 런타임 변형 대상으로 직접 사용하지 않음 |

치수·피벗·경로·메시 분할은 모델링 착수 때 기준 자료와 함께 확정한다. 이번 설계 작업에서 Blender 실행, 모델 생성·수정·내보내기는 하지 않는다.

추후 경로 후보는 `Assets/B/Models/PressureBandage/`, `Scripts/BleedingControl/PressureBandage/`, `Data/PressureBandage_Training.asset`, `Scene/B_PressureBandage_Tutorial.unity`다. 현재 생성된 자산·확정 클래스명으로 취급하지 않는다.

## 10. 사용자 확인 기준 — 구현 후 수행, 현재 모두 미확인

| 확인 | 기대 결과와 실패 기준 |
|---|---|
| 임포트·구성·검사 | 오류·누락·중복 없음. 정적 구성 통과와 실제 조작 통과 구분 |
| 시작·중복 입력 | 시작 전 잠금, 시작 한 번. 자동 시작·중복 회차는 실패 |
| 배치 | 유효한 면·위치만 수락. 가까이 스치거나 반대 면 접촉으로 통과하면 실패 |
| 직접 압박 연습 | 손 접촉·추적이 유효할 때만 연속 진행, 끊기면 초기화. 의료적 압력·시간으로 표시하면 실패 |
| 양손 인계 | 어느 손이든 유지·감기 가능. 접촉이 끊겼는데 유지 성공으로 계산하면 실패 |
| 순차 감기 | 정상 빠른 이동 수락, 순간 이동·건너뛰기·팔 관통 거절 |
| 놓기·추적 소실·포커스 복귀 | 정지 후 새 기준으로 재개, 복귀 순간 경로 진행·완료 없음 |
| 적용 상태 파손 | 유효하지 않은 감김·고정 및 그에 의존하는 확인 철회, 필요한 선행 동작 복구 가능 |
| 감기 전후 확인 | 서로 다른 확인 기록. 실제 온도·혈류를 측정한 것으로 표시하면 실패 |
| 최종 확인 | 현재 상태 불충족 시 차단, 상태 복구 뒤 새 확인 입력 필요 |
| 표식·한글 안내 | 조작점·방향 명확, 잘림·겹침·입력 가로막음 없음 |
| 완료·반복 다시하기 | 도구·기록·표현 전부 초기화, 시작 대기 잠금, 이전 회차 혼입 없음 |

실행 검증은 사용자 담당이다. 에이전트는 Unity Play·Simulator·batchmode·테스트·빌드를 수행하지 않는다. 헤드셋 확인은 기존 방침대로 후속 일정으로 둔다.

## 11. 구현 전에 확정할 내용

| 항목 | 현재 결정 |
|---|---|
| 기본 장비 구성 | 사용자 선택에 따라 드레싱 + 롤붕대 기본형 |
| 실제 제품·규격 | 미정. 브랜드 제품 절차로 표시하지 않음 |
| 적용 교안 | 미정. 국내 예비군 승인 교육이라고 표시하지 않음 |
| 감기 방향·겹침·회전 수·고정법 | 교안 검토 필요. 테이프 고정은 초안 |
| 직접 압박에서 감기로의 전환 | 시나리오 구간 전환으로 구분, 실제 압박 유지 방법은 교육 검토 필요 |
| 실제 압박 시간·힘·장력 | VR 정답 수치로 만들지 않음 |
| 관찰·질문 내용 | 교육 담당 검토 후 고정. 기본형은 정상 적용 한 가지 상황 |
| 모델 | 추후 Blender 제작, 이번 작업 제외 |

기술 프로토타입은 이 미확정 목록을 명시한 가상 조작 연습으로 구현할 수 있다. 정식 교육용 배포 문구와 의료적 완료 기준을 확정한 것으로 취급하지 않는다.
