## 3. 유지할 동작과 설정

- 패드 1개로는 분석하지 않는다. 전원·두 패드·대응 앵커 점유를 함께 확인한다.
- 접촉 판정은 좌우 컨트롤러 위치와 등록된 환자 Collider 기준이다. UI 레이·책상·바닥·AED는 환자 접촉 판정 대상이 아니다.
- 추적 소실·확인 불가는 비접촉으로 통과하지 않는다. 분석 중에는 시간을 0으로 되돌려 다시 손 떼기를 기다린다.
- 분석 5초, 충전 3초, 손 판정 반경 0.08m는 교육용 설정이다. 실제 기기·의료 기준으로 설명하지 않는다.
- 충전 중 접촉으로 충전 시간 자체를 초기화하지 않는다. 충격은 충전 완료·양손 비접촉·장비/패드 상태 유효·새 누름일 때만 입력 순간 재검사 후 허용한다.
- 충전 중 누른 채 완료 후 놓거나, 접촉 중 누른 채 손을 떼는 동작만으로 충격하지 않는다. 새 입력이 필요하다.
- 다시하기는 패드 최초 부모·로컬 배치·물리·interactionLayers·throwOnDetach·시각 모델·Collider·케이블을 복원하고 앵커 점유와 환자 부착 표시를 해제한다. 전원 OFF, 충격 Idle, 분석 시간과 입력 기록 초기화 후 시작을 기다린다.
- Pad01 → 오른쪽 위 가슴, Pad02 → 왼쪽 옆가슴 대응과 사용자 앵커 override를 유지한다. 인체 루트 X축 반전·MirrorFix 재질·기존 FBX 원본을 보존한다.
- 모든 안내 문구는 `TrainingSubtitles` 상수와 `All`로 관리한다.
