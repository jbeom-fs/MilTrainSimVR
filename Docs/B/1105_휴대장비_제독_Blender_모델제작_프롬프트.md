### 3. 신규 제작 후보 — 재사용 가능한 품목은 이 목록에서도 제외

**A. 가상 도구 케이스 `DC_KitCase`**

- 본체 `Part_CaseBody`와 뚜껑 `Part_CaseLid`를 분리하세요.
- 닫힘·열림 준비 상태를 나중에 Unity에서 표현할 수 있도록 뚜껑 원점을 경첩 축에 두세요. 개폐 애니메이션·리그는 만들지 마세요.
- 내부에는 패드형 도구 하나가 들어갈 공간을 확보하세요. 불필요한 내용물·추가 도구는 만들지 마세요.
- 기준 Empty: `Anchor_LidHinge`, `Anchor_ToolRest`. 경첩 회전축과 도구 기본 자세를 문서에 기록하세요.
- 초기 크기 제안: 약 0.18 × 0.13 × 0.06m. 실제 제품 치수가 아닌 개발용 가정임을 적으세요.

**B. 파지형 패드 도구 `DC_Applicator`**

- 손으로 잡는 지지부 `Part_PadGrip`와 아래쪽의 작용 면 `Part_PadSurface`를 구분하세요. 이는 가상 조작 도구이며 실제 제독 재료·약제 구조를 재현한 모델은 아닙니다.
- 작용 면은 손잡이와 시각적으로 구분되고, 뒤집혔을 때도 어느 면인지 알 수 있게 하세요.
- 기준 Empty: `Anchor_Grip`은 손 파지 중심, `Anchor_Contact`는 작용 면 중심에 두세요. `Anchor_Contact`의 로컬 +Z가 작용 면 바깥 법선을 향하도록 하고 실제 위치·축을 문서화하세요.
- 표면 처리 판정에 사용할 면의 범위·크기를 문서에 기록하세요. 판정용 Collider는 만들지 마세요.
- 초기 크기 제안: 약 0.10 × 0.07 × 0.02m. 개발용 가정입니다. 자유 천 물리·스키닝·변형 리그·사용 흔적 애니메이션은 넣지 마세요.

**C. 사용 도구 회수 용기 `DC_CollectionBin`**

- 패드가 들어갈 수 있는 열린 입구와 실제 내부 깊이를 표현하세요. 안이 막힌 상자나 단면 평면으로 만들지 마세요.
- 사용 전 케이스와 구분되는 형태·중성 색상을 사용하세요. 방호 인증·폐기 규정·특정 위험물 표시는 붙이지 마세요.
- 기준 Empty: 입구 중심 `Anchor_Opening`, 바닥 안쪽의 도구 놓임 기준 `Anchor_Return`.
- 초기 크기 제안: 약 0.22 × 0.18 × 0.16m. 개발용 가정이며 실제 폐기·제독 설비 규격이 아닙니다.
- 동일 목적에 적합한 기존 용기가 있으면 신규 제작하지 말고 경로와 재사용 방법만 보고하세요. 별도의 일반 트레이는 추가하지 마세요.

위 치수는 가로·깊이·높이 기준입니다. 손 접근·케이스 수납·회수 입구 통과를 고려해 조정할 수 있으며, 최종 치수를 기록하세요. 가상 회수 용기는 공간 연결용 모델이고 실제 제품의 사용 후 처리법을 확정하는 것이 아닙니다.

### 4. Blender 구조·품질

- 모델링은 Blender에서 수행하세요. Metric, Unit Scale=1, 1단위=1m 기준으로 만드세요.
- 신규 모델별 독립 루트를 두고 메시 `Part_`, 기준 Empty `Anchor_` 이름을 일관되게 사용하세요. 게임용·재사용 참고·촬영용 컬렉션을 분리하세요.
- 개별 모델은 원점 기준으로 내보내세요. 검토 장면에서 나란히 놓은 배치 오프셋이 FBX에 포함되지 않게 하세요.
- 뚜껑 피벗과 앵커 축은 보존하고, 축척 1·음수 축척 없음·정상 법선을 확인하세요. 일괄 변환 적용으로 경첩 축이나 기준점을 바꾸지 마세요.
- 가까이서 잡고 보는 VR 소품으로 모서리 두께·적절한 bevel·형태 구분을 확보하세요. 겹친 면·깜빡임·거꾸로 된 면·불필요한 내부 중복 메시를 제거하세요. 의도한 열린 부분과 메시 오류는 구분하세요.
- 신규 세트 합계 목표 15,000 triangles 이하, 공유 재질 4개 이하. 초과가 필요하면 실제 통계와 이유를 보고하세요. 이는 제작 예산이며 성능 통과 기준은 아닙니다.
- 텍스처가 필요한 경우 1K를 기본으로 하며, Unity URP에서 단순하게 연결 가능한 재질과 상대 경로 PNG를 제공하세요. Blender 전용 노드 효과에만 외관이 의존하지 않게 하세요.
- 한글 라벨·제품 로고·설명 문구는 메시나 텍스처에 굽지 마세요. 사용 전/사용 후 상태를 색으로 바꿀 여지가 있도록 작용 면의 재질을 분리하세요. 상태 전환 기능은 구현하지 마세요.

### 6. 확인과 보고

Blender에서 모델을 확인하고 FBX를 별도 검토 장면에 다시 가져와 다음을 대조하세요.

- 예상 치수·원점·부품 수·이름·부모·뚜껑 회전축·앵커 위치/방향.
- 케이스 안에 도구가 들어가고, 뚜껑이 열릴 때 큰 관통이 없는지.
- 도구 파지부와 작용 면이 구분되고 회수 입구를 통과하는지.
- 면 방향·UV·텍스처 경로·재질 및 triangle 통계.

전체 사선, 케이스 닫힘/열림, 도구 윗면/작용 면, 회수 용기 내부, 피벗·앵커를 확인할 수 있는 미리보기를 제공하세요. 촬영 요소는 게임용 FBX에서 제외하세요.

최종 보고는 ① 재사용해서 제작 제외한 품목과 경로 ② 실제 신규 제작 파일 ③ 최종 치수·부품·앵커·통계 ④ Blender/FBX 재반입 확인 결과 ⑤ 제품 미확정으로 남긴 항목 ⑥ 사용자 Unity 확인 항목 순서로 작성하세요.

Blender 재반입 성공을 Unity 임포트·VR 조작·교육 과정 검증 완료로 기록하지 마세요. Unity에서의 크기·축·재질·잡기점·피벗·접촉 면 확인은 사용자에게 남기세요. 기존 파일 변경이 필요하면 임의 변경하지 말고 대상·이유와 대안을 보고하세요.
