# 2026-10-28 K1 착용 조작 간소화 — 변경 기준

최신 상태: 간소화 구현은 `cbfb198`에 커밋됐다. 사용자가 `Worn` 로그를 제공한 뒤 현재 기능 전체 확인 완료를 보고했다. 끈 조임·점검은 조작 없이 안내로만 제공하기로 확정했다. 이후 교육 UI(`db38038`), 아바타·거울(`3c7837e`), 다시하기(`692f916`)도 구현·커밋과 사용자 확인을 마쳤다. **추가 관찰인 Worn 후 손 놓기 때 끈 풀림은 사용자 지시로 수정 보류**하며 기능 전체 확인과 구분한다. 최신 통합 상태는 [오늘 마감 기록](1028_작업마감_진행상황.md)을 우선하며, 아래 구현 전·정적 수정 당시 설명은 이력으로 보존한다.

## 1. 사용자 요청과 현재 확인 상태

- 사용자는 Simulator에서 끈 펼침을 확인했지만 조작이 매우 어렵다고 보고했다.
- 최근 제공 로그는 `Extracted → Unfolding → Extracted → Unfolding`이며, 해당 로그에는 `Ready`·`FaceHeld`·`Worn`이 없다.
- 새 요청: 얼굴(카메라) 근처에 가져오면 정해진 위치에 자동 스냅하고, 잡고 있지 않아도 고정한다. 끈은 대략 뒤로 가져오면 착용되도록 판정을 매우 완화한다.
- 이 문서의 새 요청이 이전의 수동 펼침 완료 필수·위쪽 영역 통과·두 영역 순서 검사·단계별 추가 이동 요구보다 우선한다. 과거 문서는 이력으로 보존한다.

## 2. 목표 조작

완전 추출 → 얼굴 근처 접근 → 자동 정렬·얼굴 고정 → 본체 손 놓기 → 한 손으로 끈을 대략 뒤로 가져오기 → 자동 안착·착용 완료.

### 얼굴 스냅

- 주머니에서 완전히 꺼낸 방독면이 얼굴 앞의 넓은 근접 범위에 들어오면 정해진 얼굴 기준 자세로 부드럽게 정렬한다.
- `Extracted`·`Unfolding`에서도 가능해야 한다. `Ready` 도달이나 수동 펼침 완료를 선행 조건으로 요구하지 않는다.
- 스냅 시 필요한 머리끈 준비 자세는 자동으로 맞춘다. 접힌 자세에서 착용 경로 시작 자세로 넘어가는 표현을 정리하고, 수동 펼침과 착용이 동시에 본을 제어하지 않도록 한다.
- 정확한 본체 각도를 사용자가 맞추게 하지 않는다. 최종 위치·회전은 기존 얼굴 기준을 사용한다.
- 스냅 진입과 유지에 본체 그립 유지를 요구하지 않는다. 본체를 놓아도 얼굴에 고정되어 머리를 따라간다.
- 수납·부분 추출 중에는 얼굴 스냅하지 않는다. 얼굴 추적이 유효할 때만 진입·정렬한다.
- 진입 범위를 넓히면 명시적 해제 후 재스냅 차단 범위도 함께 검토한다. 기존 진입·이탈 거리의 대소 관계가 깨져 구성이 무효가 되지 않도록 한다.

### 끈 착용

- 얼굴 고정 후 어느 손으로든 좌우 끈 조작점 중 하나를 잡아 뒤쪽으로 가져오면 된다.
- 머리 기준의 넓은 뒤쪽 영역에 조작 손이 도달하면 남은 끈을 자동 안착시키고 `Worn`으로 확정한다.
- 위쪽 영역 통과, 정수리 통과, 두 영역의 순서, 좁은 경로 추종은 요구하지 않는다.
- 재잡기·추적 복귀 때 영역 밖 재진입이나 단계별 2cm 추가 이동을 요구하지 않는다. 선택·추적이 유효해진 뒤 현재 뒤쪽 위치를 판정할 수 있어야 한다.
- 손을 정확한 완료 지점에 계속 맞추지 않아도 한 번 유효하게 뒤쪽 도달을 확인하면 안착을 이어간다. 끈을 놓거나 추적을 잃은 동안은 멈추고, 다시 잡거나 추적이 복귀하면 이어간다.
- 얼굴 앞에서 끈을 잡고 가만히 있는 것만으로 완료되지 않는다. 머리 뒤까지 컨트롤러를 깊게 밀어 넣는 조작은 요구하지 않는다.
- 손의 판정은 단순하게 하고, 끈 표현은 기존 `K1MaskHarnessPose.ApplyRoute`의 0~5 경로로 부드럽게 연결한다.
- 다른 손과 본체 그립은 착용 진행에 필요하지 않다. 완료 이벤트는 한 번만 발생한다.

## 3. 기존 코드와 달라져야 하는 지점 — 정적 확인

- `K1MaskWear.Update`: 현재 `TrySnapToFace`는 `Ready`에서만 호출된다. 새 요청은 추출 완료 직후부터 얼굴 근접을 판정해야 한다.
- `TrySnapToFace`: 현재 `grab.isSelected`와 선택 손 추적을 진입 조건으로 사용한다. 새 요청은 본체를 놓아도 근접 스냅과 얼굴 고정이 가능해야 한다.
- `DriveStraps`: 현재 ① 위쪽 영역, ② 뒤쪽 영역, 재개 이동 기준과 단계별 목표를 사용한다. 새 요청은 뒤쪽 도달 중심으로 단순화한다.
- 수동 펼침은 얼굴 밖에서 사용할 수 있어도 되지만, 착용을 위한 필수 조작이 되어서는 안 된다.

## 4. 유지할 기능과 범위

- 주머니·고정장치·덮개·완전 추출 판정.
- 얼굴 기준 위치, 본체 제어권의 단일 관리, 머리 추종.
- 본체를 잡고 Activate를 새로 눌러 명시적으로 해제하는 방식, 끈 복귀, 재스냅 차단.
- 접힌 수납 자세, 원본 FBX·JSON·본 구조·표현 경로 표본.
- `K1MaskHarnessPose`의 본 제어와 직렬화된 렌더링 bounds 적용.
- 기존 사용자 변경과 Simulator 활성화. 타 팀·공용 자산과 설정은 변경 대상이 아니다.

## 5. 사용자 확인 기준

1. 완전 추출 직후 펼치기 없이 얼굴로 가져가면 스냅된다.
2. 부분적으로 펼친 상태에서도 얼굴에 가져가면 스냅된다.
3. 스냅 중·후 본체 그립을 놓아도 얼굴 고정과 정렬이 유지된다.
4. 고개를 움직여도 정해진 얼굴 위치를 따른다.
5. 한 손으로 끈을 대략 뒤로 옮기면 위로 들지 않아도 자동 안착·`Worn`이 된다.
6. 좌우 손·좌우 끈 조작점 네 조합 모두 같은 간단한 조작으로 가능하다.
7. 얼굴 앞에서 끈을 잡기만 해서는 `Worn`이 되지 않는다.
8. 추적이 없는 동안 착용 완료하지 않는다. 재잡기·추적 복귀 후에는 반복적인 추가 동작 없이 이어간다.
9. 명시적 해제 후 얼굴 앞에 그대로 있으면 즉시 재스냅되지 않으며, 충분히 떨어뜨렸다 다시 가져오면 스냅된다.

실행 확인은 사용자 담당. 현재는 요구사항과 기존 코드의 정적 대조만 완료했다.

## 7. 사용자 확인과 후속 교육 범위 확정 (2026-10-28)

- 사용자가 간소화 구현의 `State: Worn` 및 `Worn: straps seated behind the head.` 로그를 제공했다.
- 이어 현재 구현된 기능 전체 확인 완료를 보고했다. 확인 맥락은 Simulator이며, Quest 2 + Link 실기 완료로 확대하지 않는다. 에이전트가 실행 검증한 것이 아니다.
- 확인 범위는 현재 K1 장비 조작이다. 아직 추가하지 않은 교육 UI·다시하기·결과 기능까지 완료됐다는 뜻은 아니다.
- 사용자 결정: **끈 조임·점검은 복잡한 조작을 추가하지 않고 안내로만 제공한다.**
- 추가 끈 당기기·버클 조작·조임 수치·점검 동작 판정·밀착 합격 판정은 구현하지 않는다. 안내를 실제 수행·검사 완료로 기록하지 않는다.
- 후속 구성안: 기존 착용 완료(`Worn`) 시 완료 화면과 조임·점검 안내를 즉시 함께 표시한다. 확인 버튼이나 안내 대기 단계는 두지 않는다. 4단계의 표시 문구는 `방독면을 얼굴 가까이 가져오세요.`로 한다.
- 후속 교육 단계·화면 설계는 [1028_K1_교육단계_UI_설계.md](1028_K1_교육단계_UI_설계.md)에 정리했다. 실습 5단계와 조임·점검 안내를 포함한 완료 화면으로 구성하며 구현 전 설계안이다.
- 이 갱신은 문서 변경만 수행했다. 코드·씬·Prefab 변경, 실행 검증, 스테이징·커밋은 수행하지 않았다.

## 8. 후속 사용자 관찰·거울 요청 (2026-10-28)

- 기능 전체 확인 완료 보고 뒤, 사용자가 **`Worn` 이후 손만 놓아도 끈이 풀린다**고 추가로 보고했다. T 해제 후 복귀와 구분한다. 정상 요구는 손을 놓아도 착용 자세 유지이며 현재 원인은 미확정이다.
- 전신 거울과 이전 마네킹의 사용자 신체 연동을 요청했다. 원본 마네킹의 본·스킨 정보와 현재 추적 범위, 거울·후면 보기 구성안은 [거울·아바타 검토](1028_K1_거울_아바타_검토.md)에 기록했다.
