## 3. 단계별 행동 문장

| 단계 | 행동(상태에 따라 하나) |
|---|---|
| ① 상황·도구 확인 | 상황과 도구를 확인하세요. + 카드(상황·도구 3줄) · 확인 |
| ② 드레싱 배치 | 드레싱을 잡으세요. → 드레싱으로 상처를 덮으세요.(반대 면이면 "드레싱을 뒤집어 접촉면으로 상처를 덮으세요.") |
| ③ 직접 압박 | 두 손을 드레싱 위에 모아 유지하세요. → (접촉 유효 중) 두 손을 그대로 유지하세요. |
| ④ 감기 전 확인 | 한 손으로 드레싱을 잡아 유지하세요. → 손 쪽 색 / 온도 정보 / 손가락 감각 응답을 확인하세요. (카드: "가상 상태 카드 · 1/3" + "평소 피부색과 같음" 등) |
| ⑤ 붕대 감기 | 다른 손으로 롤붕대를 잡으세요. → 롤붕대를 시작 고리로 가져가세요. → 화살표 방향으로 다음 고리를 지나가세요. (거부 직후 2.5초: 팔 바깥으로 돌려…/화살표 방향으로 돌리세요./고리 앞에서 다시 지나가세요. 등) |
| ⑥ 끝·테이프 고정 | 붕대 끝을 잡으세요. → 붕대 끝을 표시 위치에 맞춰 놓으세요. → 테이프를 잡으세요. → 테이프를 표시된 틀에 붙이세요. |
| ⑦ 처치 후 확인 | 재출혈 표시 / 손 쪽 색 / 온도 정보 / 손가락 감각 응답을 확인하세요. (카드 1/4~4/4) |
| ⑧ 최종 확인 | 최종 확인 버튼을 누르세요. (철회·거부 후 "…다시 누르세요.", 접수 후 "완료를 처리하는 중입니다.") |

공통 선행 행동(먼저 표시): 앱 화면으로 돌아오세요.(포커스) · 컨트롤러를 시야 안으로 가져오세요.(추적) · 한 손으로 드레싱을 잡아 유지하세요.(유지) · 테이프를 먼저 내려놓으세요.

## 4. 단계·문구·표식 일치와 복구

- 표시 단계 = 지금 성립하지 않는 첫 요구를 만드는 단계(`StepOf`). 박스·단계 줄·행동·표식·확인 카드가 모두 이 하나에서 나온다.
- 표시 단계 < Runner 현재 단계이면 단계 줄에 "· 복구"를 붙인다. 예: 고정 단계에서 드레싱 이탈 → "2 / 8 · 드레싱 배치 · 복구" + "드레싱으로 상처를 덮으세요." 감김 취소로 감기 전 확인 철회 → "4 / 8 · 감기 전 확인 · 복구".
- 취소 원인 긴 문장은 표시하지 않는다. 복구 행동 한 문장으로 바로 바뀐다.
- 감기 고리·화살표·경로 점선은 행동이 ⑤·⑥일 때만 보인다(이전: 접촉·감기 전 확인 충족 && 미고정). 드레싱 복구 중에는 숨는다.
- 확인 카드는 선행 행동(유지·추적·포커스)이 필요할 때 숨는다. 버튼 활성은 기존 `CanConfirmCheck` 그대로. 거부된 입력은 저장하지 않으며 상태 기반 행동이 복구를 안내한다.
- Runner·요구 조건·기록·철회·최종 재검사는 읽기만 한다. 변경 없음.

## 10. 남은 제한

- 확인 항목이 한 번에 하나라서, 버튼을 빠르게 두 번 누르면 다음 항목을 읽기 전에 기록될 수 있다. 기존 입력 조건 유지 지시에 따라 지연·잠금을 추가하지 않았다.
- 안내판 높이가 800→560으로 줄어 세계 크기가 작아진다(중심 위치 동일). 헤드셋 거리에서 가독성은 미확인.
- 취소 원인 문장을 표시하지 않으므로 교육생은 "복구" 표기와 행동 문장만 본다. 원인 안내가 필요하다는 피드백이 있으면 별도 조정.
- 장비 단독 확인 모드(상태판이 직접 안내하는 모드)의 장문 문구는 그대로다. 이 씬에서는 쓰지 않는다.
- 글자 칸 검사는 문자 폭 추정이며 실제 TMP 줄바꿈과 다를 수 있다.

### 11.1 버튼 영역 분리 (레이아웃 개정 5)

기존 개정 4는 시작(0,-165) 280×64와 확인(0,-150) 260×60이 겹쳤다. 시작을 빠르게 두 번 누르면 상황 확인까지 처리될 수 있는 배치였다.

| 버튼 | 중심 | 크기 | 영역 x | 영역 y |
|---|---|---|---|---|
| 시작 | (0, -65) | 280×64 | -140..140 | -97..-33 |
| 확인(실습) | (0, -150) | 260×60 | -130..130 | -180..-120 |
| 최종 확인 | (0, 10) | 300×64 | -150..150 | -22..42 |
| 다시하기 | (0, -215) | 180×52 | -90..90 | -241..-189 |

- 전환 쌍 간격(세로): 시작→확인 23, 확인→최종 확인 98, 최종 확인→다시하기 167, 다시하기→시작 92. 모두 사각형 전체가 분리된다. 최종 확인에서 실습으로 복구될 때도 확인→최종 확인 쌍과 같다.
- 시작 화면 재배치: 설명 y 70 높이 190(165..-25), 시작 버튼, 준비 문구 y -150 높이 70(-185..-115). 버튼·글자 크기 유지.

### 11.2 장비 표식 규칙

`Guidance.equipmentMarks`가 행동 선택과 같은 분기에서 정해진다. 문구 문자열은 비교하지 않는다. `equipmentGuide.Suppressed = !equipmentMarks`.

| 현재 행동 | 감기 고리·화살표·점선 / 끝 표시 / 테이프 틀 | 과정 고리(잡기 표식) |

### 11.3 끝·테이프 안내

장비는 손을 놓을 때만 고정을 판정한다. 들고 있는 동안에는 같은 판정을 매 프레임 계산한 `EndCheck`·`TapeCheck`를 읽어 행동 하나를 고른다. 허용오차·확정 조건 변경 없음.

|---|---|---|
