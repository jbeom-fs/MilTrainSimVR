### B. 보호의 상의 — 모델 변형 제한

- Blender `UserWearFixReport.json` 기준: 가벼운 굽힘에서 최대 18.5mm 관통이 남는다. 소매 아래·옆구리 부위를 재검토해야 한다.
- 팔 내림의 1.5배 초과 늘어난 간선은 65 → 76개로 증가했고 최대 약 2.61배다. 손을 가슴 앞으로 한 자세도 일부 관통·늘어남이 남는다.
- 다른 자세의 관통 표본은 감소했지만 전부 해결된 것은 아니다. 동일 시점 비교 렌더에서 차이가 작다는 것과 변형 품질 통과는 다르다.
- 추가 Blender 보완 여부와 실제 거울·1인칭에서의 수용 가능성은 후속 판단이다. 피부 숨김으로 해결됐다고 취급하지 않는다.

### C. 구현됐으나 최신 실행 확인이 필요한 항목

- UserBody `IsValid` / `IsRunning` / `PoseCurrent`, 비활성 시 잠금·안전 표시, 재활성 시 추적 재수신.
- 잡은 직후 착용 방지와 영역 밖으로 떼기 안내, 추적·포커스 소실 시 준비 해제.

- 재컴파일 → 메뉴 1 → 메뉴 2 → 사용자 착용·초기화·반복 조작. 최신 [구현 기록 §12.7](1103_보호장비_사용자몸착용_전환_구현기록.md#127-사용자-확인-모두-미확인)의 ①~⑨는 전부 미확인.

실행은 사용자 담당이며 전체 기능 구현을 우선해 온 방침을 유지한다. 테스트·실기부터 다시 최우선 배정하거나 미검증을 통과로 바꾸지 않는다.

## 2. 다음 기능 구현 순서 — 사용자 합의

1. **보호의 착용 과정 완결** (2026-11-04 갱신: 시작 → 단계별 제한·단계 박스·행동 한 문장 → 자동 완료·요약 → 다시하기를 [1104 교육 과정 연결 기록](1104_보호의_착용교육과정_연결_구현기록.md)에서 구현했다. 순서는 교안 미확정이라 임시 개발 순서다. 사용자 실행은 미확인): 위 미비 작업 정리 뒤 사용자 몸 착용 기본 조작을 마감하고, 구성품·교안에 맞는 순서 확정 → 단계별 입력 제한·단계 박스·행동 한 문장 → 시작 → 자동 완료·요약 → 다시하기 연결. 현재 6종은 순서 없이 독립 착용하며 정식 Runner·시작/완료 화면은 미구현이다.
2. **휴대장비 제독 구현**: 개인 피부 제독이 아니라 휴대장비를 대상으로 한다. 대상 장비·제독킷·적용 교안을 먼저 구체화하고 도구 선택·표면 처리·누락·재접촉·회수·초기화를 구성한다. 단순 접촉 시간이나 색상 지우기를 실제 제독 효과로 표시하지 않는다.
3. **분야별 최종 운영 씬 2개로 통합**: 기능을 먼저 완성한 다음 배치한다. 구급법 = AED·지혈대·직접 압박/압박붕대. 화생방 = K1 방독면·보호의/장갑/덮개 착용·휴대장비 제독. 개별 작업 씬은 기능 확인용으로 유지한다. 현재 운영 씬 통합은 미구현이다.
4. **각 분야의 과정 선택·진입·복귀·중단·재진입 연결**: 완료와 중단 결과를 구분하고 중복 전달·상태 누수·XR/카메라/입력 시스템 중복을 방지한다. 과거 '네 과정 공통 허브부터 구현' 제안은 현재의 기능 우선·2개 분야 씬 구조로 대체된다.
5. **팀 전체 앱 연결·내용 마감·배포**: A/C와 진입·복귀 목적지, 과정 ID, 결과 전달, 씬 전환과 XR 소유권 협의. 11/20 시연 경로·빌드 구성·사용자 실기·운영 및 복구 안내 정리. 타 담당 기능을 B 작업으로 자동 확대하지 않는다.

## 5. 작업 규칙

- 코드 직접 수정 금지. 명시적으로 요청받은 한국어 구현 프롬프트만 제공. 이번 문서 갱신은 구현 승인이 아니다.
- 모델 작업은 Blender, Unity 실행 검증은 사용자 담당. 에이전트 테스트·빌드·검증용 복제 프로젝트 생성 금지.
- 기존 사용자·팀 변경을 보존. 스테이징·커밋·Push는 요청받지 않았으며 수행하지 않음.
- 재개 시 [1103 마감](1103_작업마감_진행상황.md), 이 목록, 최신 구현 기록, 현재 Git 상태를 순서대로 확인한다.
- 문서 작성 전후 `.blend` 해시 변화가 감지됐다(작성자는 모델을 수정하지 않음). 코드·씬·FBX는 대조 해시가 동일하다. Blender 원본의 추가 변경 내용과 FBX/검사 기록 대응은 다음 재개 시 확인한다. 변경을 되돌리지 않는다.
