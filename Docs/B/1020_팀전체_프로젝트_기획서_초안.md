# MilTrainSimVR 프로젝트 기획서

작성일: 2026-10-20 · 프로젝트 팀: 남우진·김정범·이주석

프로젝트의 목표, 콘텐츠 구성, 역할 분담과 개발 방향을 정리한 팀 기획서 초안이다. 담당 분야와 PC VR 실행 방식을 기준으로 교육 흐름과 공통 기능을 구체화한다.

## 1. 프로젝트 개요

Meta Quest 2와 PC VR을 활용해 예비군 교장 교육을 체험하는 Unity 애플리케이션을 제작한다. 총기 분해·결합, 구급법·화생방 제독, 시가지 전투를 담당자별로 구현하고 하나의 앱으로 통합한다.

목표는 가상 환경에서 교육 내용을 체험하고 반복 학습할 수 있는 구조를 만드는 것이다. 실제 교육과정·평가 기준 적용 범위는 추후 확정한다.

## 2. 담당 및 콘텐츠

| 담당 | 확정 분야 | 초안 구성 방향 | 미정 사항 |
| --- | --- | --- | --- |
| 남우진 | 총기 분해·결합 | 가상 총기와 부품 조작을 통한 분해·결합 교육 | 대상 총기, 부품 범위, 단계, 판정 기준 |
| 김정범 | 구급법·화생방 제독 | 도구 선택·조작, 단계 안내, 결과 피드백 | 최종 교육 항목, 교안, 제독 대상·장비 |
| 이주석 | 시가지 전투 | 가상 시가지에서 주어진 상황과 임무 체험 | 맵, 전투 방식, NPC 구성, 종료·평가 조건 |

## 3. 기본 이용 흐름 — 제안

```text
앱 시작 → 교육 선택 → 목표·조작 안내 → 콘텐츠 체험
       → 결과·피드백 → 재시도 또는 교육 선택으로 복귀
```

각 콘텐츠의 특성에 맞게 진행 방식을 설계한다. 총기 분해·결합과 구급법은 단계별 수행을, 시가지 전투는 상황·임무 진행을 중심으로 구성하고 공통 진입·종료 흐름으로 연결한다.

## 4. 공통 기능 — 협의안

- 과정 선택, 시작·종료·재시도.
- 컨트롤러 입력과 기본 상호작용.
- 음성·자막 안내와 결과 피드백.
- 과정별 완료·중단 결과 전달.

공통 시스템은 교육 진행, 장비 상호작용, Object·Animation·Transform 제어, 음성·자막 출력을 분리하는 구조를 제안한다. 자막은 별도 static class의 상수로 관리하는 방안을 적용한다. 콘텐츠 간 재사용 범위와 공통 모듈 제작 담당은 팀 협의로 정한다.

## 5. 개발 환경

| 항목 | 기준 |
| --- | --- |
| 엔진 | Unity `6000.3.13f1` |
| 실행 | Windows PC VR / Meta Horizon Link / Quest 2 |
| XR | OpenXR `1.16.1`, XR Interaction Toolkit `3.4.1` |
| 입력 | Input System `1.19.0` |
| 테스트 | XR Interaction Simulator 및 헤드셋 실기 |
| 프로젝트 | `D:\TeamProject\MilTrainSimVR` |

패키지·XR 설정은 팀 공유 기준을 따른다. 공용 샘플은 원본을 보존하고 필요한 작업본을 담당 폴더에서 사용한다. 헤드셋 실기 테스트 완료 여부는 별도로 확인해야 한다.

## 6. 프로젝트 일정 및 개발 진행안

전체 기간: **2026년 10월 15일 ~ 11월 26일**

| 구분 | 일정 |
| --- | --- |
| VR 콘텐츠 기획 | 2026년 10월 15일 ~ 10월 21일 |
| 프로젝트 컨셉 기획 발표 | 2026년 10월 21일 |
| 프로젝트 개발 | 2026년 10월 22일 ~ 11월 26일 |
| 프로젝트 완료 발표 | 2026년 11월 20일 |

완료 발표는 개발 기간 중인 11월 20일에 진행한다. 발표용 시연 범위와 발표 이후 개발 종료일까지의 작업 범위는 팀 협의로 확정한다.

개발은 아래 순서로 진행하며 세부 일정은 콘텐츠 범위 확정 후 배분한다.

| 순서 | 작업 | 확인 기준 |
| --- | --- | --- |
| 1 | 담당별 상세 범위·단계 정리 | 구현할 항목과 완료 조건 명시 |
| 2 | 담당별 대표 기능 제작 | 각 콘텐츠의 핵심 조작 시연 가능 |
| 3 | 전체 앱 통합 | 교육 진입·종료·재진입 연결 |
| 4 | 실기 검증 | Quest 2 + Link에서 조작·안내·성능 확인 |

콘텐츠별 소요시간과 최종 납품 범위는 미정이다.

## 7. 후속 확정 사항

- 콘텐츠별 상세 범위와 평가·종료 조건.
- 방독면·보호의 연계 범위와 제작 담당.
- 담당자별 코드·씬·Prefab 작업 경로와 공통 기능 담당.
- 전체 앱 진입·종료·결과 전달 규칙.
- 필요한 모델·애니메이션·음성 자산과 사용 가능한 교안.
- 세부 개발 일정, 완료 발표 시연 범위, 발표 이후 작업 범위.
- 테스트 PC 사양, 목표 성능.
