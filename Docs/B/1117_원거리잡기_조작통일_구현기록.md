## 2. 공통 잡기 기준

- **RelativeHand (제자리 조작점·수납물 당기기)**: 잡은 순간 대상 조작점에서 시작하고, 이후 XR Origin 추적 공간 안의 컨트롤러 이동만 더한다. 가까이·멀리 같은 손 이동 = 같은 조작량(거리 증폭·레버 없음). 스틱 이동·회전·텔레포트는 추적 공간을 움직일 뿐이라 조작으로 계산되지 않는다. 대상이 플레이어와 함께 움직이는 경우(다른 손에 든 물건, 얼굴의 방독면)는 리그와 함께 실려 간다(`CarriedByRig`). 추적 없음·중단 보류 프레임은 점만 유지하고 그 사이 이동을 버린다.
- **FreeHold (자체 변환기를 쓰는 자유 물건: K1 방독면 추출 후, KD-1)**: 잡을 때 물건 각도 유지, 이후 손 회전 변화량만 반영. 손에서 0.1 m보다 먼 그립점(손에 가장 가까운 충돌체 점)은 0.3 s(SmoothStep) 동안 손으로 가져온다. 다시 잡기·손 교체는 새로 시작, 추적 복구·보류 해제는 현재 자세에서 기준만 다시 잡고 남은 가져오기를 이어간다.
- **GrabBring (XRI 기본 변환기를 쓰는 자유 물건)**: XRI 동적 부착 + attach ease-in 0.3 s로 가져온다. 물건 attach 점이 손 attach 점에서 1 cm 넘게 떨어져 있으면 "가져오는 중"(LateUpdate 판정, XRBodyTransformer가 XRI보다 먼저 실행되므로 걷기로 오판하지 않음).
- 가져오는 중에는 부착·착용·안착·감기·자동 부착·추출 완료 판정을 하지 않는다. 그 사이 놓으면 일반 놓기로만 처리하고 완료로 보지 않는다.
- 각 장비의 추적 유효성·교육 단계·잠금·수납 상태·올바른 손·한 손 한 물건 규칙은 그대로 두고 **거리 조건만** 제거했다.

## 4. 지혈대 조임·고정 (`TourniquetOperation`)

- 첫 유효 회전이 조임 방향을 정한다. 이후 **반대 회전은 진행도를 바꾸지 않는다.** 입력 기준(RefDirection)은 계속 갱신되므로 되돌린 양이 나중에 한꺼번에 적용되지 않는다.
- 진행도는 **필요 회전량 이상인 첫 진입각(180°의 배수)에서 멈춘다**(기본 360 → 360°). 막대가 정확히 고정부 옆 진입각에 서 있으므로 더 돌려 진입각을 지나치지 않는다. 달성 상태는 유지된다.
- 다시 잡기·손 교체: 새 기준만 잡고 첫 프레임은 계산하지 않는다(기존). 추적 소실·중단 보류: 점 유지, 복구 시 점프 없음. 60°/0.15 m 초과 급변은 기존대로 버린다.
- 고정 동작은 그대로 필요하다(360° 도달만으로 고정되지 않음): 진입각(±8° 창, 2 mm에 걸쳐 정렬) → 0.019 m 내림 → −30° 끼움. 작은 보조 2개 추가(직렬화): 내림 마지막 3 mm 스냅(`lowerSnapTravel`, 내릴 때만), 끼움 마지막 5° 스냅(`seatSnapDegrees`, 기존 0.5°).
- 역회전 방지는 Turning 단계만. −30° 끼움 단계는 기존처럼 양방향(0~30°) 조작.
- 상태판 `막대 회전 N° / 360°`, 단계, 효과음(회전 진행 증가 시만)은 같은 값을 읽는다. 문구의 360°는 게임 조작 설정이며 의료 기준으로 쓰지 않았다. `RecoverTurn` 문구는 진행도가 줄지 않아 사실상 나타나지 않는다(상수는 보존).

## 5. K1 덮개 자동 개방 (`K1CarrierLid`)

- 새 직렬화 설정 `autoOpenFrom` = **0.70**, `autoOpenSeconds` = 0.35 s (프리팹 저장값). 기존 `fullyOpenEnter 0.97 / fullyOpenExit 0.93` 히스테리시스와 `maxHandDistance`는 제거.
- 잠금 해제 후 손이 덮개를 0.70까지 열면 나머지를 0.35 s 동안 SmoothStep으로 1.0까지 연다(잡고 있든 놓았든). 자동 개방 중 손 입력은 쓰지 않고 기준을 계속 버린다.
- **완전 개방 = 실제 개방도 1.0.** 그때 `IsFullyOpen`과 `FullyOpenChanged(true)`가 한 번 발생하고, 방독면 추출 허용·교육 사실(LidFullyOpened)이 같은 값을 쓴다. 이후 교육 중 닫히지 않는다(덮개 손잡이는 놓인 뒤 꺼져 방독면 앞을 가리지 않음). 다시하기(ResetForNewRun)만 닫힌 초기 상태로 되돌리며 이벤트 없음.
- 교육 중단 확인(Suspended)·앱 포커스 없음 동안 자동 개방이 멈추고, 복귀하면 멈춘 곳에서 이어간다. 오래된 손 이동은 적용하지 않는다. 덮개 효과음(개방도 0.3 통과)은 자동 개방 전에 이미 울려 중복 없음.
- 안내 문구: "잡기를 놓은 뒤 덮개 손잡이를 잡아 여세요. 충분히 열면 끝까지 저절로 열립니다."

### 사용자 확인 절차

1. Unity 컴파일 오류·Missing 참조 없음(`TrackedGrabHold`, `HandTracking` 포함).
2. 대상별로 가까이 잡은 뒤 컨트롤러를 가리거나 시야 밖으로 → 물건이 마지막 자세 유지. 실패: 물건이 이동·회전.
3. 손 위치·방향을 바꾼 상태로 추적 복구 → 그 순간 위치·각도 변화 없음. 실패: 순간이동, 손 기본 각도로 회전, 잡기 시작 오프셋으로 복귀.
4. 복구 뒤 손 이동·손목 회전 → 새 변화량만 반영.
5. 원거리로 잡아 가져오는 도중 소실 → 멈춤, 복구 → 멈춘 자리에서 남은 이동을 부드럽게. 실패: 소실 동안 진행됨, 복구 순간 도착, 처음부터 다시 가져옴.
6. 소실·복구 반복, 다른 손으로 교체, 놓고 다시 잡기 → 누적 오차·튀는 회전 없음.
7. 추적 무효 중·복구 직후 부착·착용 자동 발생 없음(PB 끝·테이프 표시 근처, 보호의 영역 근처, AED '부착 가능' 표시 없음, 지혈대 미리보기 없음).
8. 정상 AED 부착·지혈대 부착·보호의 착용·압박붕대 감기·끝·테이프, 교육 다시하기, 스틱·UI 동작 유지.
9. B → 허브 → A/C → 허브 → B 왕복 후 각 씬 입력 유지.
