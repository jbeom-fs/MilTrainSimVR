# 압박붕대 교육 ③~⑥ 단계 드레싱 배치 조건 보완 (2026-11-03)

상태: **코드·데이터 수정 완료. 컴파일·메뉴 1/2·Play·Simulator 모두 미확인. 미커밋.** 근거는 [11/02 마감](1102_작업마감_진행상황.md) §2.3이다. 이전 작업(7단계 자동 완료 등)과 사용자 변경은 미커밋 상태 그대로 보존했다.

## 1. 변경

| 단계 | 전 | 후 |
|---|---|---|
| ① 상황·도구 확인 | Situation | 동일 |
| ② 드레싱 배치 | Situation, Dressing | 동일 |
| ③ 직접 압박 | Situation, Contact | Situation, **Dressing**, Contact |
| ④ 감기 전 확인 | Situation, Contact, PreCheck | Situation, **Dressing**, Contact, PreCheck |
| ⑤ 붕대 감기 | Situation, Contact, PreCheck, Wrap | Situation, **Dressing**, Contact, PreCheck, Wrap |
| ⑥ 끝·테이프 고정 | Situation, Contact, PreCheck, Wrap, Fix | Situation, **Dressing**, Contact, PreCheck, Wrap, Fix |
| ⑦ 처치 후 확인 | AllRequirements | 동일 |

- Dressing = `pb-equipment` / `dressing-placed`, State, ExpectedValue true. Link가 매 프레임 `dressing.IsPlacementValid`로 기록한다. GRAB이나 한 손 유지 조건은 아니다.
- 변경 파일:
  - `Tutorial/PressureBandageTrainingIds.cs`(`Steps`)
  - `Assets/B/Data/PB_PressureBandageTraining.asset`(YAML)
- Setup·장비·Link·Guide·UI·씬·Prefab은 바꾸지 않았다. 레이아웃 개정도 7 그대로다.

## 2. 교육 데이터 반영

- 자산 YAML의 `pb-contact`·`pb-pre-check`·`pb-wrap`·`pb-fix`에서 `situation-confirmed` 바로 뒤에 `dressing-placed` 조건 블록을 넣었다(20줄 추가). 블록 내용은 `Kind 1`(State), `pb-equipment`, `ExpectedValue 1`, `HoldSeconds 1`이다.
- 단계 ID·순서·기존 조건·GUID(meta 미변경)는 그대로다.
- 정적 대조 결과:
  - 조건 수는 1/2/3/4/5/6/7, 합 28.
  - Dressing은 ②~⑦에 각각 1회.
  - 대상은 장비 신호(`dressing-placed`·`wrap-complete`·`application-fixed`)가 `pb-equipment`, 나머지가 `pb-trainee`.
  - 모든 Kind와 ExpectedValue는 1.
- 메뉴 1 `ExpectedSteps()`는 `Steps.needs` 순서대로 State/true 조건을 만든다. `HoldSeconds`는 기본값 1이다. 따라서 메뉴 1 결과는 수정한 자산과 같다.
- 메뉴 2는 기존 검사("Training steps and conditions match the course")가 단계 ID·조건 수·순서·종류·대상·신호·기대값을 전부 비교하므로 누락을 잡는다. 보완은 필요 없었다.

## 3. 동작 영향(정적 판단)

- Runner는 ③~⑥ 단계에 머무는 동안 드레싱 배치가 무효이면 그 단계를 넘기지 않는다. 이미 지난 단계로 되돌리는 정책은 없고, 바꾸지도 않았다.
- 안내: Guide는 원래 `FirstMissing`(Dressing이 Contact보다 앞)으로 배치 복구 안내를 보였다. 이제 단계 판정과 같은 조건을 본다.
- 바꾸지 않은 것:
  - 직접 압박 이력 유지: `contactPracticed`는 철회되지 않는다. 배치를 복구하면 다시 압박하지 않고 이어진다.
  - 적용 취소에 따른 감기 전·후 확인 철회
  - 감기 전 확인의 한 손 유지
  - 감기·끝 SNAP·테이프의 드레싱 GRAB 불요
  - 자동 감기·진행률·끝 8 cm SNAP·테이프 판정
  - 7단계 자동 완료·다시하기
