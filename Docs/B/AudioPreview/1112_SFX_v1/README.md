## 용도와 제작 방향

- **UI_Click_v1.wav**: 버튼 입력이 실제 처리될 때 한 번 재생하는 짧은 팝. 호버·오류용 아님. 2.5 ms의 곡선 어택, 빠른 감쇠, 끝 18 ms 테이퍼. 약 1,180→650 Hz 사인 성분과 매우 작은 필터 노이즈로 구성. 금속성 충격·강한 저음·긴 잔향 성분을 넣지 않았다. 반복 피로도·입력 피드백 명료도는 청취 확인 대상.
- **TrainingComplete_v1.wav**: 교육 전체 완료 때 한 번 재생하는 부드러운 3음 상승 확인음. 매 단계 반복용 아님. 주파수 587.33 / 739.99 / 880.00 Hz, 각 시작 시점 0 / 0.165 / 0.335초. 사인 중심에 작은 배음, 각 음 12 ms 어택과 끝 100 ms 테이퍼 적용. 마지막 음은 자연 감쇠 후 0.780초에 종료. 경보 반복·화려한 보상음 장식·긴 음악을 넣지 않았다. 브랜드·운영체제 음원을 참조·복제하지 않고 직접 조합했으며, 청감상 유사성은 미평가.
- **BandageWrap_Loop_v1.wav**: 부드러운 천·거즈가 풀리고 겹쳐지는 질감을 목표로 한 필터 노이즈 합성 루프. **실제 천 녹음 아님.** 서로 다른 노이즈 3층과 독립적인 느린 불규칙 변조로 미세한 마찰 변화 구성. 타격·선율·완료 신호·규칙적인 박자 없음. 향후 실제 감기 진행률이 늘어나는 동안만 재생하고 멈춤·중단·완료 때 정지하는 용도. 이번에는 그 연결을 구현하지 않았다.

용도별 피크를 클릭 약 −12 dBFS, 완료 약 −10 dBFS, 붕대 약 −26 dBFS로 각각 설정했다. 같은 피크로 일괄 정규화하지 않았다. 붕대의 전체 RMS는 클릭보다 약 14.75 dB, 완료보다 약 18.82 dB 낮다. 지속 배경음의 낮은 음량을 의도했으며 실제 체감 차이는 청취 판단이 필요하다.

## 저장 파일 재읽기: 헤더·파형·레벨 수치 분석

합성 전 메모리의 값 대신 **저장한 WAV를 다시 열어** RIFF/WAVE 파일 길이, fmt/data 청크, 형식 필드와 PCM 표본을 확인했다.

공통 실제 형식: **WAV, 비압축 integer PCM(format tag 1), 48,000 Hz, Mono 1채널, 16 bit little-endian**. 바이트율 96,000 bytes/s, block align 2 bytes. 데이터 길이는 표본 수 × 2 bytes와 일치.

| 파일 | 실제 길이 | 표본 수 | 샘플 피크 dBFS | 전체 RMS dBFS | 클리핑 표본 | DC 평균 FS |
|---|---:|---:|---:|---:|---:|---:|
| `UI_Click_v1.wav` | 0.110000초 | 5,280 | -12.000 | -25.688 | 0 | 0.000000000 |
| `TrainingComplete_v1.wav` | 0.780000초 | 37,440 | -10.000 | -21.619 | 0 | 0.000000000 |
| `BandageWrap_Loop_v1.wav` | 2.600000초 | 124,800 | -26.002 | -40.440 | 0 | 0.000000000 |

계산 기준:

- signed int16 표본을 32768로 나눠 FS 값으로 변환.
- 피크 = 20 log10(max(abs(x))), RMS = 20 log10(sqrt(mean(x²))). RMS는 파일 전체 기준. LUFS나 체감 음량 측정값 아님.
- 클리핑 표본은 −32768 또는 +32767인 표본 수. 모든 파일 0개이며 샘플 피크 −6 dBFS 이하. 제작 중 하드 클리핑·리미팅을 사용하지 않았다.
- 최종 PCM 정수 합이 0이므로 전역 DC 평균도 0. 양자화 후 남은 DC 잔차는 활동 표본에 최대 1 LSB만 조정해 제거했다.
- 보조 4배 Fourier 보간 피크 추정: 클릭 −11.996, 완료 −9.988, 붕대 −26.002 dBFS. 인증된 true-peak/dBTP 계측은 아니다.
- 클릭·완료의 첫/마지막 표본은 모두 0. 곡선 어택·릴리스로 비주기 파일의 시작·끝 불연속을 억제했다.

외부 녹음·압축 파일·전원 험을 소스로 사용하지 않았다. 붕대의 광대역 성분과 클릭의 작은 노이즈는 의도한 합성 재료다. 수치 분석만으로 ‘들리는 잡음 없음’, ‘디지털 클릭이 들리지 않음’, ‘피로하지 않음’, ‘경보처럼 들리지 않음’을 확정하지 않는다.

## 붕대 루프 경계 처리와 수치

2.6초 전체를 **주기 신호로 직접 합성**했다. FFT 주파수 격자 위의 필터 노이즈와 같은 주기의 저속 제어 신호를 사용해 파형·음량·질감 변조가 파일 길이에서 순환하도록 구성했다. 별도 순환 크로스페이드 없이 주기성을 확보했다.

원형 이동으로 양쪽 20 ms 에너지가 비슷하고 진폭·기울기가 작은 위치를 경계로 선택했다. 양 끝 중복 표본, 앞뒤 무음 패딩, 파일 전체 페이드 인/아웃은 넣지 않았다. 매 반복마다 의도적으로 소리가 사라지는 구조가 아니다.

| 경계·파형 측정 항목 | 결과 |
|---|---:|
| 첫 / 마지막 표본 | 1 / 0 PCM codes |
| 마지막→첫 표본 차이 | 1 LSB (차이 진폭 −90.309 dBFS) |
| 경계 직전 / 경계 / 직후의 1표본 기울기 | +15 / +1 / −14 LSB |
| 내부 인접 표본 차이의 99백분위 | 133 LSB |
| 마지막 / 첫 20 ms RMS | −41.292 / −41.358 dBFS |
| 경계 양쪽 20 ms RMS 차이 | 0.066 dB |
| 겹치지 않는 전체 20 ms 구간 RMS 범위 | −43.194 ~ −37.527 dBFS |
| 전체 0인 20 ms 구간 수 | 0개 |
| 150 Hz 미만 스펙트럼 에너지 비율 | 0.00394% |
| 6,000 Hz 초과 스펙트럼 에너지 비율 | 0.00006% |

첫/마지막 표본은 시간상 1/48000초 떨어져 있으므로 반드시 같은 값일 필요는 없다. 경계 표본 차이는 내부 차이의 99백분위보다 작다. 극저역·고역 에너지 비율은 강한 저역·고역 억제를 확인하는 수치 참고값이다.

이 수치들은 파일 자체의 경계 분석이다. 실제 플레이어의 전환 지연, 2.6초 반복이 주관적으로 두드러지는지, 질감 연결이 자연스러운지까지 검증한 결과는 아니다. 끊김 없는 루프 모드에서 5회 이상 사용자 청취 확인이 필요하다.

## 제작 방식과 합성 시안의 한계

로컬 Python 3.14, 이미 설치된 NumPy와 표준 라이브러리 wave/struct 사용. 난수 시드 20261112. 내부 float64 합성 → DC 제거 → 용도별 피크 조정 → int16 반올림 → 미세 DC 잔차 보정 → WAV 저장. 별도 디더는 추가하지 않았다. 외부 API·전용 AI 효과음 생성 도구·외부 음원 다운로드·유료 서비스·새 패키지 설치 없음.

붕대음은 저역 감쇠와 부드러운 고역 롤오프를 적용한 3개 노이즈 층을 혼합했다. 필터 저역/고역 매개변수는 각각 330/2400, 1050/3100, 470/1600 Hz이며 벽돌형 대역 차단은 아니다. 각 층의 비중은 1 / 0.25 / 0.10. 2.1 / 4.5 / 1.3 Hz 저역통과 제어 신호로 완만한 불규칙 음량·질감 변화를 추가했다. 제어 신호는 노이즈 기반이며 규칙적인 박자 발진기가 아니다.

합성 초안이므로 실제 거즈 섬유·손 움직임·장력·겹침의 세부 음향까지 재현하지 못한다. 실제 천·실제 장비의 녹음 자료로 사용하지 않는다. 비닐·벨크로·사포·금속처럼 거칠게 들리는지와 실제 천에 가까운지는 청취로 판단해야 한다.

기기별 EQ·볼륨·공간 재생에서 고역이 거슬리거나 알림이 묻히는지는 미검증이다. 재생 시작·정지 처리, 감기 진행률 연동, 믹서 레벨, 공간화는 이번에 구현하지 않았다.

## 사용자 직접 확인 순서

1. **낮은 볼륨에서 클릭음을 여러 번 재생.** 입력 피드백이 분명하고 날카롭거나 피로하지 않은지 확인. 거슬리는 고역·딱 소리·긴 꼬리가 있으면 수정 대상으로 기록.
2. **완료음 재생.** 클릭과 구분되고 교육 전체 완료로 인식되는지 확인. 경보·AED 충격 안내·과한 게임 보상처럼 들리면 수정 대상으로 기록.
3. **붕대음을 5회 이상 반복.** 끊김 없는 루프 모드에서 경계 끊김·딱 소리·주기적 무음·두드러진 박자 유무 확인. 플레이어가 추가하는 파일 전환 지연과 파일 자체 경계를 구분.
4. **붕대음 위에 클릭·완료음을 함께 재생.** 주요 알림이 묻히지 않는지 확인. 전역 볼륨을 동일하게 유지하고 자동 음량 평준화는 끈 상태로 비교.
