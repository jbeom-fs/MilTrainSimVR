## 합성 방식과 차이

내부 float64 합성. 파일별 독립 NumPy default_rng 시드(2026111201~2026111221, 표 순서)를 사용했다. 공통 필터 노이즈 재료를 쓰되 새 난수, 대역, 입자 수·폭, 포락선, 레이어 비중을 다르게 설정했다. 기존 WAV 표본을 잘라 쓰거나 재합성 소스로 사용하지 않았다. 생성 코드는 임시 폴더에서만 실행했고 프로젝트 런타임·Editor·문서 폴더에 추가하지 않았다. 영구 재현용 스크립트는 이번 납품물에 포함하지 않는다. 아래 설명과 시드만으로 모든 구현 값을 재현할 수 있다고 보장하지 않는다.

노이즈는 FFT 주파수 영역에서 `(1-exp(-(f/lo)^4))*exp(-(f/hi)^4)`로 완만하게 대역을 제한했다. 제어 신호는 독립 난수를 `exp(-(f/cutoff)^4)`로 저역통과한 불규칙 신호다. 단발의 넓은 움직임은 sin^p 형태의 매끄러운 봉우리, 작은 접촉은 곡선 어택과 지수 감쇠, 미세 섬유·포장은 불규칙 위치의 짧은 노이즈 입자로 구성했다. 전체에 125 Hz 아래 감쇠와 5.7 kHz 위 완만한 정리를 적용했다. 단발은 최종 4 ms 어택·18 ms 릴리스 테이퍼를 추가했으며 첫·마지막 표본은 0이다. 긴 공간 잔향은 넣지 않았다.

- AED 전원: 약 8 ms 위치의 둔한 스위치 접촉(530/1370 Hz 단기 모드) 뒤 55 ms부터 1040 Hz 단일 확인음을 배치. 분석·충전 알림: 790 Hz 고정음과 약한 배음, 선율·상승 진행·충전 시간 흐름 없음. 충격 작동: 710/1640 Hz의 매우 짧은 몸체·릴레이 모드와 약한 후속 기기 접촉. 특정 실제 AED 알림을 참조·복제하지 않았다. 실제 제품과 청감상 유사성은 미평가다.
- AED 패드: 230~2200 Hz 중심의 넓은 눌림과 약한 불규칙 점착 입자 13개. 금속 모드 없음. PB 드레싱: 더 어두운 190~1450 Hz 거즈 접촉. PB 끝 부착: 시간차로 겹치는 두 천 포락선. PB 테이프: 650~2800 Hz 마찰과 미세 점착 입자 22개. KD-1 표면 접촉: 빠른 마른 섬유 접촉과 120 ms 이하의 짧은 스침; 긴 문지르기 없음.
- 지혈대 회전: 넓은 장력 마찰 속 약한 단일 막대 접촉. 고정 클립: 630/1270 Hz 단기 모드와 짧은 두꺼운 몸체 접촉. K1 단추: 더 가벼운 1190/2190 Hz 짧은 모드와 천 받침. 모드는 물체의 짧은 진동을 흉내 낸 합성 파라미터이며 실측 재질 특성은 아니다. 라쳇·규칙적 연속 클릭은 넣지 않았다.
- 벨크로 마감: 410 ms 안의 촘촘한 입자 62개와 누름 포락선. 길게 찢거나 뜯는 포락선 없음. K1 덮개: 낮은 천 접힘 뒤 가장자리 스침. 마스크 추출: 665 ms에 걸쳐 낮은 천·고무 층과 중간 이동 마찰이 중첩된다. 별도의 단추·지퍼음 없음.
- 보호의 장갑: 좁은 저중역 마찰의 연속 이동. 덧신: 더 넓고 낮은 합성 섬유 마찰과 겹침. 발걸음·바닥 충격·고무 팡 소리 없음. KD-1 포장: 1500~4500 Hz의 짧고 불규칙한 입자 37개와 얇은 바스락 층. 패드 착용: 중역 슬리브 천의 봉우리 2층이며 버클·벨크로 모드는 넣지 않았다.

## 루프 제작·경계 분석

TQ 2.140 s / K1 2.280 s / PC 2.420 s 전체를 각각 주기 신호로 합성했다. FFT 격자의 필터 노이즈와 같은 주기의 불규칙 제어 신호, 원형 거리로 계산한 Gaussian 마찰 입자를 사용했다. 별도 전체 페이드·앞뒤 무음 패딩·끝 표본 복제·규칙적 타격 발진기는 없다. 세 파일 모두 순환 합성이므로 파일 전체 주기 반복 자체는 존재한다. 반복 인지 여부는 사용자 청취 대상이다.

- TQ: 480~2450 Hz 중심 + 1550~3700 Hz 결 + 43개의 미세 마찰 입자. 제어 저역통과 3.7/9.1 Hz. 붕대보다 촘촘한 나일론 가이드 마찰을 목표로 했다.
- K1: 270~1450 Hz 중심 + 약한 800~2450 Hz 섬유 층 + 21개 완만한 마찰 입자. 제어 2.9/7.3 Hz. 고무 튕김·음정 변화 발진기 없음.
- PC: 200~1400 Hz와 700~2550 Hz의 독립적인 넓은 천 층 + 13개 넓은 입자. 제어 2.1/3.9 Hz. 좁은 밴드보다 느리고 여러 겹인 움직임을 목표로 했다.

양자화 후 원형 이동으로 경계를 선정했다. 후보 조건은 경계 양쪽 20 ms RMS 차이 <0.08 dB, 양쪽 RMS가 전체 RMS 진폭의 0.72배 초과다. 후보 중 경계 차분·양옆 곡률·현재 진폭이 작은 지점을 점수로 선택했다. `np.roll(q, -shift)`에 해당하며 파일 끝을 자르거나 무음을 삽입하지 않았다. 이동량은 manifest의 circular_shift_samples에 기록했다. 무음 근처를 골라 매 반복 사라지게 하는 방식은 사용하지 않았다.

manifest.csv는 Excel 열람을 고려한 UTF-8 BOM이다. 실제 저장 파일의 RIFF 길이·fmt/data 청크·wave 헤더·PCM 데이터를 다시 읽었다. duration_seconds=sample_count/48000. signed int16/32768을 FS로 사용했다. peak_dbfs=20log10(max(abs(x))), rms_dbfs=20log10(sqrt(mean(x²)))이며 RMS는 무음·꼬리를 포함한 파일 전체다. LUFS·체감 음량·인증 true peak 측정값은 아니다. clipping_sample_count는 표본이 −32768 또는 +32767인 개수다. dc_mean_fs는 표본 평균이다. 모든 파일의 표본 피크 ≤−6 dBFS, 클리핑 0, DC 평균 0을 확인했다. 100 Hz 미만·6000 Hz 초과 에너지 비율은 rFFT에 단측 에너지 가중치를 적용한 보조 수치다. 짧은 파일의 스펙트럼 분해능 한계가 있다.

sha256은 헤더를 포함한 WAV 전체, pcm_sha256은 PCM 데이터 청크만의 해시다. 루프 전용 열은 단발 파일에서 빈칸이다. loop_join_delta_lsb는 첫−마지막, loop_head_minus_tail_rms_db는 첫 20 ms−마지막 20 ms의 부호 있는 차이이며 절댓값 열을 함께 기록했다. LSB는 PCM 정수 1코드(1/32768 FS)다.

파일 대조: 지정 파일명 21개와 WAV 집합 일치, 누락·추가 WAV 0, PCM SHA-256 21개 모두 고유. 기존 비교 파일과 동일 PCM 0. 길이가 다른 파일도 짧은 길이까지 잘라 절대 정규화 내적을 비교한 최대값은 0.132856 (`PC_ClothMove_Loop_v1.wav` / `K1_ButtonRelease_v1.wav`)다. 이는 시작점 정렬 파형의 단순 유사도 보조값이며 청각적 구별을 증명하지 않는다. 같은 길이 파형 복제는 해시로, 단순 진폭만 바꾼 시작점 정렬 복제는 이 내적 비교로 추가 점검했다. 부분 재료의 지각적 유사성이나 임의 시간 이동·변형까지 판정한 것은 아니다.

## 미확인 사항·작업 경계

직접 청취·헤드셋 비교·5회 반복 평가를 하지 않았다. 따라서 청취 완료, 현실적인 실물 소리, 피로하지 않음, 루프가 자연스러움으로 확정하지 않는다. 접착·클립·단추 간 구별, 잡음 같은 지속 마찰 여부, 거슬리는 고역·저역, 합성 티, 전원·분석 알림·완료음 간 혼동, 동시 재생 마스킹은 미확인이다. 실제 재료 녹음·실측 임펄스 응답·사용자 동작 속도 연동을 쓰지 않아 질감 재현에 한계가 있다. 두 전자음은 명확한 기기 피드백용 합성음이며 실제 AED 동작·제세동 에너지를 음향으로 재현하거나 인증하지 않는다.

이번 추가 21종은 Docs/B 아래의 미적용 시안이다. Assets 반입·Unity 임포트·재생 연결·코드·씬·프리팹·설정 변경을 하지 않았다. Unity 실행·Play·Simulator·batchmode·자동 테스트·빌드·스테이징·커밋·Push 없음. 작업 전부터 있던 기존 3종의 프로젝트 적용 상태와는 별개다. 프로젝트 생성 스크립트·Editor 도구·새 패키지를 추가하지 않았다.
