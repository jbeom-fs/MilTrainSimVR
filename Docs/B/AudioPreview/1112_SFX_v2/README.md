저장 파일을 다시 읽어 수치 분석했다. 직접 청취·Unity 임포트·컴파일·재생은 하지 않았다. +6dB는 진폭 증가량이며, 체감상 두 배로 들린다는 뜻은 아니다. 헤드셋에서 실제 감기 중 음량과 루프 경계를 확인한다.

적용 시 새 v2 파일을 Assets/B/Audio/TrainingSfx/로 반입하고 구급법 BandageWrapSfx의 AudioSource 클립을 교체한다. TrainingFieldSetup의 WrapClipPath와 해당 SHA-256 기대값도 함께 갱신해야 한다. 클릭·완료 음원과 재생 조건·페이드·거리 설정은 유지한다.
