# B 교육장 허브 복귀 — 포털 방식 확정·구현 보류

> **11/11 보류 해제·구현:** 두 B 씬 출구를 A `HubPortal_ToHub` 인스턴스로 바꾸고 직접 분야 이동을 없앴다(파일 변경·정적 확인 완료, 사용자가 포털 위치를 북벽 문 앞으로 조정한 뒤 확인 완료 보고). [1111 허브 복귀 포털 구현 기록](1111_허브복귀_포털_구현기록.md)

작성: 2026-11-10. 사용자 결정과 정적 점검 결과를 기록한다. 이번 작업은 문서만 변경하며 코드·씬·자산·설정은 변경하지 않는다.

## 사용자 확인 완료

- 사용자가 11/09 마감의 후속 1번인 생성 도구 삭제 후 재컴파일·구급법/화생방 읽기 전용 검사 확인에 대해 “문제 없음 확인”을 보고했다. 해당 항목은 사용자 확인 완료로 기록한다.
- 이 보고를 Quest 2 통합 경로·성능·모든 예외 경로의 통과로 확대하지 않는다. 에이전트 실행 검증은 하지 않았다.

## 확정한 이동 흐름

**허브 → 구급법 → 허브 → 화생방 → 허브**

- 구급법과 화생방의 직접 이동은 최종 흐름에서 제외한다. 다른 분야로 가려면 반드시 허브를 거친다.
- B 교육장 출구는 허브에 구현된 것과 동일한 포털 형태로 구성한다. 허브 복귀 버튼을 추가하거나 기존 버튼을 허브 복귀 버튼으로 바꾸는 안은 채택하지 않는다.
- A가 이미 구현한 허브·포털·씬 이동 기능을 재사용하는 방향이다. 독립적인 B 전용 포털 기능을 먼저 만들지 않는다.

## 구현 보류와 재개 기준

- **사용자 지시로 포털 연결 구현은 뒤로 미룬다.** A가 포털 기능을 추가 변경할 수 있으므로 지금 B 코드·씬·자산을 수정하거나 기존 분야 간 이동 버튼을 삭제하지 않는다.
- A의 포털 변경 사항을 확인한 뒤 최신 구조를 다시 읽고 B 출구에 재사용할 범위를 정한다. 현재 함수와 동작을 최종 연결 계약으로 고정하지 않는다.
- 실습 진행·완료 화면·중단 확인 중 이동 제한, 교육 종료/중단 정리, 재진입 초기 상태는 기존 B 운영 정책을 보존하는 방향으로 후속 점검한다. 포털과의 구체적인 연계는 재개 시 확인한다.
- 현재 추가 구현 과제는 보류 상태다. 허브 복귀 버튼 구현이나 분야 간 이동 기록 갱신을 다음 작업으로 자동 시작하지 않는다.

## 11/10 정적 점검 기준

- `A_Hub.unity`에는 `B_FirstAid`·`B_CBRN` 진입 포털과 각 복귀 지점이 연결돼 있다.
- A의 `HubPortal`은 `CourseRoute.Enter()`로 진입하며, `CourseRoute.ReturnToHub()`와 `HubStart`가 허브 로드와 기록된 과정 포털 앞 배치를 제공한다. 향후 A 변경 후 재확인한다.
- B의 `TrainingFieldExit`·`TrainingFieldCoordinator`와 두 저장 운영 씬에는 현재 구급법↔화생방 직접 이동만 연결돼 있다. 이는 아직 변경하지 않은 현재 구현이며, 위에서 확정한 최종 흐름과 구분한다.
- B TrainingField 어셈블리에는 현재 A Common 참조가 없다. A 기능 직접 호출에 필요한 참조 및 연결 방식은 재개 시 최신 구조를 기준으로 검토한다.
- 공용 `EditorBuildSettings`에는 B 두 씬이 있으나 `A_Hub`는 없다. 실제 배포용 Build Profile·시작 씬은 별도 확인 대상이며 이번에 수정하지 않는다.

## 11/10 마감 후속 확인 — A 재사용 후보 추가, B 구현 보류 유지

- 마감 시작 HEAD `e78e538`에서 A 커밋 `cb627a7`과 [1110 B·C 통지](../A/1110_BC통지_허브연결.md) §6을 읽었다. `Assets/A/Prefabs/HubPortal_ToHub.prefab`은 허브와 같은 모양의 복귀 포털이며 각 출구에 B_FirstAid/B_CBRN 과정 ID를 넣는 안내가 있다.
- B·C 씬 설치와 실습 중 차단·종료 정리는 각 담당 범위다. 통지는 포털 자체 잠금이 없다고 설명한다. B 교육 소유권 연계를 별도로 설계·검토해야 한다.
- 기본 포털은 이름판까지 약 3.3m, B 실내 천장은 약 2.64m다. 재개 시 외형·이름판·머리 진입 영역·레이 선택 영역과 실제 출구 공간을 함께 확인한다.
- A가 후보를 준비했다고 사용자 보류가 해제된 것은 아니다. 현재 B 출구의 직접 분야 이동은 아직 그대로이며, 최종 목표는 허브 경유 흐름이다. 이번 마감에서 포털 설치·코드·씬·빌드 설정 변경은 하지 않았다.
- 재개 기준과 오늘 다른 작업 상태는 [1110 작업 마감](1110_작업마감_진행상황.md)을 따른다.
