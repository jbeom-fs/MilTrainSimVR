## 2. 사용한 모델과 구동 방식

- 모델: `Assets/B/Models/Mannequin/Mannequin.fbx`를 씬에 그대로 인스턴스(`mixamorig1:*` 본, 스킨 메시, 임포트 재질). K1 복사본·Humanoid Avatar·AnimatorController는 만들지 않았다.
- 이유: Humanoid 변환은 임포트 설정 변경 또는 복사본·Avatar 구성이 필요하고, 빈 상태의 기본 자세·IK 회전 기준을 정적으로 확인할 수 없다. 대신 `K1UserAvatar`가 리그를 직접 푼다(패키지 추가 없음).
- 본 제어 주체는 `K1UserAvatar` 하나. 모델의 Animator는 구성 시 비활성화. 매 계산마다 구동 본을 휴지 자세로 되돌린 뒤 설정(LateUpdate, 렌더링 직전 `onBeforeRender` 재계산).

| 부위 | 방식 |
|---|---|
| 머리·목 | **추적**: HMD 카메라 위치·회전. 머리 본 회전 = 카메라 회전 × 휴지 상대 회전 |
| 양손 | **추적**: 좌우 컨트롤러 위치·회전 + 손목 오프셋. 손 회전은 손 조준 기준(가운뎃손가락 뿌리 방향·검지 쪽)을 컨트롤러 축(+z 앞, +y 엄지 쪽)에 맞춤 |
| 팔꿈치 | **추정**: 어깨-팔꿈치-손목 2본 해석 IK, 팔꿈치 힌트(아래·바깥·뒤) |
| 몸통·골반 | **추정**: 몸 방향은 머리 수평 방향을 0.3 s 시정수로 따라감. 골반 이동으로 아바타 눈 위치를 HMD에 맞춤(기울기 최대 0.3 m, 앉기 최대 0.6 m, 들림 최대 0.15 m) |
| 다리·발 | **추정**: 발은 서 있는 기본 자세 위치(바닥)에 고정, 무릎은 2본 IK(앞쪽 힌트). 발 위치 추적 아님 |
| 척추·어깨·손가락 | 휴지 자세 그대로 |

전신 관절 측정 기능이 아니다. 거울에서 자신의 몸과 장비 위치를 확인하기 위한 추정 자세다.

## 3. 정렬 기준과 조정값 (`K1_UserAvatar` Inspector)

- 눈 기준: `eyeOffset`(머리 본 좌표의 두 눈 사이 점). 구성 시 머리 본에서 메시 최상단까지 높이의 45 % 위·42 % 앞으로 초기값 계산(원본 임포트가 `HeadTop_End` 같은 끝 본을 제거할 수 있어 메시 bounds 사용). 매 프레임 이 점이 HMD 카메라 위치와 일치하도록 골반을 이동.
- `standingEyeHeight` 1.6 m: 시작 시 마네킹을 균일 배율로 맞춤(키 대응). 사용자의 실제 선 눈높이로 조정.
- `floorHeight` 0 m: 발이 놓이는 바닥 높이(월드).
- `armLengthScale` 1: 위팔·아래팔 길이 배율(팔 길이 대응, 0.8~1.25).
- `wristOffset` (0, −0.02, −0.08) m: 오른 컨트롤러 기준 손목 위치(왼손은 x 반전). `handRotationOffset`: 손 회전 보정(왼손 반전).
- `bodyTurnTime`, `trackingBlendTime`, `maxCrouch`, `maxLean`.
- XR Origin·카메라·컨트롤러는 읽기만 하고 옮기지 않는다. 아바타는 XR Origin 밖의 `K1_MirrorAvatar/K1_UserAvatar`.
- 추적 소실: 각 입력(머리·좌·우)이 `TrackedPoseDriver` 추적 상태(위치+회전)를 잃으면 마지막 유효 자세 유지, 복귀 시 0.25 s 동안 보간. 처음 추적 전에는 휴지 자세로 제자리.
- 1인칭: `RenderPipelineManager.beginCameraRendering`에서 HMD 카메라 렌더링 때만 아바타 렌더러를 `forceRenderingOff`. 레이어 추가 없이 1인칭 시야·장비 조작을 가리지 않는다. Collider·Rigidbody·XR 상호작용 없음.

## 4. 전신 거울·후면 보기

공통(`K1ObserverView`):
- 각 화면이 자체 카메라를 가짐. 씬에는 카메라를 **꺼진 상태·대상 텍스처 없음·스테레오 없음**으로 저장. 활성화 시 RenderTexture 생성 → 카메라에 연결 → 켬. 비활성화·씬 종료 시 카메라 끄고 텍스처 `Release`·`Destroy`.
- 화면: Unity Quad + B 재질 `MAT_K1_ObserverScreen`(URP Unlit). 텍스처·타일링은 MaterialPropertyBlock으로만 지정, 재질 에셋은 그대로.
- 재귀 방지: 어떤 관찰 카메라가 렌더링할 때든 모든 관찰 화면을 숨김. 관찰 텍스처가 다시 관찰 화면에 그려지지 않는다.
- 비용 제한: 그림자·후처리·MSAA·HDR·오클루전 끔, 원거리 제한(거울 6 m, 후면 1.2 m), 해상도 조정값(거울 세로 1024 px, 후면 512 px).
- 카메라 자세·투영은 `beginCameraRendering`(URP가 이 콜백 뒤 카메라 데이터를 만듦)과 LateUpdate에서 갱신.

전신 거울(`K1_Mirror`, 0.8 × 1.8 m, 중심 (−1.15, 0.95, 0.95), 작업대 왼쪽에서 시작 위치를 향함):
- HMD 카메라 위치를 거울면에 반사한 점에서 거울면과 정렬, 거울 사각형을 지나는 비대칭 절두체(일반화 원근 투영), 근평면 = 거울면 → 거울 뒤 물체 제외. 화면에서 좌우 반전 표시.
- **단안**: 중앙 시점 한 장을 양쪽 눈에 같은 이미지로 보여 준다. 머리 위치에 맞는 원근은 반영되지만 눈별 양안 거울(정확한 깊이감)은 아니다.

후면 보기(`K1_RearView`, 0.36 × 0.36 m, 중심 (−0.62, 1.55, 1.5), 위에 `후면 보기` 3D 글자):
- 카메라가 머리 수평 방향 뒤 0.55 m·눈보다 0.06 m 위에서 뒤통수(눈 뒤 0.09 m)를 바라봄. 방향은 0.2 s로 부드럽게 따라감. 화면은 고정 위치.
- 거울은 몸 전체·앞모습, 후면 보기는 뒤통수 끈 확대로 용도 구분. 교육 단계·완료 조건에 확인 절차를 넣지 않았다.

배치: 안내판(오른쪽)·시작 버튼·주머니·손 이동 경로(x≈0)와 분리. 위치·크기·해상도는 처음 생성 때만 정하고 이후 사용자 조정값을 유지한다(거울 크기 = `Surface` 배율).

알려진 한계·확인 필요:

## 8. 사용자 확인과 커밋 반영 (2026-10-28)

- 사용자는 최초 확인 때 정면 거울이 보이지 않는다고 보고했다. 당시 기존 Editor 로그에는 후면 라벨 생성 중 `MissingReferenceException`으로 메뉴 7이 중단된 기록과 RearView 참조 누락 로그가 있었다.
