# 압박붕대 감기 조작 전환: 영역 유지식 자동 감김 (2026-11-03)

상태: **코드 수정 완료. 컴파일·메뉴 1/2·Play·Simulator·헤드셋 모두 미확인. 미커밋.**

착수 시 작업 트리:
- 감기 전 확인 입력 판정 수정, 직접 압박 완화·진행률 수정(둘 다 미커밋)
- 폰트 자산 변경
- 사용자의 메뉴 1 실행으로 바뀐 씬(레이아웃 개정 6, `Practice/ContactProgress`, `Guide_Path`)

모두 보존했다. 이번 작업은 기존 고리 통과식 감기를 대체한다. 방식 선택 모드·설정 화면은 없다. ③~⑦ Dressing 조건 누락은 별도 후속이다.

## 1. 최종 조작 흐름

직접 압박 → 감기 전 확인(한 손 유지 조건 그대로) → 다음 순서로 진행한다.

1. 롤붕대를 잡는다(어느 손이든 가능, 드레싱은 놓아도 된다).
2. 팔 위에 표시된 감기 영역으로 가져간다.
3. 영역 안에서 유지하면 감긴 띠가 팔 둘레로 늘어나고 "붕대 감기 N%"가 오른다.
4. 100%가 되면 기존 `CompleteWrap`이 실행된다. 롤 선택 해제·숨김, 붕대 끝 생성까지 한 번만 진행된 뒤 끝 배치 단계로 넘어간다.
5. 붕대 끝을 배치한다.
6. 테이프로 고정한다.

끝·테이프의 위치·면·각도·정상 놓기(추적된 손, 취소 아님) 판정과 허용오차는 변경하지 않았다.

## 2. 감기 영역

| 항목 | 값·내용 |
|---|---|
| 저장 위치 | `PB_WrapGuide`(상처 판정 프레임 자식)의 `PressureBandageWrapPath.zoneCentre`·`zoneSize`. B 소유 직렬화 값이고, 선택 시 Gizmo로 표시된다. |
| 좌표 | 경로 프레임 기준. x는 프레임 +X, y는 상처 쪽(팔 축에서 멀어지는 방향), z는 팔을 따라 손목 쪽이다. 상처 프레임을 따라 이동·회전한다. |
| 기본값 | 중심 (0, 0.18, 0) m, 크기 (0.20, 0.12, 0.20) m. 팔 축에서 0.12~0.24 m 높이, 상처 쪽 팔 바깥이다. |
| 판정점 | 롤 중심 `Anchor_RollAxis`(`Application.RollCentre`) |
| 팔 안쪽 배제 | `InWrapZone`은 상자 안이면서 외곽 경계(피부 + 여유, 드레싱 외곽, 모든 층)보다 바깥일 때만 참이다. 상자를 팔 안쪽까지 키워도 그 부분은 인정하지 않는다. |
| 표시 | `PressureBandageGuide`의 영역 윤곽. 상자 12개 모서리를 교차 띠로 그린 표시 전용 메시이며 충돌체·입력이 없다. 크기가 바뀌면 다시 생성한다. 기존 `Guide_Path` 오브젝트를 메뉴 1이 `Guide_WrapZone`으로 한 번 이름을 바꿔 재사용한다(`FormerlySerializedAs("pathDots")`). |

기존 씬에는 새 필드가 직렬화돼 있지 않아 C# 기본값이 적용된다. 메뉴 1은 영역 값을 쓰지 않으므로 사용자 조정이 보존된다.

## 3. 감기 시간과 진행량 소유

- `PressureBandageApplication.wrapSeconds`: 기본 5 s, 개발값이며 직접 압박 시간과 별개다.
- 진행량은 `wrapAmount`(0~1)를 Application 하나만 계산한다. 공개 값은 다음 두 가지다.
  - `WrapProgress`: EndPlacement 이후에는 1
  - `WrappedAngle` = `WrapProgress × 경로 전체 각`
- 진행 조건(`CurrentBlock` + `UpdateWrap`)은 모두 충족해야 한다.
  - 포커스
  - 드레싱 배치 유효
  - (Ready일 때) 교육 잠금 아님
  - 롤 선택 중
  - 선택 손 추적
  - 롤 중심이 영역 안
- 첫 유효 프레임에 감기를 시작한다(`Begin`). 이후 프레임마다 `min(deltaTime, 0.1 s) / wrapSeconds`를 더한다.
- 제거한 조건: 고리 순차 통과, 최소 접근 각도, 회전 방향, 고리별 축 위치, 이동 거리·관통·띠 범위, 롤 몸체 sweep, LooseValid.
- 교육 잠금: 이미 쥔 롤은 선택 필터를 통과하므로, `PressureBandageTrainingStart.Update`가 `Application.WrapStartLocked = !(Started && AllowsBandageParts)`를 기록한다. 이 값은 감기 시작만 막고 진행 중인 감기는 막지 않는다. 장비는 Tutorial을 참조하지 않는다.

## 4. 진행값과 연출·띠·진행률 연결

- 감긴 띠: `PressureBandageRibbons.BuildApplied`가 `WrappedAngle`까지 경로를 따라 다시 생성한다. 진행이 오르는 프레임마다 `Version`이 올라 다시 생성된다. 런타임 작업 메시 정책은 그대로이며 원본 메시를 변형하지 않는다.
- 연결 띠: `UpdateConnection`이 `WrappedAngle`에서 실제 롤 출구까지 그린다. 같은 프레임에서 진행 갱신 뒤에 계산하므로 감긴 끝과 이어진다. 무효 연결은 기존처럼 그리지 않는다(표시 전용).
- 잡고 있는 롤은 이동시키지 않는다. 별도 연출용 롤은 만들지 않았다. 감긴 띠의 전진과 롤로 이어지는 띠가 감김 연출이다.
- 진행률 줄: Guide가 같은 프레임(105 > 102)에 `WrapProgress`를 내림 %로 표시한다. UI만 앞서거나 연출만 먼저 끝나는 경로는 없다.
- 끝 위치: 기존과 같이 `AngleOf(LastWaypoint)` 기준이다(`WrappedAngle`과 같은 값).

## 5. 중단·재개·취소·다시하기

| 상황 | 처리 |
|---|---|
| 영역 이탈·롤 놓기·선택 손 추적 소실·포커스 이탈 | `counting = false`. 진행량·감긴 띠 유지. 안내는 하나만 표시 |
| 복귀 | 첫 유효 프레임은 0 추가. 최대 0.1 s 단위라 점프·즉시 완료 없음 |
| 다시 잡기·손 바꿈 | `lastRollHolder` 변경 → 첫 프레임 0. 이전 손 시간 이어받지 않음 |
| 드레싱 이탈(0.3 s)·밀림·회전 | 기존 `CancelApplication` → Ready, `wrapAmount = 0`, `CancelCount`++ → Link가 감기 전후 확인 철회, 새 시도 0%. 롤을 쥔 채여도 감기 전 확인 전에는 `StartLocked`로 시작 안 함 |
| 다시하기 | `ResetEquipment` → `ClearApplicationState`(진행 0), Ribbons 원복, Guide `ClearForReset`(진행률 캐시·줄 초기화) |

## 6. 드레싱 GRAB 요구 제거 지점

- `Application.CurrentBlock`: `DressingHandNotTracked`·`DressingNotHeld`·`SameHand` 삭제. 배치 유효만 확인한다.
- `Application.UpdateWrap`: 드레싱 선택 변경 감지 삭제(`lastDressingHolder` 삭제). 드레싱을 놓아도 중단·초기화되지 않는다.
- `TryPlaceEnd`·`TryFixTape`: `IsHoldValid` 대신 `focused && IsPlacementValid`. 실패 이슈 `HoldRequired`는 `PlacementRequired`로 바꿨다.
- 고정 시 `CancelSelection(dressing.Grab)`은 유지한다(잡고 있을 때만 놓게 함).
- Course Guide `BandageAction`: 드레싱 손 추적·유지 선행 조건과 "드레싱 유지" 표식을 제거했다. 테이프 내려놓기는 드레싱과 테이프를 양손에 쥐었을 때만 안내한다.
- StatusBoard `BandageInstruction`: 같은 방식으로 정리했다. `HoldDressingForBandage`·`HoldBeforeFix`를 삭제하고 `FixNeedsPlacement`를 추가했다.
- 유지한 것:
  - 한 손 한 부품 필터
  - 감기 전 확인의 한 손 유지(`CanConfirmCheck`, Guide PreCheck 분기)
  - 직접 압박 양손 판정

## 7. 안내 문구(⑤ 붕대 감기)

화면에는 단계 줄, 행동 한 문장, "붕대 감기 N%"가 표시된다.

| 조건 | 행동 |
|---|---|
| 롤 미보유 | 롤붕대를 잡으세요. / (감는 중) 롤붕대를 다시 잡으세요. |
| 드레싱 + 테이프로 양손 사용 | 테이프를 먼저 내려놓으세요. |
| 선택 손 추적 소실 | 컨트롤러를 시야 안으로 가져오세요. (표식 숨김) |
| 영역 밖 | 롤붕대를 표시된 영역으로 가져가세요. (영역 윤곽) |
| 영역 안 | 영역 안에서 롤붕대를 유지하세요. (영역 윤곽) |
| 포커스 이탈 | 앱 화면으로 돌아오세요. |

- 고리·화살표 관련 행동(`ActMoveRollToStart`, `ActFollowPath`, `ActRollAway`, `ActRollCloser`, `ActAroundArm`, `ActFromHere`, `ActReverse`, `ActGateAgain`, `ActUseOtherHand`)과 장비판 이슈 문구는 삭제했다.
- 진행률 줄은 `Practice/StepProgress` 하나다.
  - ③에서는 "압박 유지 N%", ⑤에서는 "붕대 감기 N%"를 표시하고 동시에는 표시하지 않는다.
  - 끝·테이프·다른 화면에서는 빈 줄이다.
  - 기존 `Practice/ContactProgress`는 메뉴 1이 한 번 이름을 바꾼다. Guide 필드는 `progressText`(`FormerlySerializedAs("contactProgressText")`)다.

## 9. 사용자 적용 절차

1. 재컴파일한다.
2. 메뉴 1을 실행한다. 로그에서 `Guide_Path renamed to Guide_WrapZone`과 `progress line ... renamed to Practice/StepProgress`를 확인한다.
3. 메뉴 2를 실행한다. 영역 검사와 INFO 값을 확인한다.
4. Play/Simulator로 확인한다.

영역 위치가 손에 닿기 어렵거나 팔과 겹쳐 보이면 `PB_WrapGuide`의 `zoneCentre`·`zoneSize`를 조정한다. 메뉴 2가 팔 침투를 검사한다.

## 10. 남은 제한

- 연출용 롤은 만들지 않았다. 감김 연출은 감긴 띠와 연결 띠로만 표현된다. 잡은 롤은 손에 남는다.
- 롤 몸체가 외곽에 닿는 자세여도 진행은 된다(영역 판정은 롤 중심 기준). 이때 연결 띠는 그리지 않는다.
- 진행 중에는 매 프레임 감긴 띠 메시를 다시 생성한다(최대 약 600 스테이션). Quest 2 성능은 사용자 확인이 필요하다.
- 감기 시간·영역 크기·회전 수는 개발값이다. 교안 방식·장력·시간이 아니다.
