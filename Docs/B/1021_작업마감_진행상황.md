1. 시작 화면에서 시작 선택.
2. 전원 버튼 안내·강조가 나오고 실제 버튼 선택으로 AED 전원을 켬.

### 부착 기준과 표시

| AED 패드 | 판정 앵커 | 새 인체 표시 |

- 사용자가 현재 위치와 위 대응 관계를 이번 구현 기준으로 승인했다. `provisional=false`이며 예시 위치 라벨은 제거됐다.
- 거리 허용값 `0.06m`, 부착면 방향 `45°`, 면 위 회전 `180°`로 해당 회전 검사는 꺼진 상태다. 이를 의료 기준 수치로 설명하지 않는다.
- 씬의 앵커 위치·Marker override는 사용자 조정값이다. Prefab 기본값으로 임의 복원하지 않는다.

- `AedPad` 논리 루트, 부착 상태, Rigidbody는 유지한다. 루트 자체를 꺼서 콜백·완료 판정을 깨뜨리지 않는다.
- 취소와 정상 놓기를 구분하며, 고정 후 XRI의 지연 detach가 다시 던지지 않도록 throw·보간·속도를 처리한다.
