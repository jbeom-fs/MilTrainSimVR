# MilTrainSimVR 전체 기획 발표 — PPT 제작 브리프

작성일: 2026-11-18  
용도: 이 문서 하나를 전달받은 제작자가 프로젝트 저장소나 앞선 대화를 읽지 않고 발표용 PPT를 작성할 수 있도록 하는 요약본.  
현재 산출물: 내용·구성·미디어 배치 계획. PPT 파일은 아직 제작하지 않았다.

## 1. 발표 조건과 사실 표현

- 언어: 한국어.
- 발표 대상: 프로젝트를 처음 접하는 평가자·청중. 개발 목적, 콘텐츠, 사용자 경험을 설명한다.
- 분량: 표지 포함 총 14장, 사진·영상 설명 시간을 포함해 약 10~12분.
- 발표 전제: 사용자가 지정한 “전체 기능이 정상 동작한다”는 가정으로 완성된 사용자 경험을 소개한다.
- 이 전제는 실제 컴파일·헤드셋 테스트·성능 측정·교육 효과 검증 완료를 뜻하지 않는다. 테스트 통과나 실측 수치를 새로 만들지 않는다.
- 교육 효과는 “기대 효과”로 표현한다. 실제 교안 인증, 군 공식 채택, 의료·제독 효능 검증, 실훈련 대체, 비용 절감률 등을 주장하지 않는다.
- 현재 기능, 기획 목표, 향후 확장을 구분한다. 음성 교관, 멀티플레이, 장기 학습 기록 저장, 개인별 분석 등은 현재 기능으로 넣지 않는다.
- 원본 사진·영상은 아직 이 문서에 첨부되지 않았다. 아래 자료 ID는 앞으로 받을 자료의 식별자이며 실제 파일 경로가 아니다.
- 자료가 없어도 PPT 초안을 작성한다. 해당 공간에 편집 가능한 사진·영상 자리와 필요한 장면을 표시한다. 자료가 삽입된 것처럼 보고하지 않는다.

## 2. 프로젝트 핵심 정보

### 프로젝트 소개

프로젝트명: MilTrainSimVR  
발표 부제: PC VR 기반 예비군 교육 체험 시뮬레이션

Meta Quest 2와 Windows PC를 연결해 가상 교육장에서 총기 교육, 구급법, 화생방, 시가지 전투를 체험하는 Unity 애플리케이션이다. 사용자가 장비를 직접 조작하고 안내에 따라 과정을 수행한 뒤 결과를 확인하며 반복 연습하는 환경을 목표로 한다.

핵심 문장:

> 가상 교육장에서 장비를 직접 조작하고, 수행 결과를 확인하며 반복 연습하는 VR 교육 체험 프로젝트.

### 콘텐츠 범위

4개 분야, 9개 콘텐츠로 소개한다. 허브는 콘텐츠 개수에 포함하지 않는다.

| 분야 | 콘텐츠 | 사용자 경험 |
|---|---|---|
| 총기 교육 | K2C1 분해·결합 | 부품 조작, 순서 수행, 결합 후 기능 점검 |
| 총기 교육 | 사로 사격 | 준비 절차, 표적 사격, 사격 후 안전 확인 |
| 구급법 | AED 사용 | 장치 조작, 패드 부착, 분석·충격 안내에 따른 진행 |
| 구급법 | 지혈대 사용 | 장비 배치, 조임과 고정 조작 |
| 구급법 | 직접 압박·압박붕대 | 드레싱 배치, 직접 압박, 붕대 감기와 고정 |
| 화생방 | K1 방독면 착용 | 휴대주머니 조작, 추출, 얼굴 착용과 머리끈 조작 |
| 화생방 | 보호의 착용 | 상의·하의·장갑·덧신 착용 |
| 화생방 | KD-1 휴대장비 제독 | 도구 준비와 지정된 장비 표면 처리 |
| 시가지 전투 | AI 적과의 시가지 전투 | 이동·엄폐·교전, 섬멸·점령 목표, 전투 결과 확인 |

### 전체 사용자 흐름

앱 시작 → 연병장 허브 → 교육장 선택 → 목표·조작 안내 → 실습 → 결과·수행 요약 → 다시하기 또는 허브 복귀.

- 구급법과 화생방은 별도 교육장이다. 한 교육장 안에서는 실습대를 이동해 원하는 과정을 명시적으로 시작한다.
- 구급법과 화생방 사이를 이동할 때는 허브를 거친다.
- 구급법·화생방 교육 과정은 한 번에 하나만 진행한다.
- 콘텐츠 특성에 따라 단계 수행, 결과 요약, 전투 결과의 형태가 다르다. 모든 콘텐츠에 같은 점수·등급·평가 모드가 있다고 표현하지 않는다.

### 주요 공통 경험

- 컨트롤러를 이용한 장비 잡기와 UI 선택.
- 단계 설명과 공간 표식으로 현재 행동 안내.
- 과정별 다시하기와 교육 종료.
- 공통 메뉴: 계속 / 메인으로 / 게임종료. 다시하기는 과정별 기능이며 공통 메뉴의 버튼이 아니다.
- 허브 회전 선택: 부드럽게 돌기 / 끊어 돌기.
- 사격 콘텐츠의 조준 선택: 확대 조준 / 가늠자 조준.
- 조준 선택에 따라 총이나 조작 체계 전체가 달라지는 것은 아니다. 사로 사격과 시가지 전투는 통합된 총기 조작을 사용한다.
- 효과음은 조작·수행 결과 피드백에 사용한다. 보호의 상의·하의는 착용 성공 순간에만 단발로 재생한다.

### 환경과 팀

| 항목 | 내용 |
|---|---|
| 엔진·언어 | Unity 6000.3.13f1, C# |
| 실행 | Windows PC VR, Meta Quest 2, Meta Horizon Link |
| XR | OpenXR, XR Interaction Toolkit, Input System |
| 3D 작업 | Blender를 활용한 모델 제작·수정 |
| 남우진 | 총기 분해·결합, 사로 사격, K2C1 모델과 허브 |
| 김정범 | 구급법·화생방 교육, 교육 UI와 공통 메뉴 |
| 이주석 | 시가지 전투, 적 AI, 전투용 총기 조작과 XR 환경 관리 |

팀 역할은 주요 담당 기준이다. 모든 모델을 직접 제작했다거나 모든 기능을 한 사람이 단독 구현했다고 확대하지 않는다.

## 3. 슬라이드별 내용

각 장의 “화면 문구”는 PPT 본문 초안이다. “발표자 메모”는 노트에 넣고 화면에는 반복하지 않는다. 사진·영상이 들어오면 본문을 더 줄여도 핵심 의미는 유지한다.

### 01. 표지 — MilTrainSimVR

화면 문구:

- PC VR 기반 예비군 교육 체험 시뮬레이션
- 남우진 · 김정범 · 이주석

시각 자료: IMG_01 허브 전경을 크게 배치. 제목 가독성에 필요한 범위에서만 어둡게 처리한다.

발표자 메모: 가상 교육장에서 여러 군사 교육 내용을 직접 수행하는 프로젝트라고 소개한다.

### 02. 기획 배경

화면 문구:

- 교육 내용을 직접 수행하며 익히는 환경
- 장비를 조작하고 순서를 수행하는 체험
- 익숙하지 않은 동작을 반복하고 결과를 확인하는 연습

시각 자료: 텍스트 중심. 검증되지 않은 기존 교육의 문제점이나 효과 비교 그래프는 넣지 않는다.

발표자 메모: “설명을 이해하는 것에 더해 직접 행동하고 결과를 확인할 수 있는 체험을 만들고자 했습니다.”

### 03. 프로젝트 목표

화면 문구:

- 가상 장비를 직접 잡고 조작
- 단계별 안내와 수행 결과 확인
- 다시하기를 통한 반복 체험
- 여러 교육 콘텐츠를 공통 허브로 연결

시각 자료: 조작 → 수행 확인 → 반복의 간단한 흐름. 복잡한 시스템 구조도는 사용하지 않는다.

발표자 메모: 목표는 장비와 절차에 대한 친숙도를 높일 수 있는 체험 환경을 제공하는 것이다. 학습 효과를 이미 입증했다고 표현하지 않는다.

### 04. 전체 콘텐츠 구성

화면 문구:

| 분야 | 구성 |
|---|---|
| 총기 교육 | K2C1 분해·결합 / 사로 사격 |
| 구급법 | AED / 지혈대 / 직접 압박·압박붕대 |
| 화생방 | K1 방독면 / 보호의 / KD-1 |
| 시가지 전투 | AI 적을 상대로 한 교전과 임무 수행 |

시각 자료: IMG_02~IMG_05 분야별 대표 사진 4개. 이 장에서만 전체 범위를 한눈에 비교한다.

발표자 메모: 총 4개 분야, 9개 콘텐츠로 구성된다. 총기 교육 2개, 구급법 3개, 화생방 3개, 시가지 전투 1개다.

### 05. 전체 이용 흐름

화면 문구:

- 연병장 허브에서 교육장 선택
- 안내 확인 → 실습 → 결과 확인
- 같은 과정 다시하기 또는 허브 복귀

시각 자료: IMG_06 허브 포털 사진과 간단한 진행 흐름. 이 장에는 별도 영상을 필수로 두지 않는다.

발표자 메모: 구급법과 화생방 교육장 안에서는 실습대 사이를 이동해 원하는 과정을 시작한다. 분야 간 이동은 허브를 거친다.

### 06. 총기 교육 ① — K2C1 분해·결합

화면 문구:

- 직접 부품 조작
- 순서와 결합 위치 안내
- 학습·평가 모드
- 결합 후 기능 점검과 결과 확인

시각 자료: VID_01 분리·결합 핵심 동작 15~20초를 크게 배치. 없으면 IMG_07 부품 조작 사진 자리로 대체한다.

발표자 메모: “총을 보는 데서 끝나지 않고 부품을 직접 다루며 구조와 순서를 경험하도록 구성했습니다.” 단계 수를 임의로 적지 않는다.

### 07. 총기 교육 ② — 사로 사격

화면 문구:

- 사격 준비 → 표적 사격 → 안전 확인
- 양손 파지와 총기 조작
- 탄착·명중 결과와 절차 수행 확인
- 확대 조준 / 가늠자 조준 선택

시각 자료: VID_02 조준·격발 15~20초, IMG_08 탄착 또는 결과 화면. 영상과 결과 사진이 모두 읽히도록 배치한다.

발표자 메모: 명중뿐 아니라 사격 전후 절차도 체험하는 구성이다. 조준 선택이 총기 조작 전체를 바꾸는 것으로 설명하지 않는다.

### 08. 구급법

화면 문구:

- AED: 장치 조작과 패드 부착, 안내에 따른 진행
- 지혈대: 배치·조임·고정
- 직접 압박·압박붕대: 압박 유지와 감기·고정
- 행동에 따른 단계 진행과 수행 요약

시각 자료: IMG_09 AED, IMG_10 지혈대, IMG_11 압박붕대 사진. 세 과정명이 각 장면과 연결되게 한다.

발표자 메모: 도구를 직접 조작해야 과정이 진행되는 점을 설명한다. 실제 처치 효능이나 공식 자격 평가를 제공한다고 표현하지 않는다.

### 09. 화생방

화면 문구:

- K1 방독면: 주머니 조작·추출·착용
- 보호의: 상의·하의·장갑·덧신 착용
- KD-1: 도구 준비와 지정된 장비 표면 처리
- 거울·공간 표식으로 상태 확인

시각 자료: VID_03 대표 착용 또는 제독 장면 15~20초. IMG_12~IMG_14 중 영상에 나오지 않는 과정의 사진을 함께 배치한다.

발표자 메모: 몸의 착용 위치와 손 조작을 연결한 체험이다. KD-1은 휴대장비 제독 과정이며 피부 제독으로 소개하지 않는다. 시뮬레이션의 완료 판정을 실제 보호 성능·제독 효과 검증으로 표현하지 않는다.

### 10. 시가지 전투

화면 문구:

- 건물·골목·지하 통로를 활용한 교전
- 적 AI의 경계·순찰·공격
- 섬멸 목표와 장기화 시 점령 목표
- 승패 사유와 명중률 등 전투 결과 확인

시각 자료: VID_04 이동·엄폐·교전 20~25초, IMG_15 결과 화면.

발표자 메모: 사용자 1명이 AI 적을 상대로 공간을 살피며 대응한다. 적 수·맵 크기·제한 시간 등 변경될 수 있는 수치는 원본 자료 확인 없이 넣지 않는다. 협동·대전 멀티플레이나 전투 중 구급법 연계 치료를 현재 기능으로 넣지 않는다.

### 11. 공통 사용자 경험

화면 문구:

- 단계 안내와 공간 표식
- 수행에 따른 시각·음향 피드백
- 과정별 다시하기와 공통 일시정지 메뉴
- 회전 방식·조준 방식 선택

시각 자료: IMG_16 공통 메뉴, IMG_17 교육 안내판. 설정 화면이 별도로 제공되면 자료 ID를 추가해 교체할 수 있다.

발표자 메모: 교육 내용이 달라져도 안내와 이동·메뉴 흐름을 이해하기 쉽게 구성했다. 공통 메뉴 버튼은 계속·메인으로·게임종료다.

화면 문구:

- Unity · C# / OpenXR · XR Interaction Toolkit

## 6. PPT 작성·검수 기준

- 16:9, 한국어 글꼴 사용. 별도 디자인 지시가 없으면 밝거나 짙은 단색 바탕에 파랑 계열 강조색을 사용하고 실제 장면과 충분한 대비를 확보한다.
- 군사 소재를 과장된 전쟁 포스터처럼 꾸미기보다 교육·체험 프로젝트로 읽히게 한다.
- 한 장에 한 주제. 분야 전체를 소개하는 04장과 세 과정을 묶는 08·09장은 비교에 필요한 범위만 함께 배치한다.
- 기본 제목 32pt 이상, 본문 20~24pt 수준을 목표로 하고 넘치면 문구를 줄인다.
- 장별 화면 문구는 핵심 3~4개 수준. 긴 설명은 발표자 노트로 옮긴다.
- 표·텍스트·도식은 가능한 한 편집 가능한 개체로 만든다. 미디어와 본문을 하나의 이미지로 합치지 않는다.
- 도구의 세부 버전·파일 경로·개별 버그·미검증 체크리스트는 발표 본문에 넣지 않는다.
- 실제 성능 수치, 비용·시간 절감 수치, 사용자 만족도는 제공된 측정 자료가 없으면 넣지 않는다.
- PPT 내용·레이아웃 검수는 진행하되 게임 프로젝트의 Unity 실행·빌드·테스트를 수행하지 않는다.
- 최종 PPTX를 작성할 때 14장 구성, 한글 표시, 텍스트 잘림·겹침, 사진 비율, 영상 연결과 편집 가능 여부를 확인한다.
- 발표자 노트에 장별 설명을 넣는다. 가정·기대 효과와 실제 측정 결과를 혼동하는 문구가 없는지 확인한다.
