## 2. 완료·유지할 내용

### 교육 UI와 두 운영 씬

- KD-1을 기준으로 기존 5개 과정의 제목·단계·목적/방법·현재 행동·시작/완료/다시하기 UI를 통일했다. 후속 표시·입력 보완은 사용자 검증 완료 보고를 받았다.
- `B_FirstAid`는 AED·지혈대·직접 압박/압박붕대, `B_CBRN`은 K1·보호의·KD-1이다. 분야는 씬으로 나누되 각 분야의 세 과정은 같은 교육장 안에서 진행한다.
- 각 씬의 XR/입력은 공통 시스템이 소유한다. StationRoot와 Content·PracticeAnchor·FloorAnchor 등을 기준으로 장비·판정·안내가 함께 이동하는 구조를 유지한다. 추후 전체 환경 모델 반입 시 실습 위치를 옮길 수 있어야 한다.
- 동기 시작 승인, 과정별 보류·재무장, 실제 HMD 추적 후 입구 1회 정렬, 입구 준비 중 순간이동 요청 유입 차단을 유지한다. `Time.timeScale`은 변경하지 않는다.

### 사용자 피드백과 PB 후속 개선

- 보호의 잡을 품목 안내, 다른 과정 패널의 글자 비침 대응, 지혈대 초록 영역 중심 안내, PB 상처 표시, 지혈대/PB 앉은 자세, PB 테이프 근접 부착, 과정별 교육 중단 처리를 반영했다.
- **AED 환자는 원래처럼 누워 있어야 한다.** AED까지 앉힌 것은 요구 범위 해석 오류였고 복구됐다. 기존 로그와 저장 씬에서 원본 메시·패드 앵커 복원 및 AED 의자/기록 제거를 확인한 이력을 유지한다. 지혈대·PB의 앉은 자세는 보존한다.
- 사용자는 PB 드레싱 고정 추가 요구 외에는 검증 완료·문제없음을 보고했다. 장치·양손·양안·예외 경로 각각의 통과로 확대하지 않는다.
- PB 감기 100% 완료 후 드레싱을 상처 기준 자세로 고정하고 잡기를 해제하며 재잡기를 막는다. 상태 보드는 ‘붕대로 고정됨’을 표시하고, 초기화 시 고정을 해제한다. 공유 런타임 변경이라 메뉴 재구성은 필요하지 않다. 정적 검토에서 추가 필수 오류는 발견하지 못했다.
- 사용자가 PB 마지막 실행 확인은 넘어가도 된다고 했으므로 다음 작업으로 다시 요구하지 않는다. 이를 새 실행 통과 기록으로 바꾸지도 않는다.
