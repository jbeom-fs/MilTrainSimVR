## 2. 진행 구조

- 교육 데이터 `Assets/B/Data/K1_GasMaskDonning.asset`(메뉴 5가 생성): 5단계, 단계마다 State 조건 1개.

| 단계 | 대상.신호 | 장비 근거 |
|---|---|---|
| `k1-release-closure` | `k1-carrier.closure-released` | `K1CarrierLid.IsUnlocked` |
| `k1-open-lid` | `k1-carrier.lid-fully-opened` | `K1CarrierLid.IsFullyOpen` |
| `k1-extract-mask` | `k1-mask.mask-extracted` | `K1MaskExtraction.IsExtracted` |
| `k1-bring-to-face` | `k1-mask.mask-on-face` | `K1MaskWear.ControlsBody` 또는 `IsWorn` |
| `k1-seat-straps` | `k1-mask.mask-worn` | `K1MaskWear.IsWorn` |

- `K1TrainingLink`: Runner가 Running일 때만 기록. 장비 이벤트(`Unlocked`·`FullyOpenChanged`·`Extracted`·`StateChanged`)와 매 프레임 현재 상태를 함께 읽어 처음 확인한 사실을 true로 고정. 새 RunId면 다섯 상태를 false로 초기화. 상태만 쓰고 단계 전환은 Runner `LateUpdate`가 프레임당 1단계씩 수행 → 빠른 연속 조작에도 아직 안내되지 않은 단계 사실이 남아 정지하지 않음. 이벤트 안 재귀 전환·대기 없음.
- 입력 잠금: Link가 주머니·방독면의 모든 `XRBaseInteractable`(고정장치·덮개 손잡이·본체·좌우 끈)에 추가 선택 필터로 등록. Runner가 Running/Completed가 아니면 새 선택 거절. 기존 장비 필터·조건 유지, GameObject 비활성화 없음. 완료 후에도 허용 상태라 명시적 해제(T) 가능.
- `K1TrainingGuide`: 시작 버튼 클릭 → `runner.StartTraining()` → Status가 Running일 때만 진행 화면으로 전환. 상태값으로 연타·전환 중 재클릭 무시. 이후 Runner의 `CurrentStepId`·`Status`를 매 프레임 읽어 표시(Runner 공통 알림 추가 불필요). `Completed` 확인 시 완료 화면 1회 전환 후 유지. 이후 장비를 벗겨도 변화 없음.
- Runner `startOnStart`는 끔. Runner UnityEvent에 영구 리스너를 붙이지 않음. 시작 버튼 OnClick도 코드 구독만.

## 3. 표시 문구와 보조 안내

문구 원문은 `TrainingSubtitles` 상수(요청 문구 그대로). 단계별 표시:

| 단계 | 본문 | 보조 안내(필요할 때만) | 강조 |
|---|---|---|---|
| 1/5 | 고정장치 해제 안내 | 없음 | 고정장치 고리 |
| 2/5 | 덮개 열기 안내 | 덮개 손잡이 쥔 손 추적 끊김 → 추적 안내 | 덮개 손잡이 고리 |
| 3/5 | 꺼내기 안내 | 추출 불가(`CanGrab=false`) → `덮개를 다시 끝까지 여세요.` / 쥔 손 추적 끊김 → 추적 안내 | 본체 잡기 위치 고리 + 위쪽 화살표 |
| 4/5 | `방독면을 얼굴 가까이 가져오세요.` | 쥔 손 또는 머리 추적 끊김 → 추적 안내 | 없음 |
| 5/5 | 얼굴 고정 해제 상태 → `방독면을 다시 얼굴에 가져오세요.` / 정렬·끈 준비 중(`IsPreparing`) → `착용 준비 중입니다.` / 그 외 → 끈 안내 | 머리 또는 끈 쥔 손 추적 끊김 → 추적 안내 | 끈 안내 중에만 좌우 끈 고리 |
| 완료 | `K1 방독면 착용 체험 완료` + 조임·점검 교관 안내 | 없음 | 없음 |

- 준비 판정은 장비 상태(`IsPreparing` = 얼굴 제어 중 정렬 또는 펼침 미완료)이며 UI 타이머 없음.
- 추적 안내 문구: `위치 추적이 끊겨 잠시 멈췄습니다. 추적이 돌아오면 이어서 진행합니다.` 실패·감점 기록 없음.
- 확인·다음·다시하기·메뉴 버튼, 자동 닫힘, 읽음 기록, 점수·시간·음성 없음. G·T 키 설명 없음.

## 4. 안내판 배치

- `K1_Training/K1_GuideBoard`: World Space Canvas 0.70 × 0.42 m(700×420 단위, 배율 0.001), TrackedDeviceGraphicRaycaster, 카메라에 붙이지 않음.
- 처음 생성 시 위치 (0.5, 1.38, 1.35), XR Origin 위 1.6 m 눈높이 기준 약 1.46 m, 사용자 쪽을 향함. 작업대 위·주머니 오른쪽 뒤. 주머니·손 이동 경로(x≈0)와 겹치지 않음.
- 재실행 시 위치·크기·레이아웃·색은 유지(사용자 조정 보존). 시작·완료 진입 시 시야 앞 재배치는 넣지 않음(선택 사항, 고정 배치 우선).
- 어두운 불투명 배경, 밝은 본문, 강조색 1종(하늘색: 진행 표시·보조 안내·버튼·표식). 진행 표시 5칸은 Image라 클릭 불가, 현재 칸만 높게 표시.
- 글꼴: `Assets/B/Fonts/NotoSansKR-Regular SDF.asset`(동적). 실행 시 AED와 같은 방식으로 누락 글리프 오류 로그, 메뉴 6은 원본 폰트 파일 기준 정적 검사.
- 표식: `K1_Training/K1_GuideMarkers` 아래 6개(LineRenderer, `MAT_K1_GuideMarker` URP Unlit). 콜라이더 없음, 장비 계층 밖, 원본 재질 변경 없음. 현재 단계 표식만 켬.

## 6. 정적 검토

- Runner·Context 공통 코드 무변경. 단계 전환은 기존 LateUpdate 1단계/프레임 규칙 그대로.
- 사실 기록은 Running 중에만, 같은 RunId 안에서 유지. 완료 후 기록 중지, 완료 화면 1회.
- 입력 잠금은 새 선택만 막고 이미 쥔 손은 유지(`IsSelecting`). 장비 자체 필터와 AND로 동작.
- 표시부는 장비 상태를 읽기만 함. 장비 상태 변경 호출 없음.
- 4단계 문구에 자동 부착 설명 없음.
- 알려진 한계: Runner 시작 실패 시 시작 화면과 잠금 유지(오류 로그). 착용 전 해제 뒤에는 기존 재스냅 차단으로 0.28 m 이상 뗐다가 가져와야 다시 붙음(안내 문구는 그대로).

미확인: Unity 컴파일, 메뉴 5·6 실행 결과, Play/Simulator 동작, 글자 크기·위치 체감, Quest 2 실기.

## 7. 사용자 확인 순서

1. Unity 컴파일 완료·Console 오류 없음 확인.
2. `B_K1_Tutorial` 저장 상태에서 메뉴 5 실행 → 로그 확인 → 자동 메뉴 6 결과 FAIL·NOT RUN 없음.
3. 메뉴 5 한 번 더 실행 → 메뉴 6에서 객체·리스너·표식 수 그대로인지 확인.
4. Simulator OFF 상태로 메뉴 2·4 실행해 기존 검사 유지 확인(안내판 허용 문구 확인).
5. Simulator ON, Play:
   - 시작 전 고정장치·본체를 잡을 수 없음, 안내판 `교육 시작`만 레이로 누를 수 있음. 버튼 연타 시 `[Training] Step: k1-release-closure` 1회.
   - 1/5~5/5 문구·진행 숫자·강조 표식이 행동에 맞게 바뀜. 4단계에 자동 부착 문구 없음.
   - 해제·열기·꺼내기·얼굴 스냅을 쉬지 않고 빠르게 해도 단계가 따라오고 멈추지 않음.
   - 3단계에서 덮개를 닫으면 `덮개를 다시 끝까지 여세요.`, 다시 열면 사라짐.
   - 5단계 진입 직후 잠시 `착용 준비 중입니다.` → 끈 안내·좌우 끈 표식.
   - 착용 전 T 해제 → `방독면을 다시 얼굴에 가져오세요.` → 떼었다 다시 붙이면 끈 안내 복귀, 앞 단계 반복 없음.
   - 끈을 대략 뒤로 → `Worn` → 입력·대기 없이 완료 화면과 조임·점검 안내, `[Training] Completed: k1-gas-mask-donning` 1회.
   - 완료 후 T로 해제 가능, 완료 화면·로그 재발생 없음.
   - 한글 누락(□)·잘림·스크롤 없음, 안내판이 주머니·손 동작을 가리지 않음.
6. 위치·크기 조정이 필요하면 `K1_GuideBoard` Transform을 직접 옮김(메뉴 5 재실행 시 유지).

다시하기 순서(`K1TrainingLink.TryResetForNewRun`):
1. `resetting` 설정 → 선택 필터가 모든 새 선택 거절. 안내판 상태가 `Completed`를 벗어나 연타 무시. 장비·참조 검사(장비 `TryValidate`, 선택 중인 지점의 Interaction Manager)를 장비 이동 전에 수행.
2. `runner.StopTraining()` → `Stopped`. 사실 수집(`Observe`) 중단. 공통 Runner는 Idle로 바꾸지 않으며 안내판의 `WaitingForStart`와 별개.
3. 주머니·방독면의 모든 `XRBaseInteractable`에서 `interactorsSelecting`을 복사한 뒤 `XRInteractionManager.SelectExit`(XRI 3.4 공개 API)로 정상 종료. 양손·복수 선택 처리. 종료 후 선택이 남으면 실패. 해제 콜백(덮개·끈 손 인계, XRI Drop)은 Runner 정지·선택 거절 상태라 사실·새 선택을 만들지 않는다.
4. 장비 복원(성공 이벤트 없음): `K1MaskWear` → `K1MaskExtraction` → `K1CarrierLid`. 각 API는 자기 선택이 남아 있으면 아무것도 바꾸지 않고 실패.
5. 다섯 사실(해제·완전 열림·완전 추출·얼굴 부착·착용 완료) 즉시 false → 다음 `StartTraining` 첫 판정에서 이전 값이 읽히지 않음.
6. 성공 시에만 안내판이 시작 화면 표시. 실패 시 `Faulted`, 장비 잠금 유지, 시작 화면 표시 안 함.

## 10. 사용자 확인과 커밋 반영 (2026-10-28)

- 교육 5단계·안내판·완료 안내는 `db38038`에, 다시하기·장비 초기화는 `692f916`에 커밋됐다.
