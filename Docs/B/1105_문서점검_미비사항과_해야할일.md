## 6. 사용자 실행 확인 순서

기능 작업 우선·HMD 실기 추후 방침을 유지한다. 다음은 해당 변경을 확인할 때의 순서이며 에이전트가 대신 실행하지 않는다.

1. 미저장 작업 저장 → 컴파일 결과 확인.
2. 장비 씬 메뉴 1→2, 교육 씬 메뉴 3→4. 발 본·위치·반지름과 새 교육 데이터 순서 확인.

4. 같은 쪽 발에서는 착용, 허벅지·무릎·허리·반대 발에서는 차단. 영역 안에서 잡으면 밖으로 뺐다가 다시 접근해야 착용.
5. 추적·입력 포커스 소실 때 착용 차단, 복귀 후 진행 가능. 숙임·고개 회전 중 접근성은 별도로 기록.
6. 예정된 Quest 2 + Link 실기에서 손 도달·1인칭·거울·글자·성능 확인. 장치·코드 버전·항목별 결과를 기록.
