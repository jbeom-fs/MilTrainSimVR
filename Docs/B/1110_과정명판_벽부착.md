# 과정 이름 벽 명판 — 2026-11-10

[입구 스탠드·책상 벽 정렬](1110_입구스탠드_책상벽정렬.md)의 후속이다. 두 운영 씬의 공중 과정 타이틀(StationSign) 6개를 각 과정 벽걸이 화면 위의 벽 부착 명판으로 바꿨다.

| 구분 | 상태 |
|---|---|
| 파일 변경 | **완료.** 두 운영 씬 YAML, 공통 명판 외형 프리팹 1개(+meta) |
| 정적 확인 | **완료, 실패 0건.** 저장 파일과 실제 폰트 파일 기준 (§5) |
| 사용자 Unity 확인 | **대기.** VR 가독성, 깜빡임, 입력 영향은 확인 전 (§7) |

YAML만 직접 고쳤다. Blender, 새 C#·Editor 도구, 생성 메뉴, Unity 실행은 쓰지 않았다. 커밋·Push는 하지 않았다.

## 1. 파일

- 신규: `Assets/B/Prefabs/TrainingDisplay/TrainingStationSign_Visual.prefab` (+meta, guid `b32614d874884fecac7a5e450fab1965`).
  - 루트 `Plaque`(배율 1) 아래 `Board` 하나로 구성한다. Board는 Unity 기본 Cube(fileID 10202)이고, 배율이 곧 판 크기 0.56 × 0.16 × 0.012m다.
  - 재질은 기존 B 재질 `TrainingDisplay_Case`(디스플레이 테두리와 같은 무광 짙은 회색, sRGB 0.14~0.17)를 수정 없이 재사용했다. 벽 텍스처의 평균색이 밝은 베이지(RGB 233/228/213)라 별도 테두리 없이 판이 구분된다.
  - Collider·Rigidbody·XR·카메라·조명·스크립트는 없다.
  - 원점은 판 중심이다. +Y는 위, −Z는 실내, +Z는 벽 쪽이며, 벽 쪽 면은 로컬 Z +0.006이다.
- 수정: `Assets/B/Scene/B_FirstAid.unity`, `Assets/B/Scene/B_CBRN.unity`. 각 씬에서 바뀐 기존 문서는 다음 9개뿐이다.
  - StationSign RectTransform 3개
  - TextMeshPro 3개(fontSize·raycastTarget만)
  - FieldUI 자식 목록 3개
- 백업: `Assets/B/Models/TrainingDisplay/Source~/Backups/20261110_before_station_plaques/`에 변경 직전 두 씬과 meta를 두었다(해시 일치 확인). 지난 작업 직후 저장본이며 그 뒤 변경은 없었다.

## 2. 계층과 기존 글자 재사용

```
Station_*/FieldUI
└─ StationPlaque        새 Transform, 배율 1, 판 중심 = 벽 부착 위치
   ├─ Visual            TrainingStationSign_Visual 인스턴스, 로컬 0/0/1
   └─ StationSign       기존 GameObject·RectTransform·TextMeshPro·MeshRenderer 그대로(fileID 유지)
```

- **기존 객체 재사용**: StationSign GameObject 6개(411133227, 1471954431, 1134639753 / 786132381, 1378845182, 1194443008)의 부모 과정을 최신 씬에서 대조했다. FieldUI의 자식 목록에서 StationSign 자리에 StationPlaque를 넣고, StationSign의 m_Father를 함께 고쳤다. StationSign을 참조하는 다른 컴포넌트는 없다(자기 GameObject·부모 목록·자기 렌더러만 참조).
- **글자 RectTransform**: 로컬 위치 (0, 0, −0.0075)는 판 앞면에서 1.5mm 앞이다. 그 밖의 값은 회전 0, 배율 1, anchor·pivot 중앙, anchoredPosition 0, sizeDelta 0.52 × 0.12m(판에서 좌우·상하 각 20mm를 뺀 글자 영역)다. 판과 글자는 서로 배율을 물려받지 않는다.
- **문구**: 여섯 m_text가 `TrainingSubtitles.StationAed / StationTourniquet / StationPressureBandage / StationK1GasMask / StationProtectiveClothing / StationKD1`과 일치한다. 같은 이름을 가진 다른 월드 TMP는 없다.
- **폰트·재질**: 한글 폰트 `NotoSansKR-Regular SDF`, 공유 재질 참조, 글자색, 가운데 정렬, 줄바꿈 설정을 유지했다. 폰트 asset·atlas·glyph는 손대지 않았다.
- **입력**: raycastTarget을 껐고, Canvas·Raycaster·버튼·이벤트는 추가하지 않았다.
- **방향**: 정적 계산으로 보면, 구급법 기존 타이틀 3개는 스테이션을 180° 돌린 뒤 TMP 앞면(−Z)이 벽 쪽을 향하고 있었다(실내에서는 뒤집혀 보이는 방향). 이번 명판에서는 글자 +Z가 벽 쪽이고 앞면이 실내를 향하므로, 여섯 곳 모두 정면에서 바로 읽히는 방향이다.

## 3. 글자 크기 산정

- **월드 TMP 배율**: em = fontSize × 0.1m다. `TMP_Text`의 `fontScale = fontSize / pointSize × scale × 0.1`(원근 카메라) 근거를 패키지 소스에서 확인했다. UI 크기 30~34는 쓰지 않았다.
- **fontSize 0.36 → em 36mm**. 실제 폰트 파일 `NotoSansKR-Regular.otf`의 진행폭·외곽을 fontTools로 측정했다.

|---|---|---|---|
| AED 사용 | 0.142m | 0.209m | 32.6mm |
| 지혈대 사용 | 0.174m | 0.193m | 32.6mm |
| 직접 압박·압박붕대 | 0.293m | 0.133m | 32.6mm |
| K1 방독면 착용 | 0.225m | 0.168m | 32.7mm |

| KD-1 휴대장비 제독 | 0.295m | 0.132m | 32.8mm |

- 줄 높이 52mm, 상하 여백 각 54mm다. 가장 긴 이름도 0.52m 글자 영역 안에서 한 줄로 들어가며, 줄임표나 넘침이 없다.
- 0.38에서는 한글 높이가 34.4mm로 목표 상한에 가까워서 0.36으로 정했다. 6개 모두 같은 규격·같은 글자 크기다.

## 4. 벽 배치

- **기준**: 명판은 각 과정 벽걸이 화면의 가로 중심에 맞췄다. 화면 프레임 위쪽과 명판 하단 사이는 0.150m다.
- **벽 접촉**: 판 뒷면은 실내 벽면에서 1.5mm 앞(판 중심은 벽에서 7.5mm), 글자는 벽에서 15mm다.
- **방향**: 판의 방향은 해당 화면과 같고, 벽과 평행하게 고정된다.

| 과정 | 명판 중심 (월드, m) | yaw | 벽 | 기존 공중 타이틀 위치 |
|---|---|---|---|---|
| AED 사용 | (−0.550, 1.816, −9.4325) | 180° | 안쪽 | (−1.100, 2.230, −9.015) |
| 지혈대 사용 | (−3.9925, 1.966, −3.500) | −90° | 서쪽 | (−3.900, 2.230, −2.926) |
| 직접 압박·압박붕대 | (3.9925, 1.916, −3.400) | 90° | 동쪽 | (3.850, 2.230, −2.564) |
| K1 방독면 착용 | (−3.9925, 1.846, −3.050) | −90° | 서쪽 | (−3.575, 2.230, −3.854) |
| 보호의 착용 | (3.9925, 1.916, −4.497) | 90° | 동쪽 | (3.240, 2.230, −3.549) |
| KD-1 휴대장비 제독 | (0.250, 1.816, −9.4325) | 180° | 안쪽 | (−0.002, 2.230, −9.300) |

- **천장·창**: 명판 윗면은 최대 2.046m로, 천장 2.644m 아래다. AED·KD-1 명판(X −0.83~−0.27 / −0.03~0.53)은 남쪽 창(X ±1.51~3.2)과 겹치지 않는다.
- **주변 요소**: 현장 패널, K1·PC 거울(프레임 높이 포함), K1 후면 보기 화면, 다른 명판과 겹치지 않는다. 각 명판은 자기 과정 화면 바로 위에 있어 옆 과정과 혼동될 위치가 아니다.
- **그대로 둔 것**: 실습 구역, 책상, 장비, 환자, 실습 앵커, 입구 스탠드, 디스플레이, 차단 UI, 거울(farClip 20), 이동 목적지, 보류 중인 Walk_Rear는 손대지 않았다.

## 5. 정적 확인 결과 (실패 0건)

- **YAML 구조**: 두 씬 LF·끝 줄바꿈, 중복 fileID 0, 대상 없는 로컬 참조 0. 부모·자식과 프리팹 인스턴스 연결이 일치한다. 새 GUID는 한 번만 나온다.
- **명판·글자 대응**: 명판 6개 = 기존 StationSign 6개이며, 복제본이나 남은 공중 타이틀은 없다.
- **TMP 변경 범위**: fontSize 3 → 0.36, raycastTarget 1 → 0만 바뀌었다. 문구·폰트·재질·색은 그대로다.
- **배율·위치**: 판과 글자 모두 월드 배율 1이다. 벽 간격 1.5mm, 글자 1.5mm 앞, 앞면이 실내를 향함, 화면 위 0.150m, 천장·창·주변 요소와의 비겹침을 확인했다.
- **보존**: 기존 MonoBehaviour 404개·387개의 객체 참조는 그대로이고, 스크롤·버튼·스테이션·거울 컴포넌트는 바이트 단위로 같다. 입력 관련 컴포넌트는 추가하지 않았다.

## 6. 미확인 사항

- Unity에서 판 재질과 글자 대비, SDF 글자 선명도, 판 앞 1.5mm 간격의 깜빡임 여부.
- 실습 위치·입구·중앙 통로에서의 실제 가독성. 판·글자의 실제 렌더링 크기는 폰트 측정 기준 계산값이다.
- 교육 화면 버튼·스크롤 입력과 재진입 후 고정 상태(코드·참조 변경은 없음).

## 7. 사용자 확인 순서

0. Unity에 저장하지 않은 작업이 있으면 File > Save As로 사본을 먼저 만든다. 그다음 디스크 변경을 반영해 비교한다. 변경 직전 씬은 §1 백업에 있다.
1. 두 씬을 다시 불러와 명판 6개의 판·글자·재질을 확인한다. 공중 타이틀이 남아 있지 않은지도 본다.
2. 입구와 중앙 통로에서 각 과정을 구별할 수 있는지 확인한다.
3. 실습 위치에서 글자가 읽히는지, 명판이 화면을 가리지 않는지 확인한다.
4. 정면·사선에서 판 가림, 글자 뒤집힘, 깜빡임이 없는지 확인한다.
5. 교육 화면 버튼과 스크롤 입력이 기존대로 동작하는지 확인한다.
6. 시작·중단·완료·재진입 후에도 명판이 벽에 고정돼 있는지 확인한다.

정적 배치 확인을 VR 가독성·입력 검증 완료로 기록하지 않는다.
