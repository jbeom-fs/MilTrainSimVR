## 2. 오늘 완료한 작업

### 수동 YAML 배치로 전환

자동 반입 도구의 경계 추정·배치 탐색 보완이 반복되던 상태에서 사용자가 직접 YAML 수정을 승인했다. 구급법부터 실제 씬 파일을 수정하고 화생방에도 같은 방식으로 적용했다. 고정된 두 교육장을 구성하는 목표에 맞춰 배치를 직접 관리하고, 자동 탐색 도구에 의존하지 않는 운영 방식으로 정리했다.

A 내무반 외형과 의존 메시·재질·텍스처는 새 GUID의 B 소유 사본으로 구성했다. A의 교육·XR·입력·문 동작은 가져오지 않았다. 화생방은 구급법에서 만든 B 환경과 테이블 자산을 재사용한다. A/C 원본은 편집하지 않았다.
