# 화생방 VR 교육 콘텐츠 검토

조사일: 2026-10-19
대상: Quest 2 기반 예비군 교장 시뮬레이션의 화생방 파트
상태: 공개자료 기반 후보 조사. 담당 범위와 현행 부대 교안 확인 전.

## 확인 결과

사용자가 예상한 방독면, 방호복 착용 및 제독은 모두 군 공개 훈련 사례에서 확인되는 교육 분야다. 군 자료의 용어에 맞춰 방호복은 이 문서에서 주로 ‘화생방 보호의’로 표기한다.

- 2025년 동원훈련 보도에는 보호의·전투화 덮개·방독면을 활용한 MOPP 교육과 예비군 대상 인체제독 시범교육 사례가 있다.[1]
- 2026년 군 교육 사례에서도 보호의 착용 및 MOPP 교육과 방독면 실습을 확인할 수 있다. 해당 사례의 대상은 예비생도이며 예비군과 구분한다.[2]
- 전문부대 훈련에는 인체·장비·지역 제독과 제독 후 확인이 포함된다.[3][4]

이 사례들이 모든 예비군 교장의 현행 공통 교육과정임을 뜻하지는 않는다. 정확한 필수 항목·순서·제한시간·합격 기준은 적용 부대의 현행 교안과 평가표로 확정해야 한다.

CBRN-05의 개인제독 대상이 피부, 보호장비 또는 휴대장비 중 어디까지인지는 아직 미정이다. CBRN-06과의 경계도 부대 교안으로 정한다. CBRN-07은 제독소를 이용하는 교육생 역할과 제독소를 운영하는 요원 역할을 구분한다.

## 1차 구현 권장안

### 모듈 A: 개인방호

상황·지시 제시 → 방독면 착용·점검 → 지시된 보호태세에 따른 보호의·장갑·덮개 착용 → 결과 피드백

위 흐름은 화면 구성 예시다. 실제 장비 착용 순서와 상황별 행동 우선순위는 승인 교안을 따른다. MOPP는 별도 대형 콘텐츠보다 장비 선택·착용 상태를 바꾸는 조건으로 우선 구현한다.

### 모듈 B: 개인제독

상황·제독 대상 제시 → 도구 선택 → 승인된 제독 행동 → 누락·재오염 피드백 → 후속 지시

사용자가 제독 파트를 주로 담당한다면 모듈 B를 핵심으로 삼고, 모듈 A의 착용 완료 상태와 결과를 전체 앱에서 전달받도록 구성할 수 있다. 방독면·보호의까지 직접 구현할지는 아직 확정하지 않는다.

## 제독 범위 결정 시 구분할 것

- 개인제독: 개인이 수행하도록 정해진 대상·도구·행동의 교육.
- 인체제독소 이용: 제독소 통과와 요원 지시에 따른 행동의 교육.
- 제독소 운영: 구역 관리, 요원 역할, 인원 처리 등 별도 범위.
- 장비·지역 제독: 전문 장비와 협업이 필요한 확장 범위.

이 구분은 역할과 개발 범위를 정하기 위한 것이며 공식 제독 분류체계를 대체하지 않는다.

화학·생물·방사능 상황에 하나의 제독 도구나 동일한 처리법을 일괄 적용하지 않는다. 위협 종류와 대상·장비·제독제에 따라 시나리오 규칙을 별도로 승인받는다. 제독제 배합·농도·접촉시간 등 세부 작업 수치는 이번 콘텐츠 조사에서 정의하지 않는다.

## Quest 2 구현 고려사항

- HMD를 착용하므로 얼굴 부근·머리 뒤 동작은 가상 장비의 지정 조작점 또는 단계별 확인 방식으로 먼저 검증한다. 실제 방독면을 HMD 위에 착용하는 것을 기본 전제로 삼지 않는다.
- 컨트롤러·손 추적 입력만으로 실제 방독면 밀착성, 보호의 밀폐, 제독 효과를 검증했다고 표시하지 않는다. 절차와 가상 상태를 평가한다.
- 전신 착용은 아바타·장비 배치 화면과 단계별 조작을 활용한다. 실제 전신 움직임을 모두 측정하는 것은 별도 장비 범위다.
- 오염 색상·입자 표시는 교육용 시각화임을 표시한다. 실제 오염을 육안으로 항상 확인할 수 있다는 인상을 주지 않는다.
- 제독 성공은 단순히 화면의 색을 지우는 방식보다 승인 절차·대상·도구·재접촉 규칙으로 판정한다. 시뮬레이션 완료와 실제 제독 효과를 구분한다.
- 보호의와 구급법 파트가 같은 장비 인벤토리·평가 기록 체계를 사용하도록 공통 인터페이스를 검토한다.

## 구현 전 확보할 자료

1. 적용 부대의 현행 화생방 교안·평가표.
2. 방독면 모델, 보호의 종류, 보호장갑·전투화 덮개, 개인제독 장비의 실제 구성과 사용설명서.
3. 담당 범위가 제독 중심인지, 방독면·보호의까지 포함하는지.
4. 개인제독, 인체제독소 이용, 제독소 운영 중 목표 역할.
5. 화학·생물·방사능 중 구현할 상황과 해당 교육 대상자의 수행 범위.
6. 개발 엔진, 입력 방식, 전체 앱의 보호태세·착용 상태 전달 규칙.
