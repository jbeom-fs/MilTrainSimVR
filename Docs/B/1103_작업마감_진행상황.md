## 4. 확인 수준과 씬 상태

- **압박붕대:** 사용자는 7단계·자동 완료·다시하기 변경 묶음의 검증 완료를 보고했다. 장치별·개별 체크·헤드셋 통과로 확대하지 않는다. 이후 Dressing 조건 보완은 커밋만 확인했고 별도 실행 결과는 미보고다.
- **보호장비 기본 씬:** 과거 고정 마네킹 단계의 씬 작업 완료 보고가 있다. 보호장비 최신 변경 통과의 근거는 아니다.
- **최신 사용자 몸 착용:** 컴파일·메뉴 1/2·Play·Simulator·헤드셋 모두 미확인. 보고서상 씬은 메뉴 1 적용 전이다. 코드·Blender 결과가 있다는 것과 최신 씬이 적용됐다는 것은 다르다.
- **Blender:** 제작자의 모델 변형·FBX 재수입 검사 기록과 렌더를 정적으로 대조했다. 문서 마감 중 Blender 작업·검사를 재실행하지 않았다.
- **남은 실행:** 기존 기록 §12.7의 ①~⑨와 마지막 검토 2건의 사용자 재현. 코드를 우회해 시험하거나 다른 프로젝트에서 검증하지 않는다.
- 과거 씬을 수동 조정한 뒤 메뉴 1을 확인할 때는 먼저 사용자가 저장해야 한다. 미저장 변경이 있으면 메뉴가 중단하는 것이 정상이다.
