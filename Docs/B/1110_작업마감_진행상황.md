## 2. 오늘 반영한 작업

### 거울 외형과 렌더 거리

- Blender 제작·FBX 재반입 보고를 받은 K1·PC 외형을 읽기 검토하고 `B_CBRN`에 YAML로 배치했다. K1 1,148삼각형, PC 1,212삼각형이며 각각 8부품이다.
- 기존 거울 루트의 `Surface`·`Camera`와 형제인 `Visual` 아래에 외형을 추가했다. 반사면·카메라·head·RenderTexture 수명·아바타 제외·교육 참조는 유지했다.
- 사용자는 초기 외형 적용에 대해 확인 완료를 보고한 뒤, 먼 곳에서 기본 Skybox가 보인다고 지적했다. 두 거울 컴포넌트의 `farClip: 6`과 Skybox 배경 설정을 원인 후보로 확인했고 사용자 요청으로 두 값을 20m로 직접 변경했다. 값 반영은 확인했으나 변경 후 증상 해소 보고는 별도 없다.
- 후속 벽 배치에서 거울 위치가 달라졌다. 초기 외형 확인 완료를 현재 배치·장치·성능 전체 통과로 확대하지 않는다.

### 공통 디스플레이와 본문 스크롤

- Blender 디스플레이 7규격을 납품받았고, 사용자 선택에 따라 가장 16:9에 가까운 KD-1 외형 하나를 공통으로 사용한다. 실제 화면 비율은 720:440이며 정확한 16:9로 변형하지 않았다.
- 두 씬의 6개 과정 화면과 입구 안내 2개, 총 8곳을 같은 외형·720×440 화면으로 구성했다. 미터 단위 공통 부모 아래 기존 Canvas(배율 0.001)와 외형(배율 1)을 형제로 둔다.
- 제목·단계·주요 버튼을 고정하고 본문 21개에 uGUI ScrollRect·RectMask2D·Scrollbar와 `TrainingScrollBody`를 적용했다. 기본 조작은 레이로 스크롤바를 잡아 끄는 방식이다.
- 화면 전환·단계 변경·다시하기·재진입은 맨 위부터, 같은 단계의 문구·진행률 갱신은 위치 유지로 구성했다. PB 확인 카드가 나타나면 해당 부분을 보이도록 이동한다.
- K1 본문은 기존 패널 내부 조작 제한 때문에 패널 밖에서 CanvasGroup으로 표시를 연동한다. TQ 고지문은 하단 고정, PB 확인 버튼은 확인 카드 안에 유지했다.
- 교육 화면 차단 6개를 새 화면에 맞췄고 AED 기기 버튼 차단은 별도로 유지했다. 기존 교육·완료·중단·초기화 기능을 바꾸지 않는 범위다.

### 입구 스탠드·책상 벽 정렬

- 공중에 남았던 입구 화면 2개는 Unity 기본 Cube·Cylinder 스탠드로 보완했다. 입실 방향 −Z 기준 오른쪽(−X), 월드 (−1.2, 0, −1.4), yaw −75.75°에 두었다. 화면 중심 높이는 1.5m다.
- EntryAnchor와 기존 Canvas·문구·스크롤 참조를 보존했다. 스탠드는 외형만 있고 Collider·스크립트는 없다.
- 현재 6개 책상 뒤쪽 기준 외곽은 계산상 벽에서 2.5cm다. AED·TQ·PB·PC의 미달성 배치를 추가 조정하면서 환자·의자·장비 묶음·실습 앵커·현장 패널·차단 UI를 함께 대조했다.
- AED 환자는 누운 자세, TQ·PB 환자는 앉은 자세를 유지했다. 장비의 부모 기준 초기 위치 저장·복구 구조를 코드에서 확인했다.
- 화생방 `Walk_Rear`는 앞선 디스플레이/벽 배치에서 KD-1 구역과 겹쳐 비활성화됐다. 이후 스탠드·책상·명판 작업에서는 이동 목적지를 바꾸지 않았다.

### 대형 도장 목재 명판

- 과정별 공중 타이틀 6개를 벽 부착 명판으로 바꿨다. 최초 작은 회색 판·흰 글씨는 사용자 확인에서 가독성·현실감이 미흡하다고 보고됐다.
- 글자 없는 도장 목재 Base Color 이미지를 이미지 생성 도구로 직접 제작해 `Assets/B/Textures/TrainingSigns/PaintedWood_OffWhite_BaseColor.png`에 저장했다. 2172×724 RGB이며 원본 해시는 유지한다.
- 공통 판을 1.40×0.40×0.02m로 확대하고 전용 URP/Lit 재질을 연결했다. 기존 디스플레이·거울 공유 재질과 폰트를 명판용으로 변경하지 않는다.
- 기존 StationSign 객체·문구·폰트 참조를 유지하면서 fontSize 0.90·Bold·불투명 검정으로 변경했다. 중심 높이 2.22m, 벽 뒤 간격 1.5mm, 판 앞 글자 간격 1.5mm다.
- 최종 목재 명판은 파일 반영·정적 검토 단계이며 사용자 Unity·VR 가독성 확인은 대기다.

## 4. 남은 작업과 보류

1. **최종 목재 명판 사용자 확인:** 입구·중앙 통로에서 이름 식별, 긴 이름 한 줄 표시, 검은 합성 Bold의 선명도, 나뭇결 방향·얇은 옆면·깜빡임. PC 명판은 거울보다 계산상 6.9cm 위다. 원본 텍스처 3:1과 판 3.5:1의 차이로 가로 질감이 약 17% 늘어나는 점은 시각 확인 대상이다.
2. **스크롤·배치 사용자 확인:** 좌우 레이 드래그, 화면/단계 전환·재진입 초기화, 같은 단계 위치 유지, PB 카드 노출, K1 본문 표시, 다른 과정 사용·중단 확인 중 입력 차단, 입구 스탠드와 이동 동선.
3. **장비 접근성과 몸 간섭:** TQ 키트 0.84m, PB 키트 0.80m, PC 덧신 R 1.55m의 수평 거리. AED 가슴은 앵커 오른쪽 옆 방향으로 달라졌고 TQ·PB 의자 뒤 여유는 약 9cm다. 실제 손 도달·머리/팔의 벽 관통은 사용자 확인 전이다.
4. **거울:** farClip 20 변경 후 Skybox 증상, 이동한 실습 위치에서의 몸·장비 반사와 K1 후면 보기, 거울·명판·책상 간섭을 확인한다.
   - 2026-11-11 갱신: 사용자가 거울을 확인한 결과 이상 없다고 보고했다. 거울 항목만 확인 완료이며 다른 항목으로 확대하지 않는다. 이후 재개 기준은 [1111 교육 중단·종료 디스플레이 통합](1111_디스플레이_교육중단종료_통합.md)이다.
5. **구급법 Walk_Rear 겹침 — 사용자 지시로 보류:** 현재 AED 책상과 Z 방향 약 0.135m의 정적 겹침이 남았다. 실제 잘못된 착지를 재현한 결과가 아니다. 이 마감 요청으로 이동 영역을 끄거나 분할하지 않는다.
6. **허브 복귀 포털 — 사용자 지시로 보류:** 최종 흐름은 허브→구급법→허브→화생방→허브이며 직접 분야 이동은 제외한다. 현재 B 출구 코드는 아직 두 분야 직접 이동이다. 최종 설계와 현재 구현을 구분한다.
7. **시작 씬·배포 목록:** 공용 EditorBuildSettings는 여전히 SampleScene이 첫 씬이고 B 두 씬만 등록돼 있다. 실제 배포 Build Profile은 별도 확인 대상이다. 공용 설정은 이번에 변경하지 않는다.
