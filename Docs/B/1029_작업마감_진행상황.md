## 3. 현재 조작과 수정 내용

현재 가상 흐름은 **본체 잡기·배치 → 밴드 준비 → 막대 회전 → 막대 고정 → 시간 기록 → 마감 스트랩 → Done**이다. 실제 지혈·장력·혈류·술기 합격을 판정하지 않는다. 개발 허용오차·360° 회전량·20 mm 시각 변형 등은 VR 조작 설정이다.

- 본체 배치는 정상 해제 프레임의 NearFar attach 표본으로 판정한다. 부품 OBB와 24구간 밴드 부피를 사용해 현재·부착 후보 자세의 금지 영역을 확인한다. 부착 뒤 본체 잡기는 잠근다.
- 1챕터 정적 검사에서 허용 구간 양 끝 `OutsideAllowedZone`이 보고됐다. 후속 코드는 비교에만 0.01 mm 여유와 거리·초과량 로그를 추가했다. 최신 모델 기준 검사 통과 결과는 아직 없다.
- 완성 모델은 기존 Prefab 루트·GUID·씬 참조를 유지하는 연결 방식이다. 변형은 원본 sharedMesh 대신 작업본 정점을 사용한다. 실제 임포트 축·외형·재질·관통은 사용자 확인 대상이다.
- CS0136은 `CollectVolumes`의 `size` 이름 충돌이었다. `partCenter`·`partSize`·`bandSegmentSize`로 분리됐다. 최신 컴파일 성공은 미확인이다.
- 기록 없이 마감해 진행이 막히던 경로는 기록 후 스트랩 허용으로 바뀌었다. Done은 부착·밴드 준비·막대 고정·기록·마감을 모두 요구한다. 기록 시각은 Done 안내판에도 남는다.
- 부품 해제 프레임의 `attachUpdated` 표본을 보관해 LateUpdate에서 1회 반영한 뒤 완료를 판정한다. 손 바꿈·취소·추적 소실·표본 없음은 구분한다. NearFar 이외 interactor는 밴드 준비·마감 완료가 불가능한 제한이 있다.
- 안내판은 640×560 내용 영역과 revision 2 갱신 경로를 갖는다. 첫 메뉴 실행에서 기존 영역을 갱신하고 이후 사용자 조정을 유지한다. 문구 높이 검사는 추정이며 실제 가독성 확인은 아니다.
- `ResetToInitial()`은 배치·변형·진행·기록·시계·입력 제한을 초기화하는 코드 경로다. 교육 다시하기 버튼·Runner 연결·사용자 초기화 성공은 아직 없다.

## 5. 남은 문제와 보류

1. **최신 실행 확인:** 모델 교체·2챕터 및 4건 수정의 컴파일·메뉴·조작 결과가 필요하다. 지금 3챕터까지 완료됐다고 기록하지 않는다.
2. **모델 표현:** TIME 인쇄 반전 가능성, 마감 후 시간 패치 가림이 남았다. 현재는 덮기 전에 기록하고 안내판에 시각을 유지한다. 모델 수정 완료로 취급하지 않는다.
3. **변형·가독성 미확인:** 밴드 끝·내부 밴드·스트랩 관통, 축·재질·고스트 일치, 안내판 실제 줄바꿈과 시인성은 사용자 확인 대상이다.
4. **입력 제한:** NearFar 전용 완료 경로, 렌더 직전 OnBeforeRender 추적 미반영을 유지한다. 특정 환경의 실제 결함으로 재현됐다고 확대하지 않는다.
5. **제품·교육 범위:** 실제 제품·세대·IFU·적용 교안 확정 전이다. 모델 제작과 가상 조작 완료는 의료 절차·효과 검증이 아니다.
6. **기존 보류 유지:** 실기는 추후, K1 Worn 후 손 놓기 때 끈 풀림은 사용자 지시로 보류. AED·K1의 기존 상태와 정적 참고는 각 마감 문서를 따른다. 음성·평가·점수·제독은 오늘 추가하지 않았다.
