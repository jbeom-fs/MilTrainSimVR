# 구급법 씬 YAML 고정 배치 — 2026-11-09

사용자 승인에 따라 구현 프롬프트 대신 `B_FirstAid.unity`와 B 소유 환경 자산을 직접 수정했다. 자동 탐색·메시 충돌 분석으로 배치하지 않았다. Unity 임포트·컴파일·메뉴·Play는 실행하지 않았으며, 아래 내용은 파일 변경과 정적 검토 결과다.

## 반영 내용

- A_Sandbox의 내무반 외형만 B의 새 GUID 사본으로 구성했다. Shell, 정적 문 외형, 천장 등기구 모델을 포함하고 A의 교육 스크립트·XR·카메라·광원은 가져오지 않았다.
- 환경: `Assets/B/Prefabs/TrainingEnvironment/B_BarracksShell.prefab`. 메시·재질·텍스처 등 의존 자산 28개도 B에 복사하고 참조를 연결했다. 복사한 FBX의 카메라·광원 임포트는 껐다.
- 기존 임시 Floor는 비활성화했다. 내무반 바닥의 윗면은 Y=0이다.
- `EnvironmentRoot/B_FirstAidWalkable`에 TeleportationArea 하나와 고정 목적지용 BoxCollider 7개를 추가했다. 각 목적지 윗면은 Y=0.002m다. 기존 과정별 실습 TeleportationAnchor는 유지했다.
- B의 기존 광원에 보조 Point Light 2개를 추가했다. 재질 밝기·실제 조명 결과는 Unity에서 확인해야 한다.
- 입구·출구 앵커와 보드를 방 안으로 배치하고, 과정 이름 표지는 Y=2.23m에서 중앙을 향하도록 배치했다.

| 대상 | 월드 위치 X, Y, Z (m) | Yaw |
|---|---|---|
| 지혈대 StationRoot | -2.8, 0, -2.8 | 90° |
| 압박붕대 StationRoot | 2.8, 0, -2.8 | 270° |
| AED StationRoot | -0.55, 0, -7.6 | 0° |
| EntryAnchor | 0, 0, -0.85 | 180° |
| ExitAnchor | 1.6, 0, -0.7 | 90° |

과정 Content, 환자 자세, 장비, PracticeAnchor·FloorAnchor의 로컬 좌표, 교육·XR 참조와 이벤트는 보존했다. 기존에 사용하던 실습 자세를 유지하기 위해 PracticeAnchor를 따로 뒤로 이동시키지 않았다.

## 생성 기능 정리 후 운영 방식

이번 배치에는 자동 도구의 `BarracksEnvironmentRecord`나 `ImportManifest.json`을 만들지 않았다. 실행하지 않은 자동 반입을 성공한 것처럼 기록하지 않기 위해서다. 별도 `FixedFirstAidLayout.json`에 고정 좌표, 사본 GUID, 원본 해시를 기록했다.

- 이번 씬은 직접 열어 사용한다. 사용자 확인 완료 후 생성 기능 삭제 요청에 따라 `B/환경/1·2`와 `B/교육장/1·2` 메뉴 및 관련 생성·갱신 코드를 제거했다.
- `B/교육장/3. 구급법 검사 (읽기 전용)`은 기존 교육 구조·참조를 확인하는 용도로 사용할 수 있다. 방 안 동선과 손 도달 가능성까지 보증하는 검사는 아니다.
- 내무반 자동 반입 도구 4개와 씬·프리팹에 참조가 없는 반입 기록 클래스 및 meta를 삭제했다. 교육 런타임과 기존 검사 동작은 유지한다. 코드 정리 후 Unity 재컴파일·검사 메뉴 실행은 사용자 확인 전이다.

## 정적으로 확인한 범위

- 씬의 기존 YAML 문서 12개만 변경하고 새 문서 32개를 추가했다. 기존 MonoBehaviour와 교육 프리팹 인스턴스 문서는 그대로다.
- 씬·환경 프리팹·복사한 Window 프리팹의 YAML 구문, 중복 fileID와 파일 내부 참조를 확인했다. 누락 내부 참조가 없었다.
- 생성한 폴더·자산 GUID 52개에 중복이 없고, 사본의 자산 참조 GUID가 프로젝트 또는 패키지에 존재한다. B 환경 사본에 A 자산 GUID 참조가 남지 않았다.
- 복사 대상 A 원본·meta와 A_Sandbox의 해시 57개가 작업 전과 같다.
- 기존 미커밋 C# 4개·글꼴 및 B_CBRN의 해시가 작업 전과 같다.

이 검토는 Unity가 새 YAML과 FBX를 정상 임포트했다는 증거가 아니다. 실제 환자 형상, UI 가독성, 손 조작, 순간이동 안전성은 미확인이다.

## 사용자 확인 순서

1. Unity에서 외부 파일 변경을 반영하고 `Assets/B/Scene/B_FirstAid.unity`를 다시 연다. 이전 상태가 열린 채라면 그 상태로 덮어 저장하지 않는다. 임포트 오류·Missing Script·분홍 재질·누락 메시가 없는지 확인한다.
2. Hierarchy에서 EnvironmentRoot 아래 B_BarracksShell 1개, B_FirstAidWalkable 1개, 보조 조명 2개와 기존 Floor 비활성을 확인한다. 좌우 지혈대·압박붕대, 안쪽 AED와 위 표의 좌표를 확인한다.
3. `B/교육장/3`으로 교육 구조·참조 결과를 확인한다. FAIL이 있으면 항목과 객체 경로를 기록한다.
4. Play에서 입구 정렬 후 입구판이 읽히는지, 각 과정의 시작·실습 위치 이동·장비 잡기·중단·복귀가 기존대로 되는지 확인한다. 환자나 장비와 몸이 겹치거나 손이 닿지 않으면 미완료로 기록한다.
5. 중앙·양옆·뒤쪽 고정 이동 목적지와 과정 실습 앵커를 오간다. 벽·환자·장비 안으로 이동하거나 목적지로 돌아올 수 없으면 해당 위치를 기록한다. 바닥 전체가 이동 목적지는 아니다.
6. 출구판 버튼과 기존 씬 전환을 확인한다. B_CBRN에는 이번 배치를 적용하지 않았다.

커밋·Push는 하지 않았다. 작업 전 구급법 씬의 임시 백업은 `Temp/CodexFirstAidYaml/B_FirstAid.before.unity`에 있다. Temp는 영구 보관 위치가 아니다.

## 후속 변경 — 세 콘텐츠 테이블 모델 적용

사용자가 실습대 방향을 180° 수정하고 AED 위치를 조정한 뒤, 세 콘텐츠 모두 테이블 모델을 적용하도록 요청했다. 위의 초기 배치표보다 현재 씬에 저장된 사용자 수정 Transform이 우선한다.

- 공통 모델은 A의 Table_2를 B의 새 GUID 사본으로 가져왔다. FBX·재질·텍스처 3장, 총 5개 자산이며 A 원본은 변경하지 않았다.
- 공통 프리팹: `Assets/B/Prefabs/TrainingEnvironment/B_FirstAidTable.prefab`. A에서 사용 중인 모델 회전·재질 연결·MeshCollider 구성을 기준으로 작성했다. 모델의 자체 카메라·광원 임포트는 껐다.
- AED `Desk`, 지혈대 `TQ_Tray`, 압박붕대 `PB_Tray` 각각의 자식으로 테이블 프리팹을 배치했다. 각 콘텐츠의 기존 폭·깊이·상판 높이에 맞춰 축별로 크기를 조정했다. 지혈대·압박붕대는 원래 받침대가 작아 작은 보조 테이블 크기가 된다.
- 기존 Box의 MeshRenderer 3개와 기존 BoxCollider 2개는 비활성화했다. 테이블 충돌은 새 모델의 MeshCollider로 처리한다. 원래 PB_Tray에는 충돌체가 없었다.

| 콘텐츠 | 폭 × 깊이 | 상판 높이 |
|---|---|---|
| AED | 1.20 × 0.60m | 0.75m |
| 지혈대 | 0.50 × 0.35m | 0.78m |
| 압박붕대 | 0.45 × 0.30m | 0.90m |

모델 하단은 바닥 Y=0에 맞췄다. 기존 받침대 Transform, 사용자가 수정한 StationRoot와 AED 프리팹 위치, 환자·장비·교육 참조와 모든 기존 MonoBehaviour 문서는 변경하지 않았다. B_CBRN과 기존 미커밋 코드·글꼴도 보존했다.

정적으로는 이번 변경 전 씬과 비교해 기존 문서 8개 변경·새 프리팹 인스턴스 3개를 확인했다. YAML 내부 참조·계층 연결·새 GUID 중복·자산 참조와 세 모델의 계산상 바닥 면적·상판 높이에 이상이 없었다. Unity 임포트·컴파일·Play는 실행하지 않았다.

Unity에서 씬을 다시 연 뒤 세 모델의 재질, 크기와 상판 접촉 상태를 확인하고 `B/교육장/3` 및 Play에서 장비 집기·내려놓기·복귀를 확인해야 한다. MeshCollider의 실제 충돌과 조작감은 사용자 실행 전에는 미확인이다. 이번 테이블 변경 직전 씬 백업은 `Temp/CodexFirstAidTables/B_FirstAid.before-tables.unity`다.
