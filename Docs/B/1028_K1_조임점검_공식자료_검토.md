# 2026-10-28 K1 조임·점검 안내 공식자료 검토

최신 상태(2026-10-28): 완료 화면의 조임·점검 안내와 출처가 반영됐고, 사용자는 `SeatStrapsInstruction`만 조정한 뒤 전체 문제없음을 보고했다. 관련 교육 UI는 `db38038`에 커밋됐다. 이후 다시하기 버튼이 추가돼도 본문·출처와 안내만 제공하는 정책은 유지된다. 정식 교본이나 현행 개정 교범 확인으로 표현하지 않는다. [오늘 마감 기록](1028_작업마감_진행상황.md) 참조.

## 1. 요청과 자료 기준

- 사용자 요청: 마지막 끈 조임·점검 안내를 실제 절차를 설명하는 내용으로 변경한다. 근거는 국방부 공식자료를 사용한다.
- 조임·점검은 안내만 제공한다. 별도 조작·확인 버튼·읽음 기록·합격 판정은 추가하지 않는다.
- 프로젝트 내부에는 적용 부대의 현행 K1 교본 원문이 없었다. 기존 조사 문서도 현행 교안 미확보로 기록돼 있다.

## 2. 직접 확인한 공식 원문

- 발행처: 국방홍보원 국방일보.
- 제목: 「방독면 원리와 착용」.
- 원문 입력·업데이트 날짜: 2020-10-21.
- 확인일: 2026-10-28.
- 원문: https://kookbang.dema.mil.kr/newsWeb/20201021/1/BBSMSTR_000000100128/view.do
- 확인 위치: 본문의 착용 절차 중 머리끈 조절과 착용 검사 설명.
- 확인 방법: 웹 열람 도구에서 해당 원문 열기가 실패해 공식 URL에 읽기 전용 HTTP 요청을 수행했다. HTTP 200 응답의 제목·날짜·본문을 직접 확인했다. 블로그 전재본이나 위키를 절차 근거로 채택하지 않았다.

이 자료는 국방부 소속 기관이 발행한 공식 설명기사다. 정식 교본 원문 또는 2026년 현행 개정 교범을 확인한 것으로 표현하지 않는다. 공개 원문의 범위에서 안내 문구를 작성한다.

## 3. UI에 반영할 사실

공식 원문은 위쪽 끈, 아래쪽 머리끈, 가운데 끈 순서로 교대로 당기는 조절을 설명한다. 이어 충분히 호기를 한 다음 손바닥으로 정화통의 공기 유입 부위를 가리고 들이쉬면서 얼굴과 면체의 밀착 여부를 살피는 검사를 설명한다.

원문에서 확인하지 않은 조임 힘·길이·시간·누설 수치·실패 시 세부 교정 절차는 새로 만들지 않는다. 다른 형식의 방독면 절차도 혼합하지 않는다.

## 4. 마지막 안내 본문

아래는 공식 원문을 요약한 UI 문구안이며 직접 인용문이 아니다.

> 머리끈은 윗끈·아랫머리끈·중간끈 순으로 번갈아 당겨 조절합니다.
> 조절 후 충분히 숨을 내쉬고, 정화통 흡입구를 손바닥으로 가린 채 숨을 들이쉬어 밀착 상태를 확인합니다.

- 완료 제목은 기존 `K1 방독면 착용 체험 완료`를 유지한다.
- 출처 표기는 `국방홍보원 국방일보, 방독면 원리와 착용, 2020.10.21.`로 한다. UI 본문과 분리한 작은 출처 줄을 우선한다.
- `Worn` 도달 시 완료 화면과 위 안내를 함께 표시한다. 확인 버튼이나 자동 닫힘은 없다.
- 문구는 설명용이다. VR에서 실제 조임이나 밀착 검사를 수행·통과했다고 표시하지 않는다.
- 기존의 교관 안내에 맡기는 한 문장은 위 구체적인 설명으로 대체하는 설계다.

- 이번에는 출처 검토와 설계 문서만 변경했다. 실제 `TrainingSubtitles.CompleteBody`, UI 코드·씬·Prefab·폰트는 변경하지 않았다.
