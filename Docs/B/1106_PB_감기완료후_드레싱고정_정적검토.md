# PB 감기 완료 후 드레싱 고정 구현본 정적 검토 — 2026-11-06

## 결론

사용자 구현보고서와 실제 Application·StatusBoard·TrainingSubtitles 변경, PressureDressing·TrainingLink의 기존 진행 조건, PB 프리팹의 잡기/물리 설정을 대조했다. 현재 구성 기준에서 추가 필수 코드 오류는 발견하지 못했다. Unity 컴파일·Play·Simulator·HMD·테스트는 실행하지 않았다. 이번 변경의 동작 성공을 확인한 것은 아니다.

사용자가 앞서 ‘그 외에는 검증 완료 문제없음’이라고 보고한 나머지 항목은 완료 보고를 유지한다. 이번 검토로 기존 개선 전체를 다시 미완료로 배정하지 않는다.

## 보고서와 실제 코드 대조

| 확인 대상 | 실제 코드 | 판단 |
|---|---|---|
| 고정 시작 | PressureBandageApplication.CompleteWrap:735에서 FixDressing 호출 후 EndPlacement 전환 | 감기 100%부터 적용하며 테이프 완료까지 기다리지 않음 |
| 고정 자세 | FixDressing:822에서 상처 좌표계의 위치·회전을 기록, dressingFixed 설정 | Application이 고정 상태를 소유함 |
| 잡기 정리 | FixDressing은 CancelSelection을 호출. PressureDressing.OnSelectExited는 취소된 해제를 releasePending으로 기록하지 않음 | 정상 놓기 자리 맞춤을 새로 예약하지 않는 경로 확인 |
| 재잡기 차단 | AllowSelect:449에서 !dressingFixed 조건 | 붕대 끝·테이프의 기존 필터와 분리됨 |
| 자세 유지 | LateUpdate:519의 KeepFixedDressing이 Suspended 분기보다 먼저 실행. 차이가 있으면 Transform과 Rigidbody 자세를 SetPose로 맞춤 | 보류 중에도 유지 경로 존재 |

| 초기화 | ClearApplicationState:968에서 dressingFixed=false. ResetEquipment는 선택 취소·트레이 복원 후 해당 상태 정리와 Dressing 상태 초기화 수행 | 중단 확정·다시하기 경로에 고정 해제 연결 |
| 안내 | StatusBoard.Status:215에서 IsDressingFixed면 HoldFixedByBandage 표시. 새 상수는 글꼴 수집용 문구 목록에도 포함 | 기존 ‘유지하는 손 없음’ 대신 고정 상태 표시 |

## 물리·실행 순서 확인

- PressureDressing 실행 순서 100, Application 102, TrainingLink 104, StatusBoard 110이다. Application은 기존 드레싱 판정 결과를 사용하고 이후 진행/표시가 읽는다.
- 현재 PB 프리팹의 네 장비 Rigidbody는 kinematic, interpolation 0이며 XRGrabInteractable은 Instantaneous, throwOnDetach=false, retainTransformParent=true다. 이번 고정 로직은 isKinematic 등의 물리 설정을 새로 변경하지 않는다. 따라서 별도 물리 상태 복구 누락을 현재 구성의 결함으로 판단하지 않는다.
- 새로운 선택 차단은 기존 선택을 자동으로 끊지 않지만, 정상 감기 완료에서 CancelSelection으로 해당 드레싱 선택을 명시적으로 종료한다. 보류 진입에서 강제 선택 취소를 재도입한 변경은 없다.
- KeepFixedDressing은 PressureDressing의 해당 프레임 판정 뒤에 실행된다. 실제 손 해제·XRI 후속 처리와 표시/판정이 일치하는지는 아래 사용자 확인에 포함한다. 현재 정상 경로에서 지속적인 위치 오염을 일으키는 추가 작성자는 발견하지 못했으며, 실행 순서만으로 실제 취소 결함을 단정하지 않는다.

## 남은 확인

이번 변경은 런타임 코드와 상수만으로 연결되므로 씬/프리팹의 신규 참조 연결이나 구성 메뉴 실행을 요구하는 변경은 발견하지 못했다. 컴파일 후 사용자 확인 대상은 이번 변경에 한정한다.

1. 감기 100% 직후 손이 드레싱에서 풀리고, 손을 멀리 옮겨도 드레싱/붕대가 유지되며 이전 단계로 돌아가지 않음.
2. 드레싱 재잡기는 차단되지만 끝·테이프 조작과 처치 후 확인은 정상 완료.
3. 중단 확인/계속하기에는 고정 유지. 중단 확정/다시하기/새 회차에는 트레이에서 드레싱을 다시 잡을 수 있음.
4. 개별 PB Tutorial과 통합 현장 씬에서 같은 결과. 감기 전 직접 압박·감기 전 확인 조건은 유지.

괄호 짝 검사와 정적 참조 확인은 컴파일·실행 통과 근거가 아니다. 에이전트는 코드·씬·에셋 수정, Unity 실행·스테이징·커밋 없이 Docs/B만 갱신했다.
