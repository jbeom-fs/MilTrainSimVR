| CPR 가상 절차·리듬 연습 | 후속 후보. 실제 깊이·힘·호흡 측정과 별개 |
| 보호의·장갑·덮개 착용, 탈의·오염 확산 방지, MOPP 선택 | 담당·범위 협의가 필요한 초기/후속 후보 |
| 무안내 평가·점수·합격선·상세 오류 분석·영구 결과 저장 | 현재 과정 완결/메모리 요약 범위 밖. 별도 결정 필요 |
| AED·K1 중간 다시하기, K1 자유 재수납·재잠금 교육 | 기존 완료 후 다시하기와 별개인 확장 후보 |

K1 안내판 회전 시 겹침 오판·추출 기준, AED 다시하기 후 XRI 경고 가능성, 지혈대 NearFar 전용 완료·OnBeforeRender 미반영은 기존 정적 참고다. 실제 사용자 경로·요구 입력·재현 결과에 따라 대응하며 필수 구현 목록으로 자동 승격하지 않는다.

실제 압박력·깊이·방독면 밀착 성능 측정, 자유 천 물리, 전문 제독차·제독소 전체 운영, 멀티플레이·외부 센서·LMS/서버 연동은 현재 범위에 넣지 않는다.

## 6. 권장 구현 묶음

1. 지혈대 재시작 완결: 완료 후 다시하기·장비와 교육 상태 초기화·반복 회차·단계별 조작 표식(중간 다시하기는 사용자 지시로 제외, 구현 후 사용자 확인 전).
2. 직접 압박·압박붕대 과정 전체: 제품/모델·장비 조작·교육·완료·다시하기.
3. B 허브 통합: 네 과정 진입·복귀·중단·요약·재진입.
4. 팀 앱 연결·교육 내용 마감·실기 확인·배포.

위 묶음은 개발 완료 단위다. 한 번의 구현 내부에서 의존 순서대로 나누어 확인할 수 있지만, 버튼 하나씩을 독립적인 전체 목표로 반복 제안하지 않는다. 보류 항목은 이 목록에 보인다는 이유만으로 재개하지 않는다.
