## 2. 재질과 텍스처 임포트

- **UV**:
  - 판은 Unity 기본 Cube라 정면(−Z)에 텍스처 전체가 한 번 펼쳐지고 반복되지 않는다. 판 비율(3.5:1)이 텍스처(3:1)보다 넓어 가로로 약 17% 늘어난다(나뭇결 방향과 같은 가로 방향).

- 글자는 텍스처에 굽지 않았다.

## 4. 벽 배치

명판은 각 화면 가로 중심에 맞추고 중심 높이를 2.220m로 통일했다. 판 높이는 2.020~2.420m다.

- **벽 간격**: 판 뒷면은 벽에서 1.5mm(판 중심 11.5mm), 글자는 판 앞 1.5mm다.
- **천장**: 천장 격자(Y 2.642)까지 0.222m 남는다.

|---|---|---|---|
| AED 사용 | (−0.550, 2.220, −9.4285) | 180° | 0.434m |
| 지혈대 사용 | (−3.9885, 2.220, −3.500) | −90° | 0.284m |

- **PC 명판과 거울**: 평면상 PC 거울 위쪽에 일부 걸치지만, 거울 윗면(1.951m)보다 0.069m 위에 있어 거울을 가리지 않는다. K1 거울과는 평면상 겹치지 않는다.

- **그대로 둔 것**: 책상·환자·장비·실습 앵커·화면·차단 UI·입구 스탠드·이동 목적지·Walk_Rear는 움직이지 않았다.

## 5. 정적 확인 결과 (PASS 65, FAIL 0)

- **텍스처·재질·프리팹**:
  - PNG 원본 해시·크기, 텍스처·재질 GUID 단일, 임포트 설정, 재질 값·텍스처 연결이 위와 같다.
  - 기존 재질(Case·Metal·템플릿)은 그대로다.
  - 프리팹은 Board 크기·재질 두 줄만 바뀌었고 Collider 등 추가 컴포넌트는 없다.
- **씬 구조**: 두 씬 LF·끝 줄바꿈, 중복 fileID 0, 누락 참조 0. 부모·자식과 프리팹 연결이 일치하고, 변경 문서는 씬당 9개이며 추가·삭제는 없다.
- **보존**: 그 밖의 MonoBehaviour 401·382개는 바이트 단위로 같다(스크롤 본문, 버튼, 스테이션, 차단, 거울 farClip 20, 교육 컴포넌트).
- **글자**: TMP 변경은 크기·굵기·검정색뿐이고 문구·폰트·재질은 그대로다. 명판 3개 = 기존 StationSign 3개(씬별)이며 공중 타이틀이나 복제본은 없다.
- **배율·위치·간섭**: 판·글자 월드 배율 1, 벽 간격, 글자 간격·방향, 화면 중심 정렬, 천장·창·거울·패널·명판 간섭이 §3·§4와 같다.
