## 3. 현재 조작과 교육 흐름

### 장비 착용

고정장치 해제 → 덮개 완전 열기 → 방독면 완전 추출 → 얼굴 근처 접근 → 얼굴 스냅·끈 자동 준비 → 한 손으로 끈을 대략 뒤로 가져오기 → Worn.

- 완전 추출 뒤에는 수동 펼침을 끝내지 않아도 얼굴 스냅이 가능하다. 본체 잡기·각도·손 추적은 스냅 필수 조건이 아니며, 머리 추적과 거리·얼굴 앞쪽 조건을 사용한다.
- 스냅 후 본체를 놓아도 얼굴에 고정되고 머리를 따라간다. 끈이 접혀 있으면 자동으로 Loose_Front까지 준비한다.
- 좌우 끈 조작점 중 하나를 어느 손으로든 잡아 눈 평면 뒤의 넓은 영역에 도달하면 안착을 진행한다. 정수리·높이·좌우 경로나 두 영역의 순차 통과를 요구하지 않는다.
- T/Activate는 본체를 잡은 상태에서 새로 누르는 명시적 얼굴 해제다. 수동 펼침이나 다시하기 입력이 아니다. 일반 해제 후에는 충분히 떨어뜨려야 재스냅이 가능하다.
- `Worn` 후 손 놓기 때 끈이 풀린다는 별도 사용자 관찰은 아래 보류 사항으로 남긴다. 단순 T 해제 후 정상 끈 복귀와 혼동하지 않는다.

### 교육·완료 안내

`교육 시작` → 고정장치 해제 → 덮개 열기 → 추출 → 얼굴 배치 → 끈 착용 → 완료 화면.

- 실습은 5단계다. 진행은 실제 장비 상태와 회차 단위 달성 기록을 사용하며 단계별 확인·다음 버튼이 없다.
- 4단계에는 ‘자동으로 붙습니다.’ 문구를 넣지 않는다. 사용자 조정 `SeatStrapsInstruction`을 보존한다.
- Worn에서 완료 제목·조임 점검 안내·출처를 즉시 표시한다. 실제 끈 조임·밀착 검사·읽음 확인·점수·합격 판정은 구현하지 않는다.
- 출처는 국방홍보원 국방일보 「방독면 원리와 착용」(2020-10-21)이다. 공식 설명기사의 요약이며 정식 교본 또는 현행 개정 교범을 확보한 것으로 표현하지 않는다.

### 아바타·관찰 화면

- 기존 Generic `Mannequin.fbx`를 재사용하고 Animator를 끈 뒤 직접 본을 구동한다. HMD·양손은 추적 입력, 팔꿈치·몸통·골반·다리는 추정 자세다. 전신 관절 실측 기능이 아니다.
- 아바타는 HMD 1인칭에서 숨기고 관찰 카메라에 표시한다. XR Origin·카메라·컨트롤러를 이동시키지 않는다.
- 전신 거울과 후면 보기는 실제 방독면·머리끈의 현재 자세를 표시한다. 거울 전용 장비 복제·끈 고정은 없다.
- 거울은 중앙 시점의 단안 텍스처를 양쪽 눈에 표시한다. 눈별 스테레오 거울로 완료됐다고 설명하지 않는다.
- 최초 정면 거울 미표시 보고 뒤 메뉴 재실행 정상 작동 확인을 받았다. 과거 구성 실패 로그와 현재 정상 확인을 구분한다.

### 다시하기

완료 화면 `다시하기` → Runner 정지 → K1 장비 선택 종료 → 착용·추출·주머니 초기화 → 다섯 달성 기록 초기화 → 시작 화면.

- 초기 접힌 끈·수납 위치·잠긴 주머니로 돌아간다. 기존 접힘 캐시와 최초 주머니 상대 수납 기준을 사용한다.
- 선택을 먼저 정상 종료하며 얼굴 제어·추출 손 기준·덮개 유지·재스냅 차단 등을 정리한다. 초기화 때 Worn·Extracted 등 성공 이벤트를 새로 발생시키지 않는다.
- Runner는 Stopped, 안내판은 WaitingForStart다. `교육 시작`을 다시 눌러야 새 회차를 시작하며 그 전에는 장비 선택을 잠근다.
- 씬 재로드나 장비 재생성 없이 복원한다. 아바타·거울·후면 보기와 사용자 조정값을 유지한다. 공통 Runner·Context·Target과 AED는 이번 다시하기에서 수정하지 않았다.

## 5. 보류·잔여 사항

1. **Worn 후 끈 풀림 — 사용자 지시로 보류.** 손만 놓을 때 끈이 풀린다는 관찰이다. 원인·수정 완료는 확인되지 않았다. 다시하기의 접힘 복원은 일반 Worn 동작 수정이 아니다. 사용자 재요청 전 자동 착수하지 않는다.
2. **안내판 회전 시 버튼 겹침 오판 — 정적 조건부 문제.** 런타임은 월드 AABB, 메뉴 6은 안내판 좌표로 비교한다. 안내판 Z축 45도 등에서 실제로 떨어진 버튼을 겹침으로 판단해 Guide blocked가 될 수 있다. 실행 재현·수정 완료 근거는 없다. 기본 배치의 사용자 검증 완료와 구분한다.
3. **실기와 표현 한계.** 단안 거울의 깊이감·클리핑·프레임 비용, 마네킹 눈·손목·신체 비율, 실제 끈과 머리의 맞음은 HMD에서 별도로 확인할 대상이다. 전신 추적이나 밀착·보호 성능 검증을 뜻하지 않는다.
4. **이전 정적 참고.** 닫힌 덮개 아래로 손을 내린 뒤 재개하는 추출 기준 문제는 10/27 기록의 미재현 참고다. 오늘 수정·재현됐다고 기록하지 않는다.

음성·평가·점수·메뉴 복귀는 미구현이다. 자유 재수납·재잠금 교육도 다시하기에 의한 일괄 복원과 별개다. AED는 [10/23 마감](1023_작업마감_진행상황.md) 상태를 유지한다.
