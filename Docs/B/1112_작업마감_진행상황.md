## 3. PC VR 실행 준비 — 현재 저장본·PC 조회

PC 런타임은 로컬 레지스트리 조회 결과로, Git으로 공유되는 설정이 아니다. 현재 헤드셋이 연결됐거나 Play가 성공했다는 뜻은 아니다.

사용자 실행 순서:

1. Meta Horizon Link 앱과 헤드셋에서 Link를 연결·실행한다. 컨트롤러 연결과 오디오 출력 장치를 확인한다.
2. Unity 임포트·재컴파일 후 `B/교육장/3·4` 검사를 실행한다. 컴파일 오류·Missing·새 FAIL이 없어야 한다. 기존 Optional 경고에 일괄 Fix를 적용하지 않는다.
3. B 운영 씬에서 Play한다. 머리·양손 추적, 이동·회전, 잡기·버튼 입력이 정상이어야 한다. Game 뷰 포커스를 잃으면 장비 효과음이 멈추는 현재 설계를 고려한다.
4. 6개 과정의 시작·완료·다시하기·중단/계속/종료를 확인한다. 중단 중 입력 차단, 복구 뒤 지연 재생 없음, 종료·허브 복귀 뒤 남는 루프 없음이 기준이다.
5. 표식의 책상 가림·양안 표시와 24종 효과음의 시점·음량·공간 위치·루프 경계를 확인한다.
6. 허브 → 구급법 → 허브 → 화생방 → 허브 동선과 재진입을 확인한다. 전체 과정 목록을 완성한 뒤 A·C 왕복과 최종 Windows 빌드도 사용자 PC에서 확인한다.

PC VR EXE 배포 대상은 Windows x86_64다. 이번 문서 작업에서 Build Profile이나 타깃을 전환하지 않았다.
