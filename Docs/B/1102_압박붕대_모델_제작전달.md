## 3. 단위·치수·원점·축

Blender `Metric`, `Unit Scale=1.0`, 길이 표시 `Meters`. **1 Blender unit = 1m**. 모든 메시·Empty의 Blender 회전은 `(0,0,0)`, 스케일은 `(1,1,1)`. 음수 스케일·미러·미적용 수정자 없음.

- 위쪽 `+Z`, 드레싱·테이프 접촉 방향 `-Z`.
- 띠 길이 `+X`, 폭 `Y`, 정면 법선 `+Z`.
- 롤 회전축 `Y`. 전체 롤은 메시 원점 중심으로 회전한다.
- 아래 치수·원점·기준점 표는 **Blender 원본 로컬 좌표**다. FBX 축 변환은 §7에 별도 기록했다.

| 객체 | 로컬 치수 X×Y×Z (m) | 메시 원점 | 제작 확인용 월드 원점 XYZ (m) |
|---|---|---|---|
| `PB_DressingPad` | 0.100×0.100×0.004 | 패드 부피 중앙 | (0.075, 0.180, 0.015) |
| `PB_BandageRoll` | 0.060×0.080×0.060 | Y 회전축 중앙 | (0.270, 0.180, 0.045) |
| `PB_BandageStrip` | 1.000×0.080×0 | 시작 단면의 폭 중앙 | (0, -0.020, 0.015) |
| `PB_WrapStrip` | 1.000×0.080×0 | 시작 단면의 폭 중앙 | (0, -0.200, 0.015) |
| `PB_BandageEnd` | 0.060×0.080×0 | 본체에 이어질 시작 단면의 폭 중앙 | (0.480, 0.180, 0.015) |
| `PB_FixingTape` | 0.100×0.025×0.0003 | 테이프 부피 중앙 | (0.720, 0.180, 0.015) |

드레싱 상면 `z=+0.002`, 접촉면 `z=-0.002`. 가장자리 bevel 폭 0.0015m, 3분할을 메시로 적용했다. 위·아래는 같은 재질 내 서로 다른 아틀라스 영역과 옅은 색 차이로 구분한다. 색만으로 배치 유효성을 판정하지 말고 접촉 기준점과 면 방향을 사용한다.

롤 외반지름 0.030m, 폭 0.080m. 둘레 64분할, 둥근 가장자리와 얕은 동심 단면으로 천 층을 암시한다. 양 끝 중앙도 천으로 닫힌 형상이다. 얕은 중앙 오목함은 천 표현이며 내부 심·기계 부품이 아니다. 실제 전체 천을 나선으로 쌓은 구조가 아니므로 롤 자체를 물리적으로 풀 수는 없다.

`PB_BandageStrip`, `PB_WrapStrip`, `PB_BandageEnd`는 **두께 0인 단면 메시**다. 앞뒷면 중복 면이나 Solidify는 없다. 세 부품 모두 같은 표면 두께 기준으로 자연스럽게 이어진다. 렌더링 시 양면 설정이 필요하다. 실제 두께가 필요한 단계는 후속 모델 변경 사항이다.

테이프는 두께 0.0003m의 닫힌 입체이며 평면 모서리 반지름 0.002m. 양면 메시 복제 없이 접촉면이 존재한다.

14개 모두 렌더링되지 않는 Empty다. 모든 Empty 로컬 회전은 `(0,0,0)`, 스케일은 `(1,1,1)`. Empty 화살표 자체는 접촉 방향을 새로 정의하지 않는다. 각 역할에 명시한 부모 로컬 축을 사용한다.

잡기·접촉·유지·메시 원점을 구분했다. 시작 원점과 `Anchor_StripStart`, 회전 원점과 `Anchor_RollAxis`가 같은 것은 해당 역할상 의도된 일치다.

롤 출구는 전체 폭의 중앙이며 폭 방향 양 끝은 `y=±0.040`이다. 출구에서 풀린 띠를 접선 +X로 연결한다. `Anchor_RollExit`를 띠의 시작 또는 끝 중 어느 쪽에 연결할지는 경로 소유 방식에 따라 선택하되, 전체 연결에서 일관되게 유지한다. 실제 경로·움직임은 제작하지 않았다.

**출구와 회전의 구분:** 이 파일의 출구는 요청대로 롤 메시의 자식이다. 롤 전체를 Y축으로 회전하면 출구도 함께 회전한다. 이후 표현 구현에서 출구를 한쪽에 유지하며 천 무늬만 회전시킬 경우, 표시용 메시 회전과 출구 기준 Transform의 책임을 구분해야 한다. 현재 파일은 그 동작을 구현하거나 보장하지 않는다.

끝부분은 `x=0` 모서리를 본체 끝에 이어 사용한다. 테이프의 접촉면 중앙을 `Anchor_EndFix`에 배치하고 테이프 접촉 방향 -Z를 끝부분 표면의 반대 방향으로 맞춘다. 기준점은 위치·방향 계약이며 Collider나 접촉 판정 영역이 아니다.

## 5. 메시 분할·UV·변형·초기화

| 객체 | 정점 | 원본 면 | 내보낸 삼각형 |
|---|---:|---:|---:|
| `PB_DressingPad` | 96 | 98 | 188 |
| `PB_BandageRoll` | 1,538 | 1,600 | 3,072 |
| `PB_BandageStrip` | 505 | 400 | 800 |
| `PB_WrapStrip` | 505 | 400 | 800 |
| `PB_BandageEnd` | 35 | 24 | 48 |
| `PB_FixingTape` | 40 | 22 | 76 |
| **합계** | **2,719** | **2,544** | **4,984** |

원본 면은 삼각형·사각형·다각형을 포함한 Blender polygon 수다. FBX는 내보낼 때 삼각화했다. FBX/Unity의 렌더 정점 수는 UV·법선 경계에서 분리돼 위 원본 정점 수보다 늘 수 있다. 조명·텍스트는 이 수치에서 제외했다.

- 두 1m 띠: 길이 **100구간/101열**, 0.010m 균일 간격. 폭 **4구간/5정점**, 0.020m 간격. 사각형 400개. 두 띠의 기하 구조·재질·UV 규약 동일.
- 끝부분: 길이 6구간/7열, 폭 4구간. 길이 간격도 0.010m. 원본에 꼬임·주름·접힘을 굳혀 넣지 않았다.
- 세 띠 표면의 모든 원본 면 법선은 +Z. 열린 경계는 의도된 구조다. 두 1m 띠 경계 각 208 edges, 끝부분 20 edges. 이를 비정상 구멍으로 간주해 면을 막거나 앞뒤 면을 겹치지 않는다.
- 모든 메시에 `UV0` 제공. 띠는 `U=x/0.08`, `V=(y+0.04)/0.08`. 텍스처 한 타일이 0.080×0.080m이며 1m 원본에서 U는 0~12.5, V는 0~1이다. 이미지 Wrap은 **Repeat**, 재질 tiling은 (1,1)을 기준으로 한다. UV가 0~1을 벗어나는 것은 의도된 반복이다.
- 띠의 실제 경로 길이를 줄일 때는 불필요 구간을 잘라 쓰거나 길이 변화에 맞춰 U를 조정한다. 오브젝트 X 스케일만 바꾸면 천 결도 함께 늘어난다. 표면 변형 후 필요에 따라 법선·탄젠트·렌더 bounds 갱신은 후속 구현 담당 사항이다.
- 끝부분은 U=0~0.75다. 앞 본체의 마지막 U가 정수 경계가 아니면 연결점에 맞춰 끝부분 U 오프셋을 맞춰 무늬 위상을 잇는다. 원본 폭·UV 밀도는 이미 같다.
- 드레싱은 상면 U=0~0.5, 하면 U=0.5~1의 두 영역을 쓴다. 가장자리는 단순 투영이다. 롤은 측면 펼침 및 동심 단면용 극좌표 UV로 천 층을 암시한다. 롤 끝 중심의 극점 압축은 정적 단면용이며 띠 변형에 쓰지 않는다.
- 열린 띠는 특정 팔·회전 수에 종속되지 않는다. 원본에 리그·경로 Curve·애니메이션·천 물리 없음. 강한 곡률이나 비틀림에서 필요한 추가 분할은 실제 경로가 정해진 뒤 판단한다.
- 원본 mesh를 보존하고 후속 런타임 변형용 복제본을 사용한다. Empty는 메시 정점 변형을 자동 추적하지 않는다. 변형된 시작·끝 위치에 맞춰 연결 기준점을 갱신하는 책임은 후속 구현에 있다.
- 다시하기에는 복제본 메시 정점·UV, 부품 Transform, 기준점, 표시 상태, 복제된 감김 구간을 원래 상태로 되돌릴 자료가 필요하다. 이번 작업은 독립 원본과 초기 배치만 제공하며 초기화 코드를 만들지 않았다.

## 6. 재질·외부 텍스처

전달용 재질은 3개. Blender 이미지 텍스처와 Principled BSDF로 구성했으며 절차적 Noise·Voronoi·Blender 전용 천 셰이더에 의존하지 않는다. PNG는 이 작업에서 수학적으로 생성한 일반 직물 패턴이며 외부 브랜드·제품 이미지 사용 없음.

| 재질 | 적용 | BaseColor / Normal | Roughness |
|---|---|---|---:|
| `MAT_PB_Dressing` | 드레싱 | `PB_Dressing_BaseColor.png` / `PB_Dressing_Normal.png` | 0.88 |
| `MAT_PB_Bandage` | 롤·두 띠·끝 | `PB_Bandage_BaseColor.png` / `PB_Bandage_Normal.png` | 0.88 |
| `MAT_PB_Tape` | 테이프 | `PB_Tape_BaseColor.png` / `PB_Tape_Normal.png` | 0.64 |

6장 모두 **1024×1024 RGBA PNG, 불투명 alpha=1**. BaseColor는 sRGB, Normal은 Non-Color의 tangent-space **+Y/OpenGL** 기준. 금속도 0, 노멀 강도 Blender 기준 0.45. 흰색·아이보리 천과 약간 회녹색인 테이프의 색·결·거칠기를 미세하게 구분했다. 별도 Roughness map이나 ORM map은 만들지 않았다.

`.blend`는 `//Textures/…`, FBX는 `Textures\…` 상대 경로를 사용한다. 외부 파일을 함께 이동한다. FBX 텍스처 embed는 사용하지 않았다.

Unity 후속 설정:

- `PB_BandageStrip`, `PB_WrapStrip`, `PB_BandageEnd`: **양면 렌더 필수**. 프로젝트의 실제 렌더 파이프라인에 맞는 재질에서 양면을 켜고 뒷면 법선 처리도 확인한다. Blender 양면 플래그가 Unity로 자동 재현된다고 보장하지 않는다.
- BaseColor를 색상 텍스처로, Normal을 normal map으로 연결한다. 노멀의 Y 방향·강도는 실제 파이프라인에서 확인한다. 불투명 재질이며 투명/alpha blending 불필요.
- 밴드 이미지 Repeat, UV0 tiling (1,1). 드레싱 아틀라스는 기본 UV 유지. Roughness는 프로젝트 재질이 Smoothness를 쓸 경우 각각 약 0.12/0.12/0.36을 대응 시작값으로 삼을 수 있으나 Unity 외형은 미확인이다.
- 재질 자동 추출·변환·할당, importer 설정, 양면 셰이더 생성은 이번에 실행하지 않았다. PC VR 근접 관찰 품질과 압축·mipmap·성능의 최종 판단은 Unity/HMD 확인이 남는다.

## 7. FBX 내보내기 설정과 좌표 해석

| 항목 | 실제 설정 |
|---|---|
| 선택 대상 | `PB_Export` 소속 MESH 6개 + EMPTY 14개만 |
| Object Types | Mesh, Empty |
| Forward / Up | **-Z Forward / Y Up** |
| Global Scale | 1.0 |
| Apply Unit | 켬 |
| Apply Scalings | FBX Units Scale (`FBX_SCALE_UNITS`) |
| Use Space Transform | 켬 |
| Apply Transform / Bake Space Transform | **끔** (`bake_space_transform=False`) |
| Mesh Modifiers | 켬, 원본에 남아 있는 modifier는 없음 |
| Smoothing | Face |
| Tangent Space / Triangulate | 켬 / 켬 |
| Animation / Leaf Bones | 끔 / 끔, Armature 없음 |
| Custom Properties | 켬, 역할·원본 치수 상태 등 참고 메타데이터 |
| Path Mode / Embed | Relative / 끔 |

원본 `.blend`는 +Z-up을 유지한다. FBX 파일의 `UpAxis=1`, `UpAxisSign=1`, `UnitScaleFactor=100`을 직접 읽어 확인했다. FBX의 UnitScaleFactor는 센티미터 기준이므로 100은 **파일 길이 단위 1m**를 뜻한다. 모델을 100배 확대했다는 뜻이 아니다.

실제 FBX 최상위 부품 노드에는 X축 약 -90°의 축 변환 회전이 기록된다. Blender 월드 위치 `(x,y,z)`는 FBX Y-up 파일에서 `(x,z,-y)`로 기록됐다. 자식 기준점의 부모 로컬 좌표와 원본 mesh 로컬 좌표는 유지되며 상위 노드가 축 변환을 담당한다. 따라서 FBX 상위의 -90°를 임의로 0으로 지우면 자식과 모델 방향이 달라진다. 원본 부품에 별도 회전·미러를 적용하지 않는다.

이 규약상 롤의 **부품 로컬 +Y가 회전축**, 띠의 **부품 로컬 +X가 길이**, 드레싱 **부품 로컬 -Z가 접촉 방향**이다. Y-up 파일 월드 기준에서는 원본 +Z가 +Y, 원본 +Y가 -Z로 향한다. Unity의 왼손 좌표계 변환·importer의 Bake Axis Conversion 등 옵션에 따른 최종 Inspector 값은 **Unity를 열지 않아 미확인**이다. 파일 좌표 변환과 Unity 최종 표시값을 같은 것으로 단정하지 않는다. 후속 임포트에서는 스케일 1m, 롤 축, 접촉 방향, 자식 기준점을 함께 대조해야 한다.

검토용 카메라·조명·라벨 및 Collection 정리 노드는 FBX에 없다. 내보내기 후 재가져온 객체는 **MESH 6 + EMPTY 14 = 20개**로 확인했다.

## 8. 실제 확인 결과와 남은 확인

Blender에서 수행한 확인:

1. 원본 저장 후 다른 백그라운드 프로세스에서 다시 열기. 외부 이미지 6장 존재·상대 경로·해상도 확인.
2. 치수·원점·단위·회전·스케일, 메시 6개·기준점 14개와 부모 확인. 부품 확인용 배치에서 겹침 없이 독립 표시되는지 렌더 확인.
3. 전체 메시에서 중복 정점 0, 중복 면 0, 영면적 면 0, 고립 정점 0. 열린 경계를 제외한 비정상 non-manifold edge 0, 인접 면 winding 불일치 0. 닫힌 패드·롤·테이프는 양의 signed volume. 단면 띠는 모든 면 +Z이며 열린 경계가 의도대로 존재한다.
4. 두 띠 길이 간격 최소·최대 모두 0.010m, UV0·공유 재질·균일 폭 확인. 모든 부품에 미적용 modifier·음수 스케일 없음.
5. FBX를 별도 빈 Blender 장면에 재가져와 20개 이름·타입·부모 관계·스케일·Transform·형상·UV·재질 이름 비교. 전부 스케일 (1,1,1), 재가져오기 검사 통과. 원본 정점과 재가져온 형상 간 최대 위치 오차 약 **1.71×10⁻⁸m**. 검사 허용오차 2×10⁻⁶m.
6. FBX GlobalSettings와 6개 이미지 상대 참조를 파일에서 확인. 소스의 +Z 축·부품 배치를 내보내기 과정에서 변경하지 않았다.
7. 전체·부품·윗면·접촉면·롤 상세 PNG를 직접 열어 확인. 실시간 Blender의 기존 장면·저장 상태도 작업 전후 동일함을 확인.

수치와 원문 기록은 `PB_ModelValidation.json`에 있다. 이 결과는 **Blender 모델·파일 검사**이며 Unity 실행 검증이나 의료적 적합성 확인이 아니다. 자유 변형에서의 자가 교차·팔 관통·실제 경로 품질은 검사 대상이 아니며 해당 경로를 만들지 않았다.

남은 Unity 확인은 후속 구현·사용자 담당이며 이번에 실행하지 않았다:

| 항목 | 후속 기대 결과 |
|---|---|
| 임포트·단위·계층 | 1 unit=1m, 모델 폭과 롤 지름 일치, 6개 부품 및 기준점 부모 유지 |
| 축·접촉 방향 | 롤 Y 로컬 축 회전, 출구 접선, 드레싱 -Z 접촉·+Z 유지면 일치 |
| 양면·재질 | 세 단면 부품 앞뒤 표시, 직물 반복·노멀 방향·테이프 차이 유지 |
| 변형·연결 | 임의 경로에서 UV 늘어남·면 뒤집힘·연결부 틈·겹침·bounds 누락 없음 |
| 독립 표시·초기화 | 끝·띠·테이프 각각 표시/숨김, 원본 보존 및 변형 복구 가능 |

**Unity 임포트·Play·Simulator·batchmode·테스트·빌드 실행 없음. 스테이징·커밋·Push 없음.** 기존 수정 사항과 설계 문서의 미커밋 상태를 보존했다. 새 결과물은 지정된 모델 폴더와 본 전달 문서에만 저장했다.
