# 사로 사격 VR 교육 기획

작성: A · 2026-10-27
관련: [분해·결합 교육 기획](1027_분해결합_교육기획.md) (같은 틀) · [스크립트 구조 계획](1027_A스크립트_구조계획.md) · [A 맵 화이트박스](1023_A맵_화이트박스와_필요모델.md) · [C 사격 코드 재사용 검토](1027_C사격코드_재사용검토.md)

사로 사격은 A 담당이다 (10/27). 분해·결합의 사격용 총(`K2C1_Rifle`)과 패널·흐름 구조를 이어서 쓴다.

## 1. 결정 사항 (10/27)

| 항목 | 결정 |
| --- | --- |
| 사격 종류 | **25 m 영점사격만.** 실거리 기록사격(팝업 표적)은 시간이 남으면 추가 |
| 자세 | 서서 쏘기. 화이트박스 사대 거치대(높이 1 m)는 총을 놓는 받침으로 쓴다 |
| 탄창 | 탄창 모델을 만들어 손으로 결합·분리한다. 모델이 오기 전에는 상자로 구현 |
| 약실 확인 | 장전 손잡이를 뒤로 당긴 채 배출구(`Anchor_EjectionPort`)를 일정 시간 바라보면 확인으로 본다 |
| 안전 점검 | 분해·결합에서 뺀 안전 점검(탄창 분리·약실 확인)을 여기에 넣는다 ([분해·결합 기획 1절](1027_분해결합_교육기획.md)) |
| 모드 | 분해·결합과 같게 학습·평가 두 가지 (힌트 켜고 끄기) |
| 안내 | 사선 앞 패널 + 자막 (통제관 지시). 음성은 나중에 |

## 2. 교육 흐름

```text
[안내] → 사격 전 준비 → 영점사격 → 사격 후 안전 검사 → [결과] → 다시 하기 / 처음으로
```

### 2-1. 사격 전 준비 (통제관 지시를 패널 자막으로)

| # | 지시 | 완료 조건 |
| --- | --- | --- |
| 1 | 총 들기 | 사대 거치대 위의 총을 잡음 |
| 2 | 조정간 안전 확인 | 조정간이 안전 (안전이 아니면 안전으로 돌릴 때까지 기다림) |
| 3 | 탄창 결합 | 탄창을 탄창 삽입구에 끝까지 끼움 |
| 4 | 장전 | 장전 손잡이를 끝까지 당겼다 놓음 → 약실에 탄이 들어감 |
| 5 | "사격 개시" → 조정간 단발 | 조정간이 단발 |

### 2-2. 영점사격

- 정해진 발 수를 쏜다. **임시값: 3발 1조 × 3조 = 9발.** 조가 끝날 때마다 패널에 그 조의 탄착을 보여 준다. 교안 확인 필요.
- 표적지에 맞은 자리를 기록하고 탄착군을 계산한다 (4절).
- 가늠자 조정(클릭 수 계산·조정)은 **넣지 않는다.** 시간이 남으면 추가한다.

### 2-3. 사격 후 안전 검사

| # | 지시 | 완료 조건 |
| --- | --- | --- |
| 1 | 조정간 안전 | 조정간이 안전 |
| 2 | 탄창 분리 | 탄창을 빼냄 |
| 3 | 장전 손잡이 후퇴, 약실 확인 | 장전 손잡이를 끝까지 당긴 채 배출구를 1초 바라봄 (5절) |
| 4 | 노리쇠 전진 | 장전 손잡이를 놓아 앞으로 |
| 5 | 조정간 단발 → 공격발 | "탁" (약실이 비었음을 확인) |
| 6 | 조정간 안전 | 조정간이 안전 → 결과 |

### 2-4. 안전 위반 (분해·결합의 실수와 따로 센다)

| 위반 | 판정 |
| --- | --- |
| 지시 전 격발 | "사격 개시" 전, 또는 사격 후 안전 검사 중 실탄 발사 |
| 총구 방향 | 탄이 들어 있는 동안(탄창 결합 또는 약실에 탄) 총구가 표적 방향에서 크게 벗어남. 예: 사로 앞쪽에서 수평 90° 넘게. 기준은 임시 |
| 순서 위반 | 탄창이 꽂힌 채 약실 확인, 안전이 아닌 상태로 탄창 결합 등 |

- 위반이 나면 경고음과 자막을 낸다. 평가 결과에 따로 표시한다.

## 3. 결과

| 항목 | 학습 모드 | 평가 모드 |
| --- | --- | --- |
| 명중 수 / 발 수 | ○ | ○ |
| 탄착군 크기·중심 위치 | ○ | ○ |
| 표적지 그림 (탄착 점) | ○ | ○ |
| 절차 오류, 안전 위반 | 수 | 수 + 어느 단계인지 |
| 시간 | | ○ |
| 등급 | | ○ (기준 미정) |

- 표적은 25 m 앞이라 VR에서 탄착을 직접 보기 어렵다. 그래서 **패널에 표적지 그림을 그리고 탄착 점을 찍어 보여 준다.**

## 4. 표적지와 탄착

- **표적지:** 처음에는 사각 판 + 가운데 조준점 + 1 cm 격자의 화이트박스로 만든다. 실제 영점 표적 모양은 교안으로 확인한 뒤 텍스처로 바꾼다.
- **탄착 기록:** 총의 광선(히트스캔)이 표적에 맞은 자리를 표적 기준 2D 좌표(cm)로 저장한다. `IHittable`을 쓴다.
- **탄착군:**
  - 크기: 조 안에서 가장 먼 두 탄착 사이 거리 (cm).
  - 중심: 평균 위치. 조준점에서 상하·좌우로 몇 cm인지.
- **합격 기준(임시):** 3발 탄착군이 지름 ○ cm 안. 교안을 확인한 뒤 정한다.

## 5. 약실 확인 판정

- 조건:
  - 장전 손잡이가 끝까지 후퇴한 상태다 (`ChargingHandleSlide.Offset` ≥ 행정 - 여유).
  - 머리(카메라)가 배출구 쪽을 본다: 카메라 정면과 `Anchor_EjectionPort` 방향의 각도 ≤ 25°, 거리 ≤ 0.6 m.
- 두 조건을 **1초** 동안 이어서 만족하면 확인으로 본다. 각도·거리·시간은 임시값이고 헤드셋으로 조정한다.
- 학습 모드: 배출구에 강조를 표시하고, 바라보는 동안 진행 표시(원 채우기)를 보여 준다.

## 6. 탄창

| 항목 | 내용 |
| --- | --- |
| 모델 | `Part_Magazine` — 사용자가 제작한다. 오기 전에는 상자로 대신한다 |
| 결합 | 탄창을 잡고 탄창 삽입구(`Anchor_MagWell`) 근처로 가져가면 축에 물린다. 위로 끝까지 밀면 결합 (분해·결합의 끼우기와 같은 방식) |
| 분리 | 결합된 탄창을 잡고 아래로 당기면 빠진다. 탄창멈치 버튼은 처음에는 넣지 않는다 |
| 탄 수 | 탄창이 탄 수를 가진다. 총은 꽂힌 탄창에서 약실로 장전한다. 지금의 `m_Rounds` 대신 탄창을 쓴다 |
| 놓을 자리 | 사대 거치대 위 탄창 자리. 떨어뜨리면 그 자리로 되돌린다 |

## 7. 장소

- 같은 씬(`A_Sandbox`)의 `Room_Range`, 가운데 사로를 쓴다.
- 플레이어 시작 위치: `Point_FiringPosition`.
- 사선 앞에 사로용 패널을 둔다. 표적을 가리지 않게 옆이나 아래에 둔다.
- **처음에는 사로 교육을 따로 시작한다** (사로에서 시작). 조립실에서 문으로 걸어오는 이동은 팀 공통 흐름(교육 선택)이 정해지면 붙인다.

## 10. 미정

- 발 수·조 수 (임시 3발 × 3조).
- 탄착군 합격 기준, 평가 등급 기준.
- 표적지 모양 (예비군 영점 표적 — 교안 확인).
- 총구 방향 위반 기준 각도.
- 약실 확인 각도·거리·시간 (임시 25° · 0.6 m · 1초).
- 탄창 모델 일정, 탄창멈치 버튼을 넣을지.
- 조립실 ↔ 사로 이동 방식 (팀 공통 흐름).
- 가늠자 조정, 실거리 기록사격 (시간이 남으면).

- **헤드셋 확인 필요:** 약실 확인 각도·거리·시간 (25° · 0.6 m · 1초) — 장전 손잡이를 한 손으로 잡은 채 고개를 숙여 배출구를 보는 자세가 편한지. 학습 모드 진행 % 문구가 보이는지 (패널이 옆에 있어 안 보일 수 있다 → 나중에 총 옆 표시 고려).

| `MuzzleDirection` 총구 방향 | 총을 들고(`IsHeld`) 탄이 있는(탄창 또는 약실) 동안 총구가 표적 방향에서 **수평 90°** 넘게 벗어남. 80° 안으로 돌아와야 다음을 센다. 위아래 각도는 보지 않는다 (거의 수직이면 0°) | 안전 위반 · 총구 방향 — 총구를 표적 쪽으로 유지하세요 |
| `InsertNotSafe` 순서 위반 | 조정간이 안전이 아닌 채 탄창이 꽂힘 | 안전 위반 · 조정간이 안전이 아닌 채 탄창 결합 |
| `MagazineRemovedEarly` 순서 위반 | 사격 후 안전 검사 구간이 아닌데 탄창이 빠짐 | 안전 위반 · 안전 검사 전에 탄창 분리 |

- 허용 구간은 흐름이 정한다: 격발 = 영점사격, 탄창 분리 = 사격 후 안전 검사. 감시는 교육을 시작할 때 켜고(위반 수 0), 결과·처음으로에서 끈다 → 조립실에서 총을 들고 오는 동안은 세지 않는다.
- 탄창이 꽂힌 채 약실 확인은 절차 실수(`MagazineStillIn`)로 센다 — 두 번 세지 않는다.
- 경고음은 `TrainingFeedback.PlayError` (임시 신호음). 같은 위반 피드백은 1.5초 간격 (위반은 매번 셈).
- 결과: 요약 줄에 "안전 위반 N회". **평가 모드**는 위반마다 "위반: 이름 (그때 단계)" 줄을 더한다 (3절).
- **15-4 발견 처리:** 사격 전 준비에서 끝낸 단계가 다시 풀리면 되돌린다 — 장전 뒤 탄창을 빼면 3단계(탄창 결합)로, 약실이 비면 4단계(장전)로 (`RangeProcedure.Regress`). 뺀 것 자체는 `MagazineRemovedEarly`.

### 16-1. 확인 (에디터 Play, 평가 모드)

| 한 일 | 결과 |
| --- | --- |
| 조정간 단발로 탄창 결합 | `InsertNotSafe` 1, 문구 |
| 장전 뒤 5단계에서 탄창 분리 | `MagazineRemovedEarly` 1, 3단계로 되돌림 → 다시 꽂으니 (약실 탄 있음) 5단계로 |
| 5단계에서 단발로 돌리며 바로 격발 | `PrematureFire` 1 (그 탄은 조에 안 들어감) |
| 든 총(시험 `TestHeld`), 탄 있음: 60° → 120° → 85° → 95° → 0° → -130° | 120°에서 1, 85°·95°에서는 다시 안 셈, 0°로 돌아온 뒤 -130°에서 2 |
| 위로 듦 / 들지 않음 150° | 세지 않음 |
| 끝까지 → 결과 | "절차 실수 0회 · 안전 위반 5회" + 위반 5줄 (단계 포함) |

- **헤드셋 확인 필요:** 총구 방향 90° 기준이 실제 몸을 돌릴 때 적당한지, 총을 내려 들 때(거의 수직) 오판이 없는지. 경고음이 절차 실수와 같아서 구분이 안 된다 → 실제 소리를 넣을 때 따로 (분해·결합 8번 소리와 같이).
