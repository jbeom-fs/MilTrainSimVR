# K2C1 분해·결합 VR 구현 방식

작성: A · 2026-10-23
순서: [분해·결합 순서](1023_K2C1_분해결합_단계표.md)

## 1. 원칙

- 시뮬레이터이므로 **정해진 순서대로만** 분해·결합된다.
- 순서가 틀리면 부품이 빠지거나 끼워지지 않고, 소리·진동·자막으로 알린다.
- 결합은 분해의 역순이며, 같은 부품 상태(분리됨 / 끼워짐, 열림 / 닫힘)를 반대로 확인한다.

## 2. 조작

| 요소 | 방식 |
| --- | --- |
| 총기 본체 | 작업대에 고정. 사용자는 한 손으로 부품을 다룬다 |
| 부품 빼기 | 부품을 잡으면 정해진 축 방향으로만 움직인다. 정해진 거리 이상 당기면 분리되어 자유롭게 들 수 있다 |
| 본체 열기·닫기 | 힌지 축을 중심으로만 회전. 정해진 각도 이상이면 열림, 0°에 가까우면 닫힘 |
| 가스 활대 살짝 꺼내기 (분해 5) | 가스 활대 이동 중간에 걸림 위치를 둔다. 걸림 위치까지 당긴 상태에서만 노리쇠 뭉치가 빠진다 |
| 결합 | 분리된 부품을 끼울 자리의 시작 위치에 가져가면 축에 물린다. 축 방향으로 끝까지 밀어 넣으면 끼워짐 |
| 가스 활대 – 노리쇠 뭉치 결합 (결합 1) | 노리쇠 뭉치의 끼울 자리가 가스 활대에 붙어 있다. 가스 활대가 본체 밖에 있어도 결합된다 |
| 떨어뜨린 부품 | 작업대 아래로 떨어지면 매트 위 정해진 자리로 되돌린다 |

## 3. 순서 판정

| 상황 | 처리 |
| --- | --- |
| 지금 단계가 아닌 부품을 빼려 함 | 잡히지만 움직이지 않음 → 막힘 소리 + 진동 + 오류음 + 자막 |
| 지금 단계가 아닌 부품을 끼우려 함 | 끼울 자리에 물리지 않음 → 오류음 + 진동 + 자막 |
| 열기·닫기 단계가 아닌데 본체를 움직이려 함 | 움직이지 않음 → 막힘 소리 + 오류음 + 자막 |
| 반쯤 넣다가 뺌 | 끝까지 들어간 상태에서만 완료. 다시 빼낼 수 있다 |
| 같은 실수 반복 | 오류음·자막은 짧은 간격(0.8초) 안에 다시 내지 않는다 |
| 아직 손이 닿지 않는 부품 | 순서 판정으로 막힌다 (본체를 열기 전에는 내부 부품이 빠지지 않음) |

- 단계별 오류 횟수와 전체 소요 시간을 기록해 완료 시 보여 준다.

## 4. 피드백

| 종류 | 언제 |
| --- | --- |
| 막힘 소리 (덜컥) + 진동 | 순서가 아니라 움직이지 않을 때 |
| 오류음 + 자막 | 순서가 틀렸을 때. 자막은 지금 해야 할 단계를 알려 준다 |
| 끼워짐 소리 (철컥) | 부품이 끝까지 들어갔을 때, 본체가 닫혔을 때 |
| 단계 완료음 | 단계가 넘어갈 때 |

- 자막 문구는 한 곳(static class 상수)에 모아 관리한다.

## 5. 프로토타입 (박스)

- 씬: `Assets/A/Scenes/A_Sandbox.unity` 작업대 위 `ProtoRifle`.
- 스크립트: `Assets/A/Scripts/Assembly/`.
- 박스는 K2C1 실제 형상·치수가 아니다. 조작과 순서 판정 확인용이며, 새 모델이 들어오면 부품·축·거리를 다시 잡는다.
- 소리는 임시로 코드에서 만든 신호음이다. 실제 소리 자산으로 교체한다.
