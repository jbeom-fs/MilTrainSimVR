# K2C1 8파츠 모델 (UV 완료) 정리

작성: A · 2026-10-23 · 수정 2026-10-26 (텍스처·재질 추가)

UV 작업이 끝난 8파츠 모델로 교체했다. 이전 12파츠 FBX와 `K2_Assembly_Animated.blend`는 삭제했다 (git 기록에 남아 있다). 10/26 텍스처·재질을 넣었다.

## 1. 위치

```text
Assets/A/Models/K2C1/
  Parts/       FBX 8개 (Unity 가져오기)
  Source~/     Unity가 가져오지 않는 원본
    K2_Assembly_UVReady.blend   8파츠 + 조립 애니메이션 (30fps, 1–867)
    README_ko.txt               모델 패키지 설명
    Verification/               FBX·UV·형상 검사 기록 (JSON)
  Textures/{번호_부품}/         부품별 텍스처 3장 (예: 01_Upper/01_Upper_BaseColor.png)
  Materials/                    URP Lit 재질 8개 (01_Upper.mat ~ 08_ChargingHandle.mat)
```

- `Reference_Textures/`, UV 확인용 렌더(Checker·Preview)는 10/23, `UV_Guides/`는 10/26 텍스처 완료 후 지웠다. 참고 맵은 FBX와 blend 안에 들어 있다.

## 2. 부품

| FBX | 부품 | 분해·결합 단계 |
| --- | --- | --- |
| `01_Upper_UVReady` | 상부 본체 | 총기 본체 열기·닫기 |
| `02_Lower_UVReady` | 하부 본체 (노리쇠멈치 포함) | 총기 본체 열기·닫기 |
| `03_PushRod_UVReady` | 밀대 뭉치 | 분해 3 · 결합 4 |
| `04_GasRod_UVReady` | 가스 활대 | 분해 5·6 · 결합 1·2 |
| `05_BoltAssembly_UVReady` | 노리쇠 뭉치 (링·앞쪽 톱니·삽입 부품 포함) | 분해 5 · 결합 1 |
| `06_GasRegulator_UVReady` | 가스 조절기 | 분해 1 · 결합 6 |

- FBX마다 메시 1개, UV0 1개, 재질 1개. 조립 완료 위치(프레임 867) 그대로라 같은 원점에 두면 맞춰진다.

## 3. Unity 가져오기 확인 (10/23)

| 항목 | 결과 |
| --- | --- |
| 가져오기 | 8개 정상. 재질 1개씩. 임베디드 텍스처 폴더(`.fbm`)는 생기지 않음 |
| 크기 | 상부 길이 약 0.72m. 노리쇠 뭉치 0.11m — 예전 `05_BoltRing` 0.1mm 문제는 없어짐 |
| 축 | 길이 방향이 X축, 가스 조절기(총구 쪽)가 -X. C 규격(총구 +Z, 원점 손잡이)은 통합본 `K2C1.prefab`에서 맞춘다 |
| 오브젝트 스케일 | 03 밀대(0.0031), 04 가스 활대·05 노리쇠(0.0072), 08 장전 손잡이(0.0011)는 스케일이 1이 아니다. 크기는 맞게 나오지만 피벗·자식 배치 때 헷갈릴 수 있어 Blender에서 Apply Scale을 권장 |

## 4. 텍스처·재질 (10/26)

| 맵 | 파일 | 가져오기 설정 |
| --- | --- | --- |
| 기본색 | `{번호_부품}_BaseColor.png` | Default, sRGB, 알파 없음 |
| 금속·매끈함 | `{번호_부품}_MetallicSmoothness.png` | Default, Linear(sRGB 끔), R=Metallic · A=Smoothness |
| 노멀 | `{번호_부품}_Normal.png` | Normal map, OpenGL(+Y) |

- 모두 1024×1024. 페인팅 툴의 Unity URP 내보내기 형식이라 ORM 재조합 없이 URP Lit에 바로 연결된다.
- 재질 `Materials/{번호_부품}.mat`: URP Lit, Smoothness 배율 1, Normal 세기 1.
- 각 FBX의 Materials 탭 Remap으로 FBX 안 재질(`M_01_Upper_UVReady_Final` 등)을 새 재질로 바꿨다. FBX 파일은 그대로다.
- 확인: 8개 Renderer가 새 재질 사용, Unity 미리보기에서 텍스처 표시. 실제 씬 조명에서 금속감·거칠기는 눈으로 확인 필요.

## 5. 남은 것

- 통합본 `K2C1.prefab` (`Part_`·`Anchor_` 규격, 총구 +Z).
- `Part_Magazine`(탄창)은 포함되지 않았다. `Part_Trigger`(방아쇠)는 따로 없다 — C 규격 필수 항목이라 일정 정리 필요.
- 박스 프로토타입(`ProtoRifle`)을 이 8파츠로 교체.
