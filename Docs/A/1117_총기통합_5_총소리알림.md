# 총기 통합 4단계 — 총소리 · 탄착 · 명중을 C 시가지에 알리기 (`Gunfire`)

작성: A · 2026-11-17. 받는 사람: C(이주석) — 3절. 통합 순서는 [1단계 문서](1117_총기통합_1_두손파지.md) 1절.

## 1. 왜

- C 시가지에선 총 한 발을 C `Gunfire`로 모두에게 알린다 — 적이 총소리를 듣고 이쪽을 보고(`ShotFired`), 스친 총알에 대응사격하고(`BulletPassed`), 불꽃 · 탄흔이 나고(`SurfaceHit`), 경기 기록이 명중 · 처치를 센다(`BodyHit`). 사격음도 리그의 `CombatAudio`가 `ShotFired`를 듣고 낸다.
- **A 총은 이걸 하나도 안 했고, 명중도 A 표적 약속(A `IHittable`)만 불러서 C 적(C `IHittable` · `HitZone`)은 맞아도 아무 일이 없었다.** → 알림만이 아니라 명중도 C에 넘겨야 C 씬에서 쓸 수 있다.

## 2. 한 것

- **A 총(`K2C1Rifle`)**: 한 발마다 `ShotReported`(탄이 나간 곳 · 끝 · 방향 · 총구 막힘 · 맞은 것 · A가 이미 명중 처리했는지)를 알린다 — 명중 처리 뒤, `Fired` 앞. A 총 코드는 여전히 C를 모른다.
- **다리 `Assets/A/Scripts/CBridge/K2C1Gunfire.cs`** (asmdef 없음 — C를 본다, A 총에 붙음): `ShotReported`를 듣고 C 총(`TempRifle.Shoot`)과 같은 순서 · 같은 함수로
  1. 맞은 것이 C 표적이면 — 사람 몸 부위(`HitZone`)면 `Gunfire.RaiseBodyHit(총, 부위)` 먼저 → `OnHit`
  2. `Gunfire.RaiseSurfaceHit` → `Gunfire.RaiseShotFired(탄이 나간 곳, 총)` → (총구가 벽 속이 아니면) `Gunfire.RaiseBulletPassed`
- **두 번 맞는 것 막기**: A 표적(사로 표적지)은 A 총이 이미 명중 처리했으므로 C `OnHit`을 다시 부르지 않는다 — 표적지엔 C 총용 `CHitRelay`(C → A)가 붙어 있어 그대로 두면 한 발이 두 번 기록된다.
- 메뉴 `A/만들기/사격용 K2C1 C 연동 (손 · 탄창 · 총소리)`가 A 총에 붙인다. A 씬엔 `Gunfire`를 듣는 것이 없어 아무 일도 없다.

## 3. C에게 — A 총을 시가지에 쓸 때 C 쪽에서 맞출 것 (A가 고치지 않음)

- **경기 기록**: `MatchRecord`가 `shooter is TempRifle`일 때만 플레이어 사격 · 명중 · 처치를 센다. A 다리는 `shooter`로 A 총(`K2C1Rifle`)을 넘긴다 → A 총도 세려면 그 판정을 바꿔야 한다.
- **사격음 두 번**: A 총은 자기 임시 사격음(`Temp_Shot`)을 내고, C 리그 `CombatAudio`도 `ShotFired`를 듣고 사격음을 낸다 → 시가지에선 A 총 소리를 끄거나 C 소리만 쓰게 정해야 한다 (A 총 `m_ShotSound`에 빈 소리를 넣거나 A가 끄는 칸을 연다 — 알려 달라).
- 점프 버튼(`JumpButton`)이 '총 든 손'을 `TempRifle`로만 알아본다 ([3단계 문서](1117_총기통합_3_탄창멈치.md) 2절).
- 이름: A가 쓰는 C 코드 — `Gunfire.RaiseBodyHit` · `RaiseSurfaceHit` · `RaiseShotFired` · `RaiseBulletPassed`, `HitZone`, `IHittable.OnHit`. 바꾸면 알려 달라.

## 4. 확인 — 에디터 Play (A, 11/17, 헤드셋 없이)

- A 사격장 표적지에 한 발: `ShotFired` 1 · `SurfaceHit` 1 · `BulletPassed` 1 · `BodyHit` 0, **표적지 기록 1번** (두 번 아님).
- 총구 앞에 C 연습 표적(`PracticeTarget`)을 두고 한 발: **C 표적 명중 1**, `ShotFired` 1 · `SurfaceHit` 1 · `BulletPassed` 1.
- 오류 · 경고 없음.
- **확인 못 함**: 사람 몸 부위(`HitZone`) 명중 → `BodyHit` → 적 피해 (C 적이 있는 씬에서. 코드는 C 총과 같은 줄). C 씬에서 A 총은 아직 안 쓴다 — C가 옮길 때 같이 본다.
