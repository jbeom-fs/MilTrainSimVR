## 4. 남은 것

1. **헤드셋 확인** — 사용자가 식사 후 한 번에 한다 (11/03). 순서·항목은 [헤드셋 확인 목록](1103_헤드셋_확인목록.md)에 모음 (10/27 ~ 오늘 미확인분 전부). 결과는 그 문서에 적는다.
2. **정할 것**
   - 철골 금속감 · Floor_2 반질거림 · 사수 앞 표적 조명 · 표적 쪽 천장 재질 (11/02에서 그대로).
   - 해 조명 세기 2.5 — 헤드셋에서 세면 1.5 ~ 2.
   - 받침대 위 총(`K2C1_Range`)이 1 ~ 3 mm 떨린다 (속도 0.15 ~ 0.24). 예전 통짜 상자에서도 같아 원래 있던 현상 — 보일 때만 손댄다.
3. **사격장 왼쪽 문 → B·C 씬 이동** — 씬을 여는 코드를 새로 만들어 `Door_Exit/Handle_Exit`에 붙인다. 불러올 씬이 공용 빌드 목록(`ProjectSettings/EditorBuildSettings.asset`)에 있어야 할 수 있다 — 공용 파일이라 `Docs/A`에 먼저 제안.
4. **조립실 → 사로 연결** — 기능 점검을 마친 총으로 사격장 교육 시작 (지금은 임시 `K2C1_Range`). 문이 생겨 바로 할 수 있다.
5. **모델** — 이동대·집게(임시 상자), 잔디판. 창밖 임시 도형(가로등·담장·막사)을 모델로 바꾸면 같은 자리에 끼운다 — 가까운 가로등·담장부터가 효과가 크다.
6. 10/27·10/28에서 이어지는 것 — 분해·결합 등급 기준 시간, 8번 실제 소리, 사로 7번 효과(총구 화염·탄흔·소리), 점사 여부, 평가 등급.

## 5. 주의

- 창밖은 보기만 하는 곳이다 — 바깥 땅·소품에 부딪힘이 없어서, Play 중 XR 몸체를 밖으로 옮기면 아래로 떨어진다 (확인용 카메라 이동 때 주의 — 씬 뷰로 본다).
- 안개는 A_Sandbox 씬 전체 설정이다. 나중에 40 m 보다 긴 실내 공간을 만들면 거기에 안개가 낀다.
- 흙 텍스처는 코드로 만든 것 — 실제 흙 사진으로 바꾸려면 `Materials/Outdoor/Dirt.mat`의 Base Map 만 바꾼다. 메뉴를 다시 눌러도 이미 있는 텍스처·재질은 덮어쓰지 않는다 (타일링만 다시 맞춤).
- 에셋 스토어 에셋 라이선스: 스카이박스 Readme에 재배포 금지 — 저장소는 비공개로 보인다(로그인 없이 404). 공개로 바뀌면 문제가 된다.
- 문·받침대 같은 사용자 모델은 원점이 모델마다 다르다 — 빌더는 원점이 아니라 겉 상자(bounds)로 자리를 맞춘다.
- 표적지 탄착 기준점(조준점)을 '×'로 잡았다 — 검은 점(1.4 cm 위)이나 굵은 선 0·0 교차점(2.9 cm 위, 0.6 cm 왼쪽)이 맞다면 `k_K2AimUv`만 바꾸고 메뉴를 다시 누른다.
- 씬 커밋 전 TrainingPanel 레이아웃 노이즈는 (target, propertyPath)로 HEAD 와 비교해 그 항목만 되돌린다 — `-U0` 패치에서 `value:` 줄만 거르면 프리팹 위치·회전 값까지 걸려 씬이 깨진다.
- `unity command capture_*`의 저장 경로는 프로젝트 안만 된다 — `Temp/...`로 주면 `Assets/Temp/...`에 생기니 확인 뒤 지운다.
