# 헤드셋 확인 목록 — 한 번에 (11/03 기준)

작성: A · 2026-11-03. 사용자가 한 세션에 몰아서 확인한다. 10/27부터 오늘까지 **헤드셋으로 아직 안 본 것**을 걷는 순서대로 모았다 (에디터 Play·렌더로는 모두 확인함).
자세한 내용은 원래 문서를 본다: [분해·결합 목록](1027_헤드셋_확인목록.md) · [사로 목록](1028_사로_헤드셋_확인목록.md) · [문 전환](1029_내무반문_사격장전환.md) 3절 · [표적 레일](1102_표적_레일매달기.md) · [11/03 마감](1103_작업마감_진행상황.md).

## 0. 준비

1. Quest를 Link로 연결 (Link 앱에서 OpenXR 런타임 = Meta Quest Link).
2. `Assets/A/Scenes/A_Sandbox.unity` 열기. **씬의 `XR Interaction Simulator`는 꺼진 채** (켜져 있으면 화면이 머리를 따라 돈다).
3. 서서 한다. Play → 시작 자리는 내무반 작업대 남쪽(z -6.8).
4. 막히면 키보드로 메뉴 `A/시험`(분해·결합) · `A/시험/사로/`(사로)를 누른다.
5. 결과는 맨 아래 "결과 기록"에 적는다 — 고칠 것은 **무엇이 · 어떻게** 이상한지 한 줄씩.

## 1. 내무반

- [ ] **분해·결합 재확인** — [1027 목록](1027_헤드셋_확인목록.md) 표의 "재확인 필요" 13개(장전 손잡이 잡기, 가스 조절기 방향, 본체 열림 45°, 노리쇠·가스 활대, 공격발 60°, 조정간 부품 회전 등)를 13단계 진행하면서 본다.
- [ ] 패널 버튼을 레이로 누를 수 있는가, 머리줄 글자 크기.
- [ ] **창밖** — 오른쪽 창에 노을 해가 보이는가 (창틀 위에 걸리는지). 흙 땅·도로·담장·나무·막사가 어색하지 않은가. 머리를 움직일 때 원근이 자연스러운가.
- [ ] **노을빛** — 창으로 들어온 주황빛(해 세기 2.5)이 너무 세지 않은가.
- [ ] 문 오른쪽 벽 **포스터 2장**(윗변 1.95 m) 높이, **소화기**(스위치 아래 바닥) 크기·자리.

## 2. 문 전환 (내무반 → 사격장)

- [ ] 내무반 문 손잡이를 **레이 + 트리거**로, **손 그립**으로 만지면 넘어가는가.
- [ ] 까매졌다 밝아지는 동안 어지럽지 않은가, 두 눈 모두 덮이는가 (총·손·조준 창까지).
- [ ] 총을 든 채 넘어가면 손에 남는가.
- [ ] **사격장 오른쪽 문 앞**에 방 안쪽을 보고 도착하는 게 자연스러운가.

## 3. 사격장 — 둘러보기

- [ ] **햇빛 샘** — 부스 안에서 위쪽 레일·덮개 모서리를 여러 각도로 봐도 주황 줄이 없는가.
- [ ] **형광등 둘레 천장**이 까맣지 않은가 (천장 비춤 점조명).
- [ ] 어두운 정도(환경광 0.15)에서 총·탄창·사로 패널이 잘 보이는가.
- [ ] **표적 조명은 4번만** 켜져 있는가, 빛 기둥이 두 눈에서 어긋나지 않는가, 먼지가 보이는가.
- [ ] 사선 뒤 벽 **안전수칙 게시판**(1.81 ~ 3.92 m)이 대기 공간에서 읽히는가, 너무 높지 않은가.
- [ ] **사로 번호판**(왼쪽 칸막이 안쪽, 2.25 m)이 부스에 들어갈 때 보이는가.
- [ ] 남서쪽 구석 **소화기**, 왼쪽 벽 **나가는 문 + 비상구 유도등** 모양. 나가는 문 손잡이는 만져도 아무 일 없어야 한다 (잠김 — B·C 씬 이동은 아직 없음).

## 4. 사로 사격 (4번 부스)

- [ ] 사로 패널 버튼을 레이로 누를 수 있는가, 패널이 표적을 가리지 않는가.
- [ ] 받침대 위 총을 잡을 수 있는가 (총이 1 ~ 3 mm 떨리는 게 보이는지도).
- [ ] **탄창 — 받침대 아래 선반**(0.64 m)에 손이 닿는가, 어두운 선반에서 보이는가, 꺼내 꽂을 수 있는가 (거리 6 cm · 35°).
- [ ] 표적: 매달린 모양, 이송 속도(약 10초), 사수 앞 거리(약 2.8 m).
- [ ] 영점사격 5발 × 2조, 패널 **"다음 조 시작"**을 레이로 누르기.
- [ ] **표적이 움직이는 중 쏘기 → 지시 전 격발 위반**이 나오는가.
- [ ] **K-2 사격지** — 25 m에서 확대 모드로 '×'가 보이는가. '×'를 겨눠 쏘면 그 근처에 맞는가.
- [ ] 결과 화면의 사격지 그림(세로형)에 탄착 점이 **실제 맞은 자리**에 찍히는가.
- [ ] 안전 검사(약실 확인 35° · 0.8 m)까지 끝나는가.

## 5. 돌아오기

- [ ] 사격장 오른쪽 문 손잡이로 내무반(문 앞, 방 안쪽을 봄)에 돌아오는가.
