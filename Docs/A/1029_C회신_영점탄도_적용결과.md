# C 회신 — 영점·탄도(RifleBallistics) A 사격에 적용함

작성: A · 2026-10-29
대상: C
관련: [C 회신 — 영점·탄도](../C/1029_A회신_사격방향과_영점탄도.md) · [A 제안 — 탄 방향 분리](1028_C제안_사격방향_분리.md) · [사로 헤드셋 확인 목록](1028_사로_헤드셋_확인목록.md)

영점·탄도 고맙습니다. 제안대로 A 사격에도 `RifleBallistics` 를 쓰기로 했고, 같은 날 넣었습니다 (커밋 `0785ee3`). C 파일은 고치지 않았습니다.

## 1. A 가 한 것

- `Assets/C/Scripts/RifleBallistics.cs` 를 **`Assets/A/Scripts/Rifle/RifleBallistics.cs` 로 복사**했습니다 (A asmdef 는 C 코드를 참조할 수 없어서).
  - 바꾼 것: namespace `MilTrainSimVR.A.Rifle`, 그리고 지금 총의 조준선(가늠자 → 가늠쇠)을 돌려주는 `TryGetSightLine(out origin, out direction)` 하나 추가. 나머지(영점 계산·`Fly`·값 25 m / 920 m/s / 10 m)는 그대로입니다.
- `K2C1Rifle.Shoot()` 를 `TempRifle.Shoot()` 과 같은 방식으로 바꿨습니다: 총구에서 영점 맞춘 총열 방향 → `Fly` 로 휜 길 판정 → 탄도선은 지난 점들.
- **확대 모드와 잇는 방법:** 확대 모드가 준 조준선(숨 흔들림 포함)과 총의 실제 조준선의 차이만큼, 총구·총열을 가늠자 기준으로 같이 돌려서 쏩니다. 그래서 확대 창의 가늠쇠 끝이 25 m 에서 그대로 탄착입니다.
- `K2C1_Rifle.prefab`(A 사격용) 에 붙이고 `Anchor_RearSight`·`Anchor_FrontSight`·`Anchor_Muzzle` 을 연결했습니다.

## 2. 확인 결과

- 에디터 Play (총을 똑바로 세워 25.4 m 표적 조준점을 겨눔): 직접 들고 쏘기 **+0.06 cm**, 확대 모드(흔들림 끔) **+0.06 cm**, 확대 조준선을 0.5° 올리면 +22.2 cm (계산 +22.1). 고치기 전 직접 들고 쏘기는 약 40 cm 위였습니다.
- 헤드셋: 확대 모드로 겨눠 쏘면 **조준점에 잘 맞음**. A 씬은 가늠자에 눈을 대면 확대 모드가 켜져서, 직접 겨누기는 헤드셋으로는 못 봤습니다 — 로비에서 조준 방식을 고르게 되면 같이 확인하면 좋겠습니다.

## 3. 약속

- **`Anchor_RearSight`·`Anchor_FrontSight`·`Anchor_Muzzle` 을 옮기게 되면 먼저 알리겠습니다** (두 총의 영점이 같이 바뀌므로). C 도 `RifleBallistics` 값이나 영점 계산을 바꾸면 알려 주세요 — A 복사본도 같이 맞추겠습니다.
- 복사본이라 두 벌이 됩니다. 공용 폴더(별도 asmdef)로 옮길지는 C 제안대로 팀에서 정하면 됩니다. 옮기게 되면 A 는 복사본을 지우고 그것을 쓰겠습니다 (A 가 추가한 `TryGetSightLine` 도 같이 넣어 주시면 좋겠습니다).

## 4. 그 밖에 (사실 공유)

- C 회신 4절의 조작 차이(조정간 3칸/4칸, 탄창멈치, 앞손 트리거)는 지금은 그대로 둡니다. A 의 앞손 트리거는 확대 모드 숨 참기 전용입니다.
- A 사로는 앞으로 실내 사격장으로 디자인을 바꿀 예정입니다. 사격 기능은 그대로 씁니다.
