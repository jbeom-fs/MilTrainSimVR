# 총기 통합 2단계 — 트리거 당긴 정도로 쏘기 · 장전 손잡이를 감싸는 손

작성: A · 2026-11-17. 받는 사람: C(이주석) — 3절. 통합 순서는 [1단계 문서](1117_총기통합_1_두손파지.md) 1절.

## 1. 트리거를 당긴 정도로 쏘기 (`K2C1Rifle`)

- 전: XRI Activate(트리거를 절반쯤 당기면)로 쏨. 1단계 두 손 파지의 검지는 0.9에서 방아쇠에 닿아 **손가락과 발사가 어긋났다.**
- 이제: 잡은 손(권총손잡이 손)의 트리거 값을 직접 읽어 **0.9(`m_FireAt`)까지 당기면 쏘고, 0.6(`m_ResetAt`) 아래로 풀어야 놓은 것** — C `TempRifle`과 같은 방식 · 같은 값. 그 전까지는 검지가 방아쇠로 다가가기만 한다.
- 검지(`K2C1RifleHands`)는 총의 `FireAt`을 읽는다 — 값을 바꿔도 손가락과 발사가 같이 바뀐다.
- 앞손(받친 손) 트리거는 쏘기에 쓰지 않는다 — 조준 확대 모드의 숨 참기(1단계).
- 시험(에디터 메뉴 · 사로 '지금 단계 완료')의 `PullTrigger()`는 그대로 — 손을 풀어도 놓지 않는다(C와 같음).

## 2. 장전 손잡이를 잡으면 손이 손잡이를 감싼다 (`Assets/A/Scripts/Hands/K2C1ChargingHandleHand.cs`)

- 사용자 11/17: C 쪽은 장전 손잡이를 잡으면 손이 손잡이를 감싸는 모션이 있다 → A에도.
- C `RifleChargingHandle`의 손 붙이기(Grab · Release)를 가져왔다: 잡으면 보이는 손 모델을 손잡이 아래 자리(`Pose_ChargingHand`)에 붙여 **주먹(그립 1 · 검지 0.8 · 엄지 0.8)으로 감싸고**, 손 방향은 그대로, 주먹 가운데(잡기 점)가 손잡이에 오게. 손잡이를 당기면 손도 같이 따라가고, 놓으면 손으로 돌아간다. 손이 이미 레일(두 손 파지)에 붙어 있으면 건드리지 않는다.
- C와 다른 점: C 장전 손잡이는 손 자리로 잡기를 직접 보지만 A 장전 손잡이(`ChargingHandleSlide`)는 따로 잡히는 XRI 부품이라 **잡힘 · 놓음 이벤트**에 붙였다. C의 '처음 버팀 · 끝으로 갈수록 무거움 · 닫힐 때 튐' 같은 무게감은 아직 안 가져왔다 (필요하면 다음에).
- 손 붙이기 코드는 두 손 파지(`K2C1RifleHands.Attach · Detach`)와 같은 것을 쓴다.
- 메뉴 `A/만들기/사격용 K2C1 C 연동 (손 · 탄창 · 총소리)`가 장전 손잡이 부품(`HingePivot/Part_Upper/Part_ChargingHandle`)에도 붙인다. 사로 총 · 기능 점검 총 모두.

## 3. 확인 — 에디터 Play (A, 11/17, 헤드셋 없이 XRI 입력을 스크립트로 넣어)

- **트리거**: 오른손으로 사격장 총을 쥐고(단발, 장전) 트리거 0.5 → 안 나감, 0.95 → 1발, 0.95 유지 → 그대로 1발(단발), 0.3으로 풀고 0.95 → 2발째. 
- **장전 손잡이 손**: 왼손으로 장전 손잡이를 잡으면 손 모델이 `Pose_ChargingHand`로 옮겨 감 — 렌더로 주먹이 손잡이 꼭지를 감싼 것 확인. 놓으면 손으로 돌아옴.
- **받치는 손 (1단계 남은 확인)**: 왼손을 레일 자리에 둔 뒤 그립 → 받치는 손 붙음(손 모델이 `Pose_SupportHand`로), 다른 것은 안 잡힘.
  - 시험 중 하나: 손을 순간이동시킨 **같은 프레임**에 그립을 누르면 장전 손잡이가 잡혔다 — XRI 잡기 점이 한 프레임 늦게 따라오는 시험용 상황(실제 손은 연속으로 움직임). 손을 옮기고 잠시 뒤 쥐면 정상. 헤드셋에서 레일을 쥘 때 장전 손잡이가 잡히는지 봐 둘 것 (손잡이는 레일 자리에서 약 16 cm 뒤 · 위).
- 오류 · 경고 없음.
- **헤드셋 미확인**: 트리거 감(0.9가 너무 깊은지), 검지 감기, 장전 손잡이 감싸는 손 모양 · 당길 때 따라오는지, 받치는 손 · 두 손 조준.

## 4. C에게

- 가져온 것: `TempRifle`의 방아쇠 읽기(`FireAt` 0.9 · `ResetAt` 0.6), `RifleChargingHandle.Grab`의 손 붙이기 모양(주먹 값). 이 값을 바꾸면 알려 달라.

## 5. C 통지(11/17 오후)에 따라 한 것

[C 통지 — C 총 숨 참기 · 사로용 이벤트](../C/1117_A통지_C총_숨참기.md)를 pull 받은 뒤 (`f000859`, 파일 · 컴파일 충돌 없음, 실전 사격 사로 합격 확인):

- **빈 격발 소리를 A · C 모두 뺀다** (사용자 11/17 — C 통지는 "실전 사격 사로에서 A가 '탁'을 내 달라"였지만, 소리를 아예 빼고 C 쪽으로 맞추기로 함):
  - A 총(`K2C1Rifle`) 빈 격발: 소리 없이 손에 약한 진동만 (C `TempRifle`과 같음). 임시 소리 `Temp_DryFire`도 안 만든다.
  - 단계 문구: 기능 점검 5 "총구를 위로 향하고 방아쇠 당기기 (빈 격발 — 손에 약한 진동)", 사로 안전 검사 5 "조정간 단발 → 표적 쪽으로 공격발 (방아쇠 당기기 — 손에 약한 진동)".
  - 공이치기 판정(빈 격발 → 공이치기 떨어짐 → 장전 손잡이를 다시 당겨야 함)은 그대로 — 사로 · 기능 점검 순서 판정에 쓴다.
- **사로 다리(`CRangeRifle`)를 C 새 이벤트 · 함수로 줄임**: 손 트리거 직접 읽기 · 매 프레임 `ShotsFired` 보기 · 되돌리기 리플렉션을 없애고 C `TempRifle` 이벤트(`Fired` · `DryFired` · `TriggerBlocked` · `FireModeChanged` · `ChargingHandlePulled/Returned`)와 함수(`SetFireMode` · `ResetState` · `TestCycleChargingHandle`)를 쓴다. 공이치기 흉내만 다리에 남음. 리플렉션은 시험용 탄창 끼우기 하나.
- 확인 (에디터 Play): 두 총 모두 안전에서 당김 → 막힘 1, 공이치기 떨어진 채 → 떨어짐, 장전 손잡이 → 젖혀짐, 빈 약실 → 빈 격발 1, 다시 → 떨어짐. 실전 사격 사로 학습 모드 끝까지 합격(1조 5/5, 실수 0 · 위반 0), 정밀 사격도 오류 없음.
