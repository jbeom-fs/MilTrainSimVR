## 5. 주의

- **에디터 시험의 한계:** 메서드로 단계를 넘기는 시험은 XRI 잡기 경로를 안 탄다. 오늘 헤드셋 문제(잡을 때 부모 떼기, kinematic·보간 되돌림, 리그 정렬 방식)는 모두 여기서 나왔다. 조작을 고칠 때는 `XRSocketInteractor` 임시 손으로 실제 잡기를 일으켜 확인한다 ([교육 기획 13절](1027_분해결합_교육기획.md)).
- **A 씬 리그 설정 (씬에서만 바꿈):** Near-Far 정렬 `InteractableBased`, 부드러운 회전. 공용 프리팹은 그대로다.
- **캡처:** `capture_game_view`·`capture_scene_view`는 `Assets/Temp/`에 파일을 만든다. 임시 카메라로 렌더링해 프로젝트 밖에 저장한다.
- **커밋하지 않은 로컬 변경 (A 것 아님):** `ProjectSettings/Packages/com.unity.probuilder/Settings.json`. 로컬 B meta 8개는 B가 올린 것으로 바꾸고 원래 것은 세션 작업 폴더에 백업했다.
