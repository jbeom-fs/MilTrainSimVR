# 사로 사격 헤드셋 확인 목록

작성: A · 2026-10-28
대상: 사로 사격 구현 1~6번 ([사로 기획](1027_사로사격_기획.md) 12~17절). 7번(총구 화염·탄흔·소리)은 에셋이 준비되면 한다.
분해·결합 쪽은 [분해·결합 헤드셋 확인 목록](1027_헤드셋_확인목록.md)을 따로 본다.

에디터 Play에서는 모두 확인했다 (시험 메뉴 `A/시험/사로`와 스크립트 호출). 아래는 **손·머리·눈으로만 확인할 수 있는 것**이다.

## 0. 준비와 진행 순서

### 0-1. 준비

1. Quest 2 + Link, `A_Sandbox.unity`, `XR Interaction Simulator`는 꺼진 채 — [분해·결합 목록 0-1](1027_헤드셋_확인목록.md)과 같다.
2. Play 뒤 사로로 간다: 걸어가거나, 키보드에서 메뉴 `A/시험/사로/사선으로 이동` (사선 `Point_FiringPosition` (0, 0, 3.4), 표적 쪽을 봄).
3. **사로의 총은 임시 총**(`Room_Range/Lane2/K2C1_Range`)이다. 조립실에서 들고 오는 흐름은 아직 연결하지 않았다.

## 1. 사로 배치·패널 (1번, 기획 12절)

- [ ] 사로 패널 버튼을 레이로 누를 수 있는가.
- [ ] 패널 위치·각도가 적당한가: 가운데 사로 왼쪽 (-1.0, 1.45, 4.6), 30° 돌려 사선을 봄. 표적을 가리지 않는가.
- [ ] 사선 위치(z 3.4)에서 거치대(높이 1.0 m, z 4.25 ~ 4.55)까지 손이 닿는가.
- [ ] 거치대 위 총(눕혀 둠)을 잡을 수 있는가.

## 2. 탄창 (2번, 기획 13절)

- [ ] 거치대 오른쪽 탄창을 잡을 수 있는가. 잡은 자세가 자연스러운가 (잡은 자리 그대로 잡힌다).
- [ ] 탄창 윗면을 삽입구에 대면 꽂히는가 — **거리 6 cm · 각도 35°**가 너무 빡빡하거나 헐겁지 않은가.
- [x] 꽂힌 탄창을 다른 손 그립으로 뺄 수 있는가 (반지름 8 cm).
- [x] 장전 손잡이를 잡으려 할 때 탄창이 대신 빠지지 않는가 (손이 더 가까운 쪽이 잡힌다).
- [x] 꽂힌 탄창 근처를 다른 손으로 쥘 때 총이 두 손으로 잡히지 않고 탄창이 빠지는가.
- [ ] 떨어뜨린 탄창을 다시 주울 수 있는가. 바닥을 뚫지 않는가.
- [ ] 탄창을 꽂고 장전 → 단발로 쏘면 나가는가. 탄창을 빼도 약실 한 발이 나가고 그다음 "탁"인가.
- [ ] 탄창 모델 크기(1.13배)·꽂힌 모습이 손에 들었을 때도 어색하지 않은가.

## 3. 판정 — 준비·안전 검사 (4번, 기획 15절)

- [x] 준비: 총을 잡으면 1단계가 넘어가고, 안전 확인은 바로 넘어가는가.
- [x] 장전 손잡이를 끝까지 당겼다 놓으면 4단계(장전)가 넘어가는가.
- [x] **약실 확인:** 장전 손잡이를 끝까지 당긴 채 배출구를 1초 보면 넘어가는가 (**35° · 0.8 m · 1초** — 10/29 25°·0.6 m 에서 넓힘). 한 손으로 당긴 채 고개를 숙이는 자세가 편한가.
- [x] 학습 모드의 약실 확인 진행 %가 보이는가 (패널이 옆에 있어 그 자세에서 안 보일 수 있다 → 총 옆 표시가 필요한지).
- [x] 공격발은 표적 쪽 **45°** 안이어야 통과 — 기준이 적당한가. 위로 쏘면 실수 문구가 나오는가.
- [x] 단계마다 소리(임시 신호음)가 들리는가.

## 4. 영점사격 — 조준과 탄착 (3번, 기획 14절) — **가장 중요**

- [x] **가늠자·가늠쇠로 조준점을 정확히 겨누고 쏘면 탄착이 조준점 근처에 오는가.** 지금 탄은 총구 기준점(`Anchor_Muzzle`)의 앞 방향으로 나간다. 조준선과 이 방향이 어긋나 있으면 탄착이 늘 같은 쪽으로 쏠린다 → 영점사격 자체가 의미 없으니 `Anchor_Muzzle` 방향이나 가늠자·가늠쇠 위치를 맞춰야 한다. 결과 화면의 조별 중심을 기록한다.
- [x] 3발마다 조 결과 문구(4초)가 보이는가.
- [x] 25 m 앞 표적지(30 cm)가 조준할 만큼 보이는가 (격자는 안 보여도 된다).
- [x] 반동(사격용 총 그대로)이 조준을 크게 흐트러뜨리지 않는가.

### 4-1. 조준 확대 모드 (10/28 추가 — [설계](1028_조준확대모드_설계.md))

- [x] 총을 들고 눈을 가늠자 뒤로 가져가면 확대 모드가 켜지는가 (0.25 m · 10° 안). 떼면 꺼지는가. 경계에서 깜박이지 않는가.
- [x] **두 눈으로 창이 편하게 보이는가**, 어지럽지 않은가 (창은 눈 앞 0.6 m, 맨 위에 그림). 셰이더가 두 눈 모두에 제대로 그려지는가.
- [x] 가늠쇠 끝을 표적지 조준점에 맞추고 쏘면 조준점 근처에 맞는가 (결과 화면의 조별 중심).
- [x] 배율 4 · 창 30°가 적당한가. 표적지 조준점이 보이는가.
- [x] 보통 흔들림(±5 cm)·숨 참기(앞손 트리거)·숨 한계(6초)가 적당한가. 숨 막대(창 아래)가 보이는가.
- [x] 앞손 트리거가 격발되지 않고 숨 참기로만 동작하는가.

### 4-2. 영점·탄도 바꾼 뒤 (10/29 — [C 회신](../C/1029_A회신_사격방향과_영점탄도.md))

탄이 이제 **총구에서 25 m 영점 맞춘 총열 방향으로 나가 중력을 받는다** (`RifleBallistics`, C 것 복사). 확대 모드에선 겨눈 조준선만큼 총열을 같이 돌린다.
에디터 Play: 똑바로 세워 조준점을 겨누면 직접·확대 모두 (0.00, +0.06) cm, 조준선을 0.5° 올리면 +22.2 cm (계산 +22.1).

- [x] 확대 모드로 조준점을 겨눠 쏘면 **어제처럼 조준점에 맞는가** (25 m 에서는 달라지지 않아야 한다).
- [ ] 확대 모드 없이 가늠자·가늠쇠로 직접 겨눠 쏴도 조준점 근처에 맞는가 (전에는 약 40 cm 위). — **헤드셋으로는 못 봄**: 가늠자로 겨누려고 눈을 대면 확대 모드가 켜져서 끌 수 없다. A 씬은 확대 모드만 있으니 지금은 볼 일이 없고, 로비에서 조준 방식(A 확대 / C 직접)을 고르게 되면 그때 본다. 에디터 Play로는 확인함 (+0.06 cm).

## 5. 안전 위반·실수 (5번, 기획 16절) — 일부러 해 보기

| 해 볼 것 | 기대 |
| --- | --- |
| 조정간을 단발로 둔 채 탄창 결합 | "안전 위반 · 조정간이 안전이 아닌 채 탄창 결합" |
| 장전 뒤 "사격 개시" 전에 쏘기 | "안전 위반 · 지시 전 격발" |
| 사격 중(또는 준비 중) 탄창 빼기 | "안전 위반 · 안전 검사 전에 탄창 분리", 준비 중이면 탄창 결합 단계로 돌아감 |
| 탄이 든 총을 들고 몸을 옆·뒤로 돌리기 | "안전 위반 · 총구 방향" (수평 **90°**, 80° 안으로 돌아오면 다시 셈) |
| 준비 중 탄창 없이 장전·단발·방아쇠 | "아직 공격발할 순서가 아닙니다" (절차 실수) |

- [x] 위 경고가 모두 나오는가. 문구가 보이는가 (3초).
- [x] **잘못 울리지 않는가:** 총을 아래로 내려 들 때, 사선에서 몸을 조금 돌릴 때, 총을 거치대에 내려놓을 때.
- [x] 총구 방향 90° 기준이 적당한가.
- [x] 경고음이 절차 실수와 같은 임시 신호음이라 구분이 안 된다 — 7번 소리 때 따로 만든다 (확인만).

## 6. 결과 화면 (6번, 기획 17절)

- [x] 결과 글자(자동으로 최소 22까지 줄어듦)가 사선에서 읽히는가.
- [x] 오른쪽 표적지 그림의 탄착 점(1조 빨강 · 2조 파랑 · 3조 초록)이 서로 구분되는가. 조별 줄 앞 색 점과 같은 색으로 보이는가.
- [ ] 평가 모드: 제목의 등급, 위반 줄(단계 포함), 그림 아래 기준 글씨(17)가 읽히는가.
- [x] 다시 하기 · 처음으로를 누르면 그림이 사라지고 총·탄창이 거치대로 돌아오는가.
