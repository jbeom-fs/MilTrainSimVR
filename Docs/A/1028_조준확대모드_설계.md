# 조준 확대 모드 설계

## 1. 배경과 결정 (10/28)

- 헤드셋 확인 ④에서 가늠자·가늠쇠로 겨눠 쏴도 거의 맞지 않았다 (원인은 2절).
- 팀 결정: 조준을 둘로 나눈다.
  - **직접 들고 쏘기** — 지금처럼. 사격 보정은 **C**가 맡는다.
  - **조준 확대 모드** — 가늠자·가늠쇠를 확대해 보며 쏘기. **A**가 맡는다 (이 문서).
- 사용자 결정:

| 항목 | 결정 |
| --- | --- |
| 보여 주는 방식 | **(다)** 확대 창 + 주변 어둡게. 눈앞 화면 고정(머리를 따라 도는 화면)은 어지러워서 쓰지 않는다 |
| 들어가기·나오기 | **자동** — 총을 든 채 눈을 가늠자 뒤로 가져가면 들어가고, 떼면 나온다 |
| 탄 방향 | 확대 모드에서만 **가늠자 구멍 가운데(점 1) → 가늠쇠 끝(점 2)** 직선으로 판정 (사용자 그림). 평소에는 지금처럼 총열 방향 |
| 숨 참기 | 앞손 트리거를 누르고 있는 동안. 떨림이 거의 없어지고 화면이 거의 멈춘다. 5~8초 제한 뒤 다시 떨림. 방아쇠 흔들림은 남긴다 |

## 2. 원인 — 조준선이 총열과 1.06° 어긋나 있다

K2C1 모델에서 직선을 쏴서 잰 값 (총 루트 기준, m):

| 점 | 위치 | 비고 |
| --- | --- | --- |
| 가늠자 구멍 가운데 (점 1) | (0, 0.156, 0.0205) | 판 뒷면 z 0.0205, 구멍 지름 약 3 mm |
| 가늠쇠 끝 (점 2) | (0, 0.1465, 0.5336) | 기둥 앞면 z 0.5336 |
| 총구 (`Anchor_Muzzle`) | (0, 0.09, 0.729), 앞 +Z | 지금 탄이 나가는 직선 |

- 조준선(점 1 → 2)이 총열보다 **1.06° 아래**로 기운다. 조준선으로 25 m 표적을 정확히 겨누면 총열은 약 **40 cm 위**를 향한다 → 표적판 위쪽 끝(조준점 +40 cm) 근처라 거의 안 맞았다. 손떨림이 아니라 모델 기하가 주원인이다.
- 실제 총은 총열과 조준선이 25 m 근처에서 만나게 맞춘다(영점). 모델은 그렇게 맞춰져 있지 않다.
- 기존 위치 표시 `Anchor_RearSight` (0, 0.155, 0.020)·`Anchor_FrontSight` (0, 0.155, 0.525)는 추정값이었다 — 위 측정값으로 고친다 (C 공유, [C 제안](1028_C제안_사격방향_분리.md)).

## 3. 동작

### 3-1. 들어가기·나오기 (자동)

| 조건 | 들어가기 | 나오기 |
| --- | --- | --- |
| 총을 듦 | 필요 | 놓으면 바로 나옴 |
| 눈(머리 카메라)과 점 1 거리 | 0.25 m 안 | 0.32 m 넘음 |
| 조준선과 "눈 → 점 2" 각도 | 10° 안 | 15° 넘음 |

- 들어가고 나오는 기준을 다르게 둬서 경계에서 깜박이지 않게 한다. 값은 임시 — 헤드셋으로 조정.
- 머리 카메라는 두 눈 가운데라 한쪽 눈을 감고 겨누는 실제 자세와 약 3 cm 다르다 → 각도는 멀리 있는 점 2 기준으로 재서 이 차이를 줄인다 (점 1 기준이면 10 cm 거리에서 3 cm = 17°).

### 3-2. 화면 (다)

- **확대 카메라:** 점 1에 두고 조준선(아래 3-3의 부드럽게 한 선) 방향을 본다. 확대 모드일 때만 켠다. 가까운 면 1 m (총·손이 안 찍힘). 렌더 텍스처 1024².
- **확대 창:** 눈에서 조준선 방향으로 0.6 m 앞에 둔다. 보이는 크기 30°. 배율 4 → 카메라 시야각 7.5°.
  - 조준경처럼 총 바로 뒤(눈에서 10 cm)에 두면 두 눈 시차가 커서(가까운 물체) 겹쳐 보이고 눈이 피로하다 → 거리를 두고, 총·손에 가리지 않게 맨 위에 그린다 (깊이 검사 없는 전용 셰이더).
  - 창은 세상에 고정된 조준선 방향을 따른다 — 머리를 돌려도 창이 머리를 따라 돌지 않는다 (어지러움 줄임).
- **가늠자·가늠쇠 그림 + 주변 어둡게:** 창 위에 겹친다. 바깥은 검게(가늠자 테), 그 밖은 부드럽게 흐려지며 어두워진다. 가운데에 가늠쇠(보호 고리 + 기둥) — **기둥 끝 = 창 가운데 = 탄이 가는 곳**.
  - 가늠쇠 크기는 실제 크기(0.513 m 앞 기둥 폭 약 1.7 mm, 고리 반지름 약 7.7 mm) × 배율로 그린다 → 25 m 표적지(30 cm)와 크기 비율이 실제와 같다.
  - 그림은 코드로 만든다 (나중에 그림 파일로 바꿀 수 있게).

### 3-3. 조준선 — 화면과 판정이 같은 선을 쓴다

```text
조준 방향 = 부드럽게 한(손 방향) + 흔들림(숨 상태)       → 화면 (카메라)
탄 방향   = 조준 방향 + 방아쇠 흔들림(그 순간 무작위)   → 판정
```

| 숨 상태 | 손 따라가기 (시간 상수) | 흔들림 (25 m에서) |
| --- | --- | --- |
| 보통 | 0.06초 (손 떨림만 걸러 냄) | 약 2 mrad (± 5 cm) — 천천히 흔들림 |
| **숨 참기** (앞손 트리거) | 0.4초 (거의 멈춘 듯, 천천히 고칠 수 있음) | 0.15 mrad (거의 없음) |
| 숨 한계 (6초 넘음) | 0.06초 | 4 mrad (± 10 cm) — 트리거를 놓고 2.5초 쉬어야 회복 |

- **방아쇠 흔들림:** 쏘는 순간 무작위 0.6 mrad (표준편차, 25 m에서 약 1.5 cm). 숨을 참아도 남는다 → 탄착군이 0이 되지 않는다.
- 판정 직선: 시작점 = 점 2 위치(점 1에서 탄 방향으로 0.513 m), 방향 = 탄 방향. 총 자신은 건너뛴다. 벽 속 총구 검사(머리 → 손잡이 → 총구)는 그대로.
- 탄도선(보이는 선)은 총구에서 맞은 곳까지 그린다.
- 영점의 뜻: 확대 모드는 조준선으로 쏘므로 처음부터 영점이 맞은 총이다. 탄착군 크기는 흔들림·방아쇠 흔들림만으로 정해진다. 가늠자 조정 연습을 넣는다면 이 직선에 작은 각도를 더한다 (지금은 안 함, 기획 2-2절).
- 모든 값은 임시 — Inspector에서 바꾼다.

### 3-4. 숨 참기

- 입력: 앞손(총을 두 번째로 잡은 손)의 트리거를 누르고 있는 동안. 손잡이 쪽 트리거는 격발이라 쓰지 않는다. 확대 모드에서만 효과.
- 6초가 넘으면 숨 한계 → 떨림이 커진다. 트리거를 놓고 2.5초가 지나야 다시 참을 수 있다.
- 숨 상태는 화면 아래 작은 표시로 알려 준다 (참는 중 막대가 줄어듦).

## 6. 미정

- 배율 4·창 30°·흔들림 값 — 헤드셋으로 조정.
- 숨 참기를 학습 모드에서만 알려 줄지 (평가 모드는 표시만).
- 확대 모드를 평가 모드에서도 쓸지, 쓸 수 있는 구간(영점사격만?).
- 직접 들고 쏘기(C 보정)와 확대 모드 결과를 따로 기록할지.

### 7-1. 확인 (에디터 Play, 시험 눈 위치)

| 확인 | 결과 |
| --- | --- |
| 눈을 가늠자 8 cm 뒤에 두고 총을 든 것으로 | 확대 모드 켜짐 |
| 흔들림 끔, 조준선을 표적지 조준점에 맞추고 쏨 | **3발 모두 (0.0, 0.0) cm** — 화면 가운데 = 탄착 |
| 보통 숨 6발 | 조준점 둘레 ±6 cm (예: (2.6, -2.5), (0.4, 4.7), (5.8, -3.2)) |
| 숨 참기 | 2 cm 안 ((0.2, 0.5), (-1.5, -0.9)). 6초 넘자 숨 한계 → 다시 커짐 ((-6.5, 7.2)) |
| 눈을 옆으로 40 cm / 총을 놓음 | 꺼짐, 판정은 총구 방향으로 돌아감, 카메라·창 꺼짐 |
| 화면 (캡처) | 창 안에 표적이 4배, 가늠쇠 고리·기둥이 가운데, 바깥은 검고 멀어질수록 흐려짐 |

- 총구 방향과 조준선 각도 **1.061°** 다시 확인 (2절). 시험 중 총이 옆으로 누운 자세였을 때는 이 차이가 옆으로 나타났다 (표적판에서 왼쪽 0.42 m) — 똑바로 든 총에서는 위로 나타난다.
- **헤드셋 확인 필요** ([사로 확인 목록](1028_사로_헤드셋_확인목록.md) 4절): 들어가기 쉬운지(0.25 m · 10°), 두 눈으로 창이 편한지·어지럽지 않은지, 배율 4·창 30°·흔들림 값, 앞손 트리거 숨 참기, 숨 막대가 보이는지, 셰이더가 두 눈에 제대로 그려지는지(한 번 그리기 XR).
