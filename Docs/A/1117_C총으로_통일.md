# 총은 C 총 하나 · 허브는 조준 방식만 — A 쪽 맞춘 것

작성: A · 2026-11-17. 받는 사람: C(이주석). C 문서: [C 총 완성본](../C/1117_A통지_C총_숨참기.md) · [C 시가지 사격 방식 · 확대 조준](../C/1117_A통지_C시가지_사격방식_확대조준.md).

## 1. 정한 것 (A 사용자 동의, 11/17 오후)

- **총은 C 총(C 기믹) 하나.** 어디서든 총 조작(두 손 파지 · 방아쇠 · 조정간 · 탄창 · 장전 손잡이 · 반동 · 숨 참기)은 C 것.
- **허브에서 고르는 건 조준 방식만** — A = 확대 조준(A `SightAim`, C 총에 붙어 C `RifleSightZoom`이 켬) / C = 가늠자 조준(확대 없음). 리그 · 총 · 조작은 어느 쪽이든 C.
- 그래서 A의 '총기 통합 1~5단계'(C 기능을 A 총으로 옮기고 끝에 C도 A 총으로)는 **방향이 바뀌었다** — 사로는 C 총을 쓴다. A 총(`K2C1Rifle`)은 **내무반 기능 점검 총**으로만 남는다 (그 총에 넣은 손 · 방아쇠 · 탄창멈치 · 숨 반동 · C 탄창은 그대로 쓴다 — C 기믹에 맞춘 것이라 방향과 맞는다).

## 2. A가 바꾼 것

| 무엇 | 전 | 지금 |
|---|---|---|
| 사격장 (`RifleStyleSwitch`) | A 방식 = A 리그 + A 총, C 방식 = C 리그 + C 총 | **사로는 늘 C 리그 + C 총**. 고른 조준 방식은 C 총의 `RifleSightZoom`이 읽어 확대 조준을 켜고 끈다. 내무반은 그대로 A 리그 |
| 허브 안내판 위 판 | "사격 방식 고르기" — 정밀 사격 / 실전 사격 | **"조준 방식 고르기" — 확대 조준 / 가늠자 조준**, 부제에 사로 사격 · 시가지 전투 둘 다, 아래 줄 "두 손 쥐기 · 방아쇠 · 탄창 · 숨 참기는 어느 쪽이든 같습니다" |
| `RifleStyle` | 사격 방식 (A 리그+A 총 / C) | 조준 방식 (A = 확대 / C = 가늠자). 이름 · 값은 C가 읽고 있어 그대로 |
| `SightAim` | 확대 카메라에 `stereoTargetEye` | 뺌 — URP에선 효과 없이 경고만 남았다 (C 부탁 2) |

- 사격장의 A 총(`Room_Range/Lane4/K2C1_Range`) · 사로용 A 쪽 연결(`RifleStyleSwitch`의 A 칸)은 꺼진 채 남겨 둔다 — 지우는 건 정리할 때.
- 사로 절차 · 채점 · 표적지는 그대로 (C 총은 `CRangeRifle` 다리로 잇는다).

## 3. C 부탁에 대한 답

1. `SightAim`이 바깥 숨 상태(C `RifleBreath`)를 받기 — **아직 안 함.** A `SightAim`에 '숨 상태를 알려 주는 쪽' 약속을 열면 된다. 필요하면 다음에.
2. `stereoTargetEye` 줄 빼기 — **함** (2절).
3. 벽 앞 가까운 면 — A 총은 이제 내무반에서만 써서(벽 앞에서 확대할 일 없음) 그대로 둔다.

## 4. 확인 — 에디터 Play (A, 11/17, 헤드셋 없이)

- 허브 조준 방식 A → 사격장: C 리그 · C 총, **확대 조준 켜짐**. 사로 학습 모드 끝까지 합격 (1조 5/5, 실수 0 · 위반 0).
- 조준 방식 C → 사격장: C 리그 · C 총, 확대 조준 꺼짐.
- 경고 · 오류 없음 (`stereoTargetEye` 경고도 없어짐). 안내판 렌더 확인.
- **헤드셋 미확인:** 사격장에서 확대 조준(C 총) · 4배 창, 안내판 새 글.
