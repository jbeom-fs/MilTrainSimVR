# 내무반 문 — 사격장 전환

작성: A · 2026-10-29

## 1. 방식 (사용자 결정 10/29)

- 문은 **늘 닫혀 있다** (열리지 않는다, 부딪힘 상자로 걸어서 못 지나감).
- 손잡이를 만지면 (레이 + 트리거 또는 손 그립 — 둘 다 XRI '선택') **화면이 까매졌다가 건너편 방에서 밝아진다**.
  - 어두워짐 0.4 초 → 멈춤 0.2 초 → 밝아짐 0.4 초. 까만 동안에도 머리 추적은 그대로.
  - 도착: 머리가 도착 점 위(키 그대로), 바라보는 방향이 도착 점 앞.
- 손잡이는 내무반 쪽 하나 → 사격장 `Points/Point_RangeEntry` (사격장 기준 (0, 0, 1.4), 표적 쪽을 봄).
- **맵 분리** (사용자 10/29): 같은 씬, 맵만 따로. 두 방이 이어진 느낌이 아니라 "문을 열고 나가 조금 걸어 다른 곳에 왔다"는 느낌. 오가는 것은 문 전환(순간이동)으로만 한다.
  - `Room_Range` 를 **(30, 0, 0)** 으로 옮겼다 (내무반은 x ±5.2, z -9.6 ~ 0). 사격장 점 4개(`Point_FiringPosition`, `Point_RangeRifleRest`, `Point_RangeMagazineRest`, `Point_RangeEntry`)도 같이 +30. 사로 안의 값은 모두 `Room_Range` 기준이라 그대로다.
  - 사격장 사선 뒤 벽(z 0)은 통째로 막은 벽 하나(`Room_Range/Shell/Wall_South`). 예전 메움 벽·윗벽·문 막는 벽은 없앴다.
  - 내무반 문 바로 바깥은 얇은 벽(`Door_Range/Backing`, 내무반 벽 재질)으로 막아 유리 너머가 비어 보이지 않게 했다.
  - 사격장 쪽 문은 따로 디자인한다 — 돌아오는 도착 점 `Points/Point_BarracksEntry` (0, 0, -1.2, 내무반 쪽을 봄)는 만들어 두었다.
- 사격장 벽 텍스처는 사용자가 나중에 작업한다 (지금은 화이트박스 재질).
- 잠금(`DoorTransition.Locked`)은 만들어 두었고 지금은 늘 열림. 분해·결합을 마쳐야 열리게 할지는 나중에 정한다.

코드: `Assets/A/Scripts/Common/ScreenFader.cs` (머리에 붙는 까만 구, 조준 창과 같은 맨 위 그리기 셰이더), `DoorTransition.cs` (손잡이).
문: 메뉴 `A/만들기/내무반 문 (문 모델 · 사격장 전환)` → `Room_Assembly/Door_Range`.

## 2. 문 모델과 벽 (10/29 — 벽을 문에 맞춤)

모델: `Assets/A/Models/Door/sage_glass_door.fbx` — **폭 1.016 × 높이 2.644 × 두께 0.194 m**, 원점 = 아래 가운데, 앞 +Z = 사격장 쪽. 손잡이(둥근 손잡이) x -0.345 · 높이 1.0, 경첩 x +0.451.

사용자 결정: 벽 크기를 문 모델에 맞춘다, **문이 천장에 딱 닿는다**. 메뉴 `A/만들기/내무반 문 (문 모델 · 사격장 전환)` 이 한다:

| 바꾼 것 | 전 | 후 |
| --- | --- | --- |
| 내무반 높이 (벽 위 끝·천장 아래면) | 3.0 m | **2.644 m** (문 높이) |
| 문 구멍 폭 (`Wall_North_L/R` 사이) | 1.2 m | **1.016 m** (문 폭) |
| 문 위 벽 `Wall_North_Lintel` | 2.2 ~ 3.0 m | 끔 (문이 천장까지) |
| 창 위 벽 `Wall_South_Lintel_L/R` | 2.3 ~ 3.0 m | 2.3 ~ 2.644 m |

- 2.5 m 위에 닿는 것은 벽·천장뿐이라 가구는 그대로다. 벽 무늬(UV)는 `A/만들기/조립실 벽` 으로 다시 맞췄다.
- 문 화이트박스(Leaf·Frame)는 모델로 바뀌었다. 부딪힘은 문 전체 상자 하나 (`Door_Range`), 손잡이 상자(`Handle_*`)는 모델의 둥근 손잡이 자리.
- **유리:** 모델의 유리(`GLASS • door vision panel`, `GLASS • upper transom`)는 지금 불투명으로 들어와 있다 (FBX 안 재질). 유리 재질을 만들면 그 두 메시에 끼운다 — 사격장 칸막이의 `Materials/Range/Range_Glass` 를 같이 써도 된다.
- 씬에 `Door` 라는 이름은 TV장 문짝이 쓰고 있다 → 이 문은 `Door_Range`.

## 3. 헤드셋 확인

- [ ] 내무반 쪽 손잡이를 레이 + 트리거로, 손 그립으로 만지면 넘어가는가.
- [ ] 까매졌다 밝아지는 동안 어지럽지 않은가. 두 눈 모두 까맣게 덮이는가 (총·손·조준 창까지).
- [ ] 도착 자리·방향이 자연스러운가 (사격장: 부스 뒤 대기 공간, 표적 쪽).
- [ ] 총을 든 채 넘어가면 총이 손에 남아 있는가.
- [ ] (사격장 쪽 새 문이 생기면) 내무반으로 돌아오는가.
