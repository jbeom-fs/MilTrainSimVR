작성: A · 2026-11-17. 받는 사람: C(이주석) — 4절 · 5절 · 7절, B(김정범) — 7절. **읽어 주세요.**

## 1. 무엇인가 (사용자 11/17)

- 허브에 안내판을 하나 세우고 **"A 방식" · "C 방식" 두 버튼**을 둔다. 한쪽을 누르면 그쪽이 켜지고 다른 쪽은 꺼진다.
- 고른 방식으로 **A 사격장(사로 사격)**과 **C 시가지 전투**에서 총을 다룬다.
  - **A 방식** = 지금 A 사격장 방식: A 리그 + A 총(`K2C1Rifle`) — 조준 확대 · 숨 참기 · 손으로 당기는 장전 손잡이 · 공이치기 · 빈 격발 "탁".
  - **C 방식** = 지금 C 시가지 방식: C 리그(`C_XR Origin`) + C 총(`C_K2C1`, `TempRifle`) — 두 손 파지(손 모델이 총에 붙음) · 트리거를 당긴 만큼 검지가 감김 · 방탄복 탄창 · A/X 탄창멈치. 이동 · 회전 · 점프도 C 리그 설정을 따른다.
- 고른 값은 **앱을 꺼도 남는다** (PlayerPrefs). 처음 기본값은 A.
- **A 사격장은 적용 완료 (A).** **C 시가지 전투는 C가 적용해야 한다** (5절) — A는 C 파일을 고치지 않는다. 그전까지 게시판에는 사로 사격만 적어 두었다 (2절).
- 분해·결합(내무반)은 사격 방식과 상관없이 늘 A 리그 · A 총이다.

## 5. C에게 제안 — C 시가지 전투에 적용하기

C가 정하고 C가 한다. A는 쓸 수 있는 것만 준비했다.

- 읽는 법: `MilTrainSimVR.A.Common.RifleStyle.Current` (`Style.A` / `Style.C`). C 스크립트는 Assembly-CSharp라 바로 참조된다. 씬 시작 때 한 번 읽으면 된다 (허브에서만 바뀐다).
- C 방식이면 지금 그대로.
- A 방식이면 C 씬에서 A 리그 · A 총을 쓰게 바꿔야 하는데, A 총은 시가지 전투에 필요한 것을 모른다 — `Gunfire.ShotFired`(적이 총소리를 듣고 사격음을 냄), 적 · 드론 명중(C `IHittable`), 방탄복 탄창(`MagazinePouch` — C 탄창), 경기 기록(`MatchRecord`는 `shooter is TempRifle`일 때만 셈), 탄약 표시(`MatchDisplay`). A 사격장에서 한 것처럼 **C 쪽에 다리(A 총 → C 약속)를 두는 방식**을 제안한다 — 참고: A의 `Assets/A/Scripts/CBridge/CRangeRifle.cs`(반대 방향).

### 5-1. 정한 것 (11/17, A · C 이야기)

- **C 시가지 전투 적용은 C가 한다.** C 씬(`C_UrbanBlock`)과 C 스크립트를 고쳐야 하는 일이라, 같은 씬을 둘이 고치면 충돌이 나고 경기 흐름은 C가 가장 잘 안다.
- **A가 할 것:** C가 필요하다고 하는 A 총(`K2C1Rifle`) 이벤트 · 값을 A 폴더 안에서 열어 준다. 지금 있는 것: `Fired` · `DryFired` · `HitSurface(RaycastHit)` · `FireModeChanged` · `Mode` · `Chambered` · `HasMagazine` · `Rounds` · `ShotsFired` · `MuzzleForward` (3절 `RangeRifle` 전부). 필요한 것을 C 폴더 문서에 적어 주면 A가 넣고 이 절에 적는다.
- **C가 할 것:** `RifleStyle.Current`를 읽어 A 방식이면 A 리그 · A 총을 쓰게 하고, 다리 · 경기 기록 등 C 코드를 맞춘다. 끝나면 C 폴더에 적어 달라 — A가 이 문서에 옮겨 적고 게시판 부제에 시가지 전투를 넣는다 (2절).

## 7. 화면 회전 방식 (11/17 추가) — B · C 도 읽어 주세요

사용자 11/17: 사격 방식처럼 **오른 스틱 회전 방식도 허브에서 고르게.** 위치는 사격 방식 판 바로 아래.

### 7-1. 무엇인가

- 허브 게시판 아래 판 "화면 회전 방식" — 버튼 **"부드럽게 돌기 (A 방식)"** · **"끊어 돌기 (C 방식)"**. 한쪽을 누르면 다른 쪽이 꺼진다. 앱을 꺼도 남는다 (PlayerPrefs `MilTrainSimVR.TurnStyle`, 0 = 안 고름 · 1 = 부드럽게 · 2 = 끊어 돌기).
  - 부드럽게 = A 리그 값(초당 60°). 끊어 돌기 = C 리그 · XRI 기본 값(**45°**씩, 스틱을 뒤로 당기면 뒤돌기 — 사용자 11/17: C와 같게 45°).
  - 각도 · 속도는 바꾸지 않는다 — 각 리그 값 그대로 (지금 셋 다 45° · 60°/초).
- **아직 안 골랐으면 아무것도 바꾸지 않는다** — 씬마다 원래 설정(허브 · A = 부드럽게, B · C = 끊어 돌기). 판에도 "아직 안 고름"으로 보인다.
- **고르면 모든 씬에 저절로 적용된다** (사용자 11/17 결정): 허브 · 내무반 · 사격장 · 구급법 · 화생방 · 시가지 전투.
- 이 판으로 C 11/12 회신 3절의 "회전 방식 맞추기"는 **사용자가 고르는 것**으로 정리된다 (C가 말한 "허브에 환경 설정이 생기면 사용자가 고르게"와 같음).

### 7-2. 어떻게 적용하나 — B · C 파일은 고치지 않는다

- `Scripts/Common/TurnStyle.cs`가 씬이 열릴 때마다(`SceneManager.sceneLoaded` — 씬의 Awake 뒤, Start 전) 켜진 XR Origin의 두 손 `ControllerInputActionManager.smoothTurnEnabled`를 바꾼다. 허브에서 누르면 그 자리에서도 바로 바뀐다.
- 손(컨트롤러)이 꺼져 있으면(헤드셋 없는 에디터, 손 추적 중) 칸 값만 바꿔 둔다 — 다시 켜질 때 XRI가 그 값으로 동작을 켠다.
- B · C 씬 · 프리팹 · 코드는 그대로다. **실행 중 값만** 바뀐다. 사용자가 안 고르면 지금과 똑같다.
- A.Common asmdef에 XRI Starter Assets(`Unity.XR.Interaction.Toolkit.Samples.StarterAssets`) 참조를 넣었다 (A 파일).

### 7-3. B · C에게

- B · C가 자기 씬에서 회전을 따로 정하고 싶으면(예: 실습 중 회전 막기) 알려 달라 — `TurnStyle`이 그 씬은 건너뛰게 하거나, B · C가 `TurnStyle.Current`를 읽고 정하게 할 수 있다.
- **B · C 리그를 바꿀 때 알아 둘 것:** `ControllerInputActionManager`(XRI Starter Assets) 대신 다른 회전 방식을 쓰면 이 설정이 닿지 않는다.

### 7-4. 확인 (에디터 Play, A, 11/17 — 헤드셋 없이 스크립트로)

- 허브 "끊어 돌기" 누름 → 판 표시 · 저장. 시가지 전투(C 리그) 끊어 돌기 → 그 자리에서 "부드럽게"로 바꾸니 C 리그 두 손 부드럽게. 구급법(B · XRI 기본 리그) 부드럽게. 사격장 C 방식(C 리그) · A 방식(A 리그, 원래 부드럽게) 둘 다 끊어 돌기. 오류 없음.
- **헤드셋 미확인**: 실제로 스틱 회전이 바뀌는지, 손 추적 ↔ 컨트롤러 바꿀 때 값이 남는지.
- 시험 뒤 회전은 "안 고름", 사격은 A로 돌려 두었다.
