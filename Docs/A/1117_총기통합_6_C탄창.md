# 총기 통합 5단계 — A 총이 C 탄창을 쓴다 (탄창 한 벌)

작성: A · 2026-11-17. 받는 사람: C(이주석) — **3절(부탁)** · 4절. 통합 순서는 [1단계 문서](1117_총기통합_1_두손파지.md) 1절.

## 1. 정한 것 (사용자 11/17)

- 방탄복 탄창(5단계)을 하려면 탄창부터 맞아야 한다 — C 방탄복 주머니는 C 탄창(`C_Magazine`)을 꺼내는데 A 총은 A 탄창만 꽂혔다.
- **C 탄창을 A 씬으로 가져온다** — A 총도 C 탄창 삽입구(`MagazineWell`) · C 탄창(`C_Magazine`)을 그대로 쓴다. 손 모델처럼 탄창도 한 벌. C 탄창은 남은 탄이 윗면에 보이고, 끼우기 · 빼기 소리가 있고, 방탄복 주머니와 바로 맞는다.
- 사격장(A 리그)엔 방탄복 주머니를 넣지 않는다 — 사로 탄창은 지금처럼 선반에서 받는다.

## 2. 한 것

- **A 총은 탄창을 약속(`IMagazineFeed`)으로만 본다** — `Assets/A/Scripts/Rifle/IMagazineFeed.cs`: 꽂혀 있는지 · 남은 탄 · 약실로 한 발 · 끼움/뺌 알림 · 떨어뜨리기 · 비우기 · 사로 탄창 놓기 · 시험 끼우기/빼기. A 총 코드는 여전히 C를 모른다.
- **다리 `Assets/A/Scripts/CBridge/CMagazineFeed.cs`** (asmdef 없음): C `MagazineWell`을 이 약속에 맞춘다. 끼우기 · 손으로 빼기 · 떨어뜨리기 · 남은 탄 보이기는 C 삽입구 · C 탄창이 그대로 한다.
  - 사로 탄창 놓기(씬의 C 탄창을 치우고 거치대에 새 탄창 하나) · 시험 끼우기는 여기 한 곳에 두고 사로 실전 사격 다리(`CRangeRifle`)도 같이 쓴다.
- **A 총 프리팹** (`K2C1_Rifle.prefab` — 사로 총 · 기능 점검 총): A 탄창 삽입구를 빼고 C `MagazineWell`(C_K2C1과 같은 값 — 꽂힌 모습 `Part_Magazine`, 급탄구 `Attach_MagFeed`, 만드는 탄창 `C_Magazine`; **탄창 없이 시작**만 다름) + `CMagazineFeed`. 메뉴 **`A/만들기/사격용 K2C1 C 연동 (손 · 탄창 · 총소리)`** (전 이름 '사격용 K2C1 두 손 파지' — 손 · 총소리 · 탄창을 다 붙여서 이름을 바꿈).
- **사로 진행**(`RangeTrainingFlow`): 탄창 프리팹 칸을 없애고 총이 자기 탄창을 놓는다 — 정밀 · 실전 사격 모두 C 탄창 10발.
- **지운 것 (A 복사본)**: `Scripts/Rifle/MagazineWell.cs` · `RifleMagazine.cs` · `HandReach.cs`, `Prefabs/K2C1_Magazine.prefab`. 쓰는 곳이 없음을 확인하고 지웠다 (git 기록엔 남음).

## 3. C에게 부탁 — 레일 자리와 탄창 빼는 자리 (한 줄)

- C `MagazineWell`은 '레일을 받친 손이면 탄창을 빼지 않는다'를 **C `RifleHands`(`InSupportZone`)로만** 본다. A 총의 손(`K2C1RifleHands`)은 모른다.
- C 탄창 빼는 자리(총 기준 z 0.11 ~ 0.25)와 레일 자리(z 0.21 ~ 0.53)가 **앞뒤 4 cm 겹친다** → A 총에서 레일 뒤끝을 쥐면 받치지 않고 탄창이 빠질 수 있다.
- **A가 임시로 한 것**: A 총의 레일 자리를 z 0.25 ~ 0.53으로 줄였다 (메뉴가 프리팹에 넣음). 레일 뒤 4 cm에서는 받쳐지지 않는다 — C 총과 손 감각이 조금 다르다.
- **부탁**: C `MagazineWell`이 레일 자리를 A 약속 `MilTrainSimVR.A.Rifle.IRifleSupport`(`InSupportZone(NearFarInteractor)` · `SupportHand`)로 보게 해 주면 A · C 총이 같은 규칙이 된다. C `RifleHands`가 `IRifleSupport`를 따르게(이미 같은 이름 · 같은 뜻의 함수가 있다) 하고 `MagazineWell`의 `m_Hands`를 `IRifleSupport`로 받으면 된다. C 스크립트는 Assembly-CSharp라 A 약속을 바로 쓸 수 있다. 바꿔 주면 A 레일 자리를 C와 같게 되돌린다.

## 4. C에게 — A가 쓰는 C 탄창 코드 (바꾸면 알려 주세요)

- `MagazineWell`: `HasMagazine` · `Rounds` · `Inserted` · `Removed` · `TakeRound()` · `Drop()` · `Clear()`, 칸 `m_Seated` · `m_FeedPoint` · `m_MagazinePrefab` · `m_StartRounds`, 비공개 `SetSeated(bool, int)`(시험 끼우기)
- `RifleMagazine`: `All` · `Rounds` · `Grab`, 프리팹 `Assets/C/Prefabs/C_Magazine.prefab`
- C가 탄창을 바꾸면 A 사로 · 기능 점검에도 그대로 들어온다 — 탄창을 한 벌로 쓰는 이유.
