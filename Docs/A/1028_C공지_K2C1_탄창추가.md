# C 공지 — K2C1 프리팹에 탄창(`Part_Magazine`) 추가

작성: A · 2026-10-28
대상: C ([K2C1 규격 회신](1021_C회신_K2C1모델_위치와_규격.md) 5절 필수 항목)

## 1. 바뀐 것

- `Assets/A/Prefabs/K2C1.prefab` 루트 아래에 **`Part_Magazine`** 을 넣었다. 삽입구에 **꽂힌 상태**로 보인다.
- 모델: `Assets/A/Models/K2C1/Parts/09_Magazine_UVReady.fbx` (아래로 갈수록 앞으로 휜 탄창). 텍스처는 11/03에 들어왔다 (아래 5절).
- 규격 이름 그대로다. 다른 `Part_`·`Anchor_` 이름과 위치는 바뀌지 않았다.

| 항목 | 값 (루트 기준, m) |

| `Part_Magazine` 원점 | (0, -0.0126, 0.1870) = 탄창 메시 가운데, 회전 0 |
| 탄창 범위 | x ±0.0167, y -0.0893 ~ 0.064, z 0.1368 ~ 0.2372 |
| `Anchor_MagWell` | (0, 0.040, 0.175) — 그대로 |

## 2. C 쪽 영향

- `Assets/C/Prefabs/C_K2C1.prefab`, `C_EnemyDummy.prefab`이 `K2C1.prefab`의 Variant라서 **탄창이 자동으로 보인다.**
- 탄창에는 충돌체·Rigidbody·스크립트가 없다. 총 전체 잡기나 충돌에는 영향이 없다.
- 탄창이 필요 없으면 C의 Variant에서 `Part_Magazine`을 끄면 된다 (A 파일은 그대로 두고).

## 3. 앞으로

- A가 사로 사격에서 탄창 잡아 끼우기·빼기를 만든다 ([사로 사격 기획 9절 2번](1027_사로사격_기획.md)). 이 기능은 A의 Variant(`K2C1_Rifle`)에 붙인다. 기본 프리팹에는 스크립트를 넣지 않는다.
- 텍스처가 들어오면 같은 경로에 재질이 연결된다. 이름·경로는 바뀌지 않는다.

## 4. A가 C 탄창 코드를 복사함 (10/28 추가)

C의 `c798f18`(탄창 재장전)에서 아래 세 파일을 A로 복사해 고쳤다 ([재사용 검토](1027_C사격코드_재사용검토.md) 규칙: `.cs`만, namespace `MilTrainSimVR.A.Rifle`, 파일 머리에 원본·커밋). C 파일은 건드리지 않았다.

| C 원본 | A 복사본 |
| --- | --- |
| `Assets/C/Scripts/HandReach.cs` | `Assets/A/Scripts/Rifle/HandReach.cs` |
| `Assets/C/Scripts/RifleMagazine.cs` | `Assets/A/Scripts/Rifle/RifleMagazine.cs` |
| `Assets/C/Scripts/MagazineWell.cs` | `Assets/A/Scripts/Rifle/MagazineWell.cs` |

- A 사로는 손으로 빼기만 쓰고 탄창멈치 버튼은 보류했다. 장전 손잡이는 A의 `ChargingHandleSlide`를 그대로 쓴다.
- A의 `K2C1_Rifle.prefab`(A 전용 Variant)에 A 쪽 `MagazineWell`을 붙였다. `K2C1.prefab`(C가 쓰는 기본)은 바꾸지 않았다.
- 탄창 모델·`Part_Magazine` 위치를 바꾸면 C의 `C_Magazine`·급탄구 위치도 다시 만들어야 할 수 있다. 바꿀 때 알린다.

## 5. 탄창 텍스처 납품 (11/03 추가)

- 텍스처: `Assets/A/Models/K2C1/Textures/09_Magazine/` — `09_Magazine_BaseColor` · `09_Magazine_MetallicSmoothness` · `09_Magazine_Normal` (다른 부품과 같은 이름 규칙).
- 재질: `Assets/A/Models/K2C1/Materials/09_Magazine.mat` (URP Lit, 다른 부품 재질과 같은 설정).
- 연결: 다른 부품처럼 FBX 가져오기 설정에서 기본 재질 `Magazine_UVReady` → `09_Magazine` 으로 바꿔 끼웠다 (remap). `K2C1.prefab`과 그 Variant(C의 `C_K2C1`·`C_EnemyDummy` 포함)는 **아무것도 안 해도** 새 재질로 보인다. 이름·경로·위치는 바뀌지 않았다.
