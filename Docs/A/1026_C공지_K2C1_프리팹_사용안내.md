# C 공지 — K2C1 프리팹 사용 안내

작성: A · 2026-10-26
대상: C ([10/19 K2 모델 요청](../C/1019_A요청_K2모델_넣을위치와_필요사항.md), [10/21 A 회신](1021_C회신_K2C1모델_위치와_규격.md))

K2C1 완성 모델 프리팹을 올렸다 (커밋 `3aed719`). 모의 전투에서는 완전히 조립된 총 하나로 쓰면 된다.

## 1. 쓸 파일

| 파일 | 사용 |
| --- | --- |
| `Assets/A/Prefabs/K2C1.prefab` | **이것을 쓴다.** 모델과 `Part_`·`Anchor_`만 있고 충돌체·잡기·스크립트는 없다 |
| `Assets/A/Prefabs/K2C1_Assembly.prefab` | 쓰지 않는다. A의 분해·결합 교육용. 부품마다 잡기가 붙어 있어 총 전체 잡기와 부딪힌다 |

- 격발·파지 컴포넌트는 C 폴더에 `K2C1.prefab`의 **Prefab Variant**를 만들어 붙인다. A가 모델을 고치면 Variant에 자동으로 반영된다.
- `Assets/A/` 안의 파일은 고치지 말아 달라.
- 프리팹 안에 분해용 계층이 여러 단 있지만 하나의 총으로 다루면 된다. 아래 오브젝트는 **이름으로** 찾는 것을 권장한다. 경로는 바뀔 수 있다.

## 2. 크기와 방향

- 단위 m, 루트 Scale `1, 1, 1`이 실제 크기 (전체 길이 약 0.98m).
- 총구 +Z, 위 +Y, 오른쪽 +X.
- 루트 원점 = 권총손잡이 (`Anchor_Grip`과 같은 위치).

## 3. 위치 표시 (`Anchor_`, 루트 바로 아래)

**추정값이다.** 메시 형상에서 잡은 위치라 실제 손 위치·조준선과 다를 수 있다. 써 보고 어긋나면 알려 달라. A가 고친다.

| 이름 | 위치 (x, y, z) m | 용도 |
| --- | --- | --- |
| `Anchor_Grip` | 0, 0, 0 | 주 손 |
| `Anchor_Foregrip` | 0, 0.100, 0.330 | 앞손 (총열덮개) |
| `Anchor_Muzzle` | 0, 0.090, 0.729 | 총구 끝, +Z가 발사 방향 |
| `Anchor_RearSight` | 0, 0.155, 0.020 | 가늠자 |
| `Anchor_FrontSight` | 0, 0.155, 0.525 | 가늠쇠 |
| `Anchor_OpticRail` | 0, 0.132, 0.160 | 광학장비 자리 |
| `Anchor_MagWell` | 0, 0.040, 0.175 | 탄창 꽂는 곳 (탄창 장착 기준점) |
| `Anchor_EjectionPort` | 0.030, 0.105, 0.090 | 탄피 배출구 |

## 4. 움직이는 부품 (`Part_`)

| 이름 | 상태 |
| --- | --- |
| `Part_Selector` | 있음. 조정간 회전에 쓸 수 있다 (피벗 = 부품 중심) |
| `Part_ChargingHandle` | 있음. 장전 손잡이 앞뒤 이동에 쓸 수 있다 |
| `Part_Trigger` | **지금은 없음** — 5번 참고 |
| `Part_Magazine` | **아직 없음.** A가 탄창 모델을 따로 납품한다 |
| `Part_Stock` | 없음. 개머리판이 하부 본체에 붙어 있다 |

## 5. 방아쇠 — 잠정

- **잠정안 (확정 아님):** `Part_Trigger`는 두지 않는다. 격발은 컨트롤러 입력만으로 처리한다.
- **필요하면 넣을 수 있다:** 방아쇠가 눈에 보이게 움직여야 하면 알려 달라. A가 하부 본체에서 방아쇠를 분리해 `Part_Trigger`(회전, 피벗 = 방아쇠 축)로 추가한다. 이름은 10/21 규격 그대로라 C 쪽 참조는 바꾸지 않아도 된다.

## 6. 탄창 (예정)

- 납품하면 `Part_Magazine`으로 넣고 이 문서에 추가한다. 탄창 결합·분리 기준점은 `Anchor_MagWell`이다.
- 탄창 형상에 맞춰 `Anchor_MagWell` 위치를 다시 맞출 수 있다. 바뀌면 함께 알린다.
