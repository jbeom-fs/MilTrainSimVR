# C 회신 — K2C1 모델 위치와 규격

작성: A · 2026-10-21
대상: [C의 K2 모델 요청 (10/19)](../C/1019_A요청_K2모델_넣을위치와_필요사항.md)

## 1. 기준 총기: **K2C1**

레일이 있는 K2C1로 만든다. 도트사이트·스코프 장착 자리를 모델에 포함한다.

## 2. 넣을 위치와 파일 이름

A 작업물은 `Assets/A/` 아래에 둔다 (Docs/A 와 같은 규칙).

| 무엇 | 경로 |
| --- | --- |
| 모델 원본 | `Assets/A/Models/K2C1/K2C1.fbx` |
| 머티리얼·텍스처 | `Assets/A/Models/K2C1/Materials/`, `Assets/A/Models/K2C1/Textures/` |
| 프리팹 | `Assets/A/Prefabs/K2C1.prefab` |
이후 모델을 고쳐도 경로·파일 이름·아래 오브젝트 이름은 바꾸지 않는다. 그래야 C의 참조가 끊기지 않는다.

**부탁:** `Assets/A/` 안의 파일은 수정하지 말아 주세요. 격발·파지 컴포넌트는 C 폴더에서 **K2C1.prefab 의 Prefab Variant** 를 만들어 붙이면 A의 모델 갱신이 자동으로 반영된다.

## 3. 크기와 방향

- 단위: 미터. Unity로 가져왔을 때 Scale `1, 1, 1`이 실제 크기.
- 총구는 앞(+Z), 위쪽은 +Y.
- 루트 원점: 손잡이(권총손잡이) 위치.

## 4. 위치 표시용 빈 오브젝트

루트 `K2C1` 바로 아래에 둔다. 이름 앞에 `Anchor_`를 붙인다.

| 이름 | 위치 | 비고 |
| --- | --- | --- |
| `Anchor_Grip` | 손잡이 (주 손) | |
| `Anchor_Foregrip` | 앞손 (총열덮개) | |
| `Anchor_Muzzle` | 총구 끝 | +Z가 발사 방향 |
| `Anchor_RearSight` | 가늠자 | |
| `Anchor_FrontSight` | 가늠쇠 | |
| `Anchor_OpticRail` | 상부 레일 광학장비 자리 | |
| `Anchor_MagWell` | 탄창 꽂는 곳 | 탄창 장착 기준점 |
| `Anchor_EjectionPort` | 탄피 배출구 | 있으면 좋은 것, 포함 |

## 5. 따로 움직이는 부품

이름 앞에 `Part_`를 붙인다. 분리된 메시로 만들고, 피벗은 움직이는 축에 맞춘다.

| 이름 | 움직임 | 포함 |
| --- | --- | --- |
| `Part_Trigger` | 회전 | 필수 |
| `Part_Selector` | 회전 (조정간) | 필수 |
| `Part_Magazine` | 분리·장착 | 필수 |
| `Part_ChargingHandle` | 앞뒤 이동 (장전 손잡이) | 있으면 좋은 것, 포함 |
| `Part_Stock` | 개머리판 | 있으면 좋은 것, 포함 |

분해·결합 교육용 부품도 같은 `Part_` 규칙으로 추가한다. 부품 목록이 정해지면 따로 알린다. 위 이름은 바꾸지 않는다.

## 6. 일정

- 최종본: **이번 주 안 (~10/25)**. 따로 러프 버전을 거치지 않고 최종본을 바로 넣는다.
- 넣으면 Docs/A 에 알린다.

## 7. 질문에 대한 답

- K2 / K2C1: **K2C1** (1번).
- 사로 사격의 격발 담당: C와 직접 이야기한 뒤 정해서 전달한다.
