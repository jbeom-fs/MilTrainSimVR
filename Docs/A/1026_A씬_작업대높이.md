# A 씬 작업대 높이 — 0.95m

작성: A · 2026-10-26

A 씬(`A_Sandbox`)의 분해·결합 작업대는 **서서 하는 기준, 윗면 0.95m**로 쓴다. 팀 공통 기준은 아니다. A 씬에만 해당한다.

## 근거

- 분해·결합은 서서 한다.
- 손으로 하는 가벼운 조립 작업대는 보통 선 자세 팔꿈치 높이보다 10~15cm 낮게 잡는다. 성인 남성 팔꿈치 높이 약 1.05~1.10m를 기준으로 0.90~1.00m 범위에서 0.95m를 골랐다 (일반 인체치수·작업대 지침 기준의 대략값).
- 모든 씬의 XR Origin이 추적 기준을 지정하지 않았다 (XRI 기본 프리팹 그대로). 바닥 기준으로 동작하면 눈높이는 플레이어의 실제 키를 따라간다. 그래서 책상 높이는 눈높이가 아니라 팔꿈치 높이 기준으로 정했다. 헤드셋에서 실제로 바닥 기준인지는 **아직 확인하지 않았다**.

## A_Sandbox에서 바꾼 것 (0.85m → 0.95m, +0.10m)

- `Room_Assembly/Desk`: 상판을 올리고 다리를 늘렸다.
- 책상 위 물건을 같이 올렸다: `Rug`, `K2C1_Assembly`, `K2C1_RestSpots`, `Points/Point_RifleOnDesk` (깔개 윗면 0.9535m).
- 책상 모델은 A가 따로 납품한다. 납품 모델도 윗면 0.95m로 맞춘다.
