> **11/17 오후 방향 바뀜** — 총은 **C 총 하나**로 합친다 (A · C 결정, A 사용자 동의). 사로는 C 총을 쓰고, A 총은 내무반 기능 점검 총으로만 남는다. 아래 '끝에 C도 A 총으로'는 지난 내용 → [C 총으로 통일](1117_C총으로_통일.md).

## 1. 총기 통합 — 방향 (사용자 11/17)

- A 총(`K2C1Rifle`)과 C 총(`TempRifle`)은 10/27 A가 C 것을 복사한 뒤 각자 고쳐 갈라졌다 — 같은 일을 하는 파일이 두 벌, 좋은 기능은 한쪽에만 ([사격 방식 문서](1117_허브_사격방식_선택.md)).
- **C가 시가지 전투를 계속 작업 중이라, C 파일은 건드리지 않고 A 총에 C 기능부터 가져온다** (사용자 결정).
- 순서 (단계마다 사격장 · 기능 점검을 확인하고 넘어감):
  1. **두 손 파지 + 검지 감기** (C `RifleHands`) — 이 문서
  2. 트리거를 당긴 정도로 쏘기 (끝까지 당겨야 발사, 그 전엔 검지만 방아쇠로)
  3. A/X 탄창멈치
  4. `Gunfire` 알림 (시가지에서 적이 총소리를 들음) — **완료** + 명중도 C 적에 넘김 ([4단계](1117_총기통합_5_총소리알림.md))
  5. 방탄복 탄창 (시가지용) — 먼저 **탄창을 C 것 한 벌로** ([5단계 C 탄창](1117_총기통합_6_C탄창.md)). 방탄복 주머니는 A 리그에 넣지 않음 (사로는 선반 탄창)
  - (11/17 추가, [C 통지](../C/1117_A통지_C총_숨참기.md) 3-3절) 숨 참기 → 반동 배율 — **완료** ([숨 반동](1117_총기통합_4_숨반동.md))
  - (11/17) 빈 격발 소리는 A · C 모두 뺀다 — A 총도 소리 없이 진동만 ([2단계 문서](1117_총기통합_2_방아쇠_장전손잡이손.md) 5절)
- **C에게 부탁 (끝 모습):** A 총이 C 기능을 다 갖추면 **C도 A 총으로 옮겨** 총을 한 벌로 만드는 것을 제안한다. 그동안 C가 `TempRifle` · `RifleHands` 등에 새 기능을 넣거나 값을 고치면 알려 달라 — A가 같이 가져온다. 이 방향이 괜찮은지 C 폴더에 답해 주면 이 절에 적는다.

## 2. 1단계에서 한 것

### 2-1. 두 손 파지 (`Assets/A/Scripts/Hands/K2C1RifleHands.cs`)

C `RifleHands`(11/17 HEAD `ac6d798`)를 가져와 A 총에 맞췄다. 동작은 C와 같다.

- **방아쇠 손**: 총을 쥐면 총이 손에 붙는다 — 권총손잡이 자리(`Pose_TriggerHand`)가 실제 손(그립 자세)에 오고, 손 모델도 그 자리로 옮겨 손잡이를 감싼다. 검지는 트리거를 안 당기면 방아쇠울 밖 총몸 옆에 곧게, 당기는 만큼 방아쇠로 감긴다. 왼손으로 쥐면 좌우를 뒤집는다.
- **받치는 손**: 다른 손으로 레일(총열덮개) 자리에서 그립을 쥐면 손이 레일 밑(`Pose_SupportHand`)에 붙고, 총이 '방아쇠 손 → 받치는 손' 방향을 본다(두 손 조준). 그립을 놓으면 바로 떨어진다.
- XRI 두 손 잡기는 쓰지 않는다 — 총은 한 손만 잡히고(선택 필터), 위치 · 두 손 조준은 이 컴포넌트(잡기 변환기)가 정한다. 변환기 순서 `XRGeneralGrabTransformer → K2C1RifleHands → RifleRecoil` (C와 같음).
- 손 자리 · 손가락 각도는 **C가 손 모델을 재서 맞춘 값 그대로** (A · C 총은 같은 `K2C1.prefab` 모델).
- C에서 바꾼 것: C 총 대신 A 총(검지 '방아쇠에 닿음' 기준 `m_FireAt` 0.9 — C `TempRifle.FireAt`과 같은 값), C 장전 손잡이 대신 A 장전 손잡이(따로 잡히는 부품이라 그 손이 잡고 있으면 받치지 않음), `IRifleSupport` 추가(아래).
- **손 모양(`ControllerHandPose`) · 손 판정(`HandReach`)은 C 것을 그대로 쓴다** — 손은 한 벌 ([손 모델 통일](1117_손모델_통일.md)). 그래서 이 파일은 asmdef 없는 폴더(Assembly-CSharp)에 둔다 — A 총 코드 asmdef는 C를 볼 수 없다.

### 2-2. A 총 쪽 (A 파일)

- `Scripts/Rifle/IRifleSupport.cs` — 손 컴포넌트가 A 총 코드에 알려 주는 약속: 받치는 손, 레일 자리.
- `SightAim`(조준 확대): **숨 참기 = 받친 손의 트리거**. 전에는 두 번째로 잡은 손(XRI 두 손 잡기)의 트리거였는데, 이제 총은 한 손만 잡힌다. 두 손 파지가 없는 총이면 전처럼.
- `MagazineWell`(꽂힌 탄창 빼기): 레일 자리에서 쥔 손은 받치는 손 — 탄창을 빼지 않는다 (C `MagazineWell`과 같은 규칙).
- `K2C1_Rifle.prefab`: `Pose_TriggerHand` · `Pose_SupportHand`(C_K2C1 값) + `K2C1RifleHands` + 변환기 순서. 메뉴 **`A/만들기/사격용 K2C1 C 연동 (손 · 탄창 · 총소리)`** (다시 눌러도 같다). 사로 총(`K2C1_Range`) · 기능 점검 총(`K2C1_Rifle`) 모두 들어감.

## 3. 확인

- **에디터 Play (A, 11/17, 헤드셋 없이):** 사격장(정밀 사격)에서 오른손을 총 옆에 두고 잡게 함 → 권총손잡이 자리가 손 자리와 정확히 일치(거리 0, 각도 0), 손 모델이 총의 손 자리로 옮겨 감. 렌더: 손이 손잡이를 감싸고 검지는 방아쇠울 밖에 곧게. 사로 학습 모드 끝까지(1조 5/5 → 합격, 실수 0 · 위반 0) 그대로. 오류 없음.
- **헤드셋 미확인 — 꼭 볼 것:**
  - 받치는 손 · 두 손 조준의 모양 (에디터에서 붙는 것까지는 2단계 때 확인).
  - 트리거를 당길 때 검지 감기. (쏘는 기준이 검지와 어긋나던 것은 2단계에서 맞춤 — [2단계](1117_총기통합_2_방아쇠_장전손잡이손.md))
  - 조준 확대 모드 숨 참기: 받친 손 트리거.
  - 기능 점검(내무반) 총도 손에 붙는지, 장전 손잡이를 다른 손으로 당길 때 받치는 손과 겹치지 않는지.
  - 사격장 '책상 걸치기': 총이 손에 붙으므로 걸치는 느낌이 달라질 수 있다.

## 4. C에게 — A가 가져온 것 · 묶인 것

- 가져온 것: `RifleHands`(11/17 HEAD `ac6d798`)의 동작 · 값 전부. C가 손 자리 · 손가락 각도를 다시 맞추면 알려 달라 — A 값도 같이 바꾼다.
- 그대로 쓰는 C 코드: `ControllerHandPose`(`HandModel` · `IsLeft` · `TriggerValue` · `GripOverride` · `IndexOverride` · `ThumbOverride` · `IndexAnglesOverride` · `IndexSpread` · `OthersAnglesOverride` · `OthersPerFingerOverride`), `HandReach`(`HandVisual` · `GrabPoint` · `IsFreshGrip` · `InBox`). 이 이름을 바꾸면 알려 달라.
