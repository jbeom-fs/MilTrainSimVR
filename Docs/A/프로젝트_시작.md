# A 프로젝트 시작 — 총기 분해·결합

작성: A · 2026-10-21

## 1. 담당

- 총기 분해·결합 교육 콘텐츠.
- K2 모델 제작. C의 격발·양손 파지 작업도 이 모델을 사용한다.

## 2. 팀 기준 (확정)

| 항목 | 기준 |
| --- | --- |
| 실행 | Windows PC VR / Meta Quest Link / Quest 2 |
| 엔진 | Unity `6000.3.13f1`, URP |
| XR | OpenXR `1.16.1`, XRI `3.4.1`, Input System `1.19.0` |
| 테스트 | XR Interaction Simulator, 헤드셋 실기 |
| 일정 | 개발 10/22 ~ 11/26, 완료 발표 11/20 |

팀 공통 흐름은 앱 시작 → 교육 선택 → 목표·조작 안내 → 체험 → 결과·피드백 → 재시도 또는 복귀다. 총기 분해·결합은 단계별 수행 방식으로 구성한다 ([팀 기획서 초안](../B/1020_팀전체_프로젝트_기획서_초안.md)).

## 3. 정해야 할 것 (팀 기획서의 A 미정 사항)

- ~~대상 총기~~ → **K2C1 확정** (10/21).
- 분해·결합할 부품 범위.
- 분해·결합 단계와 순서.
- 판정 기준: 순서, 부품 위치, 누락.
- 교안·참고 자료.

## 4. C 요청에 회신할 항목

C의 [K2 모델 요청](../C/1019_A요청_K2모델_넣을위치와_필요사항.md)에 대한 회신: [1021_C회신_K2C1모델_위치와_규격](1021_C회신_K2C1모델_위치와_규격.md).

| # | 항목 | A 결정 |
| --- | --- | --- |
| 1 | 넣을 위치·파일 이름 | `Assets/A/Models/K2C1/K2C1.fbx`, `Assets/A/Prefabs/K2C1.prefab` |
| 2 | 크기·방향 | 미터, 총구 +Z, 위 +Y, 원점 손잡이 |
| 3 | 위치 표시용 빈 오브젝트 | `Anchor_` 접두어 8개 |
| 4 | 따로 움직이는 부품 | `Part_` 접두어. 방아쇠·조정간·탄창 + 장전 손잡이·개머리판 |
| 5 | 일정 | 이번 주 안(~10/25) 최종본, 러프 생략 |
| Q1 | K2 / K2C1 | K2C1 |
| Q2 | 사로 사격의 격발 | C와 협의 후 전달 |

분해·결합 교육용 부품도 `Part_` 규칙으로 추가한다. 부품 목록이 정해지면 C에게 알린다.

## 5. 다음 작업 후보

1. 분해 부품 범위를 정한다.
2. K2C1 최종본을 규격에 맞춰 넣는다 (~10/25).
3. Q2(사로 사격 격발 담당)를 C와 정해 회신한다.
4. 분해·결합 단계표와 판정 기준을 작성한다.
