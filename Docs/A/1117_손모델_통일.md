# 플레이어 손 모델 통일 (A 리그에도 C 손)

작성: A · 2026-11-17. 받는 사람: C(이주석) · B(김정범) — 3절 · 4절을 읽어 주세요.

## 1. 무엇을 했나 (사용자 11/17)

- 지금까지 손 모델은 C 리그(`C_XR Origin`)에만 있었고, A 리그(허브 · 내무반 · 사격장 정밀 사격)는 컨트롤러 모양이 보였다. → **A 리그에도 C와 같은 손**을 넣었다.
- **C 것을 그대로 쓴다** (복사하지 않음 — 손을 한 벌로):
  - `Camera Offset` 아래 `Assets/C/Prefabs/C_ControllerHand_L.prefab` · `C_ControllerHand_R.prefab` 인스턴스 — 컨트롤러를 따라가고 그립 · 트리거 · 엄지에 맞춰 손가락을 굽힌다 (C `ControllerHandPose`, 재질 `C_Hand.mat`, 모델 = XR Hands 샘플 손).
  - 컨트롤러 모양(`Left/Right Controller Visual`)은 끔.
  - **손으로 잡는 점**(Near-Far Interactor 근접 캐스터 원점)을 컨트롤러 앞(손보다 약 10 cm 앞)에서 손 모양 원점의 `C_PalmPoint`(주먹 가운데)로 옮김. 멀리 가리키는 광선은 그대로 컨트롤러 앞에서 나간다.
  - C의 `CombatAssetsBuilder.BuildPlayerRig`과 같은 방식 · 같은 이름이다.
- 넣은 곳: `A_Hub`의 `XR Origin (XR Rig)`, `A_Sandbox`의 `XR Origin (XR Rig)`. (`A_Sandbox`의 C 리그 인스턴스는 원래 손이 있다.)
- 만들기: 씬을 열고 메뉴 **`A/만들기/리그에 손 모델 (C 손과 같게)`** — 열린 씬의 XR Origin 모두에 맞춘다. 이미 된 것은 그대로라 다시 눌러도 같다. 코드 `Assets/A/Editor/RigHandsBuilder.cs`.

## 2. 확인

- 에디터 Play (A, 11/17, 헤드셋 없이): 허브 · 내무반(분해·결합) · 사격장에서 손 둘 켜짐, 잡는 점 = `C_PalmPoint`, 컨트롤러 모양 꺼짐, 오류 · 경고 없음.
- **헤드셋 미확인 — 꼭 볼 것:**
  - 손이 컨트롤러 자리에 맞게 보이는지, 손가락이 그립 · 트리거에 맞춰 굽는지.
  - **잡는 점이 손보다 10 cm 앞 → 손바닥으로 옮겨졌다.** 분해·결합 부품 집기, 사격장 탄창 빼기(꽂힌 탄창에 손 대고 그립 — `MagazineWell` 잡는 반지름), 장전 손잡이 잡기가 전보다 쉽거나 어려운지. 어색하면 반지름을 다시 맞춘다.
  - **정밀 사격(A 총)을 쥐었을 때 손이 총에 붙지 않는다** — A 총엔 C의 `RifleHands`(손을 권총손잡이 · 레일에 붙이는 것)가 없어서, 손은 컨트롤러 자리에 주먹 쥔 채로 있고 총은 그 근처에 잡힌다. 손이 총을 뚫어 보이면 손을 붙이는 일은 **총기 통합**([1117 사격 방식](1117_허브_사격방식_선택.md) 뒤 통합 논의)에서 같이 다룬다.

## 3. C에게 — A가 C 손에 묶인 것 (바꾸면 알려 주세요)

- 프리팹 경로 `Assets/C/Prefabs/C_ControllerHand_L.prefab` · `C_ControllerHand_R.prefab`, 그 안의 `ControllerHandPose` · `TrackedPoseDriver`, 재질 `Assets/C/Materials/C_Hand.mat`.
- 잡는 점 이름 `C_PalmPoint`(손 프리팹 원점 바로 아래) — A 메뉴가 이 이름으로 만들고 찾는다.
- C가 손 프리팹을 고치면(예: 손가락 각도, 재질) A 씬에도 그대로 들어온다 — 손을 한 벌로 쓰는 이유다. 리그 쪽 설정이 함께 바뀌어야 하는 변경(예: 잡는 점 자리를 프리팹 밖에서 정하기)이면 알려 달라.

## 4. B에게 — B 씬도 손을 넣으려면

- B 씬(`B_FirstAid` · `B_CBRN`)의 리그는 아직 컨트롤러 모양이다. 사용자는 "전부 손이 있게"를 원한다.
- **B 씬은 A가 고치지 않는다.** B가 원하면 B 씬을 열고 위 메뉴 `A/만들기/리그에 손 모델 (C 손과 같게)`를 누르면 된다 — B 씬의 리그에 같은 손 · 같은 잡는 점이 들어가고 씬이 저장된다 (B 씬 파일이 바뀌므로 B가 누르고 B가 커밋).
- 잡는 점이 손바닥으로 옮겨지므로 B의 잡기(붕대 · 마스크 등) 거리가 달라질 수 있다 — 눌러 본 뒤 헤드셋으로 확인해 달라.
