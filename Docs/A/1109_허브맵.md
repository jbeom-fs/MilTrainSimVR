# 허브 맵 — 예비군 교장 연병장

작성: A · 2026-11-09. 각 과정 씬(A · B · C)을 잇는 허브를 A가 만들기로 했다 (사용자 11/09, [씬 연결 확인](1109_B지적_씬연결_확인.md) 3절 복귀점).

## 1. 사용자 결정 (11/09)

- 공간: **예비군 교장 연병장 (실외)**, 건물이 연병장을 **ㄷ자**로 둘러싼다.
- 과정 고르기: ~~건물 문 + 이름판~~ → **연병장 위 차원 포탈** (11/09 오후 변경, 참고 그림: 받침 위에 선 볼록 렌즈 원판, 빛나는 테두리, 위에 이름). 11/09 저녁: **테두리 링 · 받침 없앰 — 볼록 렌즈 가장자리만 파랗게 물들게**. 렌즈 그림은 **각 과정 씬에서 찍은 사진**(사용자 요청, 5절) — 사용자가 나중에 바꿀 수 있다.
- **건물에는 글씨 없음** — 건물은 장식.
- 과정: A 2개 · B 2개 · C 1개. 나중에 B · C가 과정을 더 넣고 싶다고 하면 **포탈만 추가하면 되게** 한다.
