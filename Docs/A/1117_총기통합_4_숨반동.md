# 총기 통합 — 숨 참기로 반동 줄이기 (+ 두 손 반동 고침)

작성: A · 2026-11-17. 받는 사람: C(이주석) — 3절. 통합 순서는 [1단계 문서](1117_총기통합_1_두손파지.md) 1절. C 요청: [C 통지](../C/1117_A통지_C총_숨참기.md) 3-3절.

## 1. 숨 → 반동 (A 총)

C `RifleRecoil` · `RifleBreath`(C `7f4d63a`)와 같은 방식 · 같은 값을 A 총에 넣었다.

| 숨 상태 | 한 발 반동 | 제자리로 돌아오는 빠르기 |
|---|---|---|
| 보통 | 1배 | 1배 |
| 숨 참기 | **0.6배** | **1.5배** |
| 숨 한계 | 1.3배 | 0.8배 |

- 숨 상태는 A 조준 확대(`SightAim`)가 갖고 있어서, 배율도 `SightAim`(`RecoilScale` · `RecoveryScale`, 인스펙터 '숨 → 반동')에 두고 A `RifleRecoil`이 읽는다 — C에서 `RifleBreath`가 갖고 `RifleRecoil`이 읽는 것과 같은 모양.
- **A와 C가 다른 점 — 숨을 참을 수 있는 때:** A는 지금처럼 **조준 확대 모드(눈을 가늠자에 댄 상태)에서 받친 손 트리거**를 누를 때만 숨을 참는다. C는 확대 창이 없어서 **두 손으로 받치기만 하면** 참을 수 있다. 맞출지는 통합 때 정한다 (A의 숨 참기는 확대 창 흔들림과 묶여 있다).

## 2. 고친 것 — 두 손 반동이 안 줄던 것

- A 반동은 두 손으로 들면 절반(`m_TwoHandFactor` 0.5)인데, '두 번째 손이 총을 XRI로 잡았는지'로 봤다. 1단계 두 손 파지부터 총은 한 손만 잡히고 다른 손은 레일에 붙기만 해서 **늘 한 손 반동**이 나오고 있었다.
- 이제 두 손 파지(`IRifleSupport`)가 있으면 **레일을 받친 손이 있을 때 두 손**으로 본다 (C `RifleRecoil`이 받친 손으로 보는 것과 같음).

## 3. 확인 — 에디터 Play (A, 11/17, 헤드셋 없이)

- 한 발에 총구가 들리는 각도 (A 기본 3°):

  | | 한 손 | 두 손 |
  |---|---|---|
  | 보통 | 3.00° | 1.50° |
  | 숨 참기 | 1.80° | **0.90°** |
  | 숨 한계 | 3.90° | 1.95° |

  두 손 값은 C 통지 3-3절(1.50 · 0.90 · 1.95)과 같다.
- 왼손을 레일에 받치니 '두 손'으로 판정, 떼면 '한 손'. 오류 · 경고 없음.
- **헤드셋 미확인:** 숨 참을 때 반동이 줄어드는 느낌, 두 손 / 한 손 반동 차이.
