# A 맵 화이트박스와 필요 모델

작성: A · 2026-10-23

## 1. 전체 흐름

```text
조립실: 작업대에서 K2C1 분해·결합 → 문 → 사로: 25m 사격
```

## 2. 화이트박스 (`Assets/A/Scenes/A_Sandbox.unity`)

한 씬 안에 두 방을 문으로 잇는다. 방마다 루트를 나눠 두어 나중에 씬을 분리할 수 있다. 천장은 없다.

| 루트 | 크기 | 내용 |
| --- | --- | --- |
| `Room_Assembly` | 8 × 8m, 벽 3m | 작업대(상판 1.6 × 0.8m, 높이 0.85m → **10/26 0.95m**, [작업대 높이](1026_A씬_작업대높이.md)), 분해 매트 (10/26 깔개 모델로 교체), 안내판, 북쪽 벽 문(1.2 × 2.2m) |
| `Room_Range` | 10 × 32m, 벽 3m | 사선(z=4), 사로 3개(거치대 높이 1m, 칸막이), 표적 z=29 (**사선에서 25m**), 피탄벽 3m |
| `Points` | — | `Point_PlayerStart`(작업대 앞), `Point_RifleOnDesk`(매트 위), `Point_FiringPosition`(가운데 사로) |

- 재질: `Assets/A/Materials/Whitebox/WB_*` 7개 (URP Lit 단색).
- 가정: 서서 쏘기, 사로 3개. 엎드려쏴로 바꾸면 거치대·사격 위치를 다시 잡는다.
- 미확인: Play·헤드셋 실기 (작업대 높이, 이동 거리).

## 3. 필요 모델

### 3-1. 총기 — A 제작 (최우선, ~10/25)

| 모델 | 상태 | 쓰는 곳 |
| --- | --- | --- |
| `K2C1.fbx` / `K2C1.prefab` (`Part_`·`Anchor_` 규격) | 파츠 12종 모델링·UV 완료, 텍스처 작업 중, 통합본 미작성 | 조립실·사로 공통 |
| 분해 파츠 12종 (`01_Upper` ~ `12_BoltCatch_User`) | 텍스처 작업 중 | 조립실 |
| `Part_Magazine` (탄창) | **현재 파츠 목록에 없음** | 분해 첫 단계(탄창 제거)·사로 장전 |
| `Part_Trigger` (방아쇠) | **현재 파츠 목록에 따로 없음** — 하부에 붙어 있으면 분리 필요 | 사로 격발 (C 필수 요청) |
| `Part_Stock` (개머리판) | 파츠 목록에 따로 없음 — 분리 여부 확인 | C 요청 "있으면 좋은 것" |

### 3-2. 조립실 소품

| 모델 | 우선 | 비고 |
| --- | --- | --- |
| 작업대 | 높음 | 화이트박스 크기 기준. 단순 메시로 충분 |
| 분해 매트 | 높음 | 얇은 판 + 텍스처. 부품별 놓을 자리 표시(윤곽선)를 텍스처로 넣으면 판정 위치 안내에 쓸 수 있다 |
| 안내판 | 중간 | 모델보다 World Space UI 패널로 대체 가능 |
| 실내 벽·바닥·문 | 낮음 | 화이트박스 유지 후 재질만 교체해도 된다 |

### 3-3. 사로 소품

| 모델 | 우선 | 비고 |
| --- | --- | --- |
| 표적지 + 표적 거치대 | 높음 | 표적 모양(25m 축소 표적 여부)은 예비군 교안으로 확인 필요. 표적지는 텍스처로 처리 |
| 사대 거치대 / 모래주머니 | 중간 | 사격 자세 확정 후 형태 결정 |
| 피탄벽(흙둑) | 낮음 | 화이트박스 + 흙 재질로 충분 |
| 탄피 | 낮음 | 배출 연출을 넣을 때만 |

- 총구 화염·탄착 효과는 C의 `C_ImpactEffects`·`MuzzleFlash`가 있다. 사로 격발 담당(Q2)을 C와 정할 때 같이 쓸지 결정한다.

### 3-4. 소리 (분해·결합)

| 소리 | 우선 | 비고 |
| --- | --- | --- |
| 오류음 | 높음 | 순서가 틀렸을 때 |
| 막힘 소리 (덜컥) | 높음 | 순서가 아니라 부품이 움직이지 않을 때 |
| 끼워짐 소리 (철컥) | 높음 | 부품 결합·본체 닫힘. 1~2종 |
| 단계 완료음 | 낮음 | 없으면 끼워짐 소리로 대체 |

## 4. 확인할 것

1. `Part_Magazine`·`Part_Trigger`를 K2C1 통합본에 넣을 일정 (C 규격상 필수).
2. 사격 자세(서서 / 엎드려)와 표적 모양 — 예비군 교안 기준.
3. 사로 격발 담당 (Q2) — C와 협의.
4. 소품을 직접 만들지, 무료 에셋을 쓸지.
