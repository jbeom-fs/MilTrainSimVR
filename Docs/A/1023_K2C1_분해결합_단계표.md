# K2C1 분해·결합 순서

작성: A · 2026-10-23

조립실 작업대에 K2C1 한 자루를 놓고 **분해 → 결합** 순서로 진행한다. 부품 대응·조작 방식·판정 기준은 새 모델이 들어온 뒤 정한다.

## 분해

1. 가스 조절기 분리
2. 총기 본체 열기
3. 밀대 뭉치 분리
4. 장전 손잡이 분리
5. 가스 활대 분리 (노리쇠 뭉치가 붙은 채로 본체에서 빼냄)
6. 가스 활대에서 노리쇠 뭉치 분리

> 10/27 변경 (사용자): 예전 5·6단계(가스 활대를 살짝 꺼내 본체 안에서 노리쇠 뭉치 분리 → 가스 활대 분리)를 위처럼 바꿨다. 결합 순서는 그대로다.

## 결합

1. 가스 활대 – 노리쇠 뭉치 결합
2. 가스 활대 삽입
3. 장전 손잡이 삽입
4. 밀대 뭉치 삽입
5. 총기 본체 닫기
6. 가스 조절기 결합

- 결합은 분해의 역순이다.
