## 4. 남은 것

1. **헤드셋 확인 이어서** — [사로 확인 목록](1028_사로_헤드셋_확인목록.md): **④를 조준 확대 모드로 다시**(4-1절: 두 눈으로 창이 편한지·셰이더가 두 눈에 그려지는지가 제일 먼저), 그다음 ⑤ 안전 검사 → ⑥ 결과 → ⑦ 실수·위반 → ⑧ 평가 모드. 분해·결합 [확인 목록](1027_헤드셋_확인목록.md)의 "재확인 필요" 항목도 남아 있다.
2. **C와 한 번에 확인** — [C 제안](1028_C제안_사격방향_분리.md) 5절: `IShotLine` 같이 쓸지, 앞손 트리거, 기준점 값 변경, 사격 코드 한 벌로 합칠지.
3. **조립실 → 사로 연결** — 기능 점검을 마친 총을 들고 사로로 가서 사로 교육을 시작. 지금 사로 총은 임시(`K2C1_Range`).
4. **사로 7번 효과** (총구 화염·탄흔·소리) — 에셋이 준비되면.
5. **임시값 정하기** — 발 수·조 수(3 × 3), 조 합격·등급 기준(4 cm 등), 표적지 모양, 판정 값, 확대 모드 배율·흔들림 ([사로 확인 목록](1028_사로_헤드셋_확인목록.md) 7절, [설계](1028_조준확대모드_설계.md) 6절).
6. **내무반** — 천장 석고 텍스 텍스처(사용자 제공 예정), 방 안 조명, 라디에이터·TV·탄창 텍스처.
7. 10/27에서 이어지는 것 — 분해·결합 등급 기준 시간, 분해·결합 8번 실제 소리, 점사 여부.

## 5. 주의

- 탄착 판정은 히트스캔(총구에서 직선). 확대 모드일 때만 가늠자 → 가늠쇠 직선. 직접 들고 쏘기의 보정은 C 담당.
- `Anchor_RearSight`·`Anchor_FrontSight` 값을 측정값으로 바꿨다 (`K2C1.prefab`, C도 씀) — C와 확인 전.
- 시험 메뉴: `A/시험/사로/` (사선 이동, 시작, 단계 완료, 탄창 끼우기·빼기). 확대 모드는 `SightAim`의 `TestHeld`·`TestEye`로만 에디터 시험 가능.
- 에디터 시험 때 주의: `Quaternion.FromToRotation`은 0.1° 미만을 돌리지 않는다 — 총을 겨눌 때는 `LookRotation`을 쓴다.
