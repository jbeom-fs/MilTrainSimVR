# B · C 통지 — 허브(과정 고르는 곳) 연결

작성: A · 2026-11-10. 받는 사람: B(김정범) · C(이주석).

B가 11/05 ~ 11/06 문서에서 물어본 **씬 연결(진입점 · 복귀점 · 과정 ID · 빌드 진입점)**에 대한 A의 답이다 ([A 정리](1109_B지적_씬연결_확인.md)).
A가 과정을 고르는 **허브 씬**을 만들었다. 이 문서는 B · C가 허브와 연결하려면 알아야 할 것과 확인해 줄 것을 적는다.
B · C 문서와 코드는 A가 고치지 않는다. 회신은 각자 폴더에 써 주면 A가 읽고 이 문서 7절에 옮겨 적는다.

## 1. 한 줄 요약

- 허브: `Assets/A/Scenes/A_Hub.unity` — 예비군 교장 연병장, 과정마다 **포탈** 하나.
- 허브 → 과정: 포탈에 걸어 들어가면 화면이 까매지고 **그 과정 씬을 Single로 불러온다.** B · C 씬은 따로 할 일이 없다.
- 과정 → 허브: **`Assets/A/Scenes/A_Hub.unity`를 Single로 불러오기만 하면 된다.** 출구(문 · 버튼 · 메뉴)는 각 담당이 자기 씬에 만든다.
- 확인 부탁: C 씬 이름 · 과정 ID(4절), 빌드 목록 제안(5절).

## 2. 허브의 포탈 (과정 ID와 씬)

| 포탈 이름 | 과정 ID | 불러오는 씬 | 담당 |
|---|---|---|---|
| 분해·결합 | `A_Assembly` | `Assets/A/Scenes/A_Sandbox.unity` | A |
| 사로 사격 | `A_Range` | `Assets/A/Scenes/A_Sandbox.unity` | A |
| 구급법 | `B_FirstAid` | `Assets/B/Scene/B_FirstAid.unity` | B |
| 화생방 | `B_CBRN` | `Assets/B/Scene/B_CBRN.unity` | B |
| 시가지 전투 | `C_Urban` | `Assets/C/Scenes/C_UrbanBlock.unity` | C — **확인 필요** |

- 씬 경로가 비었거나 그 경로에 씬이 없으면 포탈 이름 아래에 **"준비 중"**이 뜨고 들어가도 넘어가지 않는다.
- **과정을 더 넣고 싶으면** A에게 과정 ID · 이름 · 씬 경로를 알려 주면 포탈을 하나 더 세운다 (A 빌더 표에 한 줄).
- 포탈 렌즈 그림은 각 씬에서 찍은 사진이다. B 씬은 11/09에 찍어서 환경 모델이 없는 화면이다. **바꾸고 싶은 그림이 있으면** A에게 주면 된다 (세로로 조금 긴 1 : 1.26 그림이 렌즈에 꽉 찬다).

## 3. 연결 방법

### 3.1 허브 → B · C 씬 (B · C가 할 일 없음)

- 허브 포탈이 화면을 까맣게 한 뒤 `SceneManager.LoadScene(씬 경로, LoadSceneMode.Single)`로 불러온다. 허브의 XR Origin · 화면 가림은 허브 씬과 함께 없어진다.
- B · C 씬은 **지금처럼 자기 XR Origin과 시작 자리**로 시작하면 된다. 허브에서 들어왔는지 알 필요 없다.
- 고른 과정 ID가 필요하면 A의 `MilTrainSimVR.A.Common.CourseRoute.Current`(정적 문자열)를 읽을 수 있다. 쓰려면 asmdef에 `MilTrainSimVR.A.Common` 참조가 필요하다. **쓰지 않아도 된다** — 씬마다 과정이 하나라면 필요 없다.

### 3.2 B · C 씬 → 허브 (출구는 B · C가 만든다)

둘 중 하나를 고르면 된다.

```csharp
// ① A 코드를 참조하지 않는 방법 — 허브 씬이 빌드 목록에 있어야 한다 (5절)
UnityEngine.SceneManagement.SceneManager.LoadScene("Assets/A/Scenes/A_Hub.unity", UnityEngine.SceneManagement.LoadSceneMode.Single);

// ② A 코드를 쓰는 방법 — asmdef 에 MilTrainSimVR.A.Common 참조.
//    에디터에서는 허브가 빌드 목록에 없어도 경로로 불러온다 (공용 빌드 목록을 안 바꾸고 시험할 수 있다)
MilTrainSimVR.A.Common.CourseRoute.ReturnToHub();
```

- 허브는 **마지막으로 들어간 과정의 포탈 앞**에 포탈을 등지고 세운다. 그 과정이 없으면(예: 허브를 거치지 않고 B 씬에서 바로 실행) 정문 안쪽 시작 자리에 세운다.
- B 씬끼리 오간 뒤 허브로 돌아오면 **처음 허브에서 고른 포탈** 앞에 선다 (예: 구급법 → 화생방 → 허브 = 구급법 포탈 앞). 화생방 포탈 앞에 세우고 싶으면 알려 달라 — B가 ②를 쓰는 경우 A가 과정 ID를 바꾸는 함수를 열어 둘 수 있다.
- 허브는 켜질 때 까만 화면에서 밝아진다. B · C는 나가기 전에 자기 화면을 까맣게 해 두면 넘어가는 순간이 매끄럽다 (안 해도 동작은 한다).
- 넘어가기 전에 B · C가 정리할 것(실습 중 이동 제한, 결과 저장 등)은 각자 정한다. **결과 전달은 지금 하지 않는다** ([A 정리](1109_B지적_씬연결_확인.md) 3절).

### 3.3 A 쪽 (참고)

- 내무반(분해·결합)과 사격장(사로 사격)은 **서로 잇지 않고 각각 허브와만 잇는다** (11/10 오후). 내무반 문 · 사격장 문 두 개 모두 손잡이를 만지면 허브로 나간다 — 늘 열림.
- `A_Range`로 들어오면 사격장 문(`Door_Barracks`) 앞, `A_Assembly`로 들어오면 내무반 시작 자리에 선다. 사격장 총은 사로에 따로 놓여 있다.
- B가 반입 도구에서 찾는 이름(`Room_Assembly` · `Shell` · `Door_Range` · `Barracks`)은 바꾸지 않았다.

## 6. B · C 씬에 '허브로 돌아가는 포탈' 놓기 (미리 준비, 11/10)

B가 11/10에 B 교육장 출구를 허브와 같은 포탈로 하기로 했다 ([B 문서](../B/1110_허브복귀_포털방식_보류.md)). **B · C 씬에 놓는 것과 그 방식은 각 담당이 정한다** — A는 쓸 수 있는 프리팹과 정보만 준비해 둔다. A 코드 · 자산은 고치지 않고 그대로 끌어다 쓰면 된다.

### 6-1. 프리팹

`Assets/A/Prefabs/HubPortal_ToHub.prefab` — 허브 포탈과 같은 모양(볼록 렌즈 · 가장자리 파란 물듦 · 반짝이 · 머리 쪽으로 도는 이름판). 렌즈 그림은 허브 연병장 사진(`Materials/Hub/Portals/Hub_PortalLens_Hub.mat`), 이름 "연병장 (허브)".

| `HubPortal` 칸 | 넣어 둔 값 | 놓을 때 |
|---|---|---|
| 과정 ID (`m_CourseId`) | 비어 있음 | **자기 과정 ID를 넣는다** — `B_FirstAid` · `B_CBRN` · `C_Urban`. 허브가 이 ID의 포탈 앞에 세운다. 비우면 정문 안 시작 자리 |
| 이름 (`m_Label`) | 연병장 (허브) | 바꿔도 된다 |
| 씬 경로 (`m_ScenePath`) | `Assets/A/Scenes/A_Hub.unity` | 그대로 |
| 돌아오는 자리 (`m_ReturnPoint`) | 없음 | 비워 둔다 (허브 안 포탈만 쓴다) |
| 화면 가림 · 머리 (`m_Fader` · `m_Head`) | 없음 | 비워 두면 씬에서 찾는다 (아래) |

### 6-2. 놓는 법

1. 프리팹을 씬에 끌어다 놓는다. **원점 = 렌즈 아래 바닥, 앞(+Z) = 사람이 다가오는 쪽.** 렌즈 폭 1.9 · 높이 2.4 m(바닥에서 0.5 m 위), 이름판까지 약 3.3 m.
2. 과정 ID를 넣는다 (6-1 표).
3. 넘어가는 법 두 가지: **걸어 들어가기** — 머리가 렌즈 앞뒤 상자(폭 1.5 · 높이 2.4 · 두께 0.9 m, 렌즈 가운데 높이 1.7 m) 안에 들어가면. **레이로 고르기** — 렌즈를 레이 + 트리거. 시작할 때 머리가 이미 상자 안이면 한 번 밖으로 나왔다가 들어가야 넘어간다.
4. 들어가면 화면이 까매지고(아래) 허브를 불러온다. 허브는 까만 화면에서 밝아지며 그 과정 포탈 앞에 포탈을 등지고 세운다.

### 6-3. 씬에 있어야 하는 것 · 알아 둘 것

- **XR Interaction Manager · 레이 손**: 보통 XR 리그면 이미 있다 (레이 고르기용, 걸어 들어가기는 없어도 된다).
- **머리**: 비워 두면 `Camera.main` — XR 리그 카메라가 **MainCamera 태그**여야 한다. 아니면 `m_Head`에 카메라를 넣는다.
- **화면 가림**: A의 `ScreenFader`가 씬에 없으면 까매지지 않고 바로 넘어간다 (동작은 같다). 까맣게 하고 싶으면 그 씬의 XR 리그에 A의 `ScreenFader`를 붙이거나, 각자 화면 가림을 쓴다.
- **코드 참조 필요 없음**: 씬에 컴포넌트를 놓기만 하면 된다. B · C 코드에서 A 함수를 부를 때만 asmdef에 `MilTrainSimVR.A.Common` 참조를 넣는다.
- **실습 중 막기 · 종료 정리**: 포탈 자체에는 잠금이 없다. 실습 중에 못 나가게 하려면 각자 포탈 오브젝트(또는 `HubPortal` 컴포넌트)를 끄고 켠다. 나가기 전 정리도 각자.
- **빌드**: 허브(`A_Hub`)가 빌드 목록에 없으면 빌드에서는 이름 아래 "준비 중"이 뜨고 넘어가지 않는다 (에디터에서는 된다) — 5절.
- **A 폴더의 프리팹 · 재질은 고치지 않는다.** 모양을 바꾸려면 자기 폴더에 프리팹 변형(Prefab Variant)을 만들거나 A에게 말한다. A가 포탈 코드를 바꾸면 이 절에 적는다.
- 3-2절의 "B 씬끼리 오간 뒤 허브로 돌아오면 처음 고른 포탈 앞" 문제는, 출구 포탈마다 자기 과정 ID를 넣으면 생기지 않는다.

에디터 Play 확인 (A, 11/10): 프리팹에 과정 ID `B_FirstAid`를 넣고 들어감 → 허브를 불러와 구급법 포탈 앞(0, 0, 4.5)에 섬.
