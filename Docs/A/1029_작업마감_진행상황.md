## 4. 남은 것

1. **헤드셋 확인** — 문 전환(레이·그립, 어지러움, 도착 자리, 총을 든 채), 부스 위로 옮긴 사로 패널(읽기·누르기), 넓어진 테이블에서 총·탄창 집기, 임시 조명 밝기. 분해·결합 [확인 목록](1027_헤드셋_확인목록.md)의 "재확인 필요"도 남아 있다.
2. **표적을 이송 레일에 매달기** — 레일 아래 날개에 걸린 이동대 + 긴 막대 + 표적지 (바닥 기둥 없앰). 그다음 **움직임**: 사수 쪽으로 왔다가 교체 후 25 m 로.
3. **사격장 쪽 문** (따로 디자인) — 돌아오는 도착 점 `Points/Point_BarracksEntry` 에 `DoorTransition` 으로 잇는다. 그전엔 사격장에서 내무반으로 돌아오는 길이 없다.
4. **조립실 → 사로 연결** — 기능 점검을 마친 총을 들고 문으로 사격장에 가서 교육 시작 (지금 사로 총은 임시 `K2C1_Range`). 문 잠금(`DoorTransition.Locked`)을 분해·결합 완료와 이을지.
5. **텍스처** — 사격장 벽·막은 벽, 문 유리(지금 FBX 의 불투명 재질). 사용자가 작업.
6. **정할 것** — 평가 등급(정식 사격지 때), 사로 임시값(발 수·조 수·판정 값, [확인 목록](1028_사로_헤드셋_확인목록.md) 7절), 문 전환 길이(걸어간 느낌: 까만 시간 늘리기·발소리).
7. 10/27·10/28 에서 이어지는 것 — 분해·결합 등급 기준 시간, 분해·결합 8번 실제 소리, 사로 7번 효과(총구 화염·탄흔·소리), 점사 여부.
