# KD-1 외형 모델 전달 기록

2026-11-05. Blender 5.2.1 LTS 제작. 기존 가상 세트의 교체 설치가 아니라 **별도 KD1 산출물**이다. 기존 `.blend`, FBX, 재질, 텍스처, meta/GUID와 현재 사용자 Blender 세션을 변경하지 않았다. 모델 제작·내보내기·검사는 별도 백그라운드 Blender 프로세스에서 수행했다.

## 자료와 확인 범위

- 사용자 첫 번째 첨부: 올리브색 포장과 황색 인쇄 배치 참고. 채팅에 표시된 이미지를 관찰했으며 작은 글씨를 추정해 채우지 않았다.
- 국방홍보원, [신형 개인제독 키트 KD-1](https://demaclub.tistory.com/2851), 2015-10-28. 외포장, 개별 포장 4개, 손 착용 패드 사진을 확인했다. 사진 설명의 촬영자는 이경원 기자다.
- [외포장 사진](https://t1.daumcdn.net/cfile/tistory/2609314B563094E503), [개별 포장 4개 사진](https://t1.daumcdn.net/cfile/tistory/25052B4B563094E907), [손 착용 사진](https://t1.daumcdn.net/cfile/tistory/2646AB4F563095BD2F). 변경하지 않은 참고 원본을 `References/`에 보관했다. 실물 사진을 게임용 텍스처에 투사하지 않았다.

2015년 공개 사진은 당시 외형의 근거다. 2026년 모든 군 보급형의 공통 규격·색·인쇄·사용법을 증명하지 않는다. 의약품 성능, 실제 약제·분말 구조, 실제 처리 효과를 재현하거나 검증한 모델이 아니다.

**확인한 외형:** 유연한 외포장, 납작한 개별 밀봉 포장 4개, 가장자리 밀봉부·작은 측면 절취 표시·황색 방향 표시, 얇고 어두운 패드, 넓은 손 고정 부분, 노출된 손가락, 가장자리 마감.

**제작 가정:** 공식 실측 치수는 확보하지 못했다. 아래 치수는 사진 비례와 기존 마네킹 손으로 정한 개발용 추정값이다. 가려진 뒷면, 슬리브의 측면 부착·내부 재료 상세는 단순화했다. 봉제 종류·약제 층·잠금장치를 확정하지 않았다. 상단 밀봉부 9mm를 제거하고 입구를 벌린 개봉형은 **시연용 가정**이며 실제 개봉 위치·방법의 정답을 뜻하지 않는다.

## 재사용·제작 제외 및 변경 내용

- 기존 `Assets/B/Models/Mannequin/Mannequin.fbx`의 오른손 가중치 영역을 참고용으로 추출했다. 원래 메시의 면을 사용하고 강체 회전·이동만 적용했으며 손을 새로 만들거나 원본 크기를 바꾸지 않았다. 원본 마네킹·골격도 숨긴 참고 컬렉션에 남겼다. 손/마네킹은 FBX에서 제외했다.
- K1 방독면·휴대주머니, 보호의·장갑·덧신, 인체, 총기·장구류, 작업대·일반 트레이·받침대·교육 UI·오염 표시는 기존 자산을 유지하고 신규 제작에서 제외했다. 원래 경로와 용도는 상위 `../../Source~/README_Delivery.md`의 재사용 표를 따른다. 이번에 Unity 씬에 연결하거나 배치하지 않았다.
- 기존 `DC_CollectionBin`은 별도 교육장 소품으로 보존했다. KD-1의 구성품으로 포함하지 않았으며 다시 만들지 않았다.
- 기존 `DC_KitCase`/`DC_Applicator`는 실제 KD-1 외형에 적합하지 않아 게임용 메시·재질을 재사용하지 않았다. 실제 이전 `.blend`와 FBX를 별도 프로세스에서 확인했고 결과는 `PriorAssetInspection.json`에 기록했다.
- 기존 경첩식 하드 케이스 → 얇은 밀봉 외포장+개별 포장. 두꺼운 파지 블록/밝은 스펀지 → 얇은 어두운 작용 시트+넓은 열린 손 슬리브. 경첩·지퍼·단단한 손잡이·손가락을 감싸는 장갑은 없다.

## 치수·메시 통계

Blender X×Y×Z의 외접 경계, 단위 mm. **공식 군 규격·실측값이 아니다.**

| 자산 | 외접 치수 | Triangles |
|---|---:|---:|
| KD1_OuterPack, 밀봉 | 200×160×32.910 | 1,440 |
| KD1_Packet, 밀봉 1개 | 176×140×6.466 | 896 |
| KD1_Pad, 착용 참고 | 160.007×122.039×86.670 | 2,560 |
| KD1_Pad_Packed | 160.007×122.039×4.000 | 2,560 |
| KD1_OuterPack_Open, 분리 조각 포함 | 244.004×200.002×38.513 | 2,896 |
| KD1_Packet_Open, 분리 조각 포함 | 215.204×176.002×10.142 | 1,808 |

개봉 외포장 본체의 평면 경계는 약200×151mm, 개봉 패킷 본체는 약176×131mm다. 위 개봉형의 더 큰 경계는 옆에 놓인 조각 때문이며 실제 포장 규격이 커진 뜻이 아니다.

패드 작용 시트의 제작 두께는 약1.8mm, 손 슬리브 약0.65mm, 가장자리 마감 약0.55mm다. 착용형의 86.670mm 높이는 **손 삽입 공간과 정적 굴곡을 포함한 경계**다. 두꺼운 고체 패드나 스펀지 두께가 아니다. 포장형은 전체 높이4mm다. 착용형은 기존 손의 굴곡에 맞춰 작용 시트의 주변부를 정적으로 굽혔으며, 모델 루트/Contact 기준보다 일부 가장자리가 아래에 있다.

- 메인 3종 고유 메시 합계: **4,896 triangles**.
- 외포장1+패킷4+착용형 패드1을 표시한 세트: **7,584 triangles**.
- 별도 상태 6종을 모두 각각 계산한 합계: **12,160 triangles**. 여러 상태를 동시에 표시할 필요는 없다.
- 메인 메시 이름: `Part_OuterPack_Sealed`, `Part_Packet_Sealed`, `Part_PadContact_Fitted`, `Part_HandSleeve_Fitted`, `Part_EdgeBinding_Fitted`.
- 4개 패킷의 메시·UV·재질 데이터는 동일하다. 다른 모델 4개를 만들지 않았다.
- 게임 재질 **4개**, 참조 텍스처 **3장**, 모두1024×1024 RGB PNG. 이미지 저장분 총합은 압축하지 않은 RGB 기준9MiB이며 Unity의 실제 GPU 메모리·압축·mipmap 비용은 별도다. 인쇄 편집 원본2장은1024×1024 RGBA이고 게임 재질이 직접 참조하지 않는다.

## 피벗·앵커 계약

아래는 각 루트 기준 Blender XYZ, 단위 mm다. 모든 앵커와 Part는 해당 루트의 직접 자식이다. 소품에는 경첩 피벗이 없으며, 포장의 Grip은 연성 포장의 잡기 기준이다.

Blender에서는 이름 충돌을 피하려고 `Anchor_Grip.KD1_OuterPack`처럼 모델 이름을 덧붙였다. **각 FBX에서는 요구한 역할 이름으로 내보냈다:** `Anchor_Grip`, `Anchor_Open`, `Anchor_PadRest`, `Anchor_HandFit`, `Anchor_Contact`. 정확한 원본/FBX 이름 대응·행렬은 `ValidationReport.json`에 있다.

| 상태 | Anchor_Grip | Anchor_Open | Anchor_PadRest |
|---|---|---|---|
| 외포장 밀봉 | (0,0,16.455) | (0,80,16.455) | — |
| 외포장 개봉 | (0,0,19.257) | (0,71,19.257) | — |
| 패킷 밀봉 | (0,0,3.233) | (0,70,3.233) | (0,0,1.600) |
| 패킷 개봉 | (0,0,5.071) | (0,61,5.071) | (0,0,3.700) |

- Grip/PadRest의 로컬 +Z는 Blender +Z. Open은 X=-90°로, 로컬 +Z가 개봉 쪽 **Blender +Y**를 향한다.
- 착용형 `Anchor_HandFit=(0,-61,35.053)`. 기존 오른손 손목 중심과 삽입 관계를 기준으로 했다. 로컬 +Y가 손가락 방향, +Z가 손등 쪽이다. 단단한 손잡이 파지점이 아니다.
- 포장형 `Anchor_HandFit=(0,-61,2.500)`. 눌린 포장 자세의 기준이며 이 자세에 손이 들어간다는 의미가 아니다.
- 두 패드 상태의 `Anchor_Contact=(0,0,0)`, X=180°. **로컬 +Z = Blender -Z**, 실제 중앙 작용 면의 바깥 법선이다. 작용 면은 `Part_PadContact_*`로 분리했다. 원점 접촉점과 실제 면의 거리·법선도 새로 확인했다.

밀봉 외포장 안의 패킷 바닥 Z는3.4/10.0/16.6/23.2mm다. 포장형 패드의 패킷 내부 놓임 기준은 밀봉 상태Z=1.6mm, 개봉 상태Z=3.7mm다. 이 위치는 실제 형상의 교차 검사를 통해 정했으며 기존 가상 도구의 좌표를 복사하지 않았다.

## 색상·인쇄·텍스처

- 포장 BaseColor는 사용자 사진을 우선한 올리브 계열이다. 표면 조명·거칠기에 따라 회녹색으로 보일 수 있다. DEMA 사진의 회흑색과 차이를 확인했고 같은 현행 제품의 보편적 색이라고 단정하지 않았다.
- 어두운 패드 질감은 사진을 직접 투사하지 않고 재구성했다. 의학적·화학적 재료 구조를 나타내지 않는다.
- 황색 군용 표시·품명·수량, 개별 포장의 외용 문구·대응 방향 표시만 반영했다. 군용 심벌은 사진을 관찰해 근사 재구성한 것이며 공식 벡터 원본이 아니다.
- 읽히지 않는 작은 글씨를 창작하지 않았다. 로트·재고번호·제조일·제조회사는 인쇄하지 않았다. 역사적2002.08 날짜도 모델에 넣지 않았다.
- 인쇄는 고밀도 문자 메시가 아니다. `Artwork/KD1_Outer_Print.png`, `KD1_Packet_Print.png`의 투명 영역을 교체해 같은 UV 위치의 BaseColor에 다시 합성할 수 있다. 설명·번호를 바꿀 공간을 별도 유지했다.
- 실제 게임 재질은 단순 BaseColor/Roughness/Metallic0. WorkingFace와 BindingSleeve를 분리해 이후 사용 상태 표현을 연결할 수 있지만 이번에 상태/오염 제거 기능은 만들지 않았다. 외부 약제·분말 효과 없음.
- 상대 텍스처 경로는 원본 기준 `//../Textures/...`. FBX는 각 출력 위치에 맞춘 상대 경로, 텍스처 비포함이다. 텍스처 파일은 별도로 유지했다.

## 제작·내보내기·확인

Metric, Unit Scale=1, 1단위=1m. 제작 축은 **Blender +Z 위, -Y 전방**, Unity 목표 **+Y 위, +Z 전방**이다. 손 착용의 손가락 방향은 독립적인 HandFit 로컬+Y 기준이다.

Blender 기본 FBX exporter를 사용했다. `global_scale=1`, `apply_unit_scale=True`, `apply_scale_options=FBX_SCALE_UNITS`, `axis_forward=-Z`, `axis_up=Y`, `use_space_transform=True`, `bake_space_transform=False`, `bake_anim=False`, `path_mode=RELATIVE`, `use_selection=True`, `object_types={MESH,EMPTY}`. 수동 사전 축 회전과 바이너리 후처리는 없다. Unity에서 축/단위를 임의로 중복 보정하지 않는다.

새 KD-1 원본을 다시 열고, 6개 FBX를 각각 새로운 Blender 씬에 재반입했다. **기존 가상 세트의 검증 결과를 재사용하지 않았다.**

- 원점·축척·이름·부모 관계·앵커 방향·삼각형 수 대조.
- 정점 최대 차이 약0.000022mm, UV 차이0, 코너 법선 방향 유지. 단순 재질의 Roughness/Metallic과 슬롯·텍스처 경로 유지.
- 게임 메시의 닫힌 manifold·양의 signed volume·UV1개·0..1 유한 좌표, 중복 위치 정점·느슨한 정점·면적0 삼각형 없음.
- 실제 4개 인스턴스의 외포장 수납, 밀봉/개봉 패킷의 포장형 패드 수납, 기존 손과 착용형 패드의 지정 정적 자세를 삼각형 BVH로 확인했다. 표면 교차0. 밀봉 포장 모델은 둘레를 봉한 외형으로 내부 공간을 표현하며 내부 약제나 개별 재료층을 재현하지 않는다.
- 기하 검사는 지정한 정적 자세의 확인이다. 자유 천, 손의 모든 관절 자세, 잡기/인계/동적 개봉·추출·VR 조작을 검증하지 않았다.
- 개봉형 패킷의 시연용 입구에서 포장 자세 패드를 Z=3.7mm에 두고 Blender +Y로 이동하는 직선 경로도 1mm 간격181개 위치에서 확인했다. 표면 교차0. 이는 가정한 정적 형상의 통과 여유이며 실제 제품 개봉 절차나 동적 기능의 검증은 아니다.
- 가까운 미리보기에서 가장자리 마감과 작용 시트의 노출면이 겹치지 않도록 착용형 마감을 정적 시트에 맞췄다. 슬리브 부착부의 재료가 만나는 미세한 접합 여유는 상세 봉제 방식의 재현이 아니다.
- 원본/FBX/재질/텍스처·앵커 수치: `ValidationReport.json`. 원본 보존: `PreservationCheck.json`, 현재 사용자 Blender 보존: `LiveBlenderPreservation.json`.

## 사용자 Unity 확인 항목

Unity는 실행하지 않았다. 다음은 사용자 확인 항목이며 완료 보고가 아니다.

1. 3개 메인 FBX와 필요한 Variants만 임포트하고1m 기준 치수·+Y 위/+Z 전방·루트 축척/음수 축척·계층을 확인한다. 변환을 중복 적용하지 않는다.
2. 상태별 FBX를 같은 위치에 동시에 표시하지 않는다. 인스턴스로 패킷4개를 구성하고 공유 메시·재질이 유지되는지 확인한다. 개봉 조각은 독립 Part다.
3. URP Lit에3개 BaseColor와4개 공유 재질을 연결한다. WorkingFace 슬롯을 별도로 유지하고 뒷면·얇은 가장자리·입구·UV/노멀·인쇄 선명도를 확인한다.
4. Open은 입구 쪽, HandFit은 손목/삽입 기준, Contact의 로컬+Z는 작용 면 바깥쪽인지 확인한다. 실제 VR 손/컨트롤러와 다른 손 크기에 대한 검증은 추후 조작 구현 후 수행한다.
5. 실제 제품 치수·뒷면 상세·현행 교안·개봉 방식이 확보되면 추정값과 가정을 다시 조정한다. 본 모델을 현재 보급형의 확정 규격 또는 실제 제독 효과 검증 자료로 사용하지 않는다.

Unity 코드·씬·Prefab·기존 meta·Packages·ProjectSettings 변경, Unity 실행·테스트·빌드·커밋·Push는 수행하지 않았다. 이번 산출물의 Blender/FBX 확인은 Unity 임포트·VR 조작 검증과 구분한다.
